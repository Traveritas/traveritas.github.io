FancyText 是一套保持轻量与克制的本地文本工具，将 126 种基于 Unicode 码点与组合符的文字样式收拢进全局热键与系统托盘。呼之即出，回车即走。

！？轻轻？！——一个整天挂在托盘里的小工具，最好让人感觉不到它的存在。所以弹窗一收起，它就把界面用过的内存还给系统，任务管理器里只剩几 MB；

！？美美？！——支持Win11 Mica 半透明材质，深浅色和强调色随系统切换，动画效果可开关。可自定义：主题、强调色、预览字号、弹窗位置、快捷键。

01意图

  • 召之即来的本地工具：摆脱繁复笨重的网页工具，在任意输入场景下通过快捷键瞬时唤出，回车复制完整结果后即刻隐藏。
  • 与字素的深层对齐：完整处理 Unicode 增补平面、字素簇（Grapheme Cluster）分割与组合符叠加，通过动态字体回退避免跨语言区段渲染时的缺字方块。

02形态

  • WPF 弹窗桌面版：全局热键（Ctrl+Alt+F）呼出，隐藏后自动修剪工作集，日常驻留内存约 12MB。
  • 命令行工具 (fancy)：仅数百千字节的独立 CLI 二进制，支持按样式单向转换、随机输出与 JSON 管道消费。
