# 两态正文写作手册

正文可以随全站醒/梦两个状态切换内容。长按空白处 2200ms 入梦检验（或已入梦时同手势 1300ms 回醒）即换面；无 JS、读屏器、`prefers-reduced-motion` 恒读醒面真值。

## 行内换字 `[[醒|梦]]`

在任意段落、标题、列表里把一个词写成两面：

```md
夜里再读，[[同一段已经|这段忽然]]改了主张。
```

- 醒面读到「同一段已经」，梦面读到「这段忽然」。
- 产出为站内标准双文案元素（`data-morph`），随长按线到达逐个乱码换面，梦态还会随机走神。
- 两侧均为**纯文本**，不能嵌 markdown 语法（加粗、链接都不行）；两侧不能含 `]`。
- 标题里也可用（如 `## 器物[[志|谱]]`）。
- 适度使用：每个双面元素都注册进换面清单，一篇文章几处到十几处为宜，整段整句请用块级。

## 块级换段 `:::dream` / `:::wake`

```md
这段未标记，两面都读。

:::wake
只在醒面出现：晨跑、咖啡、日程表。
:::

:::dream
只在梦面出现：同一时刻，房间里下着旧年的雪。
:::
```

- 块内是完整 markdown（标题、列表、引文都可以）。
- 未标记的正文两面共读——通常用它承住两版的共同骨架，只在分岔处写块。
- `:::wake` 与 `:::dream` 相邻摆放即可表达「同一段的两种写法」。
- 换面发生在长按闩锁的瞬间：出现的一侧淡入浮现（约 0.9s），消失侧即时让位；行内换字才有逐个乱码。
- 容器标记只认 `dream` / `wake` 两个名字。

## 行内光景 `((浮起))` / `{{流过}}`

两个只在梦面成立的小样式：**逐字浮起**与**流光**。醒面（含无 JS、读屏、`prefers-reduced-motion`）下它们退成普通正文 —— 浮起归位、流光褪回墨色。

```md
((水汽漫开))时字会各自浮起，{{而同一句话}}可以有一线暖光从字面流过。
```

- `((…))` 逐字浮起：每个字是一个独立小盒，梦面按 `--i` 错开相位做量化浮动（`step-end` 瞬切，与左上角字标同一条曲线）。**2–8 字为宜**：拆字之后字串内部不再换行，两端对齐也会在这里留一个缺口。
- `{{…}}` 流光：一个字都不拆，一道暖光自左向右流过字面，不影响换行与两端对齐。整段折行时每行各取一截渐变，所以长段落请按句使用。
- 两者都是**纯文本**：不嵌 markdown，也不嵌 `[[醒|梦]]`（写了会原样显示）；正文里要用竖线请写全角 `｜`。
- **表格里不要写参数**：参数的分隔符 `|` 与表格的列分隔符是同一个字符，单元格里的 `|span=210%` 会被当成新的一列。不带参数的 `((…))` / `{{…}}` 在单元格里没问题。
- 复制与读屏不受影响：字还在原位，逐字盒的顺序就是原文顺序，复制出来是完整的字串。

### 参数

参数跟在 `|` 后面，逗号分隔。**认不出的键或不符合单位形状的值会被丢弃**（当作没写），不会漏进 style 属性。

```md
((更高的字|amp=6px))  ((慢半拍的字|dur=4.4s,stagger=-0.6s))  ((顶点微温|amp=3px,tint=32%))
{{窄而快|span=210%,dur=3.2s}}  {{偏暖的一线|hue=70%,angle=96deg}}
```

| 语法 | 键 | 取值 | CSS 变量 | 默认 |
| --- | --- | --- | --- | --- |
| `((…))` | `amp` | px / em / rem | `--float-amp` | 3px |
| | `dur` | s / ms | `--float-dur` | 2.8s |
| | `stagger` | s / ms（可负） | `--float-stagger` | -0.4s |
| | `tint` | %（顶点的琥珀比例） | `--float-tint` | 0% |
| | `sway` | 纯数（横向比例，0 = 纯垂直） | `--float-sway` | 0 |
| `{{…}}` | `angle` | deg | `--sheen-angle` | 100deg |
| | `hue` | % | `--sheen-hue` | 45% |
| | `span` | % | `--sheen-span` | 300% |
| | `dur` | s / ms | `--sheen-dur` | 7s |
| | `steps` | 整数（抽帧档数） | `--sheen-ease` | linear（不抽帧） |

不写参数时全部走 `src/styles/global.css` 的默认值；也可以在容器上覆盖同名变量一次改一片（样式预览页「醒梦双态」一节的滑杆就是这么接的）。

## 文风与两态语感规范

在撰写两态正文或界面文案时，严格遵循以下审美底线：

1. **绝对禁止生活化裁缝语系**：不要使用“针、缝、穿针、起针、落针、八针、针脚”等生活化或机械刺缀语汇。项目进度统一采用「八阶成形 / 浮现度 (Eight Depths)」，以意识/睡眠深度刻度与光学显影替代。
2. **禁止直白打标签（不言梦而梦感自生）**：不要在文案里生硬地喊出“这是梦 / 你在做梦 / 快醒了 / 读起来像梦话 / 智能体与梦共同建造 / 梦里点也会通 / 可核验”。梦感应当源于知觉距离、悬停、微光与语言本身的质感。
3. **禁止伪严谨的“官僚审计”与财务台账词汇**：严禁使用“账目 / 台账 / 案号 / 待立项 / 构想条目 / 相关档案 / 可核验 / 半可核验”等冰冷、生硬的审计、政企审批或财务黑话。列表就是干净的名录与存目，互链使用克制的 `关联篇章` / `关联记述`，仓库链接采用温和的 `✓ 公开仓库` / `○ 暂无公开`。
4. **禁止程序员中二叙事与极客自嗨**：严禁在个人主张或文案中出现“白昼写代码，夜里构筑世界”、“活跃坐标”、“占用公网地址”、“代码变成落雪”等打工人自我感动的网络梗或强行拼贴的极客中二隐喻。
5. **醒态 (Wake)**：克制、自然、清晰、质朴，给人以笃定、可读的高质量散文与文档感。
6. **梦态 (Dream)**：浪漫、空灵、具有哲学知觉悖论与纯善透明的电波感（汲取《素晴日》式维特根斯坦哲学命题、银河铁道与意识漂浮感，善用知觉悖论与诗性发问，但剔除猎奇与阴暗，保留纯净哲思）。

### 导航与版块映射
- **随笔 (Articles)**：醒态 `随笔` ↔ 梦态 `断章`
- **项目 (Projects)**：醒态 `项目` ↔ 梦态 `造物`
- **关于 (About)**：醒态 `关于` ↔ 梦态 `此身`

### 核心版块徽标体系（维特根斯坦命题边界）
- **随笔**：`可言说的 · SAYABLE`
- **项目**：`可构造的 · BUILDABLE`
- **试验场**：`未命名的 · UNNAMED`
- **关于/出口**：`存在于此 · PRESENCE`


## 语义与边界

- **醒面是唯一真值**：RSS、OG、搜索快照、无 JS 用户看到的都是醒面。梦面内容实际存在于 HTML 中（和站内其他双文案一致），只是不显示——别放只在梦面可见的私密内容。
- 两态只作用于**渲染层**，字数统计、夜时刻等按 md 源文件全量计算，不分面。
- 项目页（`src/content/projects/`）同样支持这套语法。

## 脚手架

```bash
npm run new:article -- "标题"        # 中文标题可再传第二个参数指定 slug
npm run new:article -- "标题" my-slug
```

创建 `src/content/articles/yyyy-mm-dd-slug.md`，默认 `draft: true`。

项目没有对应的脚手架，新项目请从模板复制命名：

- 随笔模板：`docs/templates/article-template.md`
- 项目模板：`docs/templates/project-template.md`

另有两份写完的示例稿，演示成稿的样子（模板管字段，示例稿管写法）：

- 随笔示例：`docs/templates/article-example.md`（两态换字 / 换段、浮起与流光、引文与列表）
- 项目示例：`docs/templates/project-example.md`（links / related / note 都填上、任务清单、两态段落）

两份模板都是逐字段注释的完整示例，可直接复制进内容目录后改名。模板本身放在 `docs/` 下，
不会被内容 loader 收走（loader 只扫 `src/content/` 下不以 `_` 开头的 `.md`）。

## 实现位置

- 语法解析：`src/markdown/twilight.mjs`（经 `@astrojs/markdown-satteri` 的 `features.directive` 挂入 `astro.config.mjs`）
- 小节序号：`src/markdown/ordinal.mjs`（同一份 `mdastPlugins`，构建期把 `h2` 的序号拆成一枚数字一个 span 注入；**写作侧不用管它，`##` 就是全部语法**。样式与形制见 `docs/design/content-typography.md` 第二节末）
- 行内光景的样式：`src/styles/global.css`「行内光景」一节（`.float-run` / `.sheen-run`）。
  逐字浮起的动画**常驻**、位移与顶点色都乘 `--still`（梦 1 → 醒 0）：醒面（含无 JS、读屏、RM）位移为零、
  字色回到正文原色，而换面时不再有一下骤停；流光换的是整幅 `background-image`、没有「振幅」可收，
  仍按 `body[data-reality='dream']` 开关。
- ⚠ **改完解析器要重启 dev server**：`astro.config.mjs` 与它引入的 mdast 插件只在 dev 启动时读一次，热更新不会带上（症状是新的行内语法原样输出成 `((…))`，而 CSS、老语法一切正常）。
- ⚠ **改完插件还要清构建缓存**：插件的改动不算内容改动，`npm run build` 会直接复用 `.astro/` 与
  `node_modules/.astro/` 里缓存的渲染结果（症状是「插件改了、构建成功、`dist/` 里的标记没变」）。
  先 `rm -rf .astro node_modules/.astro` 再构建。
- 块级显隐：`src/styles/global.css` 的 `[data-side]` 规则（挂 `body[data-reality]`）
- 行内换面：`src/scripts/morph.ts` 双面元素 + `src/scripts/reality.ts` 入梦检验
