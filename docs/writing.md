# 两态正文写作手册

正文可以随全站醒/梦两个状态切换内容。长按空白处 2200ms 入梦检验（或已入梦时同手势 1300ms 回醒）即换面；无 JS、读屏器、`prefers-reduced-motion` 恒读醒面真值。

## 行内换字 `[[醒|梦]]`

在任意段落、标题、列表里把一个词写成两面：

```md
夜里再读，[[同一段已经|这段忽然]]改了主张。
```

- 醒面读到「同一段已经」，梦面读到「这段忽然」。
- 产出为站内标准双文案元素（`data-morph`），随长按线到达逐个乱码换面，梦态还会随机走神。
- 两侧均为**纯文本**，不能嵌 markdown 语法（加粗、链接都不行）；两侧不能含 `]`。
- 标题里也可用（如 `## 器物[[志|谱]]`）。
- 适度使用：每个双面元素都注册进换面清单，一篇文章几处到十几处为宜，整段整句请用块级。

## 块级换段 `:::dream` / `:::wake`

```md
这段未标记，两面都读。

:::wake
只在醒面出现：晨跑、咖啡、日程表。
:::

:::dream
只在梦面出现：同一时刻，房间里下着旧年的雪。
:::
```

- 块内是完整 markdown（标题、列表、引文都可以）。
- 未标记的正文两面共读——通常用它承住两版的共同骨架，只在分岔处写块。
- `:::wake` 与 `:::dream` 相邻摆放即可表达「同一段的两种写法」。
- 换面发生在长按闩锁的瞬间（硬切，无线扫 stagger）；行内换字才有逐个乱码。
- 容器标记只认 `dream` / `wake` 两个名字。

## 语义与边界

- **醒面是唯一真值**：RSS、OG、搜索快照、无 JS 用户看到的都是醒面。梦面内容实际存在于 HTML 中（和站内其他双文案一致），只是不显示——别放只在梦面可见的私密内容。
- 两态只作用于**渲染层**，字数统计、夜时刻等按 md 源文件全量计算，不分面。
- 项目页（`src/content/projects/`）同样支持这套语法。

## 脚手架

```bash
npm run new:article -- "标题"        # 中文标题可再传第二个参数指定 slug
npm run new:article -- "标题" my-slug
```

创建 `src/content/articles/yyyy-mm-dd-slug.md`，默认 `draft: true`。

## 实现位置

- 语法解析：`src/remark/twilight.mjs`（经 `remark-directive` 挂入 `astro.config.mjs`）
- 块级显隐：`src/styles/global.css` 的 `[data-side]` 规则（挂 `body[data-reality]`）
- 行内换面：`src/scripts/morph.ts` 双面元素 + `src/scripts/reality.ts` 入梦检验
