# Ave · 右下角的旁白

Ave 不时在右下角冒出一句：进了某个版块、读到文章末尾、到了某个钟点，或者只是在页上待了一阵。她是站点的吉祥物兼旁白，说的多是描述性的话。

**台词的口吻由作者判断，不套 AGENTS.md 的文风红线。** 智能体不要替作者改 Ave 的词；需要新加占位句时，标明是占位。

---

## 1. 文件

| 位置 | 是什么 |
| --- | --- |
| `src/data/ave-lines.ts` | 台词表：内容、梦态替换句、表情、语调、出现条件、说几次 |
| `src/data/ave-voice.ts` | **生成物**：每句的音频地址、时长、字幕揭开节奏。别手改 |
| `public/audio/ave/*.mp3` | **生成物**：每句的成片（文件名是内容哈希） |
| `public/ave/face/*.webp` | 八个表情头像（160px） |
| `src/components/chrome/Ave.astro` | 外观：头像槽 + 名牌 + 一句话；内联本页自带的那句 |
| `src/scripts/ave.ts` | 调度、字幕揭开、出声、贴元素定位、设置开关 |
| `src/lib/ave-page.ts` | 文章 / 项目 frontmatter 里 `ave:` 的 schema 与转换 |
| `src/scripts/sound.ts` | `playVoice()`：与环境声共用 AudioContext，音量单独一路（工具栏「声音」里的 Ave 那一圈；环境声不让开） |
| `design/ave-voice/` | 声音流水线：引擎副本、配方、渲染脚本、头像原图 |

## 2. 写台词

```ts
{
  id: 'projects-enter',            // 稳定的 id，声音和「说过没有」都挂在它上面
  text: '这边是项目……',             // 醒态
  dream: '这边是造物……',            // 梦态（可省）
  face: 'beam',                    // smile happy beam surprised shy hurt sulk yawn
  mood: 'natural',                 // 引擎语调；除 natural 外还没按 ave-v1 调过
  when: { on: 'enter', path: '/projects' },
  once: 'session',                 // session（默认）/ ever / always
  then: 'next-id',                 // 自然说完后接着说哪一句（可省）：几句连成一段
  covers: ['other-id'],            // 说了这句就当这些也说过（可省）：内容重叠的别再冒出来
}
```

出现条件（`when`）：

| on | 什么时候 | 备注 |
| --- | --- | --- |
| `enter` | 开屏面纱打开（`html.booted`）后 `after` 秒（默认 3） | 一页只取路径最具体的那一句；可加 `visitor: 'new' / 'returning'` 只对新 / 老访客说 |
| `end` | 阅读页正文末尾进入视口 | 只在 `type="article"` 的页上 |
| `event` | 别的脚本点名 | `dispatchEvent(new CustomEvent('xm:ave', { detail: { name } }))`，不受 CUE_GAP 挡。现有：`voice-on`（用户把 Ave 的音量从 0 拉起来，她刚有了声音） |
| `then` | 只由别的句子的 `then` 接过来 | 连说的第二句起用它 |
| `clock` | 访客本地时间在 `from`–`to` 之间 | 可跨午夜；和随机池一起抽，先抽它 |
| `idle` | 随机池 | 空闲时掷骰子 |
| `still` | 静置：访客 45 秒没移鼠标、没滚、没按键 | 随机池掷中时优先从这些里抽；只在静置时出现（`STILL_AFTER`） |

路径：`'/'` 只指主页，其余按前缀匹配。

**在哪说（`at`）**：平时在右下角。台词加 `at: '<选择器>'`，或事件点名时 `detail: { name, at: 元素 }`，就贴到那个元素旁边：右边放得下放右边，不行放左边，再不行放下面 / 上面；句子第一行的线和元素的中线对齐，从元素的字尾牵一根发丝线接到框边上（端头一颗空心菱形）。滚动时跟着走，元素滚出视口就收起；元素一开始就不在视口里或找不到，照常在右下角。现在只有欢迎第三句（welcome-3）贴着工具栏的星（`.ts-star`）。

**每一篇自带的一句**：随笔、项目、瞬间都可以在 frontmatter 里写 `ave:`，读到这一篇时她说这一句；**不写就不说**。「读到」有两处：

- **漫游里点开**（主要的那处）：首页 / 目录页点开一扇窗、长成阅读形态后 3 秒说；到点时正在说别的（进页句子、随机句子），先收掉那句再说这篇的；阅读窗开着时，进页句子和随机句子都不插进来。翻到同版块的另一条，没说出口的作罢、正在说的收起，换成那一条的；收起阅读窗，她也收起。默认每次点开都说（访客可在设置里改成「第一次」或「不说」，见 §3.1）。整页上自带的那句也一样，不受 CUE_GAP 挡。靠 `reader.js` 发的 `xm:read` 事件（`detail.href` 是这一条的地址，收起时是 `null`）。
- **随笔 / 项目自己那一整页**：开屏面纱打开后 3 秒说。这种页上版块的进页句子（如 `articles-enter`）不会顶替上来。瞬间没有单独的页。

所有条目的这一句由 `Ave.astro` 在构建时收齐、内联进每一页（键是 `<集合>/<条目 id>`），所以哪一页上点开都认得。

```yaml
ave: 哇，这里怪热闹的欸？
```

或者写全（只有 `text` 必填）：

```yaml
ave:
  text: 这边很安静。
  dream: 梦态换一句
  face: smile
  mood: soft
  after: 4        # 读到之后几秒（默认 3：阅读形态从窗长大算，整页从开屏面纱打开算）
  at: .md h2      # 贴着哪个元素说
```

id 是 `page:<集合>/<条目 id>`（如 `page:articles/co-creation-notes`；文件夹形式的瞬间是文件夹名），声音和「说过没有」挂在它上面，每次来访说一次。schema 与转换在 `src/lib/ave-page.ts`；`render.mjs` 自己扫这些 frontmatter（不引 YAML 库，值只认单行字符串）。现在写了的（2026-10-26）：两篇随笔（三个声部、全样式样张）和全部七个项目（昼梦叙集、FancyText、Inkprint、Kimi Code 配色编辑器、MemePanel、NEXUS、Petween）。

改完台词跑：

```
npm run ave
```

没跑也不会坏：那句只是没有声音，字整句出现。`npm run build` 前会打印哪几句还没渲染。

## 3. 节奏（`src/scripts/ave.ts` 顶部的参数）

- 进页 20 秒内不抽随机句；之后每 25 秒掷一次，概率 0.35。掷中时先看钟点句（clock），再看静置句（still，访客 45 秒没动才算），最后才是普通随机句（idle）。
- 两句随机句至少隔 2 分钟（换页也算），一次来访最多 6 句随机句。
- 点名类（enter / end / event）只要求离上一句 20 秒；正在说话时来的点名排一句，说完再说。
- 字幕揭开之后再停 3.2 秒，每字加 0.13 秒，最多 9 秒。鼠标停在上面就不收，点 × 收起。
- 以上是「闲聊 · 常」「停留 · 常」的数（默认），访客可以在设置里换档，见 §3.1。

### 3.1 访客设置（工具栏「设置 → Ave」）

设置的第二圈是分类（界面 / 阅读 / Ave），点 Ave 在第三圈摆出这些项，点一下换到下一档：

| 项 | 档位（粗体为默认） | 管什么 |
|---|---|---|
| 说话 | **开** / 关 | 关掉就整个不出现；下面依附于说话的几项变淡，仍可调。存 `localStorage['xm-ave']` |
| 闲聊 | 不闲聊 / 少 / **常** / 多 | 随机池（含钟点句、静置句）。少 = 概率 0.2、隔 4 分钟、每次来访 3 句；多 = 0.5、隔 1 分钟、10 句；不闲聊 = 整个不掷，只剩进页、读到末尾、事件这些点名的 |
| 文章里 | 不说 / 第一次 / **每次** | 每一篇自带的那句。第一次 = 这台设备上只说一次（once: ever） |
| 字幕 | **逐字** / 整句 | 整句 = 字一下出现，声音照放 |
| 停留 | 短 / **常** / 长 | 揭开完再停的时长 ×0.6 / ×1 / ×1.6 |
| 位置 | **贴着说** / 右下角 | 右下角 = 不理台词的 `at`，总在角落 |
| 音量 → 声音 | — | 跳到「声音」的三圈，Ave 那一圈就是她的音量 |
| 再认识一次 | — | 清掉说过的记录与「来过」，下次进主页重新欢迎 |

除「说话」外都存在 `localStorage['xm-ave-prefs']`（只存改过的项）。档位、文案与各档的数在 `ave.ts` 的 `PREFS` / `CHAT` / `HOLD_K`。
- 没有 JS 就不出现；`prefers-reduced-motion` 时整句直接出现，不做位移。
- `BaseLayout` 的 `ave` 属性：默认跟着 `bare`，只有正文那一屏（NEXUS 入口）不出。

**新访客 / 老访客**：浏览器本地存 `xm-ave-visited`，欢迎第一句（`visitor: 'new'`）说出口时写上；这次来访剩下的时间仍算新访客（不会紧接着说「祢回来啦」），之后的来访才算老访客。换设备、换浏览器、无痕窗口、清了浏览数据都会再当一次新访客。新访客第一次到主页连说四句（welcome-1 → 2 → 3 → 4，第三句贴着星）；老访客进主页说「祢回来啦！」。从链接直接进某一篇的新访客，先说那一篇自己的，第一次到主页再欢迎。连说的节奏：上一句的声音说完约 2 秒就是下一句（`THEN_PAUSE`）——位置不变就原地换字，位置要变（贴到星 / 回到角落）就把框留到接近 2 秒，再快速收起（0.25 秒，不演线退场）、在新位置出现——两种接法的节奏一样。这句一开口就预取下一句的声音（`sound.ts` 的 `preloadVoice`），接上时不用等网络和解码；鼠标停在框上会先停住，移开再接。点 ×、点开阅读窗都会打断，没说完的就不说了。

开发时控制台有 `__ave.say('<id>', '<可选选择器>')`、`__ave.hide()`、`__ave.reset()`（连「来过」也清掉，刷新后就是新访客）。

## 4. 声音

- **配方**：`design/ave-voice/recipe.json`，就是 `ocvoice-re` 的 ave-v1（2026-10-12）。声源是「清亮 · 瑶瑶」，采样库内嵌在配方里，改动对照见 `recipe-notes.md`。换配方就是换这个文件，然后重跑 `npm run ave`。
- **引擎**：`design/ave-voice/src/` 是 `just another new vocal thing` 引擎（0.2.1）的原样副本。同一台词、配方和种子，永远得到同一段 PCM。
- **站点覆盖**（`render.mjs` 顶部，配方文件不动）：语速 1.8（与配方相同，引擎上限 2）、元音长度 1.3（配方 1.45），比配方略快；2026-10-26 作者嫌原先的语速 2 / 元音 1.25 偏快，放慢了约一成；去刺 EQ：3.2 kHz 以上高架 −6 dB，9 kHz 处收顶。
- **电平**：不逐句归一，引擎本来就让轻声更轻。脚本用配方自带的示范句（去刺之后）量一次积分响度，算出一个全局增益推到 −22 LUFS，所有句子共用这个增益。2026-10-26 作者嫌 −17 太大、刺耳，调到了现在的值。
- **出声条件**：工具栏「声音」里 Ave 那一圈的音量不为 0 才出声，与环境声互不相干。她说话时环境声照常（2026-10-26 作者定：不用让开），人声不吃阅读页的退后量。
- **字幕节奏**：引擎给的每个音节和标点的起点，都写进 `steps`，字跟着声音一个个露出来。

> **许可**：瑶瑶声源是 Windows 系统语音「Microsoft Yaoyao」的输出切片，许可**还没有核实**（见 `recipe-notes.md`）。公开发布前要确认 Microsoft 对系统语音输出的使用条款；要是不行，换回 Heather（LibriSpeech，CC BY 4.0，需要署名）或别的声源。

## 5. 外观

定稿（2026-10-26）：一块细边磨砂薄片，只改 `Ave.astro` 就能换外观。

- **轮廓**：上沿的折点落在框里本来就有的竖线上——头像栏那段是平的，过了头像与字之间的竖刻线才起坡，坡顶在字栏上方，到右侧晶柱的缝又落下；左下切一个 7px 小斜角。轮廓不是矩形，所以底和边交给 `.ave-card` 的两个伪元素（同一组折点：`::before` 用 evenodd 画 1px 边环，`::after` 画填充和磨砂），名牌才能伸出框外。
- **材质**：平时与工具栏薄片同一种玻璃（深色钟点换成 `--frost` 那一族）；主页 / 漫游时跟场景（`--w-glass` / `--w-edge` …），深色场景就是深色玻璃 + 浅字。框里从坡顶往右下落两道淡斜切面。
- **名牌**：伸出框沿的薄暮紫深片（`--umber`，两种底色上都是深底浅字），左下一枚小楔口扎进框里，里面一颗空心菱饰。
- **晶柱**：右侧 22px，比台面深半档。上端是关闭（平时就淡淡地在），下端一颗薄暮紫四芒星。
- **字**：`--font-display` 15px / 行高 2。每个字底下一小段线，念到才长出来，连成一条；最后念到的两个字底下是 2px 的薄暮紫线头，念完停在句尾当句读；句尾三截碎屑（和最后一个字包在 `.ave-end` 里，不单独折行）。收起时线从句首往句尾一字一字退掉，再整片淡出。
- **折行**：逐字的 span 让 `text-wrap` 不可靠，`ave.ts` 的 `balance()` 自己量：要折成几行，就把字栏收到各行差不多长，框跟着收窄。
- **位置**：右下角 `right 22px / bottom 58px`（让开页脚那一行链接）；窄屏 `bottom 64px`（让开底部的阅读工具条），头像 40px。
- **贴元素**：牵线从元素的字尾起（标题这类整行宽的块，按字实际占到的地方算），元素那头一颗空心菱形，另一头接到框的左边或右边（第一行字的高度）。那一侧不够宽就把框收窄（最窄 220px），再不够就放到元素上下。

试过的方向（2026-10-26，都删了，需要时看 git 历史）：第一版磨砂卡片；D 系列四种线（参考 `just another new vocal thing/mockups/dialogue-boxes/d-minimal*`）、没有框只垫薄雾的做法（作者嫌纯色 + 渐变的底不和谐）；参考 `b-halfscreen` / `a-crystal-wide` / `a-crystal-lean` 的三种框和它们的整合版；最后凭感觉改的三版里选了现在这一版。

**头像现在是占位**（2026-10-26）：一块像素流光（`src/scripts/ave-flow.ts`）。它和 `wander/light.js` 用同一套域扭曲 fbm、同一个 5px 像素格和 Bayer 抖动，所以头像边长取 5 的倍数（50px，窄屏 40px）；但**调色板是她自己的**，不跟本页夜色走——她不是背景的一小块，是背景前的一小块别的。

- 配色（2026-10-26 作者定：黑白灰 + 低饱和的紫、蓝，且**不要黑**）：只有四档，落在中浅灰到近白之间，紫与蓝只做薄薄的色偏——梦面偏薄暮紫，醒面偏雾蓝。`WAKE` / `DREAM` 两张表按醒度混合，换面时头像也跟着换色。
- 主光上叠一层细场（绕着中值起伏，不抬高平均亮度），再加**自适应曝光**：每帧把这十格见方的明暗推到两端，上下沿慢一步跟随。不加这一下，光挪开的那几秒整块就退成一片同色，看不出是她的颜色。
- 只有 Ave 露面时才动，大约 15 帧/秒；开了减少动效就只画一帧。头像那一格的内衬用她自己的紫 / 蓝压暗一档，浅色页上也不会与卡片连成一片。
- 定稿后把 `ave.ts` 顶部的 `USE_FACES` 改成 `true`，表情图会盖在占位上面，流光也不再计算。

表情图原图在 `design/ave-voice/portraits/`（「细腻」那套，625×590）。现在的处理是裁到脸部后缩到 160px：

```
ffmpeg -i 开心.png -vf "crop=430:430:105:85,scale=160:160:flags=area" -c:v libwebp -quality 88 public/ave/face/happy.webp
```
