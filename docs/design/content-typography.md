# 内页排版分层（随笔 / 项目）

> 给「补设计尚未成形的样式」这一轮用的地图。改动内页正文排版前先读这里，
> 免得在同一元素上两处各写一份、或漏掉一边。
> 摊开来看的样张：`/styleguide/`（`npm run dev` 后访问；三栏并置 + 两态开关），
> 怎么加新样张见 `docs/design/styleguide.md`。

## 一、结构：一层公共 + 两个变体

内页正文（随笔 `src/pages/articles/[slug].astro`、项目 `src/pages/projects/[slug].astro`）
的 markdown 容器都是 `<div class="md">`，排版全部集中在 `src/styles/global.css` 的
「内容页排版」一节，分三层：

```
.prose                    骨架：列宽 34em、页头、元信息、.prose-rule
├─ 默认层  .prose p/h2/h3/blockquote/ul/ol/code/pre/img
│          给 about 页这类非 markdown 长文兜底；内页里被公共层覆盖
├─ 公共层  .md …          随笔与项目取值一致的规则（含列表骨架、互链块 .xfile、小节序号 .ord）
└─ 变体层  .prose--essay  随笔：宋体夜话（长文阅读正典）
           .prose--project 项目：黑体方正文（与随笔保持体温差）
```

变体类挂在 `<article class="prose prose--essay">` 上，**必须挂在 `.prose` 同一个元素**：
`--measure: 34em` 是 em 单位，会按该元素自身的字号折算列宽。

**层序约定**：公共层刻意排在默认层之后，同权重时以公共层为准；
变体层写成 `.prose--x .md …`（比公共层多一个类），权重天然更高，不需要 `!important`。
新加规则时按这个顺序往下排即可。

**行内光景**（`((浮起))` / `{{流过}}`，写作手册见 `docs/writing.md`）样式在 `global.css`
「行内光景」一节，随笔与项目同款：浮起的动画**常驻**，位移与顶点色都乘 `--still`
（梦 1 → 醒 0）—— 醒面位移为零、字色就是正文原色，无 JS 与 RM 下同理；流光仍按
`body[data-reality='dream']` 开关（它换的是整幅 `background-image`，没有「振幅」可收）。

- **逐字浮起**拆字成 `inline-block`（每个字一盒）：字串内部不再换行，两端对齐在此留缺口，2–8 字为宜。
- **流光**不拆字，不影响换行与两端对齐；只动 `background-position`，不碰字号字距，所以没有布局抖动。
- 参数都是自定义属性（`--float-amp/dur/stagger/tint/sway`、`--sheen-angle/hue/span/dur/ease`），
  默认值写在 keyframes 与 `background-image` 里；正文侧由 `((…|k=v,…))` 覆盖，预览页「醒梦双态」一节有滑杆。

**代码配色**由 `astro.config.mjs` 的 `shikiConfig.theme` 指向 `src/markdown/shiki-theme.mjs`：
主题里的颜色写成 `var(--umber)` / `var(--ghost-ink)` / `var(--fg-soft)` 这类字符串，会被原样写进
token 的行内样式，于是代码的颜色跟着醒梦两态（`reality.ts` 逐帧改写的强调色）与夜色一起走。
底由主题与 CSS 写成同一条 `color-mix(in srgb, var(--fg) 4%, transparent)`：主题的值是**行内**样式，
会压过样式表，所以两边必须同值（写 `transparent` 不是「交回 CSS」，只会把底抹掉）。
琥珀在代码里一次都不出现 —— 它属于锚点与进度。

**小节序号 · 定格漂浮**（2026-09-25 落地，取代原先的 `content: counter(sec, cjk-ideographic)`）：
h2 的序号由 `src/markdown/ordinal.mjs` 这个 **mdast 插件在构建期注入**（挂在 `astro.config.mjs`
的 `mdastPlugins` 上），内容页因此仍然零客户端 JS。为什么不用 CSS 计数器：`::before` 里的
`counter()` 只能吐出一个不可分割的原子，没有可逐一点名的子元素 —— 错相就无从谈起。

- **结构**：`.ord` 是一个行内记号，里面**一枚数字一个 `.ord-digit`**（零填充两位、`--i` 供错相）。
  数字是**真文本**，读屏照常读出「01 <标题>」，与旧写法的 counter 内容等价。
- **醒与梦共用同一套字**：序号吃标题自己的字（`h1/h2/h3` 统一走 `--font-display`，
  两个变体都不另设），是标题那一行的延续，不是插进来的第二套字。两面的差别只有动与不动 ——
  梦面每枚数字按 1px 整像素阶跃、`step-end` 零补间地定格漂浮（与品牌字标 `brand.ts`、
  正文 `((浮起))` 同一条曲线，0.4s 错相），醒面振幅收到 0。
- **动画常驻、振幅乘 `--still`**（2026-09-25 改，此前是「按面开关动画」）：这条 keyframes
  逐帧读根变量 `--still`，好处是换面时振幅被连续带过，坏处是动画因此走主线程。
  实测（`design/.probe-float-ramp.cjs`，同一构建内注入旧机制做 A/B）：
  随笔页 6 枚，p50 4.2ms 不变；样式预览页 46 枚 + 29 段逐字浮起，静置 p50 12.6 → 16.7ms。
  **取舍的分界是数量**，不是页面：内容页一节两枚，数量级差一到两个数量级。
- **浮动只走 translate ⇒ 不改变任何占位**：标题永远不会因为入梦而位移，序号也就不需要固定盒；
  数字直接落在标题的基线上，不需要 `vertical-align` 之类的补偿。
- **比例数字要自己补一刀**：标题字（Noto Serif SC）的数字是比例宽，实测「1」0.589em、
  其余 0.698em，而 `font-variant-numeric: tabular-nums` 对它**是空操作**（写上也没用）。
  不补的话「01」比「02」窄 1.4px，每章标题的文字起点会逐章错开 —— 原先用汉字（等宽）时
  不存在这个问题。做法是给 `.ord-digit` 一个 `min-inline-size: 0.7em`（量出来的最宽数字）
  + `text-align: center`，即手工版 tabular figures。**换标题字时要重新量一次。**
- 色彩吃 `--amber`，醒面被 `reality.ts` 插值成冷灰 `#a7b1ba` —— 与旧写法的取色完全一致。

> **做过又撤掉的一版**：先按「点阵显影」做过 —— 醒面等宽数字、梦面把同一个数字拆成 3×5 点阵
> 逐枚定格漂浮。撤掉的原因是**两个面换了字体表现**（数字 vs 点阵各是一套字形），与「醒梦之间
> 应当是同一件东西的两种读法」不合；而且它逼出一整套额外结构（固定盒、两层叠放、溶散曲线、
> `--ord-dot`/`--ord-gap` 两个尺寸旋钮）。改用「同一套字 + 只有动与不动」之后，组件缩到
> 一个插件函数 + 三条 CSS 规则。逐点独立错相也在那一版里被证伪过：相邻点的相位差恰好是
> 一整档阶梯，整枚数字会同时摊开六个高度，字形当场散掉（6× 特写下只剩噪点）。

页面 `<style>` 里只剩该页独有的块：随笔的 `.dawn-glow`、`.tag-row`、`.wake-card`；
项目的 `.pin-line`、`.coverband`、`.file-note`、`.link-list`、`.pj-next`。
（随笔页原有的「起笔琥珀标尺」（`.prose-rule::before`）已于 2026-09-25 移除，见第三节。）

## 五、改完怎么验证（这次踩过的坑）

1. **先修工具**：`getComputedStyle(el).getPropertyValue('fontWeight')` 取不到值——
   这个 API 只认连字符名（`font-weight`），驼峰一律返回空串，会让整份对比静默通过。用 `cs.fontWeight` 这种属性访问。
2. **对比布局要连 `y/x/宽/高` 一起比**，不能只比属性值：
   这次列表项 `margin-top` 从 0.4em 变成了 0，但因为外边距塌陷，`y` 与高度逐项完全一致，属惰性差异。
3. **开屏有会话档位**：`boot.ts` 用 `sessionStorage` 的 `xm-boot-seen` 判断首访。
   首访揭幕在 3.1s，同会话后续页面走 1.05s 快版。**不预热就对比，会把开屏时机差当成样式差**
   （现象是同一元素一版醒面文案、一版梦面文案——因为入梦换面发生在 `booted` 之后 120ms）。
   做法：每换一个源先随便加载一页预热，再统一在 2s 后采样。
4. **morph「走神」是随机的**：`[data-morph]` 元素会周期性乱码再归位，两态演示页里这类 span 的宽度每次采样都不同。
   判断方法：同一版构建连采三次，自身就会抖的行不算差异。
5. **浮动动画会带相位噪声**：采样前把 `--still` 置 0 并强制一次重排（读一次 `offsetHeight`），
   否则引文的 `transform` 矩阵每次都不同。
6. **行内光景与序号自 2026-09-25 起也吃 `--still` 了**：两族的动画**常驻**，振幅乘 `--still`
   ⇒ 把 `--still` 置 0 就能让它们停下（旧写法是「按面开关」，置 0 没用，得显式切面）。
   要断言醒面，断的是「动画名仍在、位移恒为 0」，而不是「没有 animation」。
   流光仍是按面开关：醒面那一段的 `background-image` 恒为 `none`。
7. **改了 markdown 插件必须清内容缓存**：插件（`mdastPlugins`）变了而**内容没变**时，
   `npm run build` 会直接用 `.astro/` 与 `node_modules/.astro/` 里缓存的渲染结果，
   `dist/` 里还是旧标记 —— 现象是「改了插件、构建成功、产物没变」。改完插件先
   `rm -rf .astro node_modules/.astro` 再构建。
8. **`step-end` 读出来是 `steps(1)`**：`getComputedStyle` 的序列化形式与手写的关键字不同，
   断言要比较归一化后的值（`steps(1)` ↔ `step-end`），否则会为一条没坏的东西报错。
9. **定格动画之后别再读相位**：为了拍「波峰」那一帧会把所有 `animation-delay` / `currentTime`
   改成同一个值，此后再读 `animationDelay` 拿到的自然是定格值。相位类断言一律用**定格之前**
   那份探针；另外 WAAPI 的 `currentTime` **包含 `animation-delay`**，定格前先把每枚自己的
   错相 `updateTiming({delay: 0})` 抹平，否则相位会整体偏掉一档。
10. **`screenshot({clip})` 用的是页面坐标**：目标在首屏之下时，只给 `getBoundingClientRect()`
    的视口坐标会截到别处（现象是「放大特写里全是正文，看不见序号」）。要加上 `scrollX/scrollY`
    并配 `captureBeyondViewport: true`。

小节序号那一轮的抽查脚本是 `design/.shot-ordinal.cjs`（`npm run build && node design/.shot-ordinal.cjs`）：
4 条路由 × 醒/梦两面 + 无 JS 态，31 条断言（醒面**动画常驻而位移为 0**、梦面 `ord-digit-float`
逐枚错相、波峰浮到 −3px、**两面之间盒宽与标题文字起点逐像素相同**、各章节序号等宽、
「11」类不缩窄、无 JS ＝ 醒面），另出 6× 特写与波峰定格帧供肉眼验收。

本轮改造的实测结果：4 条路由（随笔 2 篇 / 项目 2 篇）× 改动前后，
`article.prose` 子树逐元素几何与排版全部一致；仅存的差异是新增的变体类名本身、
上面第 2 条的惰性边距、`color-mix` 与字面 rgba 的序列化差异（数值相同），以及第 4、5 条的运行时噪声。

### 定格漂浮族 · 换面的连续性（2026-09-25）

「定格漂浮族」＝ 同一套 Celeste 风格简谐位置量化浮动的四条：品牌字标 `.brand-char`、
小节序号 `.ord-digit`、逐字浮起 `.float-ch`、构块场 `.fld-sq`。它们此前都写成
「按面开关动画」（`body[data-reality='dream']:not(.reality-holding) …{ animation: … }`），
于是换面时有两个躲不掉的动作：长按一激活（`reality-holding` 落下）整族**从当前档位一步拽回基线**；
回梦闩锁时又瞬间起跳。实测长按一次，随笔页会有 **109 帧**停在「 animation 已被摘掉」的状态上，
最大一帧跳变 **3px**。

改法：动画常驻，振幅乘 `--still`（品牌、序号、逐字浮起三条都改；`.fld-sq` 是第 160 枚的量级，
维持按面开关，理由见 `Constructs.astro`）。三处配套：

- **keyframes 里出现 `--still` ⇒ 动画走主线程**。这是代价，用数量卡；口径与数字
  （`design/.probe-float-ramp.cjs`，同一构建内注入旧机制做 A/B，5 次中位，读 Chrome 自己的
  `Performance.getMetrics` 差值：TaskDuration / RecalcStyleDuration）：
  · 随笔页（6 枚序号）：静置 −3%、长按 +3% —— 都在噪声内；
  · 样式预览页（46 枚序号 + 29 段逐字浮起）：静置 +1…3%，**长按 +17% 主线程任务、
    +30% 样式重算**（≈ +0.17ms/帧，合 0.002ms 每枚每帧）。
    这一笔买的是「长按期间这些浮动不熄」本身：旧机制是靠「长按一激活就把它们全摘掉」
    才省下来的，省掉的正是我们要去掉的那一下骤停。
- ⚠ **别用帧间隔 p50 量这件事**。无头里 rAF 不锁 vsync（实测随笔页能跑到 126 次/秒，
  而主线程已占 70%），p50 读的是调度节奏，不是造价 —— 这一轮先按那个口径报了
  「+4ms/帧」，换成计数器口径后同一对配置只差 3%。要用就用 `Performance.getMetrics`
  或时间线里的 `UpdateLayoutTree`，并且**别同时挂逐帧采样器**（它每帧 `getComputedStyle`
  会自己把样式重算逼出来，账记到被量的东西头上）。
- **试过、都不管用**（都在噪声内或更差）：把振幅量化成 1/8、1/32、1/128 档（`round()`）、
  丢掉 `will-change`、把振幅收成单个元素级长度变量、用 `@property` 把 `--still` 注册成 `<number>`。
  四条一起说明：**重解是被「被读的那个变量在动」触发的，不看它的值变没变** ——
  所以只要振幅还跟着逐帧的醒度走，这笔钱就省不掉。真正的替代只有一条：让 keyframes 回到
  字面量（可合成、零重解），把落定改由 `transition: translate` 承担 —— 代价是落定变成
  一个固定时长的缓动、锚在闩锁那一刻，而不是跟着线的进度走；入梦那一侧还得把相位错开
  改成正值才能不带跳变。值与价都摆在这儿：为这一页的一笔 0.17ms/帧 换掉「跟着线走」，
  这一轮判定不划算。
- **提层（`will-change: translate`）只留在梦面**：醒面振幅恒 0，让字留在普通层上，
  次像素抗锯齿不变。对照实测（`design/.probe-float-wake-pixels.cjs`）：全站动画暂停后，
  「序号动画在」与「摘掉动画」两帧逐像素比 **0/20757 与 0/2904 像素不同** ⇒ 醒面恒等。
- **品牌还多一件事**：振幅归零之后，每秒一次的字母轮转就不再是浮动的一部分，只会变成一下
  突兀的跳动。所以 `brand.ts` 的轮转也读醒度（`wakeMix() > 0.02` 即停转），中途松手退回梦面
  时从同一个词接着轮。闩锁后 180ms 的磨砂溶变换回 Traveritas 时振幅已是 0，换字不带位移。

对照脚本：`design/.probe-float-ramp.cjs [tag] [legacy]`（`legacy` ＝ 在同一构建里把旧机制原样
贴回来做 A/B；每轮的 JSON 落在 `design/.shots-ramp/`，已被 `design/**/.shots*` 忽略）。
