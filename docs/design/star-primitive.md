# 星 · 立体星的细节参数（2026-11-10）

> 结论先行：**三轴正交六尖星（±x ±y ±z）的结构成立，问题全在细节。** 这一组原型把细节拆成可量的旋钮逐个扫过，
> 顺带推翻了几条早前写在别处的说法。原型都在 `design/mocks/star-t-*/` 与 `design/mocks/star-v-*/`。

## 一、先定一条：结构与姿态

**「±x ±y ±z 投影成六芒星」只在 yaw 45°、pitch 35.264°（体对角视线）成立。** 三个几何体都是八面体对称，
任何角度下六支的投影半径在 9.24–16.00 之间摆动；离开体对角 22° 掉出可用区，40° 起塌成四角或六边形。
961 格实测：≥70 分只占 16%，<40 分占 25%。

所以：**静置或小幅度动都没问题，连续整圈转必然有三分之二的时间不像六芒星。**
这也解释了工具栏那颗星为什么一直没出问题——它永远画在 45°。

八个体对角视线两两 IoU 全是 1.0000，所以「换个满分姿态」在画面上看不出区别。

## 二、四个旋钮的扫描结果

### 粗细（半宽 / 支长）

| 值 | 读数 |
|---|---|
| 0.119 | **现役**，内角 3.04 单位 / 15.18px，读作刺 |
| **0.26** | **推荐**，内角 5.36 单位 / 26.81px，甜区 0.20–0.32 |
| 0.32 以上 | 六支开始被吃掉 |
| 0.62 | 已是六边形带六个小凸 |

- 半宽是**填满中心的那一笔**。支尾回伸（1.4）对剪影完全无效，内角一个数都不变。
- 六重谐波幅度 a6（0.672→0.138）比内角更适合当「还像不像六芒星」的量尺。

### 弧线（支的剖面）

**凹 0.04**：中段收窄 28%（半宽 1.9→1.37），腰在离根 49%，尖端半角 8.3°→5.0°。三件事同时发生才有晶体感——
中段有腰、尖端被带锐、轮廓仍是硬边。

- **凸整族排除**：只是把内角填平成六段圆弧，往花走。
- **露珠尖端不成立**：单支放大很好看，六支并置立刻垮——尖端半角 8.3°→44.1°，六片圆头瓣，读成六瓣花。
- 「曲率伤小尺寸」对凹 0.04 **不成立**：几何上 48px 亏 0.30px，但真画到像素格上再数是 3.9 vs 3.9，被栅格抹平。
  真吃亏的是 S 形（48px 少 0.6）。

### 平滑（脊、明暗、尖端、棱、截面）

| 旋钮 | 判断 |
|---|---|
| **脊折高** | **最要紧**。0.5 起才看得见，**0.75–1.5 甜区**，1.8 起六刃互压、内角被吃 |
| **明暗档数 / 跨度** | 第二要紧。3 档够立住、**4 档最稳**、5 档与 4 档无从分辨。跨度 **0.10–0.92**（0.24–0.80 发灰、0.05–0.97 发花） |
| 尖端 | 官能而非观感：200px 上一半档位与「不做」差 1 像素内 |
| 棱上圆角 | 配角，只在 400px 看一条刃时读得出 |
| 截面边数 | 200px 看不出。**反直觉：六边最平**（脊上是平面，整条一起亮，折的信息被抹掉），四边最利，八边才有三段 |

### 光向 —— 先于上面所有旋钮

**光不能只在屏幕平面里。** 六支的两肩在屏幕上落在 0/60/120°，屏幕平面内的光总与某一对平行，
那两支整支同色、折白折。第一次扫折高时 0.25/0.5/0.75 三档读数完全相同就是这个原因。

定 `LIGHT = normalize([0.78, 0.42, 0.45])`（az30/el25），判据是**六支里最差那支**而非平均——一支平了整颗就塌。

### 中心那堆碎条

不是「中心缺东西」，是**支尾太尖**的后果：越到末端越窄，六条在中心附近只剩一两像素宽，
交出来的十几个小三角每一个都不属于任何一条支——所以「没有意义」。

三档交代里 **劈开（沿光垂直方向分两半，一明一暗）** 最好，因为它与六支的明暗结构接得上；
平顶（一块朝观者的小六边形）便宜最稳但略脱钩；退淡（与底色同值）能用但看起来像盖上去的。

## 三、代价

现役 `drawStar()` 是 **7 path**。合成后约 **24 path**（磨砂档），最省的柔钝档也要 19。**约 3.4 倍。**

落进工具栏那种每帧重画的地方要按这个倍数算账；作为「浮在别处的一层」则无所谓。

## 四、被推翻的几条旧说法

| 旧说法 | 实测 |
|---|---|
| 「这里内角 2.8135 单位 / 14.07px」 | **3.0354 / 15.18px**，两个独立实现各自复现，2.8135 怎么量出来的没定位到 |
| 「支尾回伸是往星心填东西的那一笔」 | 不成立。0→6.0 内角一数不变、剪影面积不变，只改中心约 6% 的明暗 |
| 「正八面体的剪影是六芒星」 | 不成立。**凸多面体的正交剪影恒为凸形**，六芒星有六个内凹缺口。正八面体在等轴下给的是正六边形 |
| 「3D 在 64px 以下换不到任何东西」 | 只对**六支针**那一类成立。带倒角的厚板 64px 仍是清楚的星；失效的只是厚度（10% 倒角 = 5.6px 带） |
| 「六边截面更像晶体」 | 反了。六边最平，四边最利，八边才有三段 |
| `transparent + DoubleSide` | 会被 three 拆成两个 pass。闭合实体改 `FrontSide` 后 resin 从 2 calls 掉回 1，画面零变化 |

## 五、尚未解决的

- **触发式翻动的角度暴露**：三轴同时动必然经过坏角度，怎么在路径上压缩它，尚未量。
- **梦面那套 `--umber` 底色没试**，所有判断只在 `#f0f3f6` 与 `#2a2b38` 两底上做出。
- **六芒星与 favicon 是两个符号**：favicon 的腰是正六边形，六尖星的腰是内凹六芒星，同族但不同轮廓。
- 全部只验 Chrome。
