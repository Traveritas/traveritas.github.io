# 审美方向简报：《醒梦》

来源：《醒梦》艺术风格指导（初稿 v0.101，共 15 页/17 节），原文位于 `D:\myDownloads\个人与杂项\醒梦艺术风格指导.pdf`。
**用户注记：该文档只代表风格的大致方向，并不准确**——它是设计起点，不是约束清单；落地时允许偏离，偏离幅度由用户逐案验收。

> 核心宣言：**这里不是梦，也不是现实。它是人在即将醒来时，看见的最后一层世界。** 世界应当始终保留一种感觉：它可能马上消失。

## 1. 核心概念

"醒梦"不是单纯的梦，也不是醒/梦二元对立，而是**介于二者之间的状态**：已知自己在做梦却仍停留在梦中；或已醒来却保留梦中的感受、逻辑与残影。世界是"现实经过记忆、意识、情绪重新组织之后留下的内部风景"。

## 2. 核心气质

神秘 / 朦胧 / 温暖 / 虚饰 / 如梦 / 安静 / 温和。
不是恐怖梦境，也不是冰冷空洞的阈限空间——陌生感带来的首先不是恐惧，而是**好奇、迟疑、安静和轻微的失真感**。温暖 ≈ 柔和的光、被包裹感、无法明确回忆的熟悉感、梦结束前的一点不舍。

## 3. 视觉语言

- **形态**：简单几何体、大型平面、圆/环/柱/框架、长距离延伸的线、重复但不规律的结构。倾向：巨型框架、巨大的环、无用途的高塔、漂浮平台、巨型门状结构、纪念碑（却没有纪念对象）、介于雕塑/装置/建筑之间的巨构。可以违反部分工程逻辑，但不随机——"似乎拥有某种规则，只是暂时无法理解"。
- **现实物**：门、椅子、花、窗、床、楼梯、路灯、电话、水杯、布料、玩具、书……不需要保持现实语境（门可独立于花田、楼梯通向天空）。原则：**世界负责陌生，现实物负责熟悉**，冲突构成梦感。现实物 = 认知锚点。
- **材质**：半透明、玻璃样、磨砂、树脂样；光滑、柔和反射、低粗糙度、不过度金属化。"被现实制造出来，却不像现实材料"。推荐组合：**磨砂玻璃 + 半透明树脂 + 柔和哑光**。禁止大量：铁锈、裂纹、污泥、强风化、密集机械细节、重工业质感。巨构可以巨大，却依然柔和、干净、安静。
- **色彩**：低饱和偏浅色系——浅蓝、雾蓝、淡粉、灰粉、近白冷色、黑白灰。分工：**蓝=距离/空间/清醒/安静；粉=温度/梦/记忆/柔软；黑白灰=结构/秩序/清晰**。颜色之间像隔着雾、玻璃、光，被轻微稀释；**不能所有场景都是蓝粉渐变**。少量克制异质色（淡金、极浅紫、冷绿、低饱和近荧光）作记忆点。
- **空间**：**空间本身就是内容**。花田、水面、雾、空旷平台、巨型室内、无边界的房间、阈限式过渡区。公式：**少量结构 + 巨大尺度 + 大面积留白 + 一个现实锚点**。
- **巨构**：不是远古遗迹，而是**心理结构/思维结构/意识活动的空间化/记忆中的形状**。重点不是"谁建造"，而是"为什么我的意识能理解它存在，却无法理解它的用途"。要求：**秩序感 + 不可理解性**。避免随机、机械堆砌、传统科幻超级机器。
- **自然元素**：花/草/水/云/风/光/少量树/雾，对冲几何的人工感。花田不是漂亮背景，可承载柔和、生长、记忆、无意识、梦境表层、安慰。理想：**巨构像植物一样存在，而花像建筑的一部分**。

## 4. 人物 / 世界观 / UI / 音乐 / 动画

- **人物**：非视觉中心；观察者/行走者/意识载体。简洁轮廓、大面积纯色、少量几何细节、柔和材质；弱化文化标签与时代特征。安静、干净、略微不真实。
- **世界观**：参考梦/思维/意识/记忆/感知心理学，但不把术语做成设定名词。①不解释一切，保留未知 ②不堆历史（纪元/帝国/战争/时间线）③重视局部规则（梦如何变化、空间如何变化、记忆是否可靠）④允许象征——花田既是地点也是心理状态，巨构既是物体也是思想。
- **UI**：简约线面 + 半透明 + 几何结构。细线、简单平面、大面积留白、柔和半透明背景、克制动画；不过度拟物、不赛博朋克。**UI 不会"跳出来"，而像从画面中浮现**：轻微淡入、线条延展、柔和缩放、缓慢呼吸、微弱漂浮、极轻的模糊变化。
- **音乐**：极简电子 + Ambient；不负责"推动"，负责"让人停留在状态里"。醒=更少音符/更清晰/边界明确；梦=更多混响/重叠/循环/音色边缘模糊。**醒与梦之间不应有明显开关**——理想状态是分不清何时切换。
- **动画**：暂不设硬性风格限制；自然、平稳、克制、不过度夸张。

## 5. 禁止事项

①完全复刻现实（现实只是素材）②过度极简（不能退化成"几个方块放空白背景"，必须保留材质/空间/自然物/现实物/光影细节）③过多历史设定 ④过多人物关系 ⑤传统废土巨构（锈蚀/战争遗迹/工业废城）⑥**单纯复制 Dreamcore/Liminal Space**（空商场/泳池/老式录像滤镜等现成符号的堆砌）——只可参考，须发展自己的视觉符号。
⑦**生活化、裁缝与手工作坊隐喻**：严禁出现“针、缝、穿针、起针、落针、八针进度、针脚”等字眼。项目进度采用「八阶成形 / 浮现度 (Eight Depths)」，以意识/睡眠深度刻度与光学显影替代。
⑧**直白出戏与打破第四面墙的标签**：严禁出现“这是梦/你在做梦/快醒了/读起来像梦话/智能体与梦/梦里点也会通/半可核验/可核验”等标签式字眼。高级的梦感应当是“字句如水汽微光，不言梦而梦感自生”。

## 6. 视觉母题候选（最终定 2–4 个）

环 · 门 · 框 · 花 · 玻璃 · 水面 · 阶梯 · 悬浮物 · 细线 · 镜面 · 帷幕 · 巨型空洞
母题应能同时进入：世界/场景/UI/人物/音乐/叙事。

**用户补充（2026-09-19）**：目前偏向**玻璃/水晶碎块**的质感方向（呼应"玻璃/镜面/悬浮物"候选，也契合"梦的碎片/易碎感"）；环/门/框不完全符合想法，降为可用但非首选。技术含义见选型文档 3.3 节：棱面几何 + 透明/光滑/环境贴图/虹彩的平价材质组合。

**用户二次补充（2026-09-19，Phase 2 评审后）**：碎块图标与首个主页"**过于规整（组成太简单）且丑**"——要求构图更丰富、更有机。新推荐母题：**花**，最喜欢**百合的简约花型**、偏**抽象花的形状**（拟真亦可）。设计含义：① 花形避免机械放射对称，花瓣需长度/开角抖动；② 构图要有层次的丰富度，不做单一简单图形；③ 百合线稿（俯视罗塞特/侧视）为主形态，玻璃/磨砂保留为材质语言（可做"磨砂花瓣"）。

**用户三次补充（2026-09-22）：文风、隐喻与双态叙事规范**：
1. **核心主张问句化**：避免教科书式的板滞陈述句，多采用富有知觉张力和哲学悬浮感的问句（如“在即将醒来的那一瞬，世界究竟是在成形，还是正在融化？”）。
2. **隐喻方向**：以“方向 A（意识/睡眠深度阶律）+ 方向 B（光学与显影）”为核心。脑电波只作为背景低调的视觉纹理与频段指示，不作大段医学说教。项目进度统一使用「八阶成形 / 浮现度 (Eight Depths)」。
3. **双态（醒 vs 梦）文风分工**：
   - **醒态 (Wake)**：克制、自然、清晰、质朴，让人一眼能看懂，避免伪严谨的官僚审计感；
   - **梦态 (Dream)**：浪漫、哲学知觉悖论、纯善透明的电波感（汲取游戏《素晴日》中维特根斯坦式逻辑哲学论、银河铁道与意识漂浮感，但剥离猟奇/黑暗，保留其纯净、轻盈、空灵与诗意）。
4. **版块徽标体系（方案二 · 维特根斯坦命题边界）**：
   - 随笔：`可言说的 · SAYABLE`
   - 项目：`可构造的 · BUILDABLE`
   - 试验场：`未命名的 · UNNAMED`
   - 关于/出口：`存在于此 · PRESENCE`
5. **导航双态映射**：
   - 随笔 ↔ `断章`
   - 项目 ↔ `造物`
   - 关于 ↔ `此身`

## 7. 验收判断标准（做任何内容时自问）

- 视觉：是否既陌生、又保留一点现实中的熟悉感？
- 情绪：是否神秘、却不主动制造敌意？
- 空间：是否留有呼吸和停留的余地？
- 材质：是否带轻微的不现实感？
- 世界观：能否被体验、而不需要大量文字解释？
- 人物：角色是否属于世界、而非凌驾于世界？
- 音乐：是否在维持状态、而非强迫情绪？
- 母题：是否与"醒梦"存在某种关系？
