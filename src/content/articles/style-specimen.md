这一段未作任何两态标记，醒与梦两面读到的是同一组字。大多数日常行文皆依此展开，两态机制只在需要分岔处点落：一个词的[[换面|倒影]]，或者一整段的另一种可能。在随笔变体下，正文字形采用**思源宋体**，排版保持克制、舒展的两端对齐，行高与字距均经过微调，使长文具备沉静的阅读体温。

行内可以自然容纳[站内链接](/about/)、`行内代码`、**加粗强调**与*斜体微光*。加粗在随笔中带有 600 字重与 30% 梦色下衬；行内代码则不填底色，而是在字身下方压上一条梦色发丝线，以此标示外来语的存在。

## 结构与小节

小节标题的序号由构建期插件自动注入，无需手动编号。在醒面，数字静止停驻在基线之上；长按入梦后，每枚数字将以整像素阶跃定格漂浮，与品牌字标保持同一条律动曲线。

正文段落之间的呼吸由统一的外边距维持。文字既不拥挤，亦不涣散，在白昼与微暗的光线中保持清晰的视觉层级。

### 三级标题的层级

三级标题目前继承默认层的度量，保留适度的留白与紧凑的字号。它并不参与自动编号，专用于小节内部的次级递进。

## 两态显隐与行内光景

双声轨文字构成了本站的深层脉络。同一段正文可以随阅读状态呈现出截然不同的心境，但醒面始终是唯一的真值所在。

:::wake
这是只在醒面浮现的叙述：质朴、笃定、清晰，像晨光初照时落在桌案上的手记。所有事物的轮廓清晰可辨，时间和事件在此处各安其位。
:::

:::dream
这是只在梦面浮现的叙述：如果一个词的含义取决于它在知觉中的距离，那么当视线微微移开，整座世界便悄然悬浮于半透明的微光之中，随时可能消融，又随时可能重新被记起。
:::

除了段落级的转换，行内还可以点缀微小而克制的光景。在醒面，它们静默退回寻常墨色；而在梦面，字句会按既定相位悄然起伏。

((水汽漫开))是逐字浮起的默认状态；((更高的字|amp=6px))拥有更明显的起伏档位；((慢半拍的字|dur=4.4s,stagger=-0.6s))则错开步调缓步上升。若希望在波峰处带出一抹微温，可采用((顶点微温|amp=3px,tint=32%))；若需要轻微的水平晃动，则可赋予((横向微晃|sway=0.4))。

流光则不拆分字符，一道暖色自左向右滑过字面：{{同一句话里有一线暖光走过}}。它亦可调节节奏，如{{窄而快|span=210%,dur=3.2s}}、{{偏暖的一线|hue=70%,angle=96deg}}，或是带有逐帧定格感的{{抽帧流光|steps=4}}。

## 列表与次第

列表用于收纳平行的物象或递进的思绪。在随笔中，无序列表项拥有独特的倾斜琥珀微刻度：

- 微光与水汽漫开的边缘，保留着未曾干涸的痕迹
- 磨砂玻璃后面的轮廓正在逐渐聚拢
- 帷幕横置在遮蔽与显露之间
  - 次级缩进条目：细部的分支延伸
  - 第二个次级条目：层级分明而不突兀
- 尺度本身作为意象，悬停于视界尽头

当需要表达严密的先后次第时，有序列表保留了原生的数字标记，并换用等宽字体与柔和色调呈现：

1. 首先让事物的边缘保持适度的含混
2. 随后在微光中确定其存在的边界
3. 最终任由界线退隐为纯粹的留白

任务清单在正文中呈现为质朴克制的进度标记，与项目侧保持一致的符号语言：

- [x] 结构骨架与双态管线已完全落定
- [x] 全站设计令牌与字体系统校准
- [x] 任务清单符号化与两档明暗排版
- [ ] 持续完善的排版样张存目

## 引文、代码与名录

引文在正文中被视为来自梦侧的声音，带有柔和的暖色左缘与极其舒缓的微幅浮动：

> “语言的边界，即是我的世界的边界。凡能够言说的，都能够说清楚；凡不可言说的，必须保持沉默。”
>
> 沉静的字句在阅读间隙轻轻悬停，给目光留出一处停顿的浅滩。

代码块同样被赋予梦色左边缘，搭配专为夜色调校的令牌色彩，并自动在右上角标明语言标签：

```ts
// 醒梦插值与时间轴映射
const at = (m: number) => 23 * 60 + 7 + m; /* 夜内分钟 */
const stage = STAGE_INFO[stageAt(at(124))]; // 浅梦转深眠
```

表格采用无外框的名录形式，仅保留横向的发丝线，数字列统一对齐：

| 分期 | 挂钟时刻 | 意识波形 | 体温感知 |

| 浅梦 | 23:19    | θ 波     | 微凉     |
| 深眠 | 01:11    | δ 波     | 沉静     |
| 异相 | 02:08    | 眼动     | 微温     |
