本篇展示项目变体下的完整样式系统与构造规范。与随笔变体的宋体长文阅读正典不同，项目侧选用**黑体方正文**，基准字号为 16px，行高 2.05，字距 .02em，与随笔保持鲜明的「体温差」，呈现如同施工信纸般的清晰质地与结构感。

在项目正文中，行内成分同样紧密嵌合：[站内链接](/about/)使用温暖的琥珀中间色，`行内代码`填入 7% 前景色衬底成规则小方块，**加粗强调**赋予 700 字重并以 24% 琥珀色作为下部衬线，而*斜体*则用于辅助标记。行内双声轨文字亦可在此无缝流转：[[醒态结构|深眠构想]]随长按动作自如翻转。

## 构造标尺与小节印章

项目变体下的二级标题具备独有的「印章板」小节序号：序号数字被包裹在 1px 细线方框内，与右侧延伸的发丝线贯通成完整的标尺。即使在章节数跨越至两位数时，数字盒的宽度也严格保持均等，印章形态始终恒定。

在醒面，印章与右侧标尺绝对静止；入梦后，方框内的数字将按整像素阶跃定格浮动，而方框本身与标题文字绝不发生哪怕一个像素的推挤位移。

### 三级度量规范

三级标题继承清晰的层级间距，为结构更细密的构造步骤提供明确的分区锚点，不带有自动注入的印章序号。

## 施工清单与次第

任务清单是项目变体的核心表现形式之一。在 Markdown 中书写的复选项目，在项目侧被专门解析为具有高度工业感与秩序美的状态指示符：

- [x] 确立项目变体黑体方正文与 34em 列宽度量
- [x] 小节序号印章化与右侧发丝线自动贯通
- [x] 施工清单勾选态与未勾选态的符号转换
- [x] 方框板块语言（代码块、表格、封闭图版）全量适配
- [ ] 动态交互小样与穿插式三维实体装载
- [ ] 深眠阶段的更多物象与图形语言扩展

已完成项目以明晰的琥珀色勾选符 `✓` 点亮，并呈现常规前景色；未完成项则显示为等宽中空圆环 `○`，文字退为次级柔和色调。

平行的无序条目同样由专属于项目变体的等宽空心圆环统领：

- 模块化设计令牌与组件化视图抽离
- 零客户端 JavaScript 的静态渲染底线
  - 纯 CSS 与 SVG 实现的封面波纹与幽灵编号
  - 构建期 AST 处理实现的无损双面文案
- 跨页状态同步与长按手势判定

当需要表达严密的先后逻辑时，有序列表呈现清晰的等宽刻度标记：

1. 确立模块接口与数据边界
2. 构建静态标记并验证各分辨率下的几何对齐
3. 注入两态微调与夜色深度响应

## 两态切面与光景响应

项目不仅是一份清单，同样承载着不同知觉深度下的意图陈述。

:::wake
清醒层面的构造规范：去除冗余依赖，坚持静态生成，以极度克制与笃定的架构确保整个系统的轻盈与恒久稳定。
:::

:::dream
深眠层面的知觉沉降：它像是一块沉入水底的半透明树脂，几何外缘极其分明，而核心深处封存着来自遥远星轨的微弱脉冲。
:::

行内光景在项目正文中同样生效：((逐字浮起))可在深眠状态下轻轻起伏，亦可调节为((振幅微调|amp=5px))或((顶点微温|amp=3px,tint=28%))；流光划过字面时带起微光：{{流光掠过}}或{{偏暖的一线|hue=65%,angle=95deg}}，醒面时则全部规整复位。

## 板块、引文与封闭图版

引文在项目变体中保持与全站一致的梦侧暖边与极其轻柔的浮动质感：

> “构造之物并不喧哗。它在沉静中落定自己的支点，等待光线穿过它的棱角。”

项目侧的代码块与随笔侧不同，不再采用开放式的左边缘线，而是闭合为直角 1px 细线方框，右上角附有大写等宽语言标签：

```ts
// 项目度量与成形度计算
interface ProjectSpec {
  status: '构想中' | '进行中' | '已完成';
  depth: 2 | 5 | 8;
  measure: '34em';
}
const spec: ProjectSpec = { status: '进行中', depth: 5, measure: '34em' };
```

表格同样被赋予完整的方框结构与 2% 前景微底色，表头加粗强化，单元格内边距严谨统一：

| 模块名称 | 呈现形态 | 边框规范 | 字符设定 |
| -------- | -------- | -------- | -------- |
| 标题印章 | 嵌入式方框 | 1px 琥珀 45% | 等宽数字 |
| 代码容器 | 封闭直角框 | 1px 发丝线 | 细滚动条 |
| 施工清单 | 琥珀勾选/圆环 | 符号代换 | 隐藏原生选框 |

图版亦以封闭板块形式呈现，周围环绕 1px 细线与微底色，图注以极小字号的等宽角注标定：
