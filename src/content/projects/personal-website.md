## 技术形态

**框架与架构**：基于 Astro 纯静态生成，内容页在无 JS 环境下骨架与排版完整可读。

**原生轻量动效**：不依赖重量级动效库，交互均由原生 CSS 与轻量 TypeScript 驱动。

**轻量线景渲染**：首页采用 WebGL / Canvas 地形线景，支持 Worker 离屏渲染，保持轻盈静止感。

**审美底色**：「醒梦」——低饱和微温、磨砂漫反射、大面积留白与安静悬停。
