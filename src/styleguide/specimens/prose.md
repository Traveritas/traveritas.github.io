## 知觉的距离

世界在即将醒来时并不稳固。**它保留轮廓**，却不再保证轮廓的含义——*这并非隐喻*，只是注视持续得太久时，被注视之物会轻微地退开。

一段话里可以有[链接](/about/)、`行内代码`、**加粗**与*强调*；行内成分的温度差应小到几乎察觉不到。换行
不应带来新的段落，只应留下一次停顿。

行内另有两处光景：((水汽漫开))时字会各自浮起，{{而同一句话}}可以有一线暖光从字面流过——醒面时两者都只是寻常的墨色。

### 三级标题

`h3` 仍只吃默认层（`1.1rem` / 上边距 `2.2em`）——记号留给自制的「小节」组件的下一层，眼下还没和上面两套 `h2` 排成序。（它上面那两枚 `h2` 序号已经由「小节序号 · 定格漂浮」接管：与标题同一套字，切到梦面看它逐枚浮起。）

段落之间的节奏由下边距决定：公共层 `1.5em`，项目变体把它压到 `1.3em`。

## 并置与次第

无序列表用于并置同类事物：

- 微光与水汽漫开的边缘，没有确凿的轮廓
- 圆环正在聚拢
- 帷幕横置在遮蔽与展露之间
  - 缩进一级的子项
  - 子项的第二个条目
- 尺度本身作为母题，悬于视界边缘

有序列表用于次第：

1. 先让它保持含混
2. 再给它一条边界
3. 最后把边界擦去

> 梦里的句子总比醒来时短一些。
>
> 因为有些成分，只在闭上眼之后才被允许存在。

代码与引文都算「外来语」：随笔侧共用一条梦色左缘，项目侧成方框；行内 code 在随笔里只有一条梦色下划线，在项目里填底成小块。语言签吃 `data-language`，token 只用站内令牌（注释 `--fg-soft`、关键字 `--umber`、字符串与类型 `--ghost-ink`、其余中性）。

```ts
const at = (m: number) => 23 * 60 + 7 + m; /* 夜内分钟 → 挂钟 */
const stage = STAGE_INFO[stageAt(at(181))]; // 异相 · 眼动
```
