# 变体 G2 · 凝露张力（Surface Tension Dewdrop）· 实测笔记

## 主张
继承方案 G 水汽微晕与 1:1 热点绝对定锚基底，构建“表面张力与微湿润感”液体物理模型：玻璃晨露般的弯液面（Meniscus）半透光泽轮廓、移动滞后-拉长-弹回（Spring-Back）Q 弹动力学、悬停浸润铺展（Wetting Spread）、毛细水线导轨与高压结晶琥珀结 ◆。「露凝于镜，聚散生息；动带弹回之润，定显澄澈之形」。

## 醒 / 梦 各自的机制与关键参数
- 元素结构：`.dew-core`（3px 绝对同帧热点微核）+ `.dew-aura`（动力学容器）+ `.dew-organism`（3.6s 纯 CSS 超慢微呼吸）+ `.dew-body`（流体体积）+ `.dew-meniscus`（半透表面张力弯液面轮廓）+ `.dew-specular`（浸润透亮水膜）+ `.dew-ripple`（微颤与微波）。
- 醒态：清澈冰霜冷露，微张力边界锐利，冷灰银雾，正向对齐屏幕轴；阻尼 $\tau = 95\text{ms}$，运动拉长最大 1.36x。
- 梦态：暖沙琥珀温露，更强流动性与浸润铺展；顺时针偏转 $14^\circ$（与全站缝线倾角严格一致）；阻尼 $\tau = 115\text{ms}$。
- 静息机制：游弋态由纯 CSS `dewIdleBreath` 驱动微呼吸（半径 16px~22px），JS rAF 落定即停（静息 5s 内严格 0 次），`will-change` 归 `auto`。

## 与方案 G 的机制差异
- **形态与弯液面**：G 为纯发散径向光晕；G2 外沿构筑微弱半透表面张力弧形边与弯液面反射弧，呈现玻璃凝露晶莹微湿润感。
- **动力学弹性**：G 为单纯一阶阻尼；G2 引入二阶欠阻尼表面张力弹簧（$\zeta \approx 0.59$），加速时呈水滴拖尾，停止时有一拍极其微小的有机收缩回弹（Q 弹温润）。
- **交互形态演化**：
  - Link：由 G 的单纯放大演化为如水滴润叶般的“浸润铺展（Wetting Spread）”透亮椭圆水膜；
  - Text：由 G 的光隙演化为受毛细作用纵向拉长的“极细半透水线导轨”（微核淡化，字面完全清晰透亮）；
  - Click：新增向内收缩微颤（Capillary Snap）与弹性复原；
  - Latch：由外向心极速收聚，按满瞬间如高压凝珠般固化结晶为 45° 实心琥珀结 ◆。

## 实测
- **控制台错误 0 · 页面错误 0 · 失败请求 0**（`.shot-cursor.cjs` 实测验证）。
- **热点同帧偏差**：`dx: 0 · dy: 0 · dist: 0.00px`（同帧口径，0 延迟 0 偏差）。
- **静息性能**：停止后平滑收敛；静息 5s 增量 `rafLast5s: 0`；静息 `will-change = auto`；固定 7 节点池，逐帧只写 `transform` 与 `opacity`。
- **状态矩阵覆盖（12 项实测）**：
  1. `rest`：3.6s 超慢低频微呼吸，半径 16px~22px 柔和收放；
  2. `move`：tau ≈ 105ms 阻尼跟随，拉伸水滴拖尾（scaleX $\le$ 1.36），停止带 Q 弹有机微回弹；
  3. `hover-link`：浸润铺展成椭圆透亮水膜（1.45~1.58x），柔和引力吸附（$\le 8\text{px}$，图 `05-hover-link.png`）；
  4. `hover-text`：毛细拉长成纤细水线导轨（宽约 4.8px，长 62px），微晕亮度 13%，微核淡化（图 `06-hover-text.png`）；
  5. `input`：细致水线微隙，微核半透不挡字；
  6. `drag`：贴附张力态（横向拉宽、张力增强，图 `10-drag.png`）；
  7. `click`：向内收缩微颤（Capillary Snap 快速收缩至 0.74），荡出 3.2px 表面波后弹性复原（图 `07-click.png`）；
  8. `hold1300 / hold2200`：向心极速收聚，水滴向核收缩至 0.35x，光晕高压浓缩（图 `08-hold.png`）；
  9. `latch`：按满瞬间晶华爆发，高压凝珠固化结晶为 45° 实心结 ◆（图 `09-latch.png`）；
  10. `scroll`：水滴微敛稳定视觉焦点；
  11. `leave`：随外壳 `fx-cursor-out` 柔和淡出；
  12. 降级：`?cursor=off`、`?reduced=1`、`forced-colors`、触摸事件全线安全降级原生光标（图 `11-off.png`, `12-reduced.png`）。

## 最不放心的
1. 欠阻尼弹性回弹参数控制；已微调阻尼比 $\zeta \approx 0.59$，确保仅产生一拍极微弱有机收缩即平滑落定，杜绝多余震荡。
2. 浸润水膜在长链接上的贴合度；已通过横向自适应系数将最大形变 clamp 在 1.58x 内，保持凝露整体性。
