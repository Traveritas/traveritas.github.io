# 方案（第四轮 · 草案）

## 为什么改切法

前三个维度（外观 / 悬停 / 展开）各自独立，结果是三份互不相干的清单：四种画矩形的方式、四种对指针的反应、八条通往同一个面板的路。它们可以任意组合，所以彼此之间没有必然联系——**一份设计能成立，靠的是它内部自洽，不是它有多少个选项。**

改法：不再按「表面 / 反应 / 转场」切，改按**一个动词**切。一个方案 = 一件东西 + 它被靠近时怎么动 + 它怎么变成可读的面。三部分不再是三个决定，而是同一个决定的三个后果——材质是动词的材料，悬停是动词的第一次发生，展开是动词的完成。

另外，三个场景共用同一种碎片（已定）：同一件东西，三种光。这样整个站读起来是**一个世界在三个时刻**，而不是三个不相干的世界——比三套各自成立的东西更贴《醒梦》。

## 六个方案

每个方案给：那个动词 · 碎片是什么 · 悬停 · 展开与收回 · 三种光下怎么活 · 它凭什么成立 · 风险。

---

### 1. 霜化 `thaw` — 融化

- **物**：一片结着霜的玻璃。内容就在霜下面，不是另画上去的。
- **悬停**：指针是一点温度。霜从落点化开一小块，露出底下那一小片清楚的正文；移开，霜慢慢结回去。
- **展开**：整片霜从中心往外退，退干净了就是正文——没有面板，读的就是这块碎片本身。收回时霜从边缘重新爬满。
- **三种光**：随笔是一层薄霜，项目是厚霜，瞬间的霜带一点暖。
- **凭什么成立**：霜是**遮蔽物**，内容是**被遮住的东西**。所以浅底深底都能读——浅底上霜是冷白的一层、化开后是深墨；深底上霜是灰白的一层、化开后是浅字。上一轮那个「一个外观伺候三种底」的死结在这里自动解开。
- **风险**：`breathe` 只做了边缘，这个要把「真的化开一块」做出来；浅底上霜的密度要调准，否则像蒙了层灰。

---

### 2. 花苞 `bud` — 分开

- **物**：一朵还没开的花苞（俯视的四瓣百合）。
- **悬停**：花苞张开一道缝，缝里透出一点光和一点内容——靠近时它认出了你。移开就合上。
- **展开**：花瓣向外张开、翻平，成为四片托着正文的瓣，正文落在花心；收回时合拢成苞。
- **三种光**：同一朵花，三种光。
- **凭什么成立**：审美简报点名要的花母题；而且「靠近就开、离开就合」是这个物件天生的行为，不需要额外解释。
- **风险**：正文是矩形排的，花瓣张开后必须给出一块干净的矩形；瓣得够大够平。上一轮的 `petal` 栽在轮廓上，这一版的关键全在张开之后那四片能不能铺平。

---

### 3. 显影 `develop` — 浮现

- **物**：一张还没显影的相纸（一层乳剂）。
- **悬停**：指针附近的一小片先显影，颜色从灰里浮出来，像光在乳剂上落了一下。
- **展开**：整张显影完成、放大成读面；字是从灰里**浮**出来的，不是跳出来的。收回时褪回灰。
- **三种光**：随笔显影快，项目慢，瞬间显影时偏暖。
- **凭什么成立**：审美简报里「方向 B：光学与显影」是写明的两条主线之一。而且它和霜化虽然都是「盖着一层再露出来」，物理不一样——霜是**有边界在退**，显影是**没有边界、整体一起变清楚**，一个是冷的一个是暖的。
- **风险**：容易做成一个 CSS 滤镜的淡入。要立住得让「显影」有方向、有先后，不能整片一起亮。

---

### 4. 镜映 `mirror` — 表面性质改变

- **物**：一面小镜子／一汪静水。
- **悬停**：一道反光跟着指针在面上移动，像真的镜面在转。这是六个方案里唯一一个**「你的位置被世界看见了」**的交互。
- **展开**：镜面扩大、立起来，成为一片可以读的面；正文像是映出来的——先从反的方向浮出来，再正过来。
- **三种光**：随笔的镜是天空的冷白，项目的是深水，瞬间的是暮色里的琥珀。
- **凭什么成立**：镜面在审美简报的母题表里，而且它把「景深 / 像素化」这套语言接住了——镜子本来就该反映你所在的这个空间。
- **风险**：「反着显影」做过头就变成特效。浅底上镜面要够暗才成得了镜（镜子的定义是有比周围更暗的反射）。

---

### 5. 悬落 `hang` — 整件东西移动过来

- **物**：吊着的东西——风铃、标本、一盏吊灯、一幅挂画。
- **悬停**：它轻轻晃一下（钟摆），带动周围一点点气流，邻近的碎片跟着微动。
- **展开**：它朝你降下来、摊平，成为一片读面；周围的碎片往上让开。收回时重新升回原位，还在轻晃。
- **三种光**：同一组悬挂物，三种光。
- **凭什么成立**：唯一一个「展开」真的动用**空间**而不是表面的方案。现实锚点最重（审美简报：世界负责陌生，现实物负责熟悉）。
- **风险**：实现最重，而且和现有 `deepen` / `page` 有表面相似——区别在于动的是**物件自己**，镜头不动。

---

### 6. 折展 `fold` — 形状改变

- **物**：折起来的信、地图、一叠纸。
- **悬停**：一角自己掀起来一点，像有风吹过。
- **展开**：一层层摊平、对齐成一片读面；收回时折回原样，折痕还在。
- **三种光**：折痕在三种光下是三种颜色。
- **凭什么成立**：折痕是天然的排版线索——折过的地方本来就分栏，和站内正文的分栏能接上。
- **风险**：和现有 `unfold` 重叠（那个是卡片长成面板，这个是物件本身的折痕）；要立住得让折痕在**没打开的时候**就看得见。

## 装饰（已定）

| 场景 | 装饰 |
| --- | --- |
| 随笔 | **风** |
| 瞬间 | **细雨** |
| 项目 | **星尘**（浮尘改：点更小更冷、密度更低、带一点极慢的闪） |

「风」是这三个里唯一不是颗粒的一个，这是好事——三个场景不会变成三种同质的粒子。风在空里看不见，只能通过它吹动的东西看见，所以**随笔的风最好做进流光着色器**（让那片光的 domain warp 缓慢地朝一个方向流），而不是再加一层 DOM 物件。这样随笔的「空」是真的空，只是空气在动。

## 怎么落地

- 原型改一个维度：`?scheme=thaw|bud|develop|mirror|hang|fold`，取代 `?look=` / `?hover=` / `?open=` 三件套。
- 现有的 8 外观 / 7 悬停 / 8 展开不浪费，降级成零件箱——方案里用得上就直接调。
- 每个方案的体量约等于现在的一个外观 + 一个展开，所以先挑两三个做，不要一次做六个。
