# 原型 · linescape-vault（天空的穹肋）

页面：`/mock/scene-linescape-vault/?v=a`（独立副本，只做 v=a；`&pins=1` 仍可叠加）

## 思路

在 linescape v=a（线圈 + 光 + 回声圈）之上，加一座看不全的穹顶：几道极大、极淡的肋从画面外来，
向圆汇聚。圆成了穹顶的顶眼（oculus），观者站在穹顶里、仰望它的一角。

- **数量与走向（桌面 5 道 / 窄屏 4 道）**：
  - 左：脚落在远处地平线上（被雾吃掉），拱过问句上方，再落向顶眼。它既是穹顶「立在这片地上」的证据，也替问句框出一片天。
  - 头顶两道：一道向左鼓、一道向右鼓，刻意不对称，避免读成一束放射线。
  - 右上一道几乎横着兜进圆，右侧一道贴着地平线上方进来。
  - 窄屏：左侧那道压低压平（拱高了会读成第二个圆）；头顶那道从右上角画外进来，避开页头导航。
- **透视**：每道肋是一条带，由两条边线（同一根线的回声）组成，加一条极淡的外侧回声。画外来的肋在画面边缘最宽（近），向顶眼收成一点（远）；脚在画内的肋则脚细、拱顶最宽。
- **溶进光里**：靠近圆（约 1.0R–1.4R）时渐隐并偏向光色；落到地平线以下的部分按距离指数沉进雾；近处的等高线照常从前面经过、擦掉它们落进地形的脚。
- **线的语言**：边线带与主线同一条算式（`waveAt`）的极弱静止波纹，每道相位不同；肋的起点、弯度、宽度都不等分。
- **双态**：醒面冷灰蓝、细、直；梦面偏暖（向琥珀光色）、略宽、略淡，边线波纹量化成小台阶，呼应梦面台地。

## 实现

- 全在 `src/scripts/proto/scene-linescape-vault-worker.ts`：`RIBS_D` / `RIBS_M` 定义，`ribLayer()` 画进一张离屏缓存。
- 缓存键：尺寸、DPR、窄屏、明暗（两位小数）、圆心、颜色。只有这些变化时才重画（逐小段描边、每段自己的不透明度，成本只花在重画那一刻）；每帧只 `drawImage` 一次，压在地形之下。
- 入场随 `skyIn` 淡入，滚动收拢随 `open²` 淡出。
- 其余文件只是 linescape 的副本（import / Worker URL 已改）：`src/pages/mock/scene-linescape-vault.astro`、`src/scripts/proto/scene-linescape-vault.ts`、`scene-linescape-vault-terrain.ts`。

## 性能（dev server，1440×900，醒面，入场后静置 3 秒）

| 项 | 数值 |
|---|---|
| 主线程样式重算 / 布局 | 0 / 0 |
| 主线程脚本 | 0.1–0.2ms |
| Worker 每帧（30fps） | 平均 4.8–6.2ms，峰值 6.4–10ms |
| 每帧点数 | 约 5.9k（肋不计入，走缓存） |

与无肋的 linescape v=a 基本持平：肋只在缓存重画时花钱。r3 有一次测到 8 次重算，复测为 0，判断是并行截图时的干扰。

## 已知问题

- 动态只看过静帧：入场时肋的淡入时机、收拢时与圆一起退场，没在浏览器里看过。
- 桌面左肋的拱顶离问句第一行约 40px，再宽的视口比例下可能贴得更近，没逐个宽度验证。
- 窄屏右侧那道肋进入圆的位置很靠右边缘，几乎被裁掉。
- 和 stem（巨茎）一样都压在同一团光上；若两者都保留需要选一个。
