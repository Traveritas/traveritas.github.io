# 星 · 三轴晶体星（design/mocks/star-set）

> 2026-11-15 ｜ 端口 **4680** ｜ `node design/mocks/star-set/serve.cjs` → http://localhost:4680/star-set/
> 截图冻结：`?deg=30`（绕支）/ `?deg=60&mode=turn`（整圈）

r1（双生 / 刻面 / 叠片）作者否了：要的是 **±x ±y ±z 正交三轴星**，即工具栏那颗的真立体版；
要更透、更彩；运动要老游戏式的匀速转、到了就停，r1 的缓动 + 回弹 + 抖动 + 掠光「太灵动」。

## 几何（`axisPolys`）
中心一块立方八面体（12 顶点 = 立方体棱中点 ×w），六个方面上各立一支：菱形截面（尖角朝另两条轴），
可先走一段微收棱柱再收尖；八个卦限各有一处凹口（`notch` < 1 往里收）。三种体态：
尖 `w .15`｜晶柱 `w .13, prism .58`｜胖 `w .23, notch .35`。

## 姿态与运动
`pose(yaw) = Rx(35.264°)·Ry(45°+yaw)`，与 `toolstar.ts drawStar()` 同一套角。
转法：绕支 90° / 绕屏幕竖轴 360° / 绕视线 60°，三种落地都与起点全同。
每拍固定角度（默认 15°，10 fps），第一拍立即动，转够当拍停；无缓动、无回弹。静止时零渲染。

## 材质
背面：出射折射 + 三通道色散（0.012–0.045 随「彩」）+ 全反射；正面：菲涅耳反射 × 薄膜虹彩 + 12% 正面折射 + 棱线。
环境：淡彩亮箱（丁香 / 冰蓝 / 玫瑰 / 薄荷 / 杏）+ 暗卡。体不透明度默认 0.55。

## r3（2026-11-15）
作者选了「尖」；要求运动不局限一个轴、中心的分割线太杂要「一体」。
- 几何换成 `onePolys`：24 片风筝形，每支的刻面直接延伸到卦限凹点 V（v = wL/(2L−w) 让风筝形平整），没有单独的芯。粗细三档 w .12 / .155 / .2。
- 背面不画棱线；正面棱线权重 0.42，且按到中心的距离 smoothstep(0.14, 0.5) 淡掉——中心只由刻面明暗读出。
- 新增「自由翻」（默认）：每次随机取立方体旋转群 23 个非单位元之一，绕其轴匀速转，≤120° 的有 35% 多加一整圈；帧数 = round(角度/每拍)，每拍等角，最后一拍正好落地。

## r4（2026-11-15）
- 默认参数：透 0.38（很透）、彩 0.9（浓）——作者定。
- 转动改成曲线：q(s) = 原位·Rx(θx s)·Ry(θy s)·Rz(θz s)·R(1,1,1)(θd s)，θ 为 90°/120° 整数倍，随机 2–4 项、合计 360–720°。每项终点都是自身对称，乘积也是，故落地全同；中途转轴连续变化。
- 时间：先快后慢（默认 ease-out quart，1.4s），仍按节拍定格（默认 12）。作者撤回了「匀速」：作为对话框旁的进场动画，先快后慢更合适。
- 进场：`spin(slot, { entry: true })`，同一条曲线 + 从 0 长到原大（前 45% 时间内 ease-out cubic 长完）。对话框演示里每句话都重放进场。

## r5（2026-11-15）
- 幅度收小：曲线 2–3 项、合计 270–450°（一到一圈半）。默认 2s / 四次缓动 / 节拍 10。
- 新增退场 `spin(slot, { exit: true, done })`：镜像缓动（先慢后快），后 45% 缩没。
- 对话框接法单独一页 `dialog.html`（底下垫一页假长文，台词取自 ave-lines.ts 原句）：
  A 半壁——贴底宽带，左半一颗巨大的星冲出带子上沿，14° 斜缝隔开字；
  B 越界——站上原位原尺寸的框，星在框后、比框大一圈，框内被磨砂糊开、框外清楚；
  C 左半——整个左半边升起一面 14° 斜切的玻璃，星在里面被左缘裁掉，字压在底部。
  `?layout=band|behind|half&still` 直接看落定状态。
