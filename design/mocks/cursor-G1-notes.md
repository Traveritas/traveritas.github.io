# 变体 G1 · 重晕光轮（Stratified Double-Halo）· 实测笔记

## 主张
在方案 G 水汽微露的基础上，构筑双层同心气晕（内核层 + 外轮层）与差速流体拉伸。外轮如月晕般淡雅开合，内核如微露般定锚聚焦，兼具层次丰富度与绝对手感。

## 醒 / 梦 各自的机制与关键参数
- 元素结构：`.halo-core`（2.5px 热点微核，1:1 同帧零延迟）+ `.halo-inner`（20px 内核微晕）+ `.halo-outer`（46px 发丝级半透圆弧光轮）+ `.diffraction-wave`（衍射波纹层）。
- 醒态：内核阻尼 $\tau = 80\text{ms}$，外轮阻尼 $\tau = 115\text{ms}$（差速拖尾拉伸，clamp $\le 1.25$）；冷灰银雾双环，正向对齐屏幕轴；清朗利落。
- 梦态：暖沙琥珀微温，顺时针偏转 $14^\circ$（与全站缝线倾角一致）；静止帧差（`?freeze=1`）下角度与色阶一眼可辨。
- 静息机制：游弋态由纯 CSS `g1IdleBreath` 驱动 3.6s 差频微呼吸，静止后完全不占用 JS 主线程与 rAF（静息 5s 内严格 0 次，合成层 `will-change` 归 `auto`）。

## 与方案 G 及其他变体的机制差异
- **vs G 原版**：G 为单一平滑径向光晕；G1 引入了类似月晕的大气折射分层，拥有内敛聚核与外延薄晕两重边界，在多层景深与深色背景下具有更丰富的纵深。
- **vs G2 凝露张力**：G2 偏向液滴物理的“表面张力与微湿润反光”；G1 偏向高空卷云微光下的“光学衍射光轮”。
- **vs G3 凝华羽雾**：G3 是极简羽化加相变微晶；G1 强调水汽在知觉空间中的多重层次回响。

## 实测与自检数据（.shot-cursor.cjs 实测）
- **自动化测试**：控制台错误 0 · 页面错误 0 · 失败请求 0。
- **热点同帧偏差**：`dx: 0 · dy: 0 · dist: 0.00px`（1:1 同步定锚，偏差严格为 0 帧）。
- **静息性能**：停止移动后平滑收敛，静息 5s 内严格 0 次 rAF（`rafLast5s: 0`），收敛时 `will-change: auto`。
- **DOM 写入纪律**：逐帧只写 `transform` 与 `opacity`，节点池固定为 9 个元素，零每帧对象分配。
- **状态矩阵覆盖**：
  1. `rest`：双层微呼吸，内核稳固，外轮柔和吐纳；
  2. `move`：差速流体拉伸，外轮先拖尾前倾，内核平滑跟随；
  3. `hover-link`：外轮扩大至 1.4x 转化为柔角取景圆框，内晕泛出琥珀温光（图 `05-hover-link.png`）；
  4. `hover-text / input`：外轮完全隐退，内核压缩为 1.8px 纤细微光导线，字面 100% 畅通（图 `06-hover-text.png`）；
  5. `click`：内核微缩，外轮荡出一圈极细衍射波纹（图 `07-click.png`）；
  6. `hold / latch`：外轮向心急剧坍缩收拢击穿内核，按满瞬间熔铸淬炼为全站 45° 实心琥珀结 ◆（图 `08-hold.png`, `09-latch.png`）；
  7. 降级：`?cursor=off`、`?reduced=1`、`forced-colors`、触控/笔输入全线安全回退原生指针。
