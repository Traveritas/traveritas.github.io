# 方案 F · 凝华微透镜（Frosted Resin Lens）· 实测笔记

## 主张
半透明磨砂树脂微晶片 + 1:1 热点微核。摒弃重度伪3D游戏CG与冷硬单调发丝线，追求《醒梦》黄金中庸：轻盈、通透、低饱和、微温。

## 醒 / 梦 各自的机制与关键参数
- 元素：`.fl-lens`（阻尼外框）+ `.fl-wafer`（22px 方圆微透镜 / 凝华微膜 / 折射高光）+ `.fl-core`（2px 热点微核，节点池恒定 6）。
- 醒：阻尼 $\tau = 80\text{ms}$，基准轴 $0^\circ$；冷灰高透冰晶树脂（`--wake`），内敛笃定；运动时沿速度方向微倾（拉伸 $\le 18\%$）。
- 梦：阻尼 $\tau = 130\text{ms}$，基准轴 $+14^\circ$（对齐全站缝线）；微温暖沙漫射（`--dream` / `--amber`）；静息纯 CSS 4.6s 低频微呼吸（0 rAF）。
- 静止帧差（`?freeze=1`）：醒态（`01-home-wake.png`）为 $0^\circ$ 冷灰正方圆高透片；梦态（`02-home-dream.png`）倾转 $14^\circ$ 泛琥珀微温漫射，一眼可辨。

## 与其余方案的机制差异
- **vs A/C/D（发丝极简线框）**：A/C/D 仅有 1px 细线或错位点，缺乏材质体量与介质折射感；F 具备自洽的微透镜体量与半透明树脂质感。
- **vs 早期水晶（CG过度）**：早期水晶堆叠复杂多面反射与伪3D；F 严守纯净平面图元、低饱和与微温漫射，无杂色与浮夸眩光。
- **vs E（菱芯光圈）**：E 偏机械开合硬质结构；F 为柔和连续曲率的树脂凝华微透镜，链接态展开为圆角胶囊框，文本态延展为磨砂导轨。

## 实测
- **错误计数**：控制台错误 0 · 页面错误 0 · 失败请求 0（`.shot-cursor.cjs` 实测）。
- **热点同帧偏差**：`dx: 0 · dy: 0 · dist: 0.00px`（同帧口径，采样龄 695ms）→ **0 帧延迟**。
- **静息性能**：停止移动后 `rafLast5s` 降至 0，静息 `will-change = auto`（动时提合成层），呼吸动效 100% 走纯 CSS。
- **逐帧写入属性**：严格只写 `transform`（translate3d / scale / rotate）与 `opacity`，**零**布局抖动、**零**逐帧写尺寸/颜色/边框。
- **状态矩阵覆盖（12 项实测）**：
  1. `rest`：方圆微透镜定锚，微核居中，静息微呼吸；
  2. `move`：随速微滞后 $\le 3.5\text{px}$，沿运动方向微前倾形变；
  3. `hover-link`：平滑磁吸展为圆角取景微框，微核虚化（图 `05-hover-link.png`）；
  4. `hover-text`：向内收拢为 2.4px 纤细磨砂导轨，完全不遮字（图 `06-hover-text.png`）；
  5. `input`：高聚焦插入符，微核微淡墨；
  6. `drag`：外圈放大至 scale 1.42 展现握持张力；
  7. `click`：40ms 紧缩至 scale 0.72，160ms 弹性回弹；
  8. `hold1300/2200`：透镜向心收拢旋转，微核聚能（图 `07-hold2200.png`）；
  9. `latch`：透镜坍缩至 0，微核瞬熔为实心琥珀结 ◆，与抽线无缝衔接（图 `08-latch.png`）；
  10. `scroll`：轻度收拢稳定视差；
  11. `leave`：`fx-cursor-out` 柔和淡出；
  12. 降级：`?cursor=off`、`?reduced=1`、`forced-colors`、触摸设备安全回退系统原生指针。

## 最不放心的
1. 半透明微透镜在极高对比度图片上掠过时，依赖极细高光边与微边框界定轮廓；实测在首屏纸卡与千层纸上边界清晰分明。
2. 文本阅读导轨收拢至 2.4px 时需要足够纤细以让出字面；实测完全不阻挡任何汉字字脊与字怀。
