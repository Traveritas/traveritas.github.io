三中心

400 px，只看中心那一块。六支的支尾都越过中心、互相穿过，所以中心本来就是一叠交错的窄片。 这一段的问题是：把边弯起来，中心是变清楚了还是更乱。

四尺寸

三种尺寸下，现役（直）与三种走法的最好那一档并排。看六支之间的凹口还张不张得开。 下面标的凹口是几何值；真画到像素格上再数，48 px 上直与凹 0.04 都是 3.9 px、96 px 上都是 7.3 px ——这两档在小尺寸上是同一颗星。S 0.020 才真吃亏（48 px 3.3、96 px 6.3）。

五读数

凹口半径是相邻两支之间那个内角到星心的距离——判「还读不读得出是六芒星」的尺子。 宽度剖面是在离根部 25 / 50 / 75 / 90% 处量两支边之间的宽度（直档是 3.80 → 0 的线性收）。 「腰」是比直档同站更窄的最大处，「腹」是更宽的最大处；单段凹只有腰、单段凸只有腹，两段才会有两个。 中心三栏量的是 r < 3.2 那一块圆里，被六支盖住零层 / 一层 / 两层以上的面积占比。

弯的参数是「控制点沿弦法向推出的距离 ÷ 弦长」，正号往外（凸）、负号往里（凹）。 单段时它就是 star-flat/star.js 里那个 pinch 的有符号版； 两段时结点靠「两侧切线共线」解出来，所以结点处不起折。
