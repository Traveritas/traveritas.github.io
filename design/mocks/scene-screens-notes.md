# 原型 · screens 场景首屏（屏风 / 磨砂玻璃纸层剧场）

页面：`/mock/scene-screens/`（`src/pages/mock/scene-screens.astro`，脚本 `src/scripts/proto/scene-screens.ts`）
截图：`node design/mocks/.shot-scene-screens.cjs [base] [tag] [--perf] [--perf-only]`（默认连 `astro dev` 的 4321）→ `design/mocks/_shots-scene/screens-<tag>-*.png`

## 思路

首屏是一个很浅的「剧场」：五块不同深度、不同宽度的磨砂竖屏立在线与问句之前。屏面近乎不透明，屏里贴着问句与线「化开的副本」——于是隔着屏的那几段是虚的，屏缝里是清晰的。滚动时屏按深度向右错开、屏面渐渐澄清，问句被一点点「记起」，然后整组淡出，把线交给第 1 幕。

只用抽象几何与光：竖屏、两道屏沿、一道偏心反光、屏缝里一束缓慢呼吸的光。没有任何写实物件，也没有醒 / 梦大字。

相对参考稿 p5-frames 的改进：
- **层次拉开**：远屏薄而淡（化开 2.2px、屏面密度低），近屏实而虚（化开 8px、屏沿与反光更亮）；冷雾蓝 / 中性灰 / 灰粉三种屏色交错，克制在低饱和。
- **排版守网格**：问句左沿、页角元信息贴页头 42rem 中栏的左沿；问句悬在线上方，线向右下走，字与线的空隙向右渐宽。层级三级：主句 / 引句（小一号、宽字距、次墨）/ 等宽元信息。问句完整在画面内，不出屏。
- **屏的切口是设计过的**：首字落在屏缝里（第一块屏挪到问句左侧），屏沿切过字时有一道亮沿交代「这里是一块玻璃」，不像渲染错误。

## 实现层次

- **屏**（`.pane`，DOM 序 = 远 → 近）：`overflow: hidden` + 静态的上下渐隐 `mask`；只有 `transform: translate3d(--p · --dx)` 随滚动变（`--dx = --z · 24vw`，窄屏 40vw）。
  - `.fill`：屏面。竖向底色渐变（挡住身后清晰的字与线）＋ 静态噪点颗粒 `--grain` ＋ 两侧竖向高光 ＋ 一道偏心反光（强度 ∝ 深度）。`opacity` 随澄清进度 `--clear` 降到两成。
  - `.gh`：化开的副本。一张与舞台同大的模糊图（`--gh1..3` 三档），反向平移 `−--p · --dx`，所以屏走、影不走；`opacity` 随 `--clear` 归零。
  - `::before / ::after`：左一道亮沿、右一道浅沿 ＋ 1px 极淡的暗边。
- **化开的副本**怎么来：脚本在尺寸 / 字体就绪时，把问句按每个字的版面位置（`offsetLeft/Top`，不受入场动画 transform 影响）和开屏姿态的线画进画布，`ctx.filter = blur()` 三档各出一张 → blob URL → CSS 变量。键是「舞台尺寸 + 字体状态」，没变就不重画。
- **光**（`.beam`）：屏缝里一束竖向柔光，只做 `opacity` 呼吸（11s）。离开首屏时 `html.hero-off` 暂停。
- **两态**：醒面屏磨得更实；梦面屏更透（`--dens` 随 `--reality-mix` 从 1 降到 0.8）—— 梦里隔着的东西反而更近，清晰的字隐约透出、和化开的副本叠成一点重影。线在梦面本身就是暖色的多股阶梯线，副本里的线取中性暖灰，两面都不突兀。
- **入场**：屏由远及近淡入（只 opacity），问句逐字落定，副本随后淡入；减动效时全部静帧（光束固定 0.5）。

## 性能

约束全部满足：开屏没有 `backdrop-filter`，没有逐帧的 clip-path / mask / filter；静置时没有 rAF；动的只有 transform / opacity（滚动时）和光束的 opacity（合成层）。

静置采样（`--perf`：1440×900、醒面、dev 模式，入场后 7s 起 trace 3s，取主渲染线程）：

| 页面 | 样式重算 | 布局 | Paint | 脚本 | 主线程任务 |
|---|---|---|---|---|---|
| `/mock/scene-screens/` | 0 | 0 | 0 | 1.2ms | 8.2ms |
| `/new/`（含工作区未提交改动） | 90 | 0 | 450 | 67.4ms | 217.4ms |

没测 GPU 合成成本：五块屏 ×（屏面 + 副本）约十几个合成层，每块屏一张全屏大小的副本图（1x 分辨率），显存占用值得在低端机上看一眼。

## 已知问题

- 窄屏梦面，近屏后的「在成形，」「化？」读起来更像「变淡的字」而不是「隔着玻璃的字」—— 屏太透时清晰原字的漏光压过了副本。要么梦面窄屏单独提高密度，要么接受为梦面的重影。
- 副本里的线是开屏姿态的直线；线本身的波动（尤其梦面的阶梯）在屏后被抹平了。离屏较远看不出，凑近屏沿能看到屏内外的线不完全接续。
- 屏沿切过字时偶有半个字的切口（如「究」「融」），这是方向本身的语言，但若嫌碎，可以把屏沿对齐到字缝（按字位算屏的 `--x`）。
- 窄屏页头导航被挤成竖排 —— 共享页头的问题，`/new/` 同样，不在本原型范围。
- 副本按入场时的 `--fg` 画一次；滚动后色板变化不影响（屏在 p≈0.5 前已淡出）。
