# cards-r1 · 卡片与展开：语言探针

> 2026-11-01。这一批不修细节，提出**三条能管整站的语言**，用「目录页的卡片」和「展开后的那块面板」当试纸。
> 每条语言都要能回答：卡片之后，文章详情页、页头、工具栏这些地方，跟着它会长成什么样。

## 为什么要动

现在的卡片更像「网页卡片」：几乎不透的白矩形、硬角、重投影、一道标准标题栏。它清楚地完成了功能，
但它和这个站一直在说的东西（玻璃 / 悬浮 / 正在成形 / 随时会消失）没有关系——它只是浮在空间上面的一块板。
展开时更明显：那扇窗「长大」成一张网页，前后不是同一种东西。

三条语言各自给一个不同的答案。**不要做成同一套的三个皮肤**，它们的前提必须真的不同。

---

## 甲 · 雾片 `mist`

**命题：卡片不是一块板，是一片雾。**

去掉标题栏、边框、重投影。留下的是：一层几乎无色的雾、一道沿边的亮线、以及字本身。
层级不靠框、不靠投影，靠字的密度、雾的浓度、留白和坐标关系。

- 卡片与背景的边界由**光的落差**给出，不是由描边和阴影给出。
- 展开时雾面顺势变宽变长，正文落进同一片雾里，中间不出现「新的一块」。
- 判据：把卡片挪到任意一张背景上，它都不显得是「贴上去的」。

## 乙 · 斜切 `bevel`

**命题：那道 14° 不是背景装饰，是卡片的结构。**

卡片本身按 14° 组织——切角、栏的错落、标题落的位置都顺着它；三栏的卡片沿同一条斜线一级级落下。
展开不是「长大」，是沿这条斜线把卡片拉长成一条可以读的东西。

- 形状就是标识：卡片的轮廓被单独抽出来，还认得出是这个站。
- 判据：把卡片轮廓抽出来看，它是可辨认的剪影。

## 丙 · 开口 `aperture`

**命题：卡片是空间里的一个开口，不是贴上去的板。**

卡片内部看到的是它背后那一层空间（更深的暗、另一种距离、一点视差或折射），文字浮在开口前面。
展开＝走进这个开口：开口撑满屏幕，正文在开口的另一侧。

- 卡片要有「里面」，不是「上面」。
- 判据：看久了会觉得卡片后面还有东西，而不是卡片上印着东西。

## 硬约束

**范围**
- 只写 `design/mocks/cards-r1/<你的案子>/`。不动 `src/`，不动 `shared/`，不装依赖，不跑 `npm run build`。

**内容**
- 卡片与正文只用 `shared/fixture.md` 里的真内容。**不要自造标题和名词**——站内字体（Noto Serif SC）是按站内用字切分的，
  新词可能没有字形，会显示成方块，看起来像设计坏了。
- 双态（醒/梦）可以只做一面，但要在 `notes.md` 里说清另一面怎么接。

**气质（《醒梦》）**
- 低饱和、玻璃 / 磨砂 / 树脂、柔光、大面积留白。
- 极简不等于空：必须有材质、空间、光的关系，不能退化成「几个方块摆在空白上」。
- 不做废土、赛博朋克、Dreamcore 现成符号（空商场 / 老录像滤镜那类）。

**文字红线**
- 不写「这是梦 / 你在做梦 / 快醒了」这类自我标注。
- 不写台账、审计、核验一类词汇；不写极客中二叙事。

**固定件**
- 左下角的星（工具栏）不改。**也不要在画面里画一个假的**：给它留出 120×120 的空位就行。

## 交付

### 1. `index.html` —— 自包含，三种状态

| 状态 | 触发 | 内容 |
| --- | --- | --- |
| 检索 | 默认 | 1440×900，三栏（随笔 2 张 / 瞬间 2 张 / 项目 2 张），栏头保留编号 · 名字 · 条数 |
| 展开 | 地址带 `#open` | 同一页切到读的那块面板；背后的三栏还在（压暗、退开、或按你的语言处理） |
| 窄屏 | 视口 ≤ 720 | 一列，同一套语言，不是「手机版的另一种设计」 |

- 用 `#open` 切换（`location.hash` 或 `:target`，都行），不要做点击交互。
- 字体：`<link rel="stylesheet" href="/fonts/noto-serif-sc/font.css">`，然后 `font-family: 'Noto Serif SC'`。
  等宽用 `/plex/ibm-plex-mono-latin-400-normal.woff2`（可选）。
- 配图：`shared/img/` 下两张（`moment-1.png` 4:3 构图片、`moment-2.jpg`）。
- 骨架可参考 `shared/boiler.html`（可选，别照抄样式）。

### 2. `notes.md` —— 六段，短句

1. 命题一句话
2. 卡片：信息与层级（每样东西在哪，为什么在那）
3. 展开：怎么从卡片来到这里
4. 外推：按这条语言，文章详情页的顶部（标题 / 元信息 / 开篇）会怎么排——写 5–8 行，不用做
5. 成本：实现上最贵的是哪一块（如果知道的话）
6. 最容易做坏的地方
