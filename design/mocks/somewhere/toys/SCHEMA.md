# 小东西 · 数据契约（SCHEMA）

每条小东西是一个对象。所有作者都按这一份写，索引页按这里的字段筛选。

## 字段

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `id` | string | `^[A-J]-\d{3}$`，前缀＝方向字母，编号连续不复用 |
| `scene` | string | 与 id 前缀相同 |
| `awake` | string | **醒态名字**，2–6 个汉字，清楚、质朴、一眼看懂是什么 |
| `dream` | string | **梦态名字**，2–6 个汉字，同一样东西的另一种叫法，轻、悬、有知觉悖论感 |
| `what` | string | 一句话说它是什么、做什么。**≤ 42 字**，不解释机制 |
| `trigger` | enum | 见下，单值 |
| `reply` | enum[] | 见下，1–2 个，按主要程度排序 |
| `intensity` | number | 1 / 2 / 3 |
| `memory` | enum | `无` / `本次` / `跨次` |
| `time` | enum | `无` / `夜里` / `随夜分期` / `每分钟` / `累积` |
| `effort` | enum | `S` / `M` / `L` |
| `note` | string? | 可选。一句风险、副作用或「容易做坏的地方」。**≤ 40 字** |

## 枚举

**`trigger`（怎么碰上它）**

| 值 | 意思 |
| --- | --- |
| `靠近` | 走到某个距离才成立（深度 / 焦平面那套） |
| `停留` | 不动，等它自己发生 |
| `悬停` | 指针停在上面 |
| `点击` | 按一下 |
| `长按` | 按住不放 |
| `拖动` | 拖 / 划 / 拉 |
| `滚轮` | 用推拉 |
| `离开` | 你走了以后它才动 |
| `无人` | 不需要你，自己在那儿 |
| `输入` | 打字、说一句话 |

**`reply`（它怎么回应）**

| 值 | 意思 |
| --- | --- |
| `光` | 明暗、颜色、亮度 |
| `形` | 轮廓、形状、材料、像素 |
| `字` | 出现或改变的一行字 |
| `位移` | 位置、距离、速度的变化 |
| `声音` | 有声音（环境声的一层，不打断） |
| `静默` | 它什么都不做——不做本身就是回应 |

**`intensity`（扰动强度）**

| 值 | 意思 |
| --- | --- |
| `1` | 几乎不察觉，要走神一下才发现 |
| `2` | 明显，但克制，不打断 |
| `3` | 会让人停一下，值得专门去找 |

**`memory`（记不记得你）**

| 值 | 意思 |
| --- | --- |
| `无` | 每次都是新的 |
| `本次` | 这一次访问里记得 |
| `跨次` | 下次来还记得（`localStorage`） |

**`time`（跟不跟时间走）**

| 值 | 意思 |
| --- | --- |
| `无` | 跟真实时间无关 |
| `夜里` | 只在夜里出现（站里 23:07–06:31 那一套） |
| `随夜分期` | 随 `night.ts` 的分期变色 / 变行为 |
| `每分钟` | 按分钟换位置 / 换状态 |
| `累积` | 攒着，攒够了才发生 |

**`effort`（工程量）**

| 值 | 意思 |
| --- | --- |
| `S` | 半天以内，纯 DOM/CSS 就能做 |
| `M` | 一两天，要一点状态机或画布 |
| `L` | 三天以上，要新写一个子系统 |

## 文件

每个方向一个文件：`data/<方向>-<序号>.js`（如 `data/A-1.js`）。

```js
/* A · 远处的地形 · 001–050 */
(window.TOYS = window.TOYS || []).push(
  {
    id: 'A-001',
    scene: 'A',
    awake: '远灯',
    dream: '它记得你来过',
    what: '脊肩上的一粒光，你停下来看它，它才慢慢亮到能看清脚下有一道竖痕。',
    trigger: '停留',
    reply: ['光', '形'],
    intensity: 2,
    memory: '本次',
    time: '无',
    effort: 'S',
    note: '亮得太快就成了指路牌',
  },
  // ……
);
```

```bash
node design/mocks/somewhere/toys/check.cjs        # 校验全部 + 报统计
node design/mocks/somewhere/toys/check.cjs A-1    # 只校验一个文件
```
