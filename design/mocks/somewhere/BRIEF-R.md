# r 组简报：一处室内 · 四个变体

**只写你自己的 `r-X.html` / `r-X.js` / `r-X.css`。`shell2.js` / `room.js` / `approach.js` / `r.css` / `light.js` / `server.cjs` / `shot.cjs` / `r0.html` 是共用底子，不许改；也不许动 `s-*` 那些旧文件与 `src/`。**

---

## 这一轮和上一轮的区别（重要）

上一轮（`s-*`）有一个设计错误：进来时检索页的三栏是三种夜色，而五位作者都把那三栏「塌成了三条带」搬到目的地，于是每个场景底下都横着三道色。用户的原话是：**「为什么所有设计都是要把三个颜色都放到下面来，从主页到检索页是可以通过精巧的设计过渡的」**。

这一轮的前提反过来了：

- **只有一套色。** `shell2.js` 的 `initFlow({ theme })` 只吃**一组**四色（底/中/光带/亮芯），三个槽填同一份，**分区这件事在这里不存在**。别再造三条带。
- **过渡是下沉，不是塌陷。** 镜头从空间上方落进房间，流光整片往上淌（你下去，它上来），房间从远处涨大直到把你包住。没有分栏、没有劈开、没有换色板。
- **优雅来自变换本身**，不来自保留原有的颜色。

## 房间的设定（用户给的）

一间屋子，**上半浸在梦一样的流光里，下半是另一种画风**。分界叫**梦线**（`room.js` 里的 `dream`，默认占房高的 44%）。

- 梦线以上的墙面、以及天花板：**不画就自动透出流光**。你要不要画、画成什么样，是你的风格决定。
- 梦线以下：**另一种画风**。这是你最大的自由——它可以是版画、可以是等高线、可以是网点、可以是某种极简的线描。但它必须和上面的像素流光**明显不是同一支笔**，否则「浸入」这件事就不成立。

## 统一交互（已经做好，你别重做）

- **点屏幕左侧 32% → 向左转**，**右侧 32% → 向右转**；每一站看的是**一个墙角**（两面墙在画面中间交成一条竖棱）。
- **点屏幕上方 22% → 抬头看天花板**，再点回平视。
- **鼠标移动时视角微微跟着走**（±3° 级别的浮动，别自己去读鼠标）。
- 键盘：`←` `→` `↑` `↓` `R` 复位。滚轮也能转。触屏点两侧同样有效。

这套手感由 `room.js` 提供，你只需要**把你的画法挂上去**。

## `room.js` 给你什么

```js
import { createRoom, trace, baseRow } from './room.js';

const room = createRoom({
  autoArrive: opt.autoArrive,   // 截图用，见下
  dur: 3000,
  dream: 0.44,                  // 梦线高度比例（想调就调，但四个变体尽量靠近）
  h: 3.0, d: 4.6, eye: 1.34,    // 房高、房深、眼高
});

room.onPaint(({ faces, g, arrive, sink, vw, vh, dreamY, W, H, D, F }) => {
  // faces 已按远近排好（远的在前），每个：
  //   k: 'back'|'right'|'front'|'left'|'ceil'|'floor'
  //   below / above：裁好投影好的屏幕多边形（可能为空数组）
  //   line：[{x,y},{x,y}] 梦线在这一面上的屏幕段（天花板与地没有）
  //   depth（越小越近）、near（0–1）、center、bbox
  // g 是 2D 上下文；canvas 是 0.65 分辨率、CSS 拉满的（像素格与底下流光同一手感）
  // arrive 0→1（进站进度）、sink 0→1（房间涨大进度）
});

room.start();
```

`trace(g, poly)` 把多边形设成当前路径（返回 false 表示点太少）。`baseRow(face, t)` 给这一面「从左到右 t」的那条竖线，两个端点。

## 硬约束

1. **一个 WebGL。** 背景只能是 `initFlow`。你的房间画在 2D canvas 上（`room.js` 已经给你了），别自己再起 canvas 叠一层、也别再建 GL 上下文。
2. **安静。** 低饱和、同一色族、亮部很少。禁高饱和撞色、禁彩虹、禁贴纸感、禁 CDN、禁新字体（`Noto Serif SC` 与 `--font-mono` 已挂好）。
3. **文案红线**（逐条遵守，写完自己 grep 一遍）：
   禁「针、缝、穿针、针脚、八针、缝合」等手作语汇；禁「这是梦 / 你在做梦 / 快醒了 / 读起来像梦话」；禁「账目 / 台账 / 案号 / 待立项 / 构想条目 / 相关档案 / 可核验」；禁「白昼写代码，夜里构筑世界 / 活跃坐标 / 占用公网地址 / 代码变成落雪」。
4. **字要真的看得清**，纯装饰层 `aria-hidden`。
5. **`prefers-reduced-motion`**：停掉自走动画；但关掉动效之后它仍然得是一处地方。
6. **性能**：0.65 分辨率的 2D canvas 够用；不要每帧重建大数组，也不要用 `filter: blur()` 去糊大面积。
