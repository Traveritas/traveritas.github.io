# p17 · 构块场（拼接）× 定距回溯 × 1Hz 抽帧 × 谐波残影

## 主张
两态差不是「换一件东西」，而是**同一片流动被两种采样率读出**：醒态整片构造体沿 14° 朝右下**单向匀速**流动、块与块之间均匀留 1–2px 缝（读得出「拼接」）；梦态同一股流动被**按 1 秒采样**读出（阶梯漂移 + 1 拍阶跃 + 谱带/残影同拍跳动），整片场恒定朝左上退 260px，接缝裂开、交叠处透出 1px 琥珀窗。

## 醒
- 三档视差 104/84/66s（23.1/28.6/36.4px/s，沿 `--seam-angle` 14°）+ 2400px 周期**单向**漂移：每档内容生成一份 → 复制两份、第二份整体位移 −(2329,581) ⇒ t=1 帧里走出画面的正是 t=0 帧候在屏外的那份（首尾逐像素同帧，不需要任何 JS）。
- 拼接几何在生成期烘焙：渲染尺寸 = 格距 m − 缝宽 g（远档 1px、中/近档 2px），相邻两块的间隙恒 = g、整数像素；tiled 与 loose **同一套尺寸** ⇒ 过渡只需 transform，不会逐帧改 width/height。
- 醒态只保留一类动画：3 条 `.fld-pan`（单向漂移，用户明确要的那条）。`.fld-saw / .fld-step / .echo-crawl / .echo-walk` 共 13 条在跑，但振幅全含 `--still` ⇒ 醒面 computed transform 恒等（实测 0 位移）。
- 并进来的 P15-B 那一层在醒态「什么都没多」：三种对照逐像素 **0/1 296 000 差、最大通道差 0**。

## 梦
- 拍 = `--fld-beat`（默认 1s）：锯齿采样（每拍前跳 DX/dur ≈ 22.4 / 27.7 / 35.3px）+ 7 档整数像素阶跃 + 四道谱带爬行（7 拍一循环）+ 三道残影游走（5 拍一循环），**全部同相**（`animation-delay: 0`，取消全部负延迟错相）。
- 回溯：`.fld-rewind` 恒退 (252, 63)px（= 260px 沿 14° 反方向），幅度 = `smoothstep(--still)` ⇒ 按下 0 速起、闩锁 0 速止、中途松手按比例退回。
- 松弛：每块沿它挑中的那条共边的法向滑开 0.30–0.52 格距 + ±0.12 格距切向错开；交叠解析求交 → 1px 琥珀窗（每份副本一个 opacity 组，逐帧只改 6 个元素）。
- 脑电（P15-B 整段搬入）：主波 4px 量化 + 零阶保持成直角阶梯，另 3 道延迟副本（步长 ×2/×3/×5、冷暖分层、±1~3px 同拍游走）。

## 四条反馈各自怎么落的
1. **恢复单向漂移**：`.fld-pan` 从变体二的「0→A→0 往返」改回 D 稿的 `from 0 → to (+DX,+DY) linear infinite`。★ 这一条**永远连续满幅运行，绝不乘 `--reality-mix` / `--still`**（代码里写死了这条纪律）—— 一旦乘幅度，梦态就会归零、回溯距离重新绑回「已经漂了多久」。
2. **定距回溯**：把「漂移」与「回溯」解耦。原版越漂越远的原因：它把漂移**幅度**乘了 σ(醒度)（梦态幅度 0 ⇒ 场被拉回生成原点），于是回溯距离 = 已漂过的累积位移（实测最多 2329px）。本稿漂移照跑，回溯交给独立的 `.fld-rewind`：**一行调 `--fld-rewind`（默认 260px）**，也可 `?rw=NNN` 覆盖（脚本按 14° 取整分解成 `--rw-x/--rw-y`）。想更短/更长只改这一个数。
3. **一秒一拍**：不是把动画调慢，而是**换采样率**——连续漂移之内套一层 1Hz 锯齿，总位移 = 连续位置 − 不足一拍的余量 = 每拍采一次样的位置；幅度有界（≈ 一拍的漂移量，20–36px），所以乘 `--still` 不会引入「回溯距离随时间增长」的问题（与 ② 同一条纪律）。再把全部抽帧元素统一到 1 拍、同相。
4. **边之间空 1~2px**：生成期就把每个正方形沿共边法向缩进（远 1px / 中近 2px）。两条断言重跑，读数见下。
- （Part 5）P15-B 的谐波残影整段搬入：BG SLOT 的四道 `.esb` + EEG SLOT 的 `eegPathD/eegDraw` + 三条残影 `<path>`（改成 markup 常驻，动画相位因此与背景场同起）。

## 最不放心的
1. **梦态脑电主波仍是 30fps 连续流动的阶梯**（外壳那条 rAF 在逐帧重写 `d`），不在 1 拍之内。用户的抱怨原话是「背景的线…每次位移之间的时间太短」——如果这条线也算，一行改法是在 `eegDraw` 里把相位量化到 1 拍（`Math.floor(ph)`）。我没擅自改：它对应线上 `src/components/chrome/Eeg.astro`，是**每页都有**的全站组件，而醒态必须与线上逐字一致。
2. **长按时漂移不停**（这正是「世界先继续流动」的那半边）：1.6s 的按压里漂移仍在跑 37–58px，所以「按下→闩锁」的**净**位移读数是 227–233px 而不是 260px；机制上的 260px 是从四层拆解里得到的（残差 0.00），逐像素的纯位移对照也是 260px。若希望净位移也读成 260px，唯一出路是长按期间把漂移一起停住。
3. **边缝是「两条 1px 边线夹一条 1~2px 底色」**（视觉上 3–4px 的带），不是「两条 1px 重叠成一条更深的线」——P16-B 声明过的同一条取舍，本稿沿用（零重叠是硬约束）。
4. **构体数少一处**：请求 24 处/份，实际 23 处/份（近档 7 而非 8）。为让两份副本的 u 区间不相交（跨副本零重叠），`UEDGE=1180` 把生成区压到 ±830×±760，占位框互斥把最后一处挤掉了。想更满：放宽 `UEDGE`（代价：副本可能撞上）或调小 `gapU`。
5. `.fld-saw/.fld-step/.echo-crawl/.echo-walk` 在醒态也在跑（恒等变换）。若裁决要求「醒态 animation 计数 = 0」，把它们挂到 `body[data-reality='dream']` 下即可，代价是「先醒后长按」这条路径上齐拍相位会与漂移错开——本稿为了同相故意不挂。
6. 共用脚本 09 号裁片是文档坐标（四稿同病）；缝的 3× 裁片与像素剖面另出在 `.shots-p17-extra/{zoom3x-wake,zoom3x-dream}.png`。
