# 方案 C · 悬丝（−4° 单笔画）· 实测笔记

## 主张
一根 1px × 9px 的发丝自 2px 热点悬垂，角度是一个钟摆：醒态绷直锁 −4°，梦态会摆、会过冲、慢慢落回 −4°；长按只是把这根 −4° 的发丝抽长（与 reality.ts:217 的 drawThread 同角）。「醒是绷直的一笔，梦是会摆的一笔」不是两个图形，是同一条线的两种读法。

## 醒 / 梦 各自的机制与关键参数
元素恒为 .cur-dot（2px 热点，中心恒与鼠标同位，1:1）+ .cur-line（1px × 9px，transform-origin 顶端）。
角度用等角弹簧：θ̈ = k(θ_t − θ) − c·θ̇，θ_t = θ_rest + clamp(vx·0.016, ±22°)，vx 为横向速度 px/s（τ = 75ms 衰减）。线长走指数放松（醒 τ = 75ms / 梦 τ = 150ms），缩短只写 scaleY。
- 醒：k = 900、ζ = 1.00、θ_rest = −4°、线长 9px、点透明 1.00。由 +13.5° 摆回 −4° 约 0.55s，**0 过冲**（单调 13.3→5.0→−1.4→−3.8→−3.98）。
- 梦：k = 250、ζ = 0.24、θ_rest = −7.2°、线长 11.6px、点透明 0.60（另消费 --still，令线/点色再淡 24% / 16%）。过冲 46%：+15.3°→−9.3°→+11.2°，约 1.9s 收敛到 −7.22°；末端另有 τ = 150ms 的长度延迟＝「飘」。
- 静止帧差（?freeze=1）：醒 rotate(−4deg) / scaleY 1.000 / dot 1.00；梦 rotate(−7.2deg) / scaleY 1.289 / dot 0.60 —— 角度、线长、点透明度三项同时差，不是「动 vs 不动」。
- 角度上限 ±22°；装饰**横向**偏移峰值 = hover-link 的水平短划 10.4px（≤ 12px），移动态 ≤ 6.5px。

## 与其余三稿的机制差异
- A 残点：按**行进距离**落点、寿命也按距离给定，刻度在空间，静止零残点；C 无任何副本 / 拖尾，距离不参与，全部状态只落在**一个连续的角度与长度**（钟摆状态量）上。
- B 四点环：机制是**缺口开合 + 进动**的整环角度运动，是围合图形；C 是单笔画，无环、无缺口，靠自身摆动而非图形开合。
- D 错位双影：机制是**偏移量即透明度**（两个相同图元，「对齐」本身成为可读量）；C 只有一个图元，可读量是角度滞后，不是位移错位。
- 与站点：长按直接落回站点自己的 −4°（不改角、不改锚点），是四稿里唯一与 reality.ts 抽线同角的机制。

## 实测（自检面板 + 独立放大采样；控制台错误 0 / 页面错误 0 / 失败请求 0）
- 热点偏差 Δx **+0.00**、Δy **+0.00**、d **0.00 px**（同帧口径，6/6 次 pointermove 采样全 0）→ 延迟 **0 帧**。
- 静息：末次移动后 6s 读 `rafLast5s` = **0**（醒、梦各测一次；`rafTotal` 停在 52 不再增长）。逐帧只写 `transform` / `opacity`（line、dot 各两项），无颜色 / 宽高 / 圆角 / filter / box-shadow / background 写入；线长只走 scaleY。
- 静息 `will-change` = **auto**（仅运动 / 过渡期打 .is-live → transform）；`#cursor-slot` 元素数 = **2**（恒定，峰值 2）。
- 12 状态（醒态数值 = rotate / scaleY / 点透明；放大图见 zoom-state-*.png）：1 静息 −4 / 1.00 / 1.00 · 2 移动 16 / 1.18 / 1.00 · 3 悬停链接 −90（躺平）/ 1.16 / 0.55 · 4 悬停正文 0（竖直插入符）/ 0.86 / 0.26 · 5 输入框 0 / 0.68 / 0.20 · 6 拖拽 −18 / 1.85 / 0.80 · 7 点按 9（真实为 ζ=0.3 欠阻尼左右各响一次）/ 1.00 / 1.00 · 8 长按 1300 −4 / 1.90 = 17.1px / 0.92 · 9 长按 2200 −4 / 2.45 = 22.1px / 1.00 · 10 闩锁 −4 / 0.50（收拢一次）/ 1.00 · 11 滚动 −4 / 0.62 / 0.90 · 12 离开窗口 −4 / 1.00 / 0.16（强制帧取淡出中途，终态为 0）。
- 降级实测：`?cursor=off` → urlAllowed 0、fx-cursor-on 0、slot opacity 0、body cursor **auto**；`?reduced=1` → rm 门 0、fx-cursor-on 0，本层走 RM 静态路径（直取位姿、不入弹簧）**rafTotal 0**、线恒 rotate(−4deg) scaleY(1)、**无摆动**；`pointerType=touch`（派发 touch 事件）→ fx-cursor-on 1→0、lastPointerType=touch、body cursor **auto**；`forced-colors: active`（CDP 仿真）→ fc 门 0、fx-cursor-on 0、slot opacity 0。
- 长按不自己造站点特效：全屏抽线 / 成结由外壳 `.fx .thread` 负责，本层只观察 body.reality-holding 把自身发丝抽长（17.1 / 22.1px），不自画全屏线。
- 截图脚本勘误：`.shot-cursor.cjs:114` 会自行补 `.html`，故 FILE 必须传 `cursor-C-filament`（不带扩展名）；按简报写 `cursor-C-filament.html` 会请求 `.html.html` → 404「not found」。四稿共同踩这个坑。

## 最不放心的
1. **9px 线是否太弱：自评「偏弱，但在本站极简尺度下成立」**。1px 线在 1440×900 约占屏高 1/160；静止时靠 2px 高对比点定锚、靠醒态 0 过冲的「不抖」立可信度，放大 8× 看是笃定的，但正常浏览尺度下存在感确实弱于任何 ≥2px 的方案。若要补强，建议只把点提到 2.5–3px（仍 1:1、不增元素、不发光）。
2. 简报写「线被吹向运动方向」，我实现的是钟摆的自然滞后（右移时尾端拖向左 = **背向**运动方向）。与「滞后并过冲」自洽，但与字面方向相反；要顺向只需把 KVEL 取负。
3. `?freeze=1` 下本层不再积分弹簧（直取位姿），为的是让两张静止帧是收敛位姿而非摆动中途；代价是冻结档本身看不到摆动，摆动证据只有采样数字与 zoom-state-move.png。
4. 「装饰最大偏移 ≤ 12px」我按**横向**口径自测（峰值 10.4px）；长按时线沿自身轴向抽到 22.1px（尖端离点 22px），若裁决把轴向长度也算偏移则超标 —— 但简报本身要求长按「延长」，二者只能取一。
5. `drag` 与 `hold2200` 都表现为「线变长」，只靠角度（−18° vs −4°）与长度区分；梦态低阻尼下二者都不摆，区分度一般。
6. 滚动态是 150ms 的瞬时态（由 scroll 事件驱动），长滚动时会被反复重置，视觉上接近「一直很短」。
7. 未测：真实 NVDA / VoiceOver、笔设备、200% 缩放（本轮无环境）；`?state=leave` 强制帧是淡出中途 0.16，不是终态。
