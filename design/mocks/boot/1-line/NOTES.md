# 开屏 mock 1 · 一线先醒

`index.html` 单页，原生 JS，不依赖构建。
截图：`node design/mocks/boot/1-line/.probe.cjs`（产出 `probe-*.png`，五个相位）。

---

## 1. 机制

首页那根 **14° 的线**先醒过来，再从"一根线"长成"一整片首页"。

1. **起笔是一粒光。** 画面先是一整块靛夜（`#0e0f1d`，就是首页的底色，不是暖白）。轴线的正中偏左，一粒光先亮起来。
2. **线从光里长出来。** 两头各带一个光头，沿 14° 同时往两边走。刚起步时它在**起伏**（就是首页的脑电线），随着走出画面，起伏一点点收平，最后是一根干净的发丝线。
3. **光跟着线漫开。** 线走过的地方，三池夜色按顺序极淡地渗出来（随笔浅蓝灰 → 瞬间紫 → 项目深蓝）。它们始终很淡，是"夜色在扩散"，不是"三块色块铺开"。
4. **不撕幕，只淡出。** 没有 mask、没有破窗、没有挖孔。线画满的那一瞬，整层开始 opacity 淡出；淡出过程中的每一帧，底下已经是首页自己的样子。
5. **交接不重新开始。** 线的进度 `reveal` 同时喂给 `HomeMock.line()`——开屏画到哪儿，首页就从哪儿接着往两端画完。观者看不出换手。

---

## 2. 时间轴（总长 2000ms）

| 相位 | 毫秒 | 发生什么 |
| --- | --- | --- |
| **起笔** | 0 – 190 | 一粒光在轴线上亮起、放大 |
| **一线** | 130 – 840 | 两个光头沿 14° 向两端走出画；线跟着露出来；光头先放大成短棒再收细 |
| **漫开** | 140 – 1030 | 三池夜色从线上渗出；起始的"粗颗粒"（`pixels(9)`）一路收到 `pixels(1)` |
| **对焦** | 600 – 1500 | 大字从 blur(14px) 对上焦 |
| **三扇门** | 960 – 1400 | 三个栏头挂到线下，各自的琥珀点先从 2.4× 收成 1 |
| **收尾** | 1300 – 1900 | 时刻、出口、下沉依次浮上来；整层淡出到 0 |
| **静置** | 1900 – 2000 | 只剩首页 |

## 3. 与首页的接缝

- **同色底**：幕就是首页靛夜，所以"淡出"不是换肤，是同一块夜慢慢变清楚。
- **同轴**：线的角度、位置（`y = 50vh + (x − 50vw)·tan14°`）与首页一致。
- **同源起伏**：线上的起伏直接借用脑电线的振幅（约 3.6px），起笔时它最明显，收尾时归零。
- **接管入场**：`HomeMock.focus()` / `line()` 由开屏驱动，首页原本那两段（1.6s 对焦、2.2s 画线）不在幕底下白演。

---

## 4. 代价与风险

1. **线在暗底上很细**，低亮度屏或强光下可能几乎看不见。真站里线宽与不透明度要按 `--fg` 反推，不能写死。
2. **起笔那粒光**是整段唯一的"亮点"；如果页面夜色偏浅（随笔页 `#c6ced9` 那一段），它要换成深色，否则看不见——这一版只做了主页靛夜。
3. **没有"打开"的动作**：整层是 opacity 淡出，没有几何事件。好处是永不跳色，坏处是揭幕的"那一刻"偏弱，观者可能说不清页面是从哪一帧开始的。
4. **三池渗出**在窄屏（390px）上会挤成一片，手机帧里能看出来。
5. 性能：全程只有 transform / opacity，元素约 8 个。但 `HM.pixels()` 会写 `.h-flow` 的 `transform` + `filter`，那是一条**整屏 filter**，手机上有成本；真站里应该换成 canvas 分辨率的整数倍缩放，而不是 filter blur。
