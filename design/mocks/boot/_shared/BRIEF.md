# 开屏 mock · 共同任务书

本文件给并行做开屏原型的子智能体读。读完再动手；不清楚的按「无法确定就先做最小可信版本」处理，不要停下来等。

## 0. 你要做的

在 `design/mocks/boot/<你的目录>/` 里做一个**能直接打开看的开屏原型**（HTML + CSS + JS，单页，不依赖构建）：

```
design/mocks/boot/<目录>/index.html      原型
design/mocks/boot/<目录>/.shot.cjs       截图脚本（照 _shared/shot.template.cjs 改）
design/mocks/boot/<目录>/NOTES.md        设计说明：机制、时间轴、与首页的接缝、代价
design/mocks/boot/<目录>/.shots/*.png    截图产物
```

跑截图：`node design/mocks/boot/<目录>/.shot.cjs`（Playwright 已可用，路径写在模板里；服务用 `_shared/server.cjs`）。
最终产出**至少 6 张桌面帧 + 2 张手机帧**，并且自己看一眼截图确认没有明显崩坏再收工。

## 1. 原型必须做的事（验收线）

1. **它模拟的是「开屏 + 首页第一帧」的连续过程**，不是孤立的 logo 动画。原型里要有一个**假首页**（不用做真的漫游/WebGL），只需还原到「一眼认出是那个首页」：靛夜底、一根 14° 线、左上大字 Traveritas（或梦面 AveritA）、线下三个入口、左下时刻。
2. **开屏要交接到首页**，不能是「遮罩一撤，首页从别的状态突然出现」。最后一帧应当**就是**首页静置的样子。
3. 时间轴总长 **1.2–2.4s**（含交接）。主页每次进入都可放（不再只是首访）。
4. 只允许动 `transform / opacity / filter`（`filter` 慎用，全屏 blur 很贵，只在 < 300px 的小盒子上用）；蒙版必须静态；目标 60fps、手机中端机不卡。
5. `prefers-reduced-motion: reduce` 时**不放**，直接落首页。
6. 无 JS 时不得留一块死幕。
7. 必须实现统一控制口（截图与验收都靠它）：

```js
window.__boot = {
  ready: true,        // 素材到位、可以开始截图
  pause(),            // 停表
  seek(ms),           // 把整个开屏（含 CSS 动画与 canvas）确定地推到第 ms 毫秒
  resume(),
};
```

`seek` 必须对 **CSS 动画**也生效：最稳的写法是**不用 CSS `@keyframes`，全部时间轴写在 JS 里**（canvas / Web Animations `currentTime`）。如果非用 CSS，就用 `document.getAnimations()` 统一设 `currentTime` 并 `pause()`。

## 2. 现在的首页（交接对象）——事实，别猜

- 底色 `#0e0f1d`（主页靛夜）。三个版块各有自己的夜色池：随笔浅蓝灰 `#c6ced9`、瞬间紫 `#1d1729`、项目深蓝 `#0d1524`。
- 一根 **14° 的线**过屏幕中心（`y = 50vh + (x − 50vw)·tan14°`）。静置时它**就是**全站的脑电线（一条会起伏的波形，振幅约 3.6px，沿这根轴）。往下滚时它先收平成直线，再转 90°、劈成两条缝。
- 左上：小字 `个人网站`（梦态 `昼梦叙集`），下面是大字 **Traveritas**（clamp 54–128px，衬线 500）。大字本身是一扇「反相窗」：它下面的流光被反相后按字形遮罩 —— 也就是**大字是流光的一块窗户**，不是一个色块。
- 三个栏头挂在线下：`01 断章 ESSAYS`、`02 闪念 MOMENTS`、`03 造物 PROJECTS`，各带一粒主题色（`--amber #9a86c4`）的点。
- 左下 `21:34 · 2026-10-18`；右下 `GitHub  RSS  ◇NEXUS`；底部中间 `下沉 ↓`。
- 背景是 1/5 分辨率上采样的**像素化流光**（fbm 噪声 + 4 色域 + 26 级有序抖动 Bayer）。所以整片光天生是**粗颗粒、有网点感**的。
- 首页入场已有两段：大字从 blur(14px) 对焦到清楚（1.6s）、脑电线从中心往两端画出（2.2s）。这两段现在**被开屏压在下面白演了**。你的方案要解决这件事：要么接管它们，要么让它们接着演。
- 站内跳转有跨文档 View Transition 余像（旧页化开）。**从别的页面跳回主页时，不要再叠一层开屏** —— 交给余像。

## 3. 旧开屏（要被替换的那一版）的元素清单

它在 `src/components/chrome/BootVeil.astro`。元素：

| 元素 | 具体 |
|---|---|
| 底色 | 暖白 `#ebe7e2`，圆面 `radial-gradient(circle at 38% 34%, #e3e5e7, #d3d7db)` |
| 主剪影 | 「碎晶放射」：中心 9 枚长短悬殊的细晶片放射 + 外围 5 枚脱离碎片（蒙版 `public/textures/loader-shard.svg`） |
| 三层填充 | ① 纯色 `#a9b3bd` ② 树脂纹理 `public/textures/resin.webp` 缓慢平移 ③ 104° 斜线（`#66493a` 62%，1px / 7px） |
| 星环 | 三道同心发丝弧（r = 70 / 80 / 92，1px，缺口正中一粒四角星芒，各转 9s / 14s / 21s，随机起角） |
| 网点 | 一条 6px 网格的网点带从晶片左侧扫到右侧 |
| 错版 | 三层沿 14° 各滑开 ~5% 再啪地归位（像套印没对准） |
| 破窗 | 挖了「晶片 + 中心小圆」孔的幕以中心为原点 scale(72)，光先从晶片缝里透出来 |
| 纹理 | `resin.webp`（树脂）、`mist.webp`（雾） |
| 节奏 | ①迸出 0–0.75s ②错版 0.75–1.4s ③破窗 1.45–2.3s |

**问题**：暖白 vs 靛夜、碎晶 vs 流光、破窗 vs 首页本来没有「窗」在等着被破 —— 前后是两件不同的东西。

## 4. 红线（违反即作废）

- 严禁生活化 / 裁缝 / 手工作坊语汇（针、缝、穿针、针脚…）。**注意**：代码里「两条缝」指首页那两根分界线，是既有术语，可以用，但文案里不要往针线上引。
- 严禁出戏标签（「这是梦」「你在做梦」「快醒了」）。
- 严禁官僚审计词汇（台账、案目、可核验…）。
- 严禁极客中二（「白昼写代码，夜里构筑世界」）。
- 文案极简，能不写字就不写字。真要写字，醒态：克制、清晰、质朴；梦态：空灵、透明的电波感。
- 美学词：神秘 / 朦胧 / 安静 / 磨砂玻璃 / 半透明树脂 / 大面积留白 / 低饱和微温。禁止：锈蚀、裂纹、污泥、重工业、赛博朋克、Dreamcore 现成符号（空商场/泳池/老录像滤镜）。

## 5. 技术约定（共用）

- 字体：`/fonts/noto/font.css`（思源宋体，站内子集，`font-family: 'Noto Serif SC'`），`/fonts/plex/400.css`（IBM Plex Mono）。字体族名见 `src/styles/tokens.css`：`--font-display: 'Noto Serif SC', …`，`--font-mono: 'IBM Plex Mono', …`。
- 纹理：`/public/textures/resin.webp`、`/public/textures/mist.webp`、`/public/textures/loader-shard.svg`、`/public/textures/loader-window.svg`（服务根挂在仓库根，所以直接用 `/public/textures/…`）。
- 尺寸：桌面 1440×900 为准，手机 390×844 必须不崩。
- 只用原生 JS，不引库。
- **不要改 `src/` 下任何文件**，也不要改别人的 `design/mocks/boot/<别的目录>/`。共享目录 `_shared/` 只读。
