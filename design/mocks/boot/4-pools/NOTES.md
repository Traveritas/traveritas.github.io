# 开屏 mock 4 · 三池先聚，线后到

`index.html` 单页，原生 JS，不依赖构建。
截图：`node design/mocks/boot/4-pools/.shot.cjs`。

---

## 1. 机制

首页的开场白本身就是一句话：**三种夜色只是一池池浮在靛夜里**，往下走才分开。这一版把这句话当成开屏。

一张 **1/5 分辨率的 2D canvas + ImageData**，和真站 `#w-light` 同一个像素密度（1440×900 → 288×180）。
没有 WebGL，没有 `filter: blur`，没有 mask。

1. **什么都没有**，只有靛夜。
2. **三团颜色从很糊的胚里长开**——浅蓝灰（随笔）、紫（瞬间）、深蓝（项目），外加一层夜气。它们各自从离自己那一栏更近的 `from` 冒出来，所以一开场就是三团、不是一滩。
3. **不规则**。每条池的等值线在两处被掰弯：
   - 角向低阶谐波（`cos2θ / sin2θ / cos4θ / sin4θ`，四个相位）—— 把圆掰成有瓣的轮廓；
   - 两套手写 fbm（照搬 `light.js` 的 `h21 / vnoise / fbm`）：低频给大团块、高频在边上咬出细的不齐。
   两者都乘在半径上（`ra /= 1 + (n−.5)·amp·warp`），所以**边是等值线不是圆**，中间仍是实的。
   四条池各用自己的噪声 offset，边界不会互相"对齐"。
4. **叠序照抄 CSS**。`.h-flow` 四层 `radial-gradient` 的圆心百分比、半径 vw、color-stop 逐条照抄成
   `{cx, cy, rx, ry, stops}`，按**同样顺序**叠 —— CSS 里先写的在下，所以数组第一个（随笔）最底、最后（夜气）最上。
   顺序反了会立刻穿帮：随笔是唯一发亮那池，压在最上就没人压暗它，左上会亮成一片白。
5. **颗粒**：4×4 Bayer 有序抖动量化到 26 级（与 `GRAIN.home` 的 26 一致），保留 `image-rendering: pixelated` 的放大感。
6. **出图不透明**。三池先叠在 `#0e0f1d` 上再写进 ImageData，alpha 一律 255。
   于是最后那张 canvas 与 `.h-flow` **是同一张图**，交接只需把 canvas 的 opacity 推到 0。
   （若让 canvas 自带 alpha 去盖 `.h-flow`，两张会在中途叠亮，那才是看得见的接缝。）
7. **线最后才到**。三池站好了，14° 线才从中心往两端画出来；线到的地方，两侧出现极弱的明暗差
   —— 像纸被对折过的那道痕。**只在线已经画到的那几列上出现**（`cov = (rv − |x−50vw|/50vw)/0.22`），不是整屏一起亮。

## 2. 时间轴（总长 2080ms）

| 相位 | 毫秒 | 发生什么 |
| --- | --- | --- |
| **聚** | 0 – 860 | 四条池各从 size×0.26 的小胚长大、从 `from` 移到 `to`；半径走 `g^2.4`，前面六七成时间还只是三小团，最后才撑到 CSS 尺寸。同时亮出各自那一版夜色（芯光 `coreA`）与更深的花瓣 |
| **收势** | 700 – 1500 | 线要来了，池子往后退（浓度乘 `recede`：随笔 0.72、另两条 0.90）。像"线把光按了下去" |
| **线到** | 1240 – 1760 | `HomeMock.line()` 从中心往两端画出；同时 canvas 里轴上方渗 2.6% 冷光、下方压 5.2% 影 |
| **收光** | 1480 – 1900 | 亮起来那一点压回首页的克制值（`lit → col`） |
| **交接** | 1540 – 1950 | 轮廓收平（噪声 amp 0.50→0.07、抖动 1.45→0.42）+ canvas 溶回 `.h-flow` |
| — | 1380 – 1830 | 大字对上焦（`HomeMock.focus`） |
| — | 1380 – 1680 | 小字与三个栏头（各自错 70ms）挂到线下 |
| — | 1680 – 1980 | 时刻 / 出口 / 下沉 |
| **静置** | 1980 – 2080 | 只剩首页 |

线的两侧明暗差在 **1700 – 1920** 退回 0 —— 落地帧里那条线就是首页静置时的脑电线，没有任何明暗差。

## 3. 与首页的接缝

1. **几何对齐**：`to`/`rx`/`ry`/`stops` 逐条对上 `.h-flow` 那四层 `radial-gradient`，`stops` 就是 color-stop 换算成 alpha。
   1540ms 起 canvas 与 `.h-flow` 是同一张图，只是前者粗（5px 颗粒）、后者细；这段时间 opacity 从 1 推到 0，
   眼睛只会看到"颗粒化开"，看不到形状跳。
2. **同源颜色**：`lit` 三色取自 `light.js` 的 `DREAM` 调色板（essay 的亮冷白、moment 的暖、project 的青）。
   开屏让它们短暂亮一次，再落回首页那种暗 —— 「聚」这个动作的意义就在这里。
3. **同源画法**：1/5 分辨率 canvas + 26 级量化 + Bayer 4×4，与 `GRAIN.home` 同一个数。
4. **接管入场**：首页自带那两段（大字 1.6s 对焦、脑电线 2.2s 画出）没有各演一遍 ——
   `HomeMock.focus()` / `line()` 都由这条时间轴驱动，起止点就是上面那张表。

## 4. 代价与风险

1. **全程 CPU 逐像素重画**（`ImageData` + `putImageData`），不是纯合成器。实测 `seek()` 单次
   **1.8–10ms**（桌面 Chrome，288×180）。开屏只在进场跑一次，可接受；但**别让它常驻** ——
   真站里这段要接进 `wander.js` 自己的 rAF，共用一帧预算。
2. **"亮一下再压回"是这一版的核心，也最容易做坏**：亮得不够就没有"聚"的感觉，亮过头就像另一套配色来了又走。
3. **三池在手机上会挤**：390px 宽里三团椭圆互相重叠，"三团"读起来可能变成"一团"。`m-01-gather.png` 里能看到。
   这是几何的真实结果、不是 bug；要更分开可把 `k0` 再压小、`to` 再拉开。
4. **交接靠"两张是同一张图"这个前提**。真站里流光底是 `light.js` 的 WebGL 着色器，
   这个前提要重新成立一次 —— 即：`poolW()` 那套池（fbm 阈值）得能在开屏里被逐像素复刻。
   本 mock 复刻的是 `.h-flow` 的 CSS 近似，不是着色器；真迁移时 `stops` 要换成 `light.js` 的 LUT。
5. **写死 14°**：`TAN` 与首页一致；若首页那根线改角度，这里要跟着改。
6. **`#home` 的底色被让给 `body`**（`#home { background: transparent }` 覆盖了片段一行）。
   因为要让 canvas 垫在 `#home` 之下而 `z-index:-1` 走不通（`#home` 自己会形成新层）。
   两处颜色都是 `#0e0f1d`，实拍无差别；这是一处对片段的改动。
7. **LUT / 噪声在 `size()` 时预建**，拖到另一块屏（devicePixelRatio 变化）会重建一次，约 30–50ms。

## 5. 自检

- 桌面 7 张（含越界 `seek(6080)`：应停在落地帧、不崩）+ 手机 3 张，全部 `read_image` 看过。
- 无页面报错。`favicon.ico` 的 404 是浏览器自己要的，已在 `.shot.cjs` 里过滤，页面里也补了 `<link rel="icon" href="data:,">`。
- `prefers-reduced-motion: reduce`：`#veil` 直接 `display:none`，`__boot.ready` 立即为真，一帧不放就位（实测 brand/entry opacity = 1）。
- 无 JS：`<noscript>` 放开所有文字，并补一根直线（波形 `d` 由 JS 生成，否则整条线会缺）。
