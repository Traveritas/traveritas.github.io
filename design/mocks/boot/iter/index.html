五 · 夜与星

星与环保留为母题，矩形条带全部去掉；三套各自只有一条审美逻辑，最后都交回真首页会有的东西：14° 脑电线、大字、流光、三池。

A · 一颗星的余像a-afterimage推荐
一粒光的成像事件：星是它，三枚同心环是它的衍射，细光脊沿 14°。光脊长成首页那根脑电线，余像退成首页的流光。
  • 闭环：星 → 环 → 光脊 → 14° 线 → 流光
  • 读法：安静、克制，环很轻

真站接入现状

已经改 src/：index.astro 用 boot={false} + GrainBoot；grain-boot.ts 跑时间轴；light.js 加 uCell / uLv / uDither / uGrainOn；wander.js 开屏期接口（setGrain / setReveal / startLightNow）；boot.ts 让出 html.booted。

第二版（同日晚些）：整个界面也一起收细。开屏期把字、栏头、时刻、出口、底注与脑电线重画进一张和流光「同格」的低分辨率画布（grain-raster.ts + #grain-ui），最后带 blur 交回真界面。TOTAL 1600 → 1780，交接 1540–1762。于是屏幕上不只是背景从粗到细，字的每一块也落在流光的下一块上。

主页目前沿用「本会话首访才放」判定：看过一次后刷新会跳过；?grain=1 强制重播，?grain=0 关闭。第一次打开时，WebGL 编译（旧记录约 1s；headless 环境更慢）之前页面是一整块暗夜，没有 loader——这是已知取舍。具体接缝、性能与验收见 INTEGRATION.md。
