# 开屏 5 · 夜与星 · 三个审美闭环（迭代版）

`design/mocks/boot/iter/5-night/` 下三个候选，每个是一套**完整开屏 + 假首页交接**（单页、原生 JS/CSS/SVG、不依赖构建）：

| 候选 | 主张 | 闭环 |
| --- | --- | --- |
| **A** `a-afterimage/` | 整场是一粒光的成像事件：星是那粒光，环是衍射，细长光脊沿 14° | 星（全站光标星）→ 衍射环 → 余像（三池位置上的紫雾 + 5px 网点）→ 首页那片流光；光脊长成首页的 14° 脑电线，最后换上它 |
| **B** `b-opening/` | 夜是实体：一整片夜被按 14° 轻轻划开一道极细的口，星是口子里的一粒光 | 口子（两条起伏的发丝边）呼吸张开 → 夜像雾一样退 → 两条边合拢成一根发丝，就是首页那根线（往下滚时它正是劈成两条缝的同一根） |
| **C** `c-pool/` | 星落进首页三池夜色的池心，光的等高线一圈圈散开，三池依次被点亮 | 星落 → 涟漪（首页那阵沿 14° 的风/等值线）→ 三池（light.js 的三池夜色）→ 星沉进轴心、线从轴心浮起 → 首页流光 |

三个候选都**没有矩形条带**，没有 UI 骨架式元素；星与环是全站光标「星环」的同一枚四芒（同一个 path），不是新造的符号。星在梦态下转 14° 也是站内星本来的倾角。

对照台：`design/mocks/boot/iter/5-night/index.html` —— 首屏每候选三个关键帧的对照板，下面是三候选同屏、同步 seek 的播放器（播放靠各自的 `__boot.resume()`，拖时间轴/从头靠对三个 iframe 同时 `__boot.seek(p·total)`）。

## 0. 公共机制（三候选共用）

- **假首页**：整块复制 `_shared/home-fragment.html`。改了三处，都是为了「终帧按真首页设计」：
  1. 那根线的几何按**视口真实像素**画（`viewBox` 跟着视口走）。原片段按 1440×900 拉伸，手机上 14° 会被压成 ~40°；真站 canvas 里它是真实 14°，改后与真站一致。
  2. 无 JS 时给 `#h-eeg-path` 一个固定的兜底 `d`，不留空线。
  3. 手机上车个栏头原本压在线上，按真站 `homeHead()` 的算法放到线下（`50vh + 62/108/154px`）。
- **接缝**：开屏层（`z-index:200`，`pointer-events:none`，`contain:strict`）压在首页之上；夜是**半透明**的（α≈0.99，同旧开屏「不压死首页光栅化」的做法），退开时首页本来就在底下。
- **线**：开屏层里一根**平滑**的 14° 线（首页线的高频震颤被沿轴压缩后会糊成锯齿，所以开屏用平滑线）。它沿自身轴 `rotate(14°) scaleX(k) rotate(-14°)` 从中心展开（纯 transform），`k = r(2−r)` 与真站 reveal 同一条曲线；交接时首页那根**带脑电震颤**的线淡入、开屏线淡出（60ms 同形交叠）。「线开始发颤」就是脑电线醒来的那一下。
- **大字**：与全站 `w-home-focus` 同一条曲线（blur 14px → 0，60% 处 opacity 到 1），由开屏的时间轴驱动，不让它在夜底下白演一遍。
- **`window.__boot`**：`{ total, ready, pause(), seek(ms), resume(), time() }`。时间轴全在 JS 的 Web Animations 里，`seek(ms)` 把所有 animation 的 `currentTime` 定到 ms；没有 `@keyframes`。`seek` 可在播完后重建再定位，所以任意毫秒都可重复截图。
- **降级**：`prefers-reduced-motion: reduce` 或 `?noboot=1` → 首帧前就打 `data-boot-skip`，开屏层 `display:none`，页面直接是首页静置；脚本检测不到 `data-boot` 时**提前返回**，不会把首页推成空夜。无 JS 时 `data-boot` 从不写上，不留死幕；脚本若半路失败，2.8s 兜底摘掉。
- **成本**：开屏层没有 `<img>`、没有 `url()`、没有整屏 `mask` / `filter` / `backdrop-filter`；动的东西只有 `transform` / `opacity`。唯一的 filter 是大字的 `blur()`（真站自己那段 1.6s 对焦本来就是 filter，元素也小）。开屏走完后整层从 DOM 摘掉（`data-boot` 摘除，动画 cancel）。
- **确定性**：假首页的 `HomeMock` 在开屏期 `stop()`，线冻结在满 reveal；真站里那根线会继续呼吸，mock 冻结只为可重复截图。

## A · 一颗星的余像（2200ms）

**主张**：整场是一粒光的成像事件 —— 星是它，环是它的衍射，光脊是它沿 14° 的衍射脊。
**闭环**：星（全站光标星）→ 三圈衍射环 → 余像是三池位置上的紫雾 + 5px 网点 → 首页那片流光；光脊长成 14° 脑电线，最后把线交还首页；大字对焦 = 视线在余像散去之后重新清楚。

| 毫秒 | 发生什么 |
| --- | --- |
| 0–240 | 夜是满的，只有正中一点将亮未亮 |
| 240–1080 | 星亮到满（主芒 + 紫芯 + 45° 副芒 + 中心结），三圈衍射环依次撑开、淡掉；一根细光脊沿 14° 从星心探出 |
| 1080–1400 | 余像（紫雾 + 5px 网点）浮上来；星从 0° 转向 14°（梦态星的倾角） |
| 1280–1950 | 夜退成首页的靛夜 |
| 1360–2000 | 光脊沿轴展开成首页那根线；星把光交出去，缩掉 |
| 1480–2060 | 大字从 blur(14px) 里对上焦 |
| 2006–2062 | 开屏线换回首页线（同形，交接帧不动一格） |
| 2062–2200 | 首页静置 |

- **代价**：三圈环是 954×954 内联 SVG，CSS scale；余像是两三层全屏静态渐变 + 一层 5px 网点（静态背景图）；全部只动 transform/opacity。~25 条 Web Animations。
- **风险**：环一旦放大到接近屏宽就会像准星，所以三圈最大只到 ~430px 半径、最亮也只在 0.45；余像的网点是整屏静态纹理，深色区域会有一层很淡的颗粒，若嫌重可去掉 `::after` 一层（观感差别不大）。

## B · 夜里的一道开口（2260ms）

**主张**：夜是实体，中心被轻轻划开一道按 14° 睡着的极细口子，星是口子里的一粒光。
**闭环**：口子的两条**起伏发丝边**（形状抄首页线）→ 呼吸张开 → 夜像雾一样退 → 两条边在结尾合拢成一根发丝，就是首页那根线；它正是首页往下滚时劈成两条缝的同一根线。

| 毫秒 | 发生什么 |
| --- | --- |
| 0–320 | 夜是满的 |
| 320–900 | 口子从中心沿 14° 划开：两条边先重合、再让开 1.5→6px；口子里亮起一线光，星在光里 |
| 900–1320 | 呼吸：两条边 6→8→7px，光晕明暗跟着起落 |
| 1320–1900 | 夜像雾一样退；口子张到最开（两条边到 12px），光从里面漏出来 |
| 1500–2040 | 口子里的光凝成开屏线、沿 14° 展开 |
| 1900–2045 | 两条边合拢成一根发丝（`d→0.6px`）；夜退尽 |
| 1640–2110 | 大字对焦 |
| 2046–2101 | 开屏线换回首页线 |
| 2101–2260 | 首页静置 |

- **代价**：两块全屏 SVG（各一根 0.55px 的 path，CSS transform 组合 `translate(±d) rotate(14) scaleX(k) rotate(-14)`）+ 一条 1780×22 的静态渐变光 + 一层夜雾。全部 transform/opacity。
- **风险**：口子最大只张开 16px，是刻意的「极细」；在很窄的屏上两条边会并成一根，观感会从「开口」退成「一线光」（仍成立，但少一层读法）。两条边的渐变两端淡出，所以在屏幕两侧看不到线头。

## C · 星落进池子（2220ms）

**主张**：首页三池夜色只是浮在靛夜里；这一版让一粒星落进池心，把三池依次点亮。
**闭环**：星落（站内的星）→ 落点光 → 沿 14° 拉长的涟漪（首页随笔区那阵风的等值线）→ 三池（light.js 的 essay / moment / project 三池色）依次亮 → 星沉进轴心，首页的线与流光从水里浮起。

| 毫秒 | 发生什么 |
| --- | --- |
| 0–240 | 星在上方亮起来 |
| 240–880 | 星落向屏幕中心，尾迹在身后 |
| 880–1000 | 落点泛光 |
| 880–1960 | 三圈涟漪沿 14° 一圈圈散开 |
| 900–1180 / 1180–1480 / 1420–1720 | 瞬间池 → 项目池 → 随笔池 依次被点亮 |
| 1500–1980 | 夜退成首页的靛夜；三池把光交还首页 |
| 1500–1850 | 星沉进轴心 |
| 1520–2040 | 首页的线从轴心往外浮起 |
| 1640–2110 | 大字对焦 |
| 2046–2101 | 开屏线换回首页线 |
| 2101–2220 | 首页静置 |

- **代价**：三池是三层全屏静态渐变（每层一个径向渐变），涟漪是三个静态径向渐变环（scale + opacity）。手机 DPR 2–3 下三层全屏渐变是这一版最重的显存项。
- **风险**：三层全屏渐变在手机上建议改成按渐变范围定尺寸的盒子（60vmax 左右）而不是 `inset:-10%` 全屏；涟漪的椭圆环在个别帧仍会读成「靶环」，已把最外两圈压到 0.15/0.10。三池的位置/色相是照 `.h-flow` 的 CSS 近似，接真站时要换成 `light.js` 的 LUT。

## 3. 与真首页的接缝（接入方案）

**开屏层与真站 DOM 并存**：`#boot` 固定 `z-index:200`、`pointer-events:none`；真站的 `#w-light`（WebGL 流光）、`#w-win`（大字反相窗）、`#w-home` 文字都不动，保持在底下继续渲染。夜用半透明 α≈0.99（同旧 BootVeil 的 0.996 思路），首页在夜底下仍然被光栅化，不会在揭幕那一帧挤着补画。`#cursor-slot` 是 240，仍在开屏层之上（星光标在开屏期也保持是真指针），若想藏起来只需在 `html[data-boot]` 下压掉。

**接管的两段入场**（现在压在夜底下白演的就是它们）：

1. **脑电线 reveal**：真线是 `#site-eeg-canvas`（Worker/OffscreenCanvas，回退 SVG），由 `wander.js` 每帧用 `revealT0` 算 `reveal` 并 `setEegSpine({reveal})`。开屏期给 `#boot` 期加门（例如 `html[data-boot] #site-eeg-group { opacity:0 }` 或让 `wander.js` 在 `data-boot` 时跳过 spine 写），开屏自己那根 SVG 线负责「从中心展开」；交接时把真线的 reveal 直接推到 1，再淡入 `#site-eeg-group`，同时淡出开屏线。真线是 canvas，形状与开屏的平滑 SVG 线不完全一样，60–120ms 的交叉淡入就是「它开始发颤」的那一下；也可以让 `wander.js` 暴露一个 `__wander.holdReveal(fn)`，由开屏按 ms 直接驱动真 reveal（更忠实，成本只是一个 uniform）。
2. **大字对焦**：真站是 `html.w-ready[data-wview='home'] .w-home-brand-box { animation: w-home-focus 1.6s }`。开屏期加 `html[data-boot] .w-home-brand-box { animation: none !important; }`，由开屏按同一条曲线驱动（可沿用现在的 WA：blur 14px→0、60% 处 opacity 1）；交接前再加一个 **`data-boot-done`**（`html[data-boot-done] .w-home-brand-box { animation: none; }`），然后摘 `data-boot`，这样 CSS 动画不会在开屏结束后补演一次。
3. **`w-ready` 门控**：`w-ready` 是 `wander.js` init 末尾加上的，其它元素（栏头、时刻等）依赖它；开屏**不要改 `w-ready` 的时机**，只改上面两条选择器即可。开屏层在 `w-ready` 之前就已经存在（boot 脚本在 `<head>` 里先打 `data-boot`），所以不会闪一帧首页。

**不放开屏时的兜底**：
- `prefers-reduced-motion: reduce`、`?noboot=1`、无 JS → 首帧前 `data-boot-skip`，开屏层不出现；`HomeMock`/真站按默认静置走，脚本在检测到 `data-boot-skip` 时**提前返回**（不要走 `seek(0)`，否则会把首页推成空夜）。
- 站内跳转回主页（跨文档 View Transition）：不再叠开屏，交给旧页的余像；沿用 BootVeil 的 `pagereveal + e.viewTransition → data-boot-skip` 逻辑即可。
- 开屏中途脚本失败：2.8s 兜底摘 `data-boot`，页面就是首页。

**性能**：三候选都只写 transform/opacity（大字的 `filter: blur()` 是唯一非合成器项，与真站现有 1.6s 对焦同价）。开屏走完 `data-boot` 摘除、动画 cancel，开屏层不进 LCP 候选（无 `<img>`、无文字）。真站接入后要额外注意：开屏期首页的 WebGL 仍在跑（约 700ms/s 常驻），开屏本身只是多一层合成，不再多一套渲染管线。

## 4. 代价、已知风险

1. **假首页不是真首页**：`HomeMock` 的线是 SVG 波形、流光是一层 CSS 叠色；真站是 Worker canvas + 1/5 分辨率像素流光 + 反相窗。三候选的终帧在 mock 里是「假首页静置」，真站接上后终帧会是真首页静置；差异集中在流光的颗粒与大字反相窗（mock 里用浅字近似）。
2. **开屏线是平滑线、首页线带震颤**：交接时会有一次很轻的「开始发颤」（60ms 交叉）。这是刻意的读法；若嫌明显，把开屏线的波形幅度加到 3.6px 或把交叉窗延长到 140ms。
3. **C 的三层全屏渐变**是显存/合成层大头（手机 DPR 3 下约数十 MB 量级）。上真站前应改小图层尺寸或直接写进 `light.js` 的池（`poolW` 已有逐像素实现）。
4. **A 的环是正圆**。环半径一旦接近屏宽会读成准星；现在最大约 430px 且峰值不透明度 0.45，把窗口拉得特别宽时仍有轻微「图样感」。
5. **B 的口子最大 16px**，在很窄的屏上会并成一条；这是「极细」的代价，不是 bug。
6. **每次进入都放**：2200–2260ms 对返访者可能偏长。要短可先压「余像/呼吸」两段（A 1080–1400、B 900–1320），因为它们不承载交接。
7. **`will-change`** 在开屏期挂在 ~10–20 个元素上，开屏结束后整层摘除、动画 cancel，不会常驻。
8. **手机**：390×844 下三候选都已截图检查；C 的涟漪/池子在窄屏上略挤，A/B 更稳。

## 5. 推荐

**推荐 A**（一颗星的余像）：闭环最硬——星就是那根线的起点，余像就是首页那片流光，大字对焦是「视线在余像散去之后重新清楚」；画面最静，任何屏幕尺寸都不会崩，代价也最小。B 是紧随其后的第二选择（「两条边合拢成一根线」是三个里最物理的交接，视觉更锐利；代价是口子太细，在窄屏上少一层读法）。C 最好看的时候在 1300–1700ms 的三池，但最重、也最容易读成「靶环」，建议作为 C 位备选而不是首选。

如果只留一个：**A**。如果要「更像夜，而不是光学」：**B**。

## 6.5 自检结果（2026-10-28 实跑）

- **页面报错**：三候选在 Chromium 里均无 `pageerror` / console error；`__boot.ready` 正常；total = 2200 / 2260 / 2220。
- **seek 确定性**：同一毫秒连拍两次，PNG 逐字节相同（A 1210ms / B 1243ms / C 1221ms）。
- **自然播完**：`data-boot` 摘除、`#boot` display:none、`document.getAnimations()` 为 0、大字 `filter` 回到 `none` —— 开屏层完全退出，不留隐身合成层。
- **减动效**：`prefers-reduced-motion: reduce` 下 `#boot` display:none、`data-boot-skip` 存在、首页直接静置。
- **无 JS**：开屏层不出现；假首页读到兜底 `d`，线仍画出来（`r-nojs.png`）。
- **对照台**：三 iframe 都 ready；播放 700ms 后三候选同步前进；把时间轴拖到 50%，三者各自停在自己的 total 一半处；首屏对照板的三帧图都能直接加载。
- **手机 390×844**：三候选各 4 帧检查；栏头已移到线下（§0），线在手机上保持真实 14°。
