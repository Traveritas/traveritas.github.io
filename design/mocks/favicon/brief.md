## 1. 要设计什么

网站的**标签页图标**（favicon / tab icon）。就是浏览器标签上那 16px 的小方块，同时也是 OG 小图与 apple-touch 图标。

**不做整套导航图标**，只做**这一枚标记**。但它要能当站标用。

你现在看到的旧 favicon 是「两枚针脚在缝点相接」——那套语汇已被项目红线废掉，**不要参考它，也不要去看它**。这次是重新想。

- `src/styles/tokens.css` —— 设计令牌（颜色、14° 发丝线 `--seam-angle`、醒梦总闸 `--reality-mix`）。

气质：神秘 / 朦胧 / 安静 / 磨砂玻璃 / 半透明树脂 / 大面积留白 / 低饱和微温。

### 主页现在长什么样（照着 `_ref/home-1440.png` 看）

- 一整片**很深的靛夜**（`#0c0f18` / `#0d1524` / `#0e0f1d` / `#1d1729` 一族的深紫蓝），不是纯黑。
- 背景铺着**极细的半调网点**（一片点阵纹理），夜里像纸也像屏。
- **左上角一团冷光**（近白偏蓝，`#e6ebf1` → `#a6b4c6` 那一族），是整屏唯一的光源。
- 一根 **14° 的发丝线**斜穿屏幕。注意：它在屏幕上不是光滑直线，而是**一级一级的台阶**（像像素化的斜线 / 楼梯）。
- 名字是**大号衬线字**，带一点消隐、残影的味道。
- 三个入口「断章 ESSAYS / 闪念 MOMENTS / 造物 PROJECTS」前面各有一枚**极小的淡紫光点**（`#a195c1` / `#9c92c8` / `#988bb6`）与罗马数字 Ⅰ Ⅱ Ⅲ。
- 左下角一颗**小星**（工具栏开关），右下角 **NEXUS** 是像素字（Silkscreen）。
- 颜色分工：**深紫蓝 = 夜与距离；淡紫 = 记忆与温度；冷灰白 = 结构、清醒、光**。
- 昼面底色 `#f0f3f6`，正文 `#232830`，异质强调色 `--amber: #9a86c4`（薄暮紫，全站唯一强调色）。

**名字**：醒面叫 `Traveritas`，梦面叫 `AveritA`（一个近似回文/镜像的巧合——这是可以用的素材，但不强制）。

## 3. 红线（违反即废稿）

1. 严禁针 / 缝 / 穿针 / 起针 / 落针 / 针脚 / 八针进度等**裁缝与手工作坊语汇**。
2. 严禁「这是梦 / 你在做梦 / 快醒了」这类**直白出戏的标签**。不言梦而梦感自生。
3. 严禁账目 / 台账 / 案号 / 可核验 / 待立项等**审计与财务黑话**。
4. 严禁「白昼写代码夜里构筑世界」式**极客中二隐喻**。
5. 不要铁锈、裂纹、污泥、重工业、密集机械细节；不要 Dreamcore / Liminal Space 的现成符号堆砌。
6. 不要为了炫技把图标画复杂——**它要在 16px 里被认出来**。

## 4. 硬性要求

1. **矢量、无外部资源**：成品是一枚内联 SVG（`viewBox="0 0 32 32"` 建议，也可以是 24/48），双击能开、能直接落进 `public/favicon.svg`。
2. **16px 要立得住**：整组必须给一排 16px 小样。糊成一团的方案直接改。
3. **两种底色都要活**：浏览器标签栏有浅色（近白 `#f0f3f6` 一族）与深色（近黑 `#202124` / `#1b1b1f`）两种；深底上不能消失，浅底上不能脏。
4. **单色可退**：说明这套在只有一种墨色（`currentColor`）时还成不成立、退化成什么。全站图标最终多半跟 `currentColor` 走。
5. **醒 / 梦两个变体**：站点有全局量 `--reality-mix`（1 = 醒，0 = 梦）。醒面冷灰克制、梦面薄暮浮起。两态要一眼看出是**同一枚图标的两种状态**，不是两枚图标。（标签页图标真要做两态，得靠 JS 换 `<link rel="icon">`——如果你走这条，在 notes 里说清怎么换、什么时候换。）
6. 动效不要求。若加了克制的动效（呼吸、微光扫过、缓慢自转），说明触发条件与时长。

## 5. 交付物（你的目录）

```
design/mocks/favicon/<你的批次>/<你的 slug>/
  index.html        自包含单页：内联 SVG + CSS，无外部资源、无构建步骤。双击能开。
  favicon.svg       干净的单枚成品（可退成 currentColor 的那一份）
  notes.md          设计说明
  shots/            你自己跑出来的截图
```

`index.html` 里至少要有这几段（版面顺序随你）：

- **主视觉**：这枚标记放到 128–180px，把"手感"交代清楚；醒 / 梦并排。
- **尺寸带**：同一枚在 32px、24px、16px 各一排，背景分别是昼面 `#f0f3f6` 与深底（如 `#16171c`）。
- **真实标签页**：画 2–3 条**浏览器标签栏**（浅色一条、深色一条），把图标放进标签里、配上站名，看看它在真实语境里像不像这个站的标签。
- **单色退让**：整枚用单一 `currentColor` 再排一遍，看还认不认得出。
- **一格语境**（可选，很加分）：把图标放到主页那张截图旁边 / 左下角小星旁边 / 一条 14° 发丝线上。

`notes.md` 写清：

- **风格一句话**：这套风格的内核是什么。
- **形从哪来**：为什么这么画，和主页的哪一处呼应。
- **醒 / 梦差在哪**：色、材质、光、还是形态本身。
- **16px 与单色下退化成什么**。
- **小巧思**：一个别人不会想到、但很贴站点的细节（没有就直说没有，别硬凑）。
- **风险 / 你不确定的地方**。
- **实际跑过的截图命令**。

## 6. 截图

统一用这支脚本（puppeteer-core + 本机 Chrome，已验证可用）：

```bash
node design/mocks/favicon/.shot.cjs design/mocks/favicon/<批次>/<slug>/index.html design/mocks/favicon/<批次>/<slug>/shots/sheet.png 1200 1500
```

参数：`<html> <out.png> [宽] [高] [--full] [--scale=2]`。`--full` 截整页。
**每套至少跑一次截图，自己 Read 那个 PNG 看过再交**（检查溢出、糊掉、颜色跑偏、16px 是否可辨）。脚本会报横向溢出与页面报错，别忽略。

## 7. 自由度的边界

风格方向由你收到的任务描述给定，**其余全放开**：构图、材质做法、命名、是否加动效、是否自创一个视觉母题，都随你。
鼓励「小巧思」——一个克制但让人记住的细节，胜过十处平均用力的装饰。
**只改你自己目录里的文件**，不要动 `public/favicon.svg` 或 `src/` 下任何东西。
