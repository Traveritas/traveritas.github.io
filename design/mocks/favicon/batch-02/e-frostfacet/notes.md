# e-frostfacet · 磨砂玻璃棱面

标签页图标 mockup · batch-02
成品：`favicon.svg`（醒，内带深浅主题判断）· `favicon-dream.svg`（恒梦面）· 单页 `index.html`

---

## 风格一句话

**一枚被敲下来的磨砂玻璃棱面：三个面一路压暗、左上留一道咬口，里面横着一道 14° 的线。**

不是一颗规整的水晶，也不是一个孤零零的多边形。是一簇碎块里最大的那一块 ——
旁边还压着一片薄板、掉着一片屑、飘着一小角。透明感靠「面与面的浓淡差 + 一条高光棱线」，
不靠整片渐变。

## 形从哪来

对着 `_ref/home-1440.png` 和 `docs/design/aesthetic-direction.md` 第 6 节：

- 站主偏的是**玻璃 / 水晶碎块的质感**，技术含义是「棱面几何 + 透明、光滑、环境贴图、虹彩」的平价材质组合。
  所以主体必须是**多面体**，不能是圆润的形体。
- 但碎块方向曾经被否过一次，原因是「**过于规整（组成太简单）且丑**」。所以这一版把力气全花在**构图的不规整**上：
  - 主体轮廓是 8 个顶点，**没有任何一组对边平行、没有一条对称轴**；左上专门啃掉一个 V 形咬口；
  - 主体之外还有**三块**：右上压着一小片薄板、左下掉出一片薄屑、右侧脱离一小角 —— 大小、朝向、深浅全不一样；
  - 整体重心偏左下，右上留空，像刚从一整块玻璃上崩下来的一角。
- 材质语言照审美文档写：半透明、磨砂、光滑柔和反射、低粗糙度、不过度金属化。全站的颜色分工也照搬 ——
  **冷灰白 = 结构 / 清醒**，**薄暮紫 = 记忆 / 温度**（`--amber: #9a86c4`，全站唯一异质色）。
- 醒面落在纸面 `#f0f3f6` 上，取冷灰一族（`#a7b1ba` 的邻居）；梦面落在靛夜 `#0c0f18` 上，
  光取薄暮紫一族（`#a195c1` / `#9a86c4`）。

## 醒 / 梦差在哪

**是同一枚图标的两种状态：骨架、构图、尺寸、朝向一个字都没动，变的是「光」和「有没有张开」。**

| | 醒（`--reality-mix: 1`） | 梦（`0`） |
|---|---|---|
| 底色 | 纸面 `#f0f3f6` | 靛夜 `#0c0f18` |
| 三个面 | 不透明冷灰 `#dfe8ef` / `#bcc7d1` / `#96a3af`，一路压暗 | 半透明叠色（冷白 20% / 薄暮紫 26% / 冷蓝灰 15%），**看得穿** |
| 那道 14° 的线 | **合着** —— 只是玻璃里一条稍深的暗棱（`#5d6a78`） | **张开**成一道楔口，薄暮紫 `#c9b6ef` 从里面出来 |
| 裂口的光 | 无 | 有：一团径向辉光从裂口内侧散开，还有一小截光顺着裂口往右下淡进空气 |
| 受光那条棱 | 一道近白高光（`#fdfeff`） | 换成**虹彩**：冷白 → 薄暮紫 → 一点冷青 |
| 右侧脱离的那一小角 | 贴着主体 | **又飘开一点，还偏了 5°** |
| 视线距离 | 边界清楚、清醒、克制 | 边缘开始化、透光、有温度 |

一句话：**醒是这块玻璃在纸上的样子，梦是它开始透光的样子。** 不是两枚图标。

## 16px 与单色下退化成什么

### 16px

这是这一方向最大的风险：棱面 + 透明，一缩就摊平成一块灰。**正面解决，靠三件事：**

1. **不靠渐变。** 16px 下还认得出的，只有「面与面的浓淡差」和「几条硬边」。
   所以三个面用**三档纯色**，不用一片连续渐变 —— 渐变一缩就没了。
2. **留一个高对比的小点。** 右侧脱离的那一小角是全图唯一**与主体不相连**的深色块。
   16px 里它只剩两三个像素，但正是这两个像素让整枚从「一块灰」变成「一块碎掉的灰」。
   梦面里它还会再飘开一点、偏 5°，缩小后仍能读出「松了」。
3. **那道 14° 的暗棱。** 0.42 宽的内棱线在 16px 里是亚像素的，它不显示为线，
   而是把左下那两档面的交界**再压暗半级** —— 于是 16px 里还剩两级明暗，而不是一级。

**section 03 排的是真的 16×16 位图**，不是把 SVG 缩到 16px 再看：
先用 **DPR 1** 把图标渲成 16×16 的设备像素，再只做最近邻放大八倍（`image-rendering:pixelated`）。
所以那一排比真实标签栏里**更难看**，糊掉的地方一点都藏不住。四种底色都过了：
醒 / 纸面、梦 / 靛夜、醒 / 浅色标签栏 `#dfe2e7`、梦 / 深色标签栏 `#202124`。
最弱的一格是**醒面在纯纸面上**：左上那片受光的面几乎和纸同色，边界靠中档与暗档两个面立住。
标签栏底色 `#dfe2e7` / `#f4f6f8` 比纯纸面略深，反而更清楚。

### 单色（`currentColor`）

`.mono` 一份：三个面退成同一种墨的 **8% / 26% / 42%**，高光棱线和虹彩**全部关掉**
（它们本来就是光，只有一种墨的时候就该消失），那道 14° 的线留成 55% 的墨。
结果是**一枚线描的碎块**：轮廓 + 两个面的分界 + 那道线。「碎」还在，材质没了。
深墨（纸面 `#232830`）与浅墨（靛夜 `#e6ebf1`）各排了一遍，16px 下都还认得出 ——
因为骨架本来就是靠浓淡差而不是靠颜色立住的。

## 两态怎么换

- **`favicon.svg`（醒）** —— 内带 `@media (prefers-color-scheme: dark)`：浅色主题给醒面，深色主题自动给梦面。
  **日常只挂这一枚就够了**，浏览器主题一变它自己跟着变。
- **`favicon-dream.svg`（梦）** —— 不带任何判断，任何时候都是梦面。
  给「标签页图标跟着站内 `--reality-mix` 走」用。

落地时由 `reality.ts` 在改写 `--reality-mix` 的同一处顺手改 `<link rel="icon">` 的 href：

```js
const dark = matchMedia('(prefers-color-scheme: dark)').matches;
icon.href = (mix === 0 && dark) ? '/favicon-dream.svg' : '/favicon.svg';
```

**那道 `&& dark` 不能省。** 梦面是为深底画的，浅色标签栏上它会化掉（见下方风险）。
两个条件都成立才切梦面，否则一律留在醒面 —— 醒面在深浅两种标签栏上都活着。

## 小巧思

**图标里那道裂口，就是主页穿屏的那根 14° 发丝线。**

主页那根线是一级一级的台阶（`_ref/home-1440.png` 里能看清），斜穿整屏。
这枚碎块里那道内棱（`(6.37,12.25) → (14.94,14.63)`）的斜率算下来是 **14.66°** ——
和 `--seam-angle: 14deg` 是同一根线。所以：

- **醒时**这条线在玻璃里合着，只是稍微深一点；
- **梦时**它张开，光顺着它漏出去，还继续往右下淡出一小截；
- section 06 就是把图标搁回那根台阶线上：**把图标里那道线延长，正好压在主页那根线上 ——
  它不是站在线旁边，它是从这条线上敲下来的一块。**

第二个小地方：右侧那一小角脱离主体后，梦面里**又多飘了一点、还偏了 5°**。
整枚图标唯一「在动」的就是它 —— 一个几乎看不见的松动。

## 风险 / 我不确定的地方

1. **醒面在纯纸面上偏淡。** 为了不让它在浅底上「白得发亮」，最亮的面压在纸面之下，
   于是左上那片受光面的边界是软的，靠中档与暗档两个面立住。16px 里能认，
   但它是四格里最弱的一格。已把三档压深过一次（`#e3ebf1 → #dfe8ef`、`#d0dae2 → #cbd6df`），
   再深就要往「一块灰色塑料」去了，所以停在这里。**这是我最不确定的一处。**
2. **梦面在浅色标签栏上会化掉。** 梦面的面全是半透明的浅色叠色，放在 `#dfe2e7` 上几乎看不见。
   所以 `favicon-dream.svg` 必须**配合深色主题**才切（见上）。
   如果你希望它俩在浅色标签栏上都能用，梦面就得改成不透明深色底 —— 但那会让两态看起来像两枚图标。
3. **「构图要丰富、有机」和「16px 要认得出」是一对矛盾。** 我按「大尺寸加东西、小尺寸自己掉」来解：
   高光棱线、虹彩、辉光、那道细内棱，16px 里全部自己消失，剩下的只有骨架。
   如果你觉得 16px 下还是偏碎、偏糊，第一步该砍的是**左下那片薄屑**（它最小、最容易被读成噪点）。
4. **favicon 的 16px 不是整数像素对齐的。** 我按 32 的 viewBox 画，浏览器缩到 16 是整数倍（÷2），
   这点是好的；但真实标签栏的图标还带 DPR 缩放，我这边没法覆盖所有 DPR。
   section 03 用的是 DPR 1 的最坏情况。
5. **`prefers-color-scheme` 与站内 `--reality-mix` 是两套信号。** 上面那行 `&& dark` 是我给的折中，
   但它意味着「浅色浏览器 + 站内梦态」时标签页会停在醒面 —— 图标和页面不同步。
   如果站主更在意同步而不是可读性，就把 `&& dark` 去掉。**这条需要你定。**

## 实际跑过的截图命令

```bash
# 整页（7 节全在）
node design/mocks/favicon/.shot.cjs \
  design/mocks/favicon/batch-02/e-frostfacet/index.html \
  design/mocks/favicon/batch-02/e-frostfacet/shots/sheet.png 1200 1500 --full
# → shots/sheet.png   页面实际 1200×3484，无横向溢出，无页面报错

# 首屏 1200×1500
node design/mocks/favicon/.shot.cjs \
  design/mocks/favicon/batch-02/e-frostfacet/index.html \
  design/mocks/favicon/batch-02/e-frostfacet/shots/top-1500.png 1200 1500
```

另外自跑了两次临时校验（脚本在系统 temp，不在本目录）：

- 把图标在 **DPR 1** 下渲成 16×16 PNG，再放大八倍逐格核对四种底色 —— section 03 里嵌的就是这两张位图；
- 把 `favicon.svg` / `favicon-dream.svg` 各在 `prefers-color-scheme: light|dark` 下渲一遍，
  确认 `favicon.svg` 会自己换面、`favicon-dream.svg` 恒梦面。

两张 PNG 都自己 Read 看过：版面完整、七节齐全、无溢出、颜色没跑偏、16px 四格都可辨。
