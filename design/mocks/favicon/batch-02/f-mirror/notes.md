# 折叶 FOLD

`design/mocks/favicon/batch-02/f-mirror/` · 方向「名字 / 镜像」· 2026-10-22

---

## 1. 风格一句话

**一枚叶，沿 14° 的折痕折过去。正立的一半与折过去的一半互为镜像——折回去，是同一枚叶。**
名字的两个读法也是这样：一个正着念，一个翻过来念，中间那段一模一样。

## 2. 形从哪来

- **水面**：主页那根 14° 的发丝线斜穿整屏。把线当成水面，叶浮在上面，底下是它的倒影；叶与倒影合起来，正好还是那枚叶。
- **镜轴**：就是那道折痕，倾角 14°，与令牌 `--seam-angle: 14deg` 同角。反射矩阵
  `0.883 0.469 / 0.469 −0.883`（绕 (16,16) 转 28° 再翻），正立的一半与折过去的一半**逐点重合**。
- **折痕不是画上去的线，是真的缺口**：六级台阶，每级进深 3.202、落差 0.7985（32 单位制），
  `atan(0.7985 / 3.202) = 14.0°`——就是主页那根像素化斜线的缩微版。缺口用 `mask` 切出来，
  所以整枚压成一种墨色也仍然成立。
- **叶尖那一点**：靠近顶端一枚 `r = 1.15` 的孔，在 `(15.6, 9.5)`。
- 整枚只有一条叶形路径 + 一条折痕路径（`#p` / `#c`），两半共用同一份路径。

## 3. 醒 / 梦差在哪

**形完全不动，只换明暗的位置。**

| | 醒 `--reality-mix: 1` | 梦 `0` |
|---|---|---|
| 正立的一半 | `currentColor` 实心（纸底上 `#232830`） | `#b6c0cf`，72% |
| 折过去的一半 | 同一份墨，12% | `#a195c1`，95% |
| 折痕 | 不画 | `#dfe6ee`，92%，带微光 |
| 叶尖 | 真孔（透出脚下底色） | 被点亮 `#e6ebf1`，blur 1.7 |
| 折过去那一半的辉光 | 无 | `#a195c1`，62%，blur 1.7 |

`index.html` 第 3 节有一支 `--reality-mix` 滑杆：颜色从冷白滑到薄暮紫，实心的质量从上半叶沉到下半叶，
**中间没有开关**，只是慢慢过去。

## 4. 16px 与单色下退化成什么

- **16px 真样**（浏览器先按 16 / 20 / 24 px 光栅化，再放大 6 倍摆出来）：
  折痕的缺口只剩半个像素、叶尖的孔快没了——但两段明暗还分得开，整枚仍然读作
  **一枚斜着立住的叶**，不是一坨。这是及格线，不是舒适区。
- **单色（`currentColor`）**：骨架不靠颜色，折痕是真缺口，压成一种墨色仍成立；
  深底上把墨色翻过来（`prefers-color-scheme`）。
- **最弱的一格是 16px + 纯平色（不许任何透明度）**：折过去的浅影没了，只剩一枚小楔形，
  缺口几乎读不出来。若「16px 单色也清楚」是硬要求，得把 12% 的浅影换成一档实心灰。

## 5. 小巧思

1. **梦面那条标签里，站名与栏头是倒着读的。** 标签写 `AveritA`，底下的
   `断章 · 闪念 · 造物` 在梦面标签里镜像成 `slemant · semob · zudob`。
   同一排标签里两枚并排——一眼看到名字翻了面。这是「两个读法」那句话直接落到标签栏上。
2. **叶尖那个洞**：醒面是真孔（透出脚下底色），梦面被点亮。同一个洞，两种光。
3. **折痕的台阶与主页那根线同源**（六级、14.0°），放回主页的语境格里与那根线同角。

## 6. 两态怎么换（如果真上线）

`<title>` 已经挂了 `data-wake` / `data-dream`，所以在换 title 的同一处换 `<link rel="icon">`，
只在跨过 0.5 时换一次，别逐帧改 DOM。

**一个要留意的工程细节**：`prefers-color-scheme` 跟的是**系统主题**，不一定是**标签栏的深浅**。
`favicon.svg` 里的换墨只解决「系统深色》；「系统浅色 + 浏览器深色标签栏」这个组合下醒面会低对比
（深墨压在深栏上，几乎看不见）。所以上线时最好把**标签栏深浅 + 站内醒梦**两条信号一起判，
或者干脆只走 JS 换文件、不在 SVG 里写 media query。

## 7. 风险 / 我不确定的地方

1. **16px + 纯平单色最弱**（见第 4 节）——若单色是硬需求，得改一档。
2. **16px 下「叶」读不读得出来**：也可能被读成纸飞机 / 折角 / 小山。它有形，但「是不是叶」是口味判断。
3. **镜像是「折一次」，不是「回文」**：它演示名字的两个读法，但不真编码字母（不是 T / A 字形）。
   若你要的是字形镜像，那是另一个方向。
4. 折过去的一半只有 12% 浅影，在低对比底（浅灰卡片）上可能消失。
5. **梦面不建议放浅色标签栏**（薄暮紫在纸底上偏淡）。
6. 页面主视觉把标记放大到 1.12 显示；两枚独立 SVG 也带了同一个比例，换面时不会跳。

## 9. 文件，以及一点说明

```
index.html          自包含单页，七节（主视觉 / 构成 / 总闸扫描 / 尺寸带 / 真实标签页 / 单色退让 / 语境）

favicon-dream.svg   梦面成品：薄暮紫 + 点亮的折痕与叶尖（恒梦面，不含 media query，由 JS 决定何时用）
notes.md
shots/
```

说明：`index.html` 与大部分截图由子智能体完成，它在写 `notes.md` 之前中断。交付前核过一遍，
修了三处：① `favicon.svg` 的 XML 注释里写了 `--`（与站内令牌同名的那处），XML 注释不允许连续双连字符，
文件当图片打不开；② 两枚独立 SVG 的叶形曲线与叶尖孔位和 mockup 不一致；③ 两枚 SVG 原来相差 12%
的显示比例，会被换面时的尺寸跳动出卖。现两枚独立 SVG 的几何与 mockup 一致。
