# d-lily · 花

`design/mocks/favicon/batch-02/d-lily/` · 2026-10-22 · 标签页图标风格方向 mockup

## 一句话

俯视一朵正在开、或正在合的花：五瓣，每一瓣的长度、开角、左右偏斜各自沿一条采样正弦取值——像有某种规则，只是暂时无法理解。

## 形从哪来

`docs/design/aesthetic-direction.md` 第 6 节有站主本人的两次补充，都指向花：最喜欢百合的简约花型、偏抽象花的形状；并且明确要求花形避免机械放射对称（花瓣需长度 / 开角抖动）、构图要有层次（不做单一简单图形）。这枚标记就照这两条落地：

- **抽象，不是写实插画**。只有五个外层瓣 + 三个内层短瓣 + 一枚花心孔，没有花蕊、没有叶、没有描边。
- **抖不是手摆的，是三条正弦**。改一个系数，整朵重排：
  - 角位移 `4.6·sin(1.9k+1.15) + 1.7·cos(3.3k)` —— 把等分的 72° 打散到 64.8°–75.8°
  - 瓣长 `9.6·(1 + 0.14·sin(1.7k+0.8))` —— 8.43 到 10.90
  - 左右偏斜 `0.13·sin(1.25k+2.3)` —— 每瓣左右半宽不等，尖梢也偏
  - 内层三瓣落在五个外层瓣的空档中点上，间距天然不均（140.7° / 149.9° / 69.4°）
  - 数字全部由 `gen.cjs` 算出、内联进页面，没有一个是手抄的坐标。
- **呼应主页的哪一处**：花心那点光，是主页左上角唯一光源缩到最小的一粒；磨砂瓣是站点的材质语言（半透明树脂 / 磨砂玻璃）；梦面那一片正在离开花心的瓣，对应「世界随时可能消失，又随时可能重新被记起」。醒面冷灰取自 `--fg` 一族，梦面薄暮紫取自全站唯一强调色 `--amber: #9a86c4`。

## 醒 / 梦差在哪

两态是**同一枚图标**——形状只差一片瓣的距离（2.15 单位），其余完全同源。

| | 醒面 | 梦面 |
|---|---|---|
| 底 | 纸面 `#f0f3f6` | 靛夜 `#0c0f18` |
| 瓣 | 实心冷灰 `#2b323c`，刻出来的感觉 | 磨砂半透明，填径向薄暮紫渐变（`#b9aede` → `#6f61a0`），由花心向外化开、边缘发薄 |
| 内层三瓣 | 同墨 42% 不透明度 | 同渐变 50%，更像一层雾 |
| 花心 | 一枚**真孔**（mask 挖空，透出底色） | 孔里点亮一团薄暮光，孔心一点近白 |
| 形态 | 五瓣 + 内层三瓣 | 同几何，但**第三瓣正在离开花心** |

换面机制：标签页图标做不到逐帧过渡。真要用两态，就用 JS 换 `<link rel="icon">`，在 `--reality-mix` 跨过 0.5 的那一下换一次，不跟着每帧走。`favicon.svg` 另走一条更省事的路（见下）。

## 16px 与单色下退化成什么

**16px 是这个方向最大的风险**——花在 16px 极易糊成一颗星、一个点、或一团棉花。正面解法，四条一起用：

1. **只做五瓣，不做六瓣**。六瓣在 16px 里必然读成一颗六角星。
2. **瓣根弦宽 > 相邻根部弧距**，五个瓣在花心处互叠成实心——小尺寸下花心不会碎成五个孤立点。
3. **花心打一枚真孔**（mask 挖空）。16px 下孔径约 2.5px，这枚白心是它区别于普通五角星的关键：一颗星没有孔。
4. **给 16px 另备一对「硬花」**（醒硬 / 梦硬）：瓣短而阔、孔加大、去掉内层三瓣与中脊。站点标签栏默认给梦面，所以梦面也有自己的一版硬花，不是只把默认花缩小。

实测（`shots/c-3.png` 放大镜 + `shots/raw-1.png` 1:1）：16px 里它读作「一朵有白心的五瓣小花」，不是一团棉花。默认花在浅底会有一点毛边（瓣尖发虚），硬花更实、更稳。

**单色退让**：整枚只用 `currentColor` 时仍成立——轮廓靠**瓣间留空**与**花心的孔**读出来，不靠颜色。内层三瓣用同一个墨色的 42%，所以单墨下它是「同一色的两层」，而不是第二种颜色。花心的孔在单墨下依然透底，这就是它不依赖底色的原因。`favicon.svg` 就是这一份。

## 小巧思

1. **花心是一枚真孔，不是画上去的白点**。用 mask 把花心挖空，透出的是它脚下的底色——纸底透纸、夜底透夜、单墨底透单墨。所以这枚标记在任意底色上都成立；而「花心其实是空的、透过去是背景」这件事，本身就很贴「世界随时可能消失」。
2. **醒梦滑杆连底色一起换面**。醒面是纸上的墨花、梦面是夜里的光，各回各的底才对得上。拖到 0.5 时两种都不占上风，恰好演示了审美方向里那句「醒与梦之间不应有明显开关——理想状态是分不清何时切换」。这也正是站点 `--reality-mix` 的做法（连 `--bg` 一起插值）。
3. **`favicon.svg` 自带 `prefers-color-scheme: dark`**。暗色浏览器主题下自动翻成冷白薄暮紫并在花心点亮，同一枚文件不用换——省掉那条换 `<link rel="icon">` 的 JS。

## 风险 / 不确定

- 16px 的孔径约 2.5px，是可见的下限；再小的显示环境（12px 及以下）会丢掉那枚白心，退成一朵实心小花。
- 硬花更实更稳，但可能丢了默认花那点「碎感」。是否值得在 16px 换硬花，请你对着 `shots/c-3.png`（×8 放大镜）与 `shots/raw-1.png`（1:1）裁。
- 单色退让时，内层 42% 依赖与底色的对比；在低对比底（浅灰底 + 浅灰墨）上会明显减弱。
- 梦面在浅色标签栏里偏淡，不建议在浅底上用梦面（页面里浅色栏给的是醒面，就是这个原因）。
- 五瓣 + 抖动在极小尺寸下的极限就是「一朵花」；如果连这也不够，只能再减到三瓣，但那就不再是花了。

## 上一轮的断点（已修）

上一轮跑到一半中断，留下几处未完成，已逐一补上：

- **梦面花瓣整层不画（真 bug）**：`gen.cjs` 里梦面的填充写死成 `url(#gD)`，而生成器实际输出的渐变 id 是 `k-dream-grad`。引用悬空，浏览器对无效 paint server 的处理是「不画」——于是梦面只剩花心那点光，主视觉里像一团光斑，完全看不出花瓣。已把 `ink` 改成占位符 `'@grad'`，由生成器填自己的渐变 id；重新生成后梦面花瓣正常。
- **`favicon.svg` 内层三瓣的旋转轴心**与生成器差 0.35（13.4 vs 13.75），已对齐。
- **叠合滑杆固定在靛夜底上**，醒面（深灰）几乎看不见。已改为底色跟着一起换面。
- **16px 只有醒面有硬花**，梦面缺一版。已补 `harddream`。
- `notes.md` 此前缺失，即本文件。
