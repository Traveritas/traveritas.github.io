规矩 · 景深六刻度位置 → 离焦量 → 半径 → 面亮度
  • 带。六枚沿 14° 轴排开（s），再各自向两侧偏移（p）——两条采样曲线把一条直线打散成「一小片」。
  • 离焦量。f = |s − s_焦| / max。焦平面在第 4 枚上，它两侧的远近都算离焦。
  • 半径。r = 1.70 + 2.00 · f^0.75 —— 离焦越远摊得越开。
  • 面亮度。同一份光摊在更大的面积上：α = 0.30 + 0.70 · (r₀/r)²。所以最实的那一枚永远是最小的那一枚。
  • 形状。越离焦，光圈叶的像越显出来——九边形，转角倒圆；f→0 时它是正圆。
  • 不碰。最后跑一遍互斥松弛，任意两枚之间至少留 0.45 的空隙（16px 下约 0.2px）。

交付与风险notes.md
  • favicon.svg：醒面，单墨可退 currentColor，自带暗色主题换墨（冷灰 → 冷白），同一份文件不用换。
  • favicon-dream.svg：梦面。要跟 reality-mix 走，就 JS 换 <link rel="icon">，跨 0.5 时换一次。
  • 最大的风险：读成气泡。气泡有暗边 + 左上一枚高光；这枚的边是亮的、没有高光——反过来就是「光」。这一条靠明度关系成立，不靠 blur。
  • 不确定：六枚在 16px 里是否还读得成「一片」而不是「六粒」；以及醒面会不会太朴素。请对着上面的放大镜与 1:1 那行裁。
