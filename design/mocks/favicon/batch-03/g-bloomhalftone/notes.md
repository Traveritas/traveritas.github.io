# 网点开花 · Bloom Halftone

`design/mocks/favicon/batch-03/g-bloomhalftone/` · 方向：网点 × 花 · 2026-10-22

---

## 1. 风格一句话

**一朵花，不是画出来的，是印出来的**：斜 14° 的半调网屏按「这一处该有多暗」决定每粒网点的大小，
花的五瓣从网点里显影；花心是网屏唯一让空的一格 —— 孔不是挖的，是印不出来。

## 2. 形从哪来

三段规矩，每一段都能复述、能重算（全在 `gen.cjs` 里）：

**① 连续调 —— 花。** 五瓣，每瓣的长度 / 开角 / 半宽 / 左右偏斜各由一条采样正弦给出：

```
开角  −90° + 72k + 4.6·sin(1.9k + 1.15) + 1.7·cos(3.3k)
瓣长  11.0 · (1 + 0.13·sin(1.7k + 0.8))
半宽  30°  · (1 + 0.10·sin(1.3k + 2.1))
偏斜  0.15·sin(1.25k + 2.3)        左右半宽不等，瓣尖因此偏
瓣形  w(u) = W · (1 − u⁶)^0.30      根部宽、外段渐收、尖梢略钝
```

五瓣油墨叠印成花头（`1 − Π(1 − t)`），所以重叠处自然更暗——不是五个形状贴在一起。
**花心 1.7 内全空，到 3.7 才恢复满墨**：那里本来就没有墨可印。

**② 网屏 —— 14°。** 方形网线绕花心转 14°，与令牌 `seam-angle: 14deg` 同角，也就是主页那根发丝线的角度。

**③ 网点 —— 面积正比于墨量。** 每格取格心的墨量 `t`，
`r = 0.44 · 网距 · √t`，再四舍五入到四档。**0.44 是硬上限**：再暗也不许两粒相碰。

## 3. 醒 / 梦差在哪

形**完全不动**，网点位置一粒不改。差在墨色与外圈：

| | 醒（reality-mix 1） | 梦（0） |
|---|---|---|
| 墨 | `#232830` on `#f0f3f6` | `#dbe3ef` on `#0c0f18` |
| 外圈三粒 | 同墨 | 薄暮紫 `#a195c1` |
| 花心 | 空 | 仍然是空的 |

**花心那格在梦里也没有被填上**——这一处是我最想让它在两态里都成立的地方。

## 4. 16px 与单色下退化成什么

16px 的解法是三层，不是简单缩放：

1. **换线数**：粗网线 `pitch 3.6`（16px 下网距 1.8px，约 25 粒）/ 细网线 `pitch 1.6`（只给 ≥96px）。
2. **对版**：搜网屏相位，让**五瓣各至少压住 3 粒**——否则总有一瓣在 16px 落空（这是最容易被忽略的一步）。
3. **落版**：粗网线的每粒点吸附到 0.5 单位（＝16px 下的 1px）格点上。
   于是 **14° 的斜网在 16px 里走成台阶**——和主页那根台阶状发丝线同一个成因，不是巧合，是同一个像素栅格。

退化成：**一小簇方方正正的点，左上密、右下疏，中间空着一格**。不是一朵花的剪影，是一朵花的**印版**。

**单色（`currentColor`）**：整套只有一种墨，本来就是为单墨设计的（印刷只有一色）。
丢掉的只是梦里外圈那三粒的薄暮紫，形一点不掉。

## 5. 小巧思

1. **高光端退化：最亮那一档网点画成方点。** 真实的半调网屏在极高光端，网点还没长成圆，先被格子的边裁成方。
   所以这套里那些小点是方的、大点是圆的——**从规矩里长出来，不是为了好看贴上去的**。
2. **花心那格是"印不出来"，不是"挖掉了"。** 全图唯一一处不是圆的空，是网屏让出来的一整格。
3. **14° 的网在 16px 里走成台阶**，与主页那根线同源同成因。

## 6. 风险 / 我不确定的地方

1. **16px 下它仍然更像"一小片点阵"而不是"一朵花"。** 这和 `c-halftone` 是同一个短板。
   我用了对版（五瓣各压住 3 粒）来救，但 16px 里「是不是花」取决于看的人——这是我这一套最不确定的一处。
2. **粗网线（25 粒）时花形偏"方"**：因为落版吸附到 1px 格点，花瓣的圆弧被量化成阶梯。
   我认为这正是"被印刷出来的"该有的样子，但也可以被读成"精度不够"。
3. **细网线在 24–32px 会起摩尔纹**（真半调本就会起），所以发货只发粗网线。
4. **醒面偏重**：满墨处 25 粒挤在一起，在浅色标签栏里是一块比较实的灰。这是"印刷"方向的取舍。
5. 梦面在浅色标签栏上偏淡，不建议浅底用梦面。
