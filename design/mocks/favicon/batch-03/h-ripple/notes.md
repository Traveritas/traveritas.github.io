# 水面的圆 · Ripple

`design/mocks/favicon/batch-03/h-ripple/` · 方向：水 · 2026-10-22

---

## 1. 风格一句话

水面上一圈涟漪：一束很轻的东西刚落下，中心一点反光，向外几道环，
**环的间距与粗细各自沿一条衰减曲线收紧，环上的缺口是那根 14° 发丝线穿过水面时留下的。**

## 2. 形从哪来

审美文档把「水面 / 雾」列为母题；主页左上是一团冷光，一根 14° 的发丝线斜穿全屏。
这枚标记就取那件事的横截面：**光落在水上，水面被那根线划过**。

- 落点不是实心圆点，是**一道很短的反光**——两头收尖、沿 14° 躺着。这一点很关键：实心圆点会立刻读成靶心或唱片，而一道反光只会读成水面。
- 圆心沿 14° 偏离几何中心 0.85，环再沿同一条轴拉长 3%。所以它天生不是正同心圆。

## 3. 生成规矩（五条，能复述，全在 `gen.cjs`）

```
1 半径    r(k) = r(k-1) + g0 · gr^(k-1)        间距按几何级数放宽
2 线宽    w(k) = w0 · (r0/r(k))^0.60           点源波振幅 ∝ 1/√r，取 0.60 让它掉得稍快
3 浓度    o(k) = (r0/r(k))^0.78                最外环"几乎化尽"
4 碎片    第 k 环有 k 道缺口，缺口宽 gw(k) = gw0 · (r(k)/r0)^0.60
          —— 数在增、宽也在增：波前走得越远，越容易断
5 光      每环的墨沿 14° 轴做线性衰减（左上 0.55 → 右下 1.0）
          —— 主页唯一的光源在左上，水面就只在那半边亮
```

第 4 条是这套的骨架：**环越往外，缺口越多越宽**。最内环只有一道 18° 的细缝，所以它仍然读作"一个圆"，
不是一段弧——这是它不至于读成一堆碎弧的原因。

## 4. 醒 / 梦差在哪

**圆心、三个半径、三个缺口角度，一个都不改。** 梦面只做三件事：

| | 醒 | 梦 |
|---|---|---|
| 墨 | `currentColor`（纸底 `#232830`） | 薄暮紫 `#b8abdb` |
| 环心 | 同心 | 各环错开一点，方向各不相同（0.16 / 0.34 / 0.58，沿 14° 反向 / 垂直 / 再反向） |
| 最外环 | 在 | 外推 0.5、淡到 0.72；最短那段再断开、转开 12° |
| 落点 | 同墨 | 近白 |

最外环"散掉"是这一套的梦面语义：**同一圈水，梦里的那圈快记不住了。**

## 5. 16px 与单色下退化成什么

- **16px 真栅格**（页面第 3 节：光栅化成 16×16 再放大八倍，不是矢量缩放）：
  三道环都还在，最内环的缺口仍看得出，落点还在。同心圆是这套的天然优势——
  它不像网点或花那样需要"换线数"，环的粗细本身就是按 1px 附近定的。
- **单色（`currentColor`）**：整套本来就只走一种墨，第 5 条规矩（沿 14° 轴的明暗衰减）也是用同一个墨色的
  不同浓度做的，所以压成单墨不掉任何形。丢的只是梦面的薄暮紫。
- **最弱的一格**：梦面 + 浅底。薄暮紫在纸面上偏淡（页面里那一格自己也标了"偏淡"）。

## 6. 怎么避开「靶心 / Wi-Fi / 加载图标 / 唱片」这四种误读

这是本方向最大的风险，逐条正面处理：

| 误读 | 怎么避开 |
|---|---|
| 靶心 | 靶心是**等距**同心圆。这里间距按几何级数放宽（3.9 / 4.4 / 5.0），一眼就不是量规。 |
| Wi-Fi | Wi-Fi 是**同心扇弧**，开口朝一个方向。这里缺口分布在各环不同方位，且**数在增**（1 / 2 / 3 道），不构成扇形。 |
| 加载图标 | 加载图标是**一段弧 + 匀速转**。这里是三整圈带缺口，静态、不对称。 |
| 唱片 | 唱片是**密而等距**的细环 + 中心圆标。这里只有三环，且中心是一道反光而不是圆点。 |

剩下唯一的风险是「声呐 / 雷达」——这需要一个"扫描线"才会成立，这里没有。

## 7. 小巧思

1. **落点是一道反光，不是圆点。** 就这一处，把"靶心 / 唱片"两种最强的误读同时挡掉了。
2. **缺口数量随半径增加**（第 k 环 k 道）——这是从"波前越远越容易断"这条物理直觉里长出来的规矩，
   不是随机撒的装饰。而最内环只有一道 18° 细缝，保住了"一个圆"的读法。
3. **墨只亮在 14° 轴的一侧**（左上 0.55 → 右下 1.0），照抄主页"唯一光源在左上"的布光。

## 8. 风险 / 不确定

1. **最像「声呐 / 雷达」**，尤其深底上发紫光时。我认为三环 + 反光的组合够远，但这是口味判断。
2. **16px 下缺口会被抗锯齿吃掉一部分**，尤其最外环那几道。真栅格里还看得出，但已经接近临界。
3. **梦面浅底偏淡**（见第 5 节），不建议浅色标签栏用梦面。
4. 这枚标记**不编码任何字母或名字**，它只描述"水面上的一件事"。若你要它承担站名的可读性，这个方向不承担。
