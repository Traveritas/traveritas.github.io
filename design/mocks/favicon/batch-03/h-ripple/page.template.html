07 · 语境放回夜里
Traveritas
缺口的方位 · 圆心的偏向

把圆心从几何中心往 14° 的方向挪 0.8；最外环那道 48° 的缺口正落在这条线上。所以它看起来像水面被什么轻轻划了一下，而不是一个摆正的圆。

08 · 生成规矩可复述 · 不是手调轮廓
%%DIAG%%
%%TABLE%%
环半径 r线宽 w浓度缺口
  • 间距：r(k) = r(k-1) + g0 · gr^(k-1)，g0 = 3.75，gr = 1.15。越往外越松。
  • 线宽：w(k) = w0 · √(r0 / r(k))。点源波的能量摊在一圈越来越长的波前上，振幅就这么掉。
  • 浓度：同一条曲线再压一道，(r0 / r(k))^0.7。所以最外环不是"画淡了"，是它本来就没剩多少。
  • 缺口：每环的缺口方位互不重叠（104° / 216° / 0° 与 300°），最外环因此碎成两段。任何一环都不是半圆。
  • 偏心：圆心沿 14° 偏离几何中心 0.8，环再沿同一条轴被拉长 3%。
09 · 风险我自己不确定的地方
同心环天生像靶心。我用四件事拆它：落点是一道横着的光不是圆点、三环缺口互不重叠、最外环断成两段、圆心偏离几何中心。16px 下前两条起主要作用，后两条是余量。
16px 的内两环间隙只有 1px 左右。放大八倍看是清楚的，但在 1x 屏上可能糊成一条。若验收觉得糊，把 g0 从 3.75 提到 4.4、环数降到 2，形状逻辑不变。
它可能被读成"水波/信号"而不是"水面"。我赌的是缺口与偏心足够把"信号"那一读压下去；这一条只有你看了才算数。
梦面在浅底上偏淡。薄暮紫放在纸面上只有约 3:1，能看但不精神。页面里浅栏只给醒面，就是这个原因。
