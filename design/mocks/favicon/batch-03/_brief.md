# batch-03 · 本批的追加简报

先读两份：`design/mocks/favicon/brief.md`（通用简报：基调、红线、硬性要求、交付格式、截图命令）
与 `design/mocks/favicon/REVIEW.md`（**站主已经否掉六个方向，这一页写了为什么**）。

本批的规则与通用简报有两处不同：

## 1. 只允许看两套旧稿，作为"及格线"

- `design/mocks/favicon/batch-01/c-halftone/`（半调网点）
- `design/mocks/favicon/batch-02/d-lily/`（花）

这两套是站主唯一认可的方向。**看它们是为了校准标准，不是抄形。**
其余所有旧目录（`a-nightlight` / `b-stepline` / `e-frostfacet` / `f-mirror` 以及 `cursor-*`、`icons/`、`wander/`）一律不要打开。

看完这两套，请回答自己一个问题：**它们为什么活下来了？** 然后让你的方案满足同样的三条——

1. 有一个**叫得出名字**的主体（花、水、光斑……不是"一束光"、"一段台阶"、"一个镜像"这种说法）。
2. 有一套**能复述的生成规矩**（网线怎么排、瓣怎么取样），而不是手调一个好看的轮廓。
3. **16px 下还是一个"东西"**，不是一个符号。

## 2. 先写 notes.md，再做图

前两批有三次子智能体跑到一半断线，断在写 notes 之前，交付就不齐。这一批请**先落 `notes.md` 的骨架**（风格一句话 / 形从哪来 / 醒梦差在哪 / 16px 与单色 / 小巧思 / 风险），做完再回来补细节。这样中途挂了也留得下东西。

## 3. 交付前必须自检这一条

独立 `.svg` 文件会被浏览器**当图片**加载，按 XML 严格解析。**XML 注释里不能出现连续两个连字符**——
所以 `<!-- 跟 --reality-mix 走 -->` 会让整个文件打不开，变成裂图。前两批有三枚 SVG 栽在这里。
凡是注释里要提站内令牌，写成 `reality-mix` 或 `seam-angle`，别带前导双横线。
交之前自己用 `<img src="...">` 引一遍，确认 `naturalWidth > 0`。
