# batch-03 · 种子说明（两套被留下的方向）

batch-01 与 batch-02 一共六套，站主看过之后只留下了两套。这一批**不另开新轴**，而是从这两套里长出来。

## 被留下的两套

### `batch-01/c-halftone` —— 十四度网点

- **留下的理由**：它是六套里唯一"材料直接就是主页材料"的一套。主页背景铺着一层极细的半调网点，
  这枚图标就是从那片网点里剪下来的一小块——斜 14° 的网线本身成像，成的是主页左上那团冷光。
- **它做对的事**：① 网屏角度落在站点的签名角度上；② 25 粒点、靠"点还在不在"定形状而不是靠"点多小"；
  ③ 全图唯一一枚方点（真网屏在极高光端网点会退化成方块）——这既是印刷上的诚实，也是全站唯一的"像素"，
  和 NEXUS 那套 Silkscreen 同族，而且它长在斜网上、自己却是正的。
- **它的短板**：16px 下轮廓是"带齿的圆团"而不是一个干净的形；它是一块**质感**，不是一个**记号**——
  远看有气质，近看说不出它是什么。

### `batch-02/d-lily` —— 折花

- **留下的理由**：六套里唯一"是个东西"的一套。它在大尺寸上最漂亮，而且花心是一枚**真孔**
  （mask 挖空、透出脚下底色），不是画上去的白点——"花心其实是空的"这件事很贴站点。
- **它做对的事**：① 五瓣，每瓣的长度 / 开角 / 左右偏斜各自沿一条采样正弦取样，
  所以"似乎有某种规则，只是暂时无法理解"，不是机械放射对称；② 瓣根弦宽大于相邻根部弧距，
  花心天然实心，16px 不碎成五个点；③ 醒梦各备了一版"硬花"（瓣短而阔、孔加大）。
- **它的短板**：16px 下往五角星上飘；它是六套里最"装饰"、最不"结构"的一套。

## 这一批怎么用它们

**可以读这两套的 `index.html` / `notes.md` / `favicon.svg`**——它们是站主点过头的，读它们不算犯规。
**不要读 `a-nightlight` / `b-stepline` / `e-frostfacet` / `f-mirror`**（都被否了，读了只会被带偏）。

**但不要照抄。** 抄一遍没有意义：站主要的是"在它们的基础上往前走一步"。
每套要能回答一句话：**你从被留下的那一套里拿走了什么，又解决了它的什么短板。**

## 这一批的三个方向

1. **`g-dotlily` · 网点花** —— 把两套合起来：花是形，网点是材料。花的轮廓给出"是个东西"，
   网屏给出"是这个站"。难点在 16px：网点必须粗到让花的轮廓活下来，而不是把轮廓吃掉。
2. **`h-develop` · 显影** —— 还是半调网点，但给它一个**记号性**的锚：不是一团光，而是一道边 / 一个孔 /
   一条正在被印出来的界线。让网点从"质感"变成"符号"。参考审美文档里"光学与显影"那条隐喻。
3. **`i-lilyline` · 百合线** —— 花，但换成**一条连续的细线**（线描 / 刻线），不是实心花瓣。
   这是给 `d-lily` 的"结构"答案：看花能不能在纯线、单墨、16px 下活下来；线本身可以带上 14°。

其余照 `design/mocks/favicon/brief.md` 的交付格式与截图要求。
