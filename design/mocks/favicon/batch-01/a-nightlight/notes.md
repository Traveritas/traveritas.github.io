# 夜里的光点 · a-nightlight

标签页图标方向 mockup · batch-01 · 2026-10-22

---

## 风格一句话

**一枚自带的夜：靛色玻璃片里悬着一点光。** 光在左上，就是主页左上角那团冷光的位置；
片的边缘，醒面是清楚的，梦面化开了——同一枚，只是边界还在不在。

---

## 形从哪来

- **那束光**。`_ref/home-1440.png` 里整屏只有一处光源：左上角一团近白偏蓝的冷光
  （`#e6ebf1` → `#a6b4c6` 一族）。它比页面上的任何形状都更像这个站的"本体"，
  所以图标就做那束光，位置照搬——光核落在 32 格里的 **(11.5, 10.7)**，约 36% / 33%。
- **那根 14° 的台阶线**。它不是被"画"进图标的，而是被画成"在光那里少了一段"：
  台阶线从左边缘进来，穿过光的外圈时被化掉，再从右侧淡出。主页那根线正是这样
  穿过冷光的外圈。
- **那片玻璃**。`aesthetic-direction.md` 的"磨砂玻璃 + 半透明树脂"落到一枚 32 格上：
  片心从左上亮起（`#181f2d` → `#080b11` 的径向），像光打在树脂上；片边一根发丝线
  把片子交代清楚。整枚**没有一根轮廓线是主角**——它靠晕、靠渐隐、靠留白被认出来。

## 醒 / 梦差在哪

| 元素 | 醒 · WAKE | 梦 · DREAM |
|---|---|---|
| 片边 | 一根发丝线，清楚（15% 白） | 没有边，光漫到片的四角 |
| 晕 | 收紧 `r 11.5`，最亮 30% | 晕开 `r 16`，最亮 36% |
| 光核 | 边缘硬：84% 处才收 | 边缘软：70% 就开始散 |
| 色温 | 冷灰白 `#f5f9fd` | 暖白偏薄暮 `#fffdf9` → `#cebde5` |
| 片色 | 冷靛 `#101623` | 偏紫 `#150e22` |
| 14° 台阶线 | 在（0.55 宽，最亮 19%） | 化尽（5%） |

**醒 = 收，梦 = 散。** 光核的位置、片的轮廓、光在左上的构图一个都没动——
两态是同一枚的两口气，不是两枚图标。一句话概括：**醒面边缘清楚，梦面边缘不在。**

## 16px 与单色下退化成什么

### 16px（这一方向最大的坑，正面解）

晕在 16px 下极易糊成一坨灰。**我的解法不是把晕压小，而是让光永远有自己的一块底**：
光落在一枚深靛玻璃片上，而不是落在标签栏的底色上。于是晕无论多大，做的都是
"把暗处照亮"；浅色标签栏里，那枚片本身就是一块清楚的深色。风险从"晕糊成灰"
换成了"片够不够大"——16px 的片就是 16px，够。

在此之上，16px 另画一套（不是把大图缩小）：

- **晕整段删掉**（不是压小），只剩 `r 9` 的一圈近晕；
- **14° 台阶线整根删掉**（0.55 宽在 16px 下是 0.28px，等于噪点）；
- **光核放大**：`r 2.5 → 3.1`，并从"硬收"再硬一档；
- **片边提亮**：15% → 32%，否则深色标签栏里片会沉掉；
- 片心抬亮一档（`#1d2534`），免得小尺寸整片沉死。

16px 下真正被认出来的是：**一枚暗片 + 一点偏左上的亮**。光晕不是身份，光点是。

`shots/d2-size.png` 底下那四张，是把 16px 的栅格**原样放大十倍（最近邻、不插值）**——
就是标签栏里真正拿到的那些像素，醒梦 × 深浅底各一张。

### 单色（`currentColor`）

单色下晕、色温、玻璃全都不成立，只剩两件事：**一个容器，一点光**。
于是退成「**墨色的片 + 抠出的一点亮**」（mask 抠洞，`favicon-mono.svg`）——
片还在，光还在，左上角那个位置还在。备选是细线片 + 实心光点，更贴站内细线的语气，
但 16px 下明显比抠洞弱（`shots/d4-mono.png` 里两版并排）。

**一句技术前提**：标签页图标是独立文档，`currentColor` 读不到页面的颜色。
所以 `favicon.svg` 里必须写死色值；单色版只服务站内（页眉、工具栏那颗星旁边）。

## 小巧思

1. **光核是活的，不是死的。** 晕 / 光雾 / 光核三层的圆心各自往左上挪 0.25 / 0.25 / 0.25，
   合起来核心比晕心偏左上 0.5——像是光源在片子外面，光是从外面照进来的。
   醒面尤其明显：核硬，偏移就看得出来。
2. **台阶线在光那里被吃掉一段。** 线的描边渐变在光的位置归零（`lineW` 的 33%–41% 段），
   所以不是"光盖住了线"，是"线在那里没有了"。这一处同时干两件事：它是两态的开关
   （醒面在、梦面尽），也是"光把结构化开"这句话本身。
3. **16px 不是缩放，是另画。** 大图缩到 16px 会糊；这里 16px 那套是独立的一张
   （删晕、删线、放大核、提亮边），两套共用一个坐标原点，所以看起来仍是同一枚。

## 风险 / 我不确定的地方

1. **醒面的底色，最需要你拍板。** 方向描述里醒面是"纸面上一枚冷光"。我最终让两态都
   自带深色玻璃片——理由是标签栏深浅两种底都要活，而"纸上一点冷光"在浅色标签栏里
   会退成一颗灰珠（片的边看不见）。第 06 节给了另一条路（浅片版，纸上一枚边缘清楚的冷珠），
   两个 16px 小样都排出来了，你挑一条。
2. **光核偏左上，是否偏太多。** 16px 下它离片心约 2px。再少一点会变成"正中一点"，
   再多一点就有点像角标了。
3. **深色标签栏里片的边很淡**（`#101623` 对 `#202124`）。`prefers-color-scheme: dark` 里
   把发丝边提到 26% 是补偿，但在纯黑标签栏里可能仍只剩一点亮。这或许正是想要的
   （光点浮在夜里），也或许太弱——需要你在真标签栏里看一眼。
4. **梦面的紫**已经压过一档（`#201830`），怕太"糖果紫"。可能还能再压。
5. **台阶线在 32px 已经接近噪点**。若你觉得 32 也不该有，把阈值提到 48 即可（改一处）。
6. **换面落地**：站内已有 `reality.ts` 的 `onMixChange()` 订阅口。建议订阅它，
   `--reality-mix` 越过 0.5 时换 `<link rel="icon">` 的 href（带一点回差，免得在阈值上抖），
   **不逐帧换**——标签页看不到过渡，换早了只会闪。若你希望标签页图标恒定不随醒梦变，
   `favicon.svg` 就是恒醒面的真值，删掉 dream 那份即可。
