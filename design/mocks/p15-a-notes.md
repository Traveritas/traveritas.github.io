# p15-A 星野标尺与微光尘粒 · Quantized Reticle & Luminous Caustics

## 主张（两态差到底是什么）
一片**观测场**：它量的是这一页从滚动里拿不走的三组几何——版心两缘、视口两个三分点、它们的四个交点。醒态是这套几何的**读数**（锚定到 1px、绝对静止、冷灰）；梦态是**同一片场按字标的拍子被抽帧、被点亮**。

## 醒 / 梦
**醒**：逐 zone 标定的墨色旋钮 `--p15-a`（light .027 / deep .138 / paper .031——同一个 alpha 在三段夜色上的 ΔL 差 5 倍以上，不标定就会"深色面隐身、浅色面抢字"）；四档全是它的倍数并一律 `color-mix(--fg, transparent)`：量线本体与刻度 100%、三分线 52%、测量站 128%、页边标注 430%。零位移、零呼吸、站 0°、无残影/无光斑/无尘粒，整场 opacity 0.72。**醒态 0 动画的机制**：`animation-duration: calc(var(--still) * 10s)` —— 醒态算出 0s，动画不在效（不是 display:none，几何仍在场）；实测 `getAnimations()` 本层 0 个（含 ::before）。
**梦**：8 个抽帧元素（2 纵线组 + 2 三分线 + 4 测量站）共用**一个字标的钟**：`10s = 7×1s 步进 + 3s 停歇`，`steps(1,end)`，与 `src/scripts/brand.ts` 的 `CADENCE_MS=1000 / BREATH_PAUSE_MS=3000` 逐值对应；各元素只差相位（`--ph −0.7…−9.2s`），振幅 1.6–3px 一律 ×`--still`（纵线只横移、三分线只竖移——另一轴线身占满视口，动了看不见）。三处**静态**差（给静止截图的那一层）：测量站转 14°（缝线角）、整场错位 (6,−5)px（一格 3px）、两条三分线各多一道 +4px 残影（opacity .55×still）。三枚**琥珀微光尘粒**落在三个交点上：3s 六档量化呼吸（与字标的 3s 停歇同拍）、光量 ×`--still`（醒态熄灭、长按逐帧明灭）、色相不写死（`--amber` 醒态本就被状态机插成 #a7b1ba，"暖色出现"本身随醒度连续发生）。画面深处两处**暖色光斑**：`radial-gradient(closest-side)`（无 filter: blur，峰心在页边），颜色取 `--ghost-ink` 随醒度插值、光量 ×`--still`、3s 三档呼吸。场 opacity 0.72→1。

## 与上一轮同向那一稿（p14-D 星野标尺）的差别——重复度诚实说明
几何母题（版心量线 + 刻度 + 十字站 + 页边字标）**重复度约一半**，不假装是新的。真新增的维度是：① **琥珀微光尘粒**（3 枚，量化呼吸 + 光量随醒度连续熄灭）；② **暖色光斑**（radial-gradient 实现的柔光，无 blur，暖度随 `--amber` 连续插值）——p14-D 完全没有这两件事。
另外四条是把上一轮的裁决点折进来：③ 醒态亮度 9.2 / 15.9 / 19.7% → **6.9 / 7.3 / 7.1%**（逐 zone 标定 alpha，"看得见但不越界"）；④ 节拍从"各自错开的 4 步 / 6.4–10.3s"换成**全场共用一个 10s 钟**，与 brand.ts 严格同源；⑤ 醒态 animation 数从"常驻但振幅为 0"变成**真 0**；⑥ 静止帧的两态差从"只有位移"补到三处静态差。**减掉的**：不再量 56rem 与左轨四档（外壳没有左轨），横向量线由"深度线"换成"视口三分点"，刻度只留在两缘。

## 最不放心的
1. **余量最薄的一处**：纸面呼吸峰值 30.4%，距红线 35% 只剩 4.6pt；而 `?freeze=1` 的矩阵（02/05/06）停在尘粒最暗那一档（0.66），实跑最亮帧比截图高 5–7pt——判读者若按实跑最亮帧读数，才是本稿的上限。
2. **尘粒正好落在版心左缘上**：正文首字压到尘核时，深色底那一处最坏对比度 3.46:1（浅面 4.4:1）。外壳自带的 14° 缝线在同一位置是 3.30:1（1px 线、横穿每一行字）——量级相同，但这毕竟是我的元素，如实记下。
3. **梦态整场错位 (6,−5)px 会让"量线对准版心"在梦里失效**。这是刻意的"被读错一格"，但如果裁决要求锚定在任何醒度下都恒定，这一条要撤（撤掉后梦态仍有 14° 站旋转与残影，静止帧照样可辨）。
4. **抽帧在长按过渡里会随 `--still` 变小而"变快"**（周期 10s→0s ⇒ 收拢那 1–2 秒步子越来越密）。数值上完全连续、方向也对（位移与光量同时归零），但我只在采样里验过，没在真机上盯过那段观感。
5. **共用脚本的 09 是页面坐标裁片、落在首屏**，看不到本层（四稿同机位同结果）；本层的 1px 证据只能靠自建的 `x-z3-*`。另：外壳的 `src` 闩锁在 latch 后不复位，同一页面上第二次真实 pointerdown 会被吞（四稿同）——要与本稿连续交互，请用 `window.__p15.hold()/release()` 或重载页面。
