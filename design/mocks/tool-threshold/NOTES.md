# 切面 `threshold` · 工具层原型（端口 4641）

> 2026-10-18。四个方向并行，这是其中「切面」那一个。
> 一件东西 + 一个动词：**一根横过屏幕的平切面线，加上线上排开的切片；切片从线上升起、用完沉回线里。**
> 定方向用，**不是定稿**。

## 运行

```bash
node design/mocks/tool-threshold/serve.cjs     # http://localhost:4641/tool-threshold/
node design/mocks/tool-threshold/.shot.cjs     # 截图 → .shots/，并在末尾打印对比度与错误数
```

地址参数：`?ctx=home|grid|read|gate|404` · `?face=wake|dream` · `?scene=essay|moment|project` ·
`?view=grid|explore` · `?q=字` · `?tool=<id>` · `?verb=0..1`（停在切片升起的中途某一帧）。

`ONLY=home,grid,read,gate,404,dream,paths,verb,mobile,tools,notches,contrast` 只跑一部分。

键盘：`T` 把游标唤到线上 · `← / →` 沿线挑 · `回车` 落定 · `Esc` 沉回去。
刻痕本身是可聚焦的按钮，`Tab` 也能走到、回车也能开。

数据与配图只读地取 `../layout-plane/`（`window.PLANE_DATA` + `assets/img/`）。

## 1 · 那件东西与那个动词

**那件东西**：`gate.astro` 那根横过屏幕的平切面线。线上等距排开 **12 片极短的刻痕**，一片是一件工具。
线以上是天光，线以下是水与正文。站内既有的 **14° 缝线**与**顶部发丝进度线**在这里一并接住——屏幕上一共三根线，切面线是横的那一根。

**那个动词**：**升起 / 沉回线里**。指针沿线扫过，那一片从线上升起、展开成一块可读的玻璃面；
用完（点线以下、或再按 `T` / `Esc`）它沉回线里，只留下那道短刻痕。**线以下（正文所在的那一半）不动。**

材质：线以上的天光（`gate.astro` 的 `--sky-wake` / `--sky-dream`）、线以下的碎光与水纹（接 `about-decor.ts` 的做法，未 import）、
升起的那块磨砂玻璃面、以及线上那枚琥珀游标。

它凭什么成立：NEXUS 已经把「一根平线 + 线上排开的切片」这套语法确立过一次（`gate.astro` 的终态）。
把同一根线带回主页 / 目录 / 阅读 / 失线页，整站于是读成**同一根线在四个时刻**；
而切片天生就是「可挑选的工具」——这句话的出处是 `design/mocks/wander/NOTES.md` 第 50 行（顶部检索框先拿掉，以后并进「工具区」）。

## 2 · 十二件工具：各自在哪、怎么到

全部落在同一根线上，从左到右依次是（`00-notches-all.png` 是它们同时露出名字的索引帧；
平时只露极短的刻痕，指针靠近或 `T` 走到才升起名字）：

| 4 | 归处 · HOME | 第 4 片 | 同上 | 回 `/` |
| 5 | 门 · NEXUS | 第 5 片 | 同上 | 去 `/gate/`；原型里点它就地把语境换成入口那一屏 |
| 6 | 出口 · EXITS | 第 6 片 | 同上 | GitHub / RSS |
| 7 | 面 · FACE | 第 7 片 | 同上 | 醒 ↔ 梦；只换线以上那一半天光与标签，线以下不动 |
| 8 | 声 · SOUND | 第 8 片 | 同上 | 环境声开关（三根微弦）；本原型不出声，只做状态与形制 |
| 9 | 目录 · CONTENTS | 第 9 片 | 同上 | 阅读页给 h2 主刻度 / h3 细刻度并跳转；别的语境给当前场景的条目名录 |

## 3 · 三条召唤路径（唤出的是同一个面）

三条路都通，且落定后都是 `#face` 这一块玻璃面（同一个 DOM、同一套排版）：

1. **边缘露头（常驻）**：线一直在，线上永远露出 12 道极短的刻痕——它本身就在说「这里能挑」。
   指针移到某一片上，刻痕变长、宝石亮起、名字浮出，点下去就升起。
   截图：`07-path-edge-risen.png`（刚升起名字，还没开面）、`07b-path-edge-face.png`（面已升起）。
2. **指针跟随 / 扫过**：指针沿线走，游标（琥珀点 + 一道 26px 的细茎）跟着走，刻痕逐个升起。
   落定时点一下，面就从游标所在的那一片长出来。
   截图：`08-path-pointer-sweep.png`（扫到第一片、名字已浮出、面还没开）、`08b-path-pointer-face.png`。
3. **快捷键**：按 `T` 把游标唤到线上（第一片），`← / →` 沿线挑，`回车` 落定，`Esc` 沉回去；
   面开着时按 `← / →` 直接换片。
   截图：`09-path-keys-cursor.png`（游标与名字已就位、面未开）、`09b-path-keys-face.png`。

三条路的一致性由截图脚本当场断言：`边缘=寻找FIND 指针=寻找FIND 快捷键=寻找FIND → 同一个面 OK`。

## 5 · 我认为这个方案成不成立、哪里最弱

**成立的部分**：这件东西是现成的、已经被站长验收过一次的（`gate.astro`），所以「同一根线在四个时刻」不是硬凑的类比，而是把既有的语法带回全站。
切片 = 工具这件事也天然——一条线上排开十二片，挑哪一片就是选哪一件，不需要额外解释。
「线以下不动」这条纪律守住之后，它没有退化成顶部工具条：工具不是常驻一排按钮，而是**一次只升起一片**，
而且升起的位置就是指针所在的位置——面从你挑的那一片长出来。

**最弱的一处**：**面升起的位置与它锚定的那一片会错开。**
面有 480px 宽、要留在屏幕内，所以靠边的刻痕（第 1 片、第 12 片）升起时会被夹回屏幕内，
面的中心就不再压在那道刻痕上——「这一片升起来了」这层因果在视觉上被削弱了一点。
现在的补救是：面的下边缘始终压在线上（它确实是长出来的），游标那枚琥珀点也留在刻痕处。
但要真的立住，大概得让面在靠边时改成**从刻痕向外展开**（左下角或右下角锚定），而不是居中——这一版没做。

**第二弱**：阅读页的天光占了上 32%，那是**真的空着**。
它贴《醒梦》的大面积留白，但也是最容易被说「浪费一屏」的地方。目录页 34% 同理。
一个可能的改法是把阅读页的线压到 22% 左右、面改成向上**溢出**并允许盖住页眉——但那就开始碰正文了，这一版没敢试。

**第三弱**：面里放十二件工具的内容密度不均——检索 / 筛 / 目录是实打实的一块面，归处 / 出口只有一行链接。
一行的面升起来，有点像「为了一行字动用了一整套升起」。

## 6 · 发现了但没处理的问题 · 需要人眼确认的地方

**没处理**：

1. **面靠边时锚点偏移**（见上）。要人眼判断这个偏移是否已经影响「因果」。
2. **换面只换了线以上**。线以下的夜色不随 `?face=` 变（阅读页两面共用浅梦底）。这是刻意的纪律，但两面在阅读页的区别只剩一层暖粉与标签，**偏薄**——需要人眼判断够不够。
3. **环境声不出声**。第 8 片只有状态与形制，没有真音频（原型不引依赖、不联网）。
4. **入口语境的晶体与面会争中间**。晶体立在 50% 正中；面若从正中的刻痕升起会压住晶体。这一版靠「锚点夹回 + 截图时挑靠边的片」绕开，没有真正的避让逻辑。
5. **触摸端只有退化**。`pointerType === 'touch'` 时不走指针扫过那一条路，只能点刻痕；面宽也直接铺满。390×844 已实测不溢出、不压字，但手感没在真机上验过。
6. **无脚本兜底只有一句提示**。工具层本来就是增强层，正文与目录的兜底（醒面真值）在原型里是完整的，但没做 noscript 下的静态目录。
7. **浅底的 `--fg-soft` 从令牌的 `#56606d` 调深到 `#4a545f`**：原值在 `#c6ced9` 上只有 4.0，柔正文过不了 4.5。这是本原型唯一的令牌偏离。
8. **`.shots/00-notches-all.png` 是截图脚本临时揭示所有标签拍的诊断帧**，不是原型本身的状态。

**需要人眼确认的帧**（我看不到「像不像」）：

- `04-gate.png` / `25-gate-face.png`：线以上天光与 `gate.astro` 原屏是否接得上（色带位置、地平亮带高度）。
- `10-verb-055.png`：升起 55% 那一帧，「从线里长出来」的读感对不对，还是像一块被裁掉一半的卡片。
- `07b-path-edge-face.png` / `08b-path-pointer-face.png`：靠边升起时锚点偏移是否可接受（第 5 节最弱那一条）。
- `00-notches-all.png`：十二片刻痕的间距在 1440 下是否太挤、名字是否互相压到。
- `02c-grid-other.png` / `02b-grid-deep.png`：异相与深眠两种夜色下线与天光是否各自成立。
- `30-m-grid.png` / `31-m-read.png`：窄屏上刻痕会不会小到点不中。

## 实现要点（给要接着改的人）

| | |
| --- | --- |
| `index.html` | 骨架：#sky / #water / #seam / #hairline / #world / #threshold（线 + 刻痕 + 游标）/ #facewrap（面）|
| `threshold.css` | 令牌与四种夜色、线的墨色、刻痕的升起、面的玻璃、两条既有线、窄屏与减动效 |
| `threshold.js` | 数据、十二个面、三条召唤路径、语境切换、水与碎光、滚动进度、`window.__th` 调试口 |
| `serve.cjs` | 照抄 `wander/server.cjs`，端口 4641，`/fonts/noto/` `/fonts/plex/` 两个前缀 |
| `.shot.cjs` | 40 张帧 + 三条路一致性断言 + 「线以下不动」断言 + 窄屏溢出断言 + 对比度实测，报告写进 `.shots/report.txt` |

- **面怎么升起**：`#facewrap` 是一块 `height: var(--th-y)` 的裁切盒（只覆盖线以上），面绝对定位 `bottom: 0`，
  由 `--rise` 驱动 `translateY((1 - rise) * 100%)`。`?verb=` 直接写 `--rise` 并加 `html.frozen` 关掉过渡。
- **线以下不动**：世界是另一个 fixed 盒（`top: var(--th-y)`），面是覆盖层，不参与它的布局。
  截图脚本每次都会比对升起前后的 `top / height / scrollHeight / scrollTop`，必须一字不变。
- **中文小字**：标签一律 `--font-body`，只有西文与数字走 `--font-mono`（Plex Mono 没有中文字形）。
- **琥珀**只用在游标、焦点、当前项与升起的那一刃，没有第二个强调色。
- 减动效下：面直接显示、刻痕直接升起、游标不呼吸、水只画一帧。

## 红线自查

- 界面文案里没有针、缝、穿针、起针、落针、针脚；线就叫线（`--seam-angle` 只作为变量名引用）。
- 没有「这是梦 / 你在做梦 / 快醒了 / 可核验」这类直白标签；梦感只走天光、悬停与微光。
- 没有账目 / 台账 / 案号 / 待立项 / 进度刻度这类词；列表就是干净的名录与存目。
- 没有「白昼写代码夜里构筑世界」这类极客中二。
- 不新增依赖、不引外部字体或 CDN、不联网。
- 只写了 `design/mocks/tool-threshold/` 这一个目录，没有碰 `src/` `public/` `dist/`，没有 git commit。
