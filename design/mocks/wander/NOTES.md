# 漫游 / 检索（布局原型 · 方向一）

> 2026-10-18。一个方向从头做完整：窗用最简的样式，悬停是倾斜，
> 同一批窗有两种看法——**漫游**给想逛的人，**检索**给要找东西的人——两者之间不是换页，是同一批东西在动。
> 背景（流光 + 重弹簧）与已定的装饰（瞬间 · 细雨、项目 · 星尘）沿用 drift。

## 运行

```bash
node design/mocks/wander/server.cjs     # http://localhost:4630/wander/
node design/mocks/wander/.shot.cjs      # 截图 → .shots/（ONLY=explore,hover,togrid,grid,find,read,toexplore,wipe,mobile,many）
```

地址参数：`?view=grid|explore`（不给就用上次的，记在 localStorage；第一次来是检索）· `?scene=essay|moment|project` · `?many=1`（每个版块复制到十几条，试内容变多）· `?wind=0`（关掉随笔的风）。

键盘：`V` 切换两种看法（检索里按，进入指针所在那一栏） · `1 2 3` 换场景（检索里是跳到那一栏） · 漫游里方向键平移、`+ -` 推拉 · 检索里方向键在窗之间走、回车打开 · 阅读里 `← →` 翻上一条 / 下一条、`Esc` 收起。

数据与配图只读地取 `../layout-plane/`。

## 窗

- 一片半透明的薄片 + 1px 边 + 3px 圆角 + 一道细标题栏。**标题栏不写版块名**（栏和夜色已经说了它是什么），左边空心小圈 + 日期，右边一条次要信息（随笔：字数；项目：状态；多图瞬间：第几张）。
- 版面以日期、标题、简介、标签为重点：标题 24px 是主角，简介最多三行，底部一排细边小签（随笔是标签，项目是链接，瞬间图注右侧放第一个标签）。**文字类的窗高度按内容排**，不再固定高度留一大块空。
  不做像素边、不做假按钮——**像素与定格归空间（流光、失焦、天气），窗本身保持干净、连续**。
- 卡面画在 canvas 里（固定 2×，检索里缩到 0.6–0.86 字仍清楚），投影与背后的磨砂由 CSS 给，**只有清楚的那一档才有**（远处只剩像素块，投影与磨砂没有意义）。
- 悬停：朝指针倾斜（漫游 7°、检索 4.5°，略欠阻尼，松开会轻轻晃回去）+ 跟着指针在玻璃上走的一小片反光 + 沿边一道亮线 + 投影加深、微微抬起。漫游里旁边的窗让开一点；检索里邻居不动（找东西的人不希望周围在晃）。
- 漫游里只有**真正清楚**的窗（离焦平面 |ln δ| < 0.1，比「没被降采样」更严——稍远稍近、字已经发虚的那几份不算）才会悬停倾斜、点了打开；其余一律是「走过去」：镜头飞过去让它落在焦平面。不清楚的窗光标是放大镜。

## 两种看法

**漫游**：drift 的空间原样（5 层 × Z 无限循环、失焦＝像素化、近硬远软的弹簧、重弹簧背景）。

**检索**：屏幕被两条 14° 的斜缝切成三栏：随笔 · 瞬间 · 项目，三种夜色并排，每栏里的窗按日期倒排成一列。

- 宽屏：中栏是一条等宽的斜带，窗居中；**左栏的窗贴着第一条缝、右栏的贴着第二条缝**——三列都顺着 14° 一级级错开，又都不碰屏幕边。缝的位置与窗的缩放是一起解出来的（1440 × 900 下缩放 0.86）。每栏各自滚，滚动时窗沿着斜缝方向走。
- 窄屏 / 竖着的手机：竖缝在手机上会斜出去两百多 px，一栏装不下一列窗，所以换成**横缝**——一长页，随笔、瞬间、项目三段，段与段之间是一条向右下倾的 14° 缝（就是 layout-plane 那条交界），整页一起滚。
- 栏头只有编号 · 名字 · 英文 · 条数。**三栏之间不画分界线**，只靠三种夜色本身分开（缝上那一格按覆盖量混色，所以边是干净的）。
- 不给每栏单独的漫游入口：右上角的开关进入你**最近停留过 0.7 秒以上**的那一栏（去点开关时一路划过的栏不算），`V` 进入指针所在的那一栏。
- **栏会呼吸**：鼠标停在哪一栏，那一栏变宽、窗放大 5%，另两栏让出地方、窗缩小约 11%、略淡；两条缝随之挪动（略欠阻尼的弹簧，换栏时缝会轻轻晃一下再停）。那一栏的底色也微微提亮。
- 顶部检索框先拿掉了（以后并进「工具区」：检索 / 回主页 / 去 NEXUS 等可挑选的工具）。检索逻辑留着（`__w.setQuery`）：标题 / 描述 / 标签 / 正文 / 图注都搜；**没命中的不消失，而是退焦两档、缩小、淡下去，排到命中的后面**——用的是空间本来的语言（模糊 = 不是你要找的）。栏头的条数变成「命中 / 总数」。

### 之间怎么动

- **漫游 → 检索**：两条缝从屏幕边上滑进来，三种光并排。当前场景的每一条，从它此刻在空间里**最清楚、最靠中间的那一份**起飞，一路对焦（像素一档档变清楚）、按飞行速度朝运动方向倾一点，落进自己的格子；其余的副本沉回景深；另两个场景的窗从各自的栏里顺着缝浮上来、由粗到细对焦。约 1.2 秒。
- **检索 → 漫游**：你选的那一栏的缝向两边推开、铺满全屏；那一栏的窗各自飞回空间里**离它最近的一份**，一路失焦到该有的档位，周围的副本晚一拍才浮出来；另两栏顺着缝沉下去、被缝扫掉。回到那个场景时镜头停在你上次离开的地方。
- **漫游里换场景**也是同一个动作：缝扫过屏幕，这边是旧的夜色、那边是新的，旧场景的窗被缝裁掉。
- 飞行的落点每帧现算（格子会滚、空间里的那一份在浮），所以落点永远是活的；中间帧可以用 `__w.freeze()` / `__w.advance(ms)` 停住逐帧看。

## 阅读

- 那扇窗自己长大：同样的玻璃、1px 边、标题栏，从卡片此刻的矩形长到阅读尺寸；前一小段钉着卡片自己的画面，随即让给真的标题栏与正文。
- 卡片上的标题栏到这里才「通电」：`‹ 1 / 6 ›` 翻同一版块的上一条 / 下一条（窗不动、内容滑过去、窗高跟着内容变），`—` 收起。
- 高度贴着内容（短的瞬间不撑满一屏）；瞬间的图贴满窗宽。
- 收起时落回卡片此刻的位置：检索里是它的格子；漫游里是它在空间里的那一份（翻页翻到一条此刻不在视野里的，就原地合上淡掉）。
- 漫游里读的时候周围的窗被推开、退一档焦；检索里其余部分压暗。

| 场景 | | |

检索视图里天气只下在自己那一栏（按缝裁），滚动时有一点视差。

## 实现上的几个坑

1. **`backdrop-filter` 只看得到最近的「背板根」里面**：祖先上有 `clip-path` / `opacity < 1` / `mask` / `filter`，窗的磨砂就只模糊容器里的东西（看不到后面的流光）。所以容器平时不裁，只在过渡与换场景的那一秒按缝裁；栏头下面的淡出改成按位置给每扇窗算透明度，阅读时的压暗用一层 veil，不动容器的 opacity。
2. **缝在 1/5 分辨率的画布上是一级级的台阶**：着色器里缝上那一格按覆盖量混两边的颜色，边是利落的、但不是锯齿；随笔那条缝一边浅一边深，亮线落在混色带中间会看不见，所以挪到暗的那一边、浅的那一边再压一道很淡的暗线。
3. 外框（品牌名、检索框、视图开关）的墨色按它底下是哪一栏来取：检索时三栏明暗不同。
