# 变体 G3 · 凝华羽雾（Vapor & Phase Frost）· 实测笔记

## 主张
基于方案 G 拓展的“相变（Phase Transition）”构型：微晕基准半径收敛至 32px 极简羽雾，消除硬界并采用指数级羽化衰减；探索《醒梦》核心命题“世界究竟在成形，还是正在融化？”——醒时水汽析出 4 点冷霜微晶晶界围合菱形取景微隙，入梦则微晶融散化作无边界微温蒸腾暖沙烟雾。「1:1 绝对定锚发丝微核，游弋凝定，触动相变」。

## 醒 / 梦 各自的机制与关键参数
- 元素结构：`.mist-core`（3px 绝对定锚微露核心）+ `.mist-aura`（轻烟阻尼容器）+ `.aura-dew`（4.2s 极低频微呼吸）+ `.aura-outer`（64px 直径指数级羽化羽雾）+ `.phase-frost`（4 点 2px 冷霜微晶晶界）+ `.aura-glow`（琥珀烘暖层）+ `.aura-ripple`（微波层）。
- 醒态（成形 · Forming）：冷灰银雾无硬界，正向对齐屏幕轴；4 点冷霜微晶晶界（距中心 11px）显影，围合成极微小的菱形取景微隙，象征世界凝结成形。
- 梦态（融化 · Melting）：4 个微晶解构散开融化（`opacity: 0`），羽雾顺时针偏转 14°，化作微温蒸腾暖沙琥珀烟雾，象征世界正在融化；静止对照帧（`?freeze=1`）下一眼可辨。

## 与方案 G 的机制差异
- **羽雾质感进化**：G 为 44px 带边框微晕；G3 收敛至 32px 半径并采用指数级平滑羽化衰减（Exponential Falloff），彻底去除环状轮廓线，呈现一缕不可捉摸的晨雾。
- **相变微晶晶界引入**：引入 4 点相变冷霜微晶（.phase-frost），在醒态勾勒极微菱形取景微隙，入梦时解构蒸散；长按相变时直观演变“凝华析出”或“升温融化”过程。
- **目标张弛重构**：悬停链接时水汽凝聚烘暖、冷霜微晶由 11px 向外张开至 20px 优雅托起目标；悬停文字时羽雾由 G 的 15% 进一步蒸散隐退至 10%，微晶隐退，仅留 1:1 发丝微核不扰阅读。

## 状态矩阵覆盖与实测数据
- **工程红线验证**：控制台错误 0 · 页面错误 0 · 失败请求 0（`.shot-cursor.cjs` 实测验证）。
- **热点同帧绝对定锚**：`dx: 0 · dy: 0 · dist: 0.00px`（同帧口径，1:1 同步写入，零延迟）。
- **静息性能**：停止移动后平滑收敛；静息 5s 内严格 0 次 rAF（`rafLast5s: 0`），收敛时 `will-change: auto`。
- **逐帧写入属性**：严格只写 `transform` 与 `opacity`，零每帧节点分配（11 个静态节点池）。
- **12 项状态矩阵**：
  1. `rest`：4.2s 极低频微呼吸（0.92~1.04x），微晶静守菱形四极，极致安静（图 `04-probe.png`）；
  2. `move`：流体阻尼跟随（tau ≈ 100ms），水滴轻烟随风微偏（scaleX clamp $\le$ 1.20）；
  3. `hover-link`：水汽迅速凝聚烘暖（琥珀暖光 0.72），微晶外展托起目标（图 `05-hover-link.png`）；
  4. `hover-text`：羽雾蒸散至 10%，微晶完全隐退，仅留 1:1 发丝微核（图 `06-hover-text.png`）；
  5. `input`：微雾蒸散，微核半透不遮挡光标定位；
  6. `drag`：微雾与微晶呈现横向贴附张力态（图 `10-drag.png`）；
  7. `click`：微核微缩至 0.6x，微雾荡出扩散微波后收拢（图 `07-click.png`）；
  8. `hold1300 / hold2200`：展现析出凝华或升温融化的相变全过程（图 `08-hold.png`）；
  9. `latch`：按满爆发琥珀光华，微核定格为全站实心琥珀结 ◆（图 `09-latch.png`）；
  10. `scroll`：阻尼跟随稳定视线焦点；
  11. `leave`：随外壳 `fx-cursor-out` 柔和淡出；
  12. 降级：`?cursor=off`、`?reduced=1`、`forced-colors`、触摸安全回退原生光标（图 `11-off.png`, `12-reduced.png`）。
