# star-v2 · 第五轮：落定姿态回到「能看见六芒星」

先说这轮为什么开。

第四轮的表做出来了，A/B/C 三列的数字都在。但我量了第二行纯剪影（径向剖面，每 2° 取一个最大半径）：**A、B、C 三列的剪影都只有 4 个峰**（80°/170°/260°/350°），不是 6 个。

原因追到第三轮：落定姿态被左乘了一个 72° 旋转（绕 `(0.688, −0.691, 0.223)`），它把「六支法线同向」那种塌陷治好了，同时也让六个尖在画面上两两重叠成四个方向。作者要的原语是**六芒星**，现在落定看到的是四芒星。这个锅是我第三轮的 brief 造成的，这一轮修回来。

作者的最新口径：**先不管晶体视觉，先把形状定好看。** 所以明暗塌陷不再是否决条件，剪影是。

## 要做的事

### 1. 扫描落定姿态的倾角（这是主任务）

让落定姿态从体对角正位出发，绕**视轴**（或某个固定的水平轴，你选一个并说明）倾斜 δ，扫 δ = 0° / 5° / 10° / 15° / 20°，每个 δ 报：

- 径向剖面的峰数（要求 6）
- 六个峰的角间距（标准 60°，报最大偏差）
- 六个峰的半径（报最大偏差百分比）
- 星内亮度 5 / 50 / 95 分位有**几档可辨明暗**（把星内亮度直方图按 8 级分箱，报占比超过 8% 的箱数）

选一个 δ，判据：**峰数 6、角间距最大偏差 ≤ 3°、峰半径最大偏差 ≤ 3%**，在此前提下取「可辨明暗档数」最多的那个。如果 δ=0 已经满足，就取 0。

轨迹整体随之平移（保持首尾同一姿态、16 格、170ms、`__star` 接口不变）。

### 2. 在选定的落定姿态上重出 A / B / C 三列的剪影行

只出**纯剪影行**（单一深色 `#2b2f36`，260px，同一画幅），外加每列的数字：面数、锐棱数、剪影峰数、峰角间距偏差、与 A 的剪影差。

另外补一句判断（挂数字）：三角截面（B）那 11.81% 的偏差具体偏在哪 —— 是臂宽变了、凹口变浅了，还是尖角变了。

### 3. 不要做的

- 材质函数、色散、tone、`back`、相机距离、`edgeW` 全部冻结，一个字不动
- 不许起浏览器、不许截图、不许做性能测量
- 只写 `design/mocks/star-v2/`
- 不许再新增变体。A/B/C 三列就是全部；这轮只换姿态并重出剪影。
