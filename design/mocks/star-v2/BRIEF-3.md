# star-v2 · 第三轮：只换落定姿态 + 放大（材质和几何都不动）

第二轮的 tone 账达标了，我在浏览器里用同一套像素统计复验过：P5/P50/P95 = 167 / 218 / 250，贴顶白 1.7%，星内 B−R 平均 +11.1、最大 51。形态也终于是立体的了。

**但我找到真正难看的那一格了：体对角正位。** 在 `u=0` 时六支完全对称、法线几乎同向，24 张面塌成两三档调子 —— 读起来像折纸。轨迹走到 `u=0.2` 那一格时，同一个模型是清楚的晶体：暗面、亮面、棱都出来了。而现在动画**恰好停在这一格**，观者看到的永远是它最丑的定格。

（证据：`u=0` 与 `u=0.2` 两帧同画幅，后者星体有 4 档以上可辨明暗，前者 2 档。我可以直接给你截图，但你看这行字就够了：正位是病格。）

## 这一轮只做三件事

1. **把 `u=0` 的姿态换成现在 `u=0.2` 那一格**（即整条轨迹整体旋一个固定偏移，使首格 = 原第二格）。要求：轨迹首尾仍逐位相等于同一个姿态矩阵；末格仍与静止帧一致；`__star` 接口、16 格、DWELL 全不动。
2. **放大**：相机拉近直到星体占 400px 画布的 **≥15%**（现在 12%）。别靠缩页面，改 `camZ` 或 FOV。
3. **不许让 tone 账退化**：P5 仍要在 150–175，P50 ≤ 220。

## 顺带记一笔（不用改）

`state().raf` 这个读数不可信：我实测触发一次，它从 830 涨到 967。但同一页面静止两秒两次截图逐字节相同、触发播完两秒后两次截图也逐字节相同，说明页面确实不重绘。所以那个计数被页面之外的东西调用了，你的「恒为 0」结论只在裸页面成立 —— 在 notes 里改成「用像素逐字节相同来证明静止」，别再用 rAF 计数当证据。
