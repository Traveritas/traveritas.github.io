## 1. 形体

- 六支沿 ±x ±y ±z，三个轴互相垂直。体对角视角下投影是六芒星。
- **细长锐利**：支长 : 根部半宽 ≈ 16 : 2.2（比站点现役的平面六芒星再细一点）。六个尖要尖到最后一点，不许做成圆头。
- 截面是四边形菱形（可以给很小的倒角），**不要圆角到接近圆**——那会变成六根针。
- 星心是**一块实心的交汇体**，六支在里面真实互插，交给深度/求交去解，不许留空洞、不许穿帮。
- 每支最多 6–8 张平面。全星面数控制在 60 以内。**大面优先于精确曲面**：宁可折三下，不要切二十下。
- 不许是「挤出的平面剪影」——必须有真实体积，从任何角度看都能看出厚度。

## 2. 材质

- 复用 `nexus-slice.ts`：环境函数、丁香色吸收、三色色散（ior ± disp）、内部全反射、棱上高光。
- 必须有可见的**折射错位**：星后面的东西穿过星体时能看出偏移和重复。
- 必须有色彩：不要灰白一片。边缘和暗部要是浅紫灰，亮部收向白。

## 3. 运动：触发式定格旋转

- **不是定轴自转**。旋转轴本身沿一条参数曲线走，例如
  `axis(u) = normalize(sin 2πu, sin(4πu + φ), cos 2πu)`，绕轴角 `θ(u) = 2πu`，
  于是轨迹是漂移的、非周期的定轴旋转。φ 你定。
- **定格**：把整段轨迹离散成 N 步（12–20 步），每步**跳变**（不插值、不加缓动），步间停顿 40–80ms。观感是走格/翻页，不是平滑转动。
- **触发**：点击星体或按空格触发一次完整循环（2.4–3.2s），最后一格必须精确落回静止姿态（yaw 45° / pitch 35.264°，即体对角视角），然后**完全静止**：不跑 rAF、不留定时器、不漂移。
- `prefers-reduced-motion`：只画正位静止帧，不绑定任何动画。
- 触发动画期间允许用 rAF；**结束后 rAF 必须归零**，这一点要能在控制台里查证。

## 4. 调试接口（硬要求）

页面必须暴露：

```js
window.__star = {
  ready,            // Promise，首帧画完 resolve
  setTime(u),       // 把星摆到轨迹上的 u∈[0,1] 的定格姿态（不播动画），用于截图
  trigger(),        // 等同于点击
  rest(),           // 回到静止正位
  stats,            // { faces, tris, blocks, halfspaces } 真实几何数
}
```
