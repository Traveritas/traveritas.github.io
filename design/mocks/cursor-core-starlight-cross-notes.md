# 方案 S1 · 四芒水汽衍射星核（Diffraction Starlight Core）· 实测笔记

## 主张与世界观对齐
在 G2 凝露张力（露凝于镜、弯液面与表面张力）水晕基底之上，将中心实核心彻底重构为《醒梦》风格的「极微水汽衍射四芒星（4-Point Gossamer Diffraction Star）」。坚决杜绝机械准星与刺眼霓虹十字，纯以 1.5px 定锚微核与四向 1px 发丝级渐淡羽化微芒，呈现光线经微露折射后自然逸散入虚空的知觉悬浮感。

## 构成体系与关键参数
- **实核心图元结构**：
  - `#star-dot`：1.5px 纯净定锚微核，1:1 同帧零延迟定锚，注册热点测距；
  - `#star-aperture`：3.2px 菱形微喉，柔和过渡微核与射线，消除生硬十字交点；
  - `.star-ray-*`：四向 1px 发丝级微芒（基准长 5px），自然渐淡羽化淡入虚空；
  - `#star-glint`：微折射微晕/微光层，悬停链接点亮微星，点击迸发微光；
  - `#star-knot`：实心琥珀结 ◆，长按顺 -4° 缝线轴向延展，按满（Latch）坍缩合璧熔铸。
- **双态色板**：醒态为纯冷银微星（`var(--fg)`，清透笃定）；梦态为暖沙琥珀微芒（`var(--amber)`，微带折射光晕与 14° 倾角协同）。
- **游弋呼吸**：纯 CSS 3.8s 超慢周期微呼吸与光辉流转（`starIdleBreath`），静息落定即停 rAF（`rafLast5s: 0`，`will-change: auto`）。

## 交互与动态生命周期
1. **游弋（Idle）**：四芒微星以 3.8s 周期产生极轻柔的星芒呼吸与光辉流转；
2. **移动（Move）**：星芒随行进速度微弱收拢至 0.80x，呈现破风流线微形，停止带 Q 弹回润；
3. **悬停文字（Hover Text）**：横向两芒收拢隐去（scaleX: 0），纵轴两芒延展为极细星轨插入标（scaleY: 2.6, op: 0.42），微核淡化（op: 0.35），完全让出字面；
4. **悬停链接（Hover Link）**：星芒优雅张开（scale: 1.45x），折射微光点亮（op: 0.85），水膜柔和椭圆铺展并微吸附（≤ 8px）；
5. **点击（Click）**：四芒向内微敛至 0.60x 后迸发微光，伴随露珠表面张力微波荡出；
6. **长按与按满（Hold & Latch）**：星芒沿 -4° 全站缝线轴向旋转排列，顺抽线延展至 2.45x；按满瞬间（Latch）四芒向内坍缩合璧，熔铸为全站实心琥珀结 ◆（45° 实心晶体，梦态泛出琥珀温光）。
