# 无界平铺 · 越远的记得越少（布局原型）

全站内容（随笔 2、项目 2、瞬间 3 则 / 5 张图、关于 1）排在一张可以向任意方向拖动的平面上。
内容很少，平面靠**重复**变得无界：一个周期里排好全部方块，周期向四面无限铺开。
原件只有一份（周期 0,0），离它越远的副本记得越少——字被截短、图降成更粗的像素、颜色褪向夜色，最远处只剩色块。
页面上不写任何解释这条规则的字。

## 运行

```bash
node design/mocks/layout-plane/build-data.mjs   # 从 src/content/ 取真实内容 → data.js、assets/img/、目录写回 index.html
node design/mocks/layout-plane/server.cjs       # http://localhost:4611/
node design/mocks/layout-plane/.shot.cjs        # 截图 → .shots/（ONLY=start,far,hover,article,moment,project,dream,mobile,nojs 只拍一部分）
```

地址参数：

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| `?rule=` | `forget`（默认） | 距离意味着什么。以后的分支（读者的记忆、双曲……）各是一个规则文件 |
| `?mech=` | `arrive,haze`、`-haze` | 在规则默认带的机制上追加 / 去掉 |
| `?seam=` | `line`（默认）· `bare` · `soft` | 明暗交界：利落的边 + 发丝线 / 只有利落的边 / 旧的四色高斯洇色（对照用） |

旧版（拆分前、竖直交界的那一版）原样留在 `legacy/`：http://localhost:4611/legacy/ 。

- 服务把 `/fonts/noto/` 映射到 `public/fonts/noto-serif-sc/`，`/fonts/plex/` 映射到 `@fontsource/ibm-plex-mono`，不复制字体。
- 配图由 sharp 出两档副本（`-m` 720 宽，方块里用；`-l` 1600 宽，阅读层用），原图不动。
- 截图脚本沿用 `design/mocks/hours/.shot-hours.cjs` 的做法：`%TEMP%/node_modules/puppeteer-core` + 本机 Chrome。
  过渡的中间帧是把 `document.getAnimations()` 全部暂停在第 N 毫秒拍的，所以是确定的帧，不是碰运气。

## 结构：内核 · 规则 · 机制

```
js/kit.js          命名空间、oklab、文本小函数、确定性哈希
js/world.js        版图：周期、色板、方块位置、14° 斜切（与规则无关）
js/field.js        底色与交界（?seam=）
js/tiers.js        记忆档 0–5 的六种写法 + 配图降档 + 打开时的「想起」（任何「记得多少」类规则共用）
js/kernel.js       内核：镜头、惯性、视口回收、悬停/焦点、原处展开、历史、目录、醒梦
js/rules/forget.js 规则 · 遗忘：距离 → 档；悬停想起一档；打开时向外再忘一档
js/mechs/basic.js  机制 · arrive（进场由近及远浮现）、haze（走远蒙雾）
js/boot.js         读地址参数，组装启动
```

- **内核不知道「距离意味着什么」**。每份副本画不画、画成什么样、能不能点、打开时周围怎么反应，都问规则；
  规则的接口写在 `kernel.js` 文件头（`place / look / paint / box / canOpen / canHover / opening / closing / closed / detail`）。
- **记忆档是一个库，不是规则**。`tiers.js` 只管「第 n 档长什么样」；「为什么是第 n 档」归规则。读者的记忆这类分支只要换一个 `place / look`。
- **机制**挂在内核事件上（`start / frame / open / close / closed / reality`），拿到的 `ctx` 里有镜头、节点、`refresh`、`ripple`（按距离排的涟漪，计时器归内核管）等。
- 打磨内核（展开收回、惯性、虚拟化、无障碍）的成果对所有规则同时生效。

## 版图

一个周期 **W × H = 2520 × 1780**（平面坐标 u, v，px）。上半是亮带，下半是暗带；色板取自 `src/styles/hours.css`：

| 区域 | 时辰 | 底色 | 方块（u, v, 宽 × 高） |
| --- | --- | --- | --- |
| 亮带左 | 随笔 · 浅梦 | rgb(225 231 239) | 《在显影处》170,222 · 452×318；《字面与光景》690,366 · 410×304（错开半格） |
| 亮带右 | 关于 · 晨光 | rgb(242 235 224) | 1640,272 · 500×300，四周大面积留白 |
| 暗带左 | 项目 · 深眠 | rgb(20 27 41) | 01 昼梦叙集 170,982 · 476×340；02 FancyText 716,1142 · 452×322 |
| 暗带右 | 瞬间 · 异相 | rgb(38 33 53) | 方图 324 宽；四张 3:2 图 392 / 300 / 300 / 360 宽（高按原图比例 + 46 说明）；文字瞬间 324×204 |

- 一夜绕着周期走一圈：浅梦 ↓ 深眠 → 异相 ↑ 晨光 → 横向相邻周期的浅梦。
- 每区左上有一枚版块名（`随笔 可言说的 · SAYABLE`），梦面换成断章 / 造物 / 闪念 / 此身。
- 方块按类型定尺寸：随笔是带日期、标题、一句描述、字数与标签的玻璃片；项目更宽，带描边的幽灵编号与状态；图像瞬间不加玻璃，直接落在夜色里，下方一行说明；关于只有名字和那句问句。
  同一列左缘对齐、相邻两块错开半格——像排过的版面，不是随机散落。
- **缩放**：视口宽 < 640 → 0.6；< 1000 → 0.78；< 1700 → 0.88；更宽 → 1。
- **起点**（平面坐标）：桌面 (880, 393)，一屏看见随笔两篇、晨光一角、交界下深眠的版块名；手机 (420, 400)。

### 14° 斜切与交界（解决了旧版「没解决的」第 1 条）

旧版四个时辰的底色一起做高斯洇色，浅色与深色之间总会过一段灰紫的中间调，成了画面里最大的形状（`?seam=soft` 可以再看到它）。现在：

- **整张平面 skewY(14°)**：屏上 y = v + tan14°·(u − W/2)。周期内水平的明暗交界，到屏上就是全站那条 14° 的发丝线（`--seam-angle`，向右下倾），而且是无限延伸、横穿所有周期的一组平行线。
  底色层是一张矩形平铺小图，整层 CSS 斜切；方块**不斜**，只按中心的 u 整块下沉，所以一排方块是一级级台阶。周期的格子因此也是斜的：横走一个周期，屏上会下沉 W·tan14° ≈ 628px。
- **明暗之间是利落的边**：亮带只在浅梦与晨光之间洇色，暗带只在深眠与异相之间洇色；两带之间 ±9px 的 smoothstep 硬接，没有中间调。小图纵向 2px 一格、横向 8px 一格，交界放大后也不糊。
- **发丝线**：屏幕空间的 SVG，只画视口里那几条，每帧改端点。1px 暖白 50% + 7px 宽 7% 的柔光；梦面略偏暖。`?seam=bare` 去掉它。
- 内容离交界的距离：亮带最下的方块离交界 110，暗带最上的离 120；方块按中心下沉，半个方块宽内交界会多斜出 ~56，所以最近处约 55。
- 外框（品牌名、右上按钮）按 `field.colorAt()` 取底色深浅换墨色；交界利落以后，取样几乎不会落在中间调上（旧版第 3 条基本消失，正压在线上时仍可能偏）。

## 底色

每个时辰 3–4 个色心（平面坐标），按环面距离做高斯加权（σ = 400），权重取 4 次方再归一，在 oklab 里混色；只和同一侧（亮 / 暗）的时辰混。

## 遗忘：距离 → 记忆档

副本中心到原件周期中心的距离 r（以周期为单位，`hypot(dx/W, dy/H)`）：

```
原件：0 档
副本：clamp(1 + floor((r − 0.55) / 0.62), 1, 5)
```

相邻的副本至少 1 档；约 2 个周期外开始只剩色块（4 档），3 个周期外全是 5 档。档位是离散的，同一个副本周期里离得远的方块会比近的先忘一档，所以遗忘是一层层漫开的，不是一格格换的。

| 档 | 字色（--mem） | 标题 | 描述 | 日期 | 配图 | 位置抖动 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | 1 | 全 | 全 | 2026 · 10 · 03 | 原图 | 0 |
| 1 | 0.78 | 前 60%（至少 4 字），末字渐隐，不打省略号 | 前 40%，同上 | 2026 · 10 | 1/10 降采样、平滑放大（柔），饱和 0.7，褪向夜色 14% | 0 |
| 2 | 0.56 | 前 3 字 | 两条字行的影子 | 2026 | 14px 一格的像素，饱和 0.48，褪 30% | 0 |
| 3 | 0.38 | 首字 | 一条影子 | — | 32px 一格，饱和 0.28，褪 46% | ±7 |
| 4 | 0.24 | — | — | — | 只剩一块颜色（图取平均色），缩到 88%，柔边 | ±22 |
| 5 | 0.14 | — | — | — | 更淡、更圆、缩到 62%；45% 的位置干脆没有 | ±52 |

- 版块名在 1 档只剩名字，2 档只剩一道短线，3 档以后不画。
- 配图的各档副本在载入后用 canvas 预先画好（`createImageBitmap` 降采样 → 逐像素去饱和、褪色 → blob URL），`image-rendering: pixelated`；不在大量元素上挂实时滤镜。
- 走远之后整片蒙一层很薄的雾（不透明度随离原件的距离升到 0.12 为止）。

## 交互

- **拖拽**（鼠标 / 触摸）：位移超过 5px 才算拖，之前的按下仍是点击。松手按最后 90ms 的速度给惯性，指数衰减，时间常数 330ms。
- **滚轮 / 触控板**：两轴都平移（Shift + 滚轮横移），位移经 70ms 的指数平滑，鼠标滚轮不会一格一跳。
- **方向键**：300px 一步（Shift 620px），Home 回到起点。
- **悬停**：原件浮起 3px、玻璃更亮；副本被想起一档（字长回来一截、像素变细），伴一次 0.42s 的去虚。触屏没有悬停。
- **回到中央**：离起点超过约 0.85 个周期时右上出现这颗按钮；点品牌名也回去。
- **醒 / 梦**：右上小开关。版块名换成梦面名，底色整片暖一点、暗一点（各时辰在 oklab 里向暖沙混 12%，明度 × 0.955），阅读层里的 `:::dream` 块与 `[[醒|梦]]` 换面。站内正式的长按入梦检验没有接进来。
- **减动效**：没有惯性，滚轮与方向键直接到位，展开 / 收回瞬间完成，入场不做浮现。

## 展开：方块在原处变成阅读层（重点）

点一块（原件或任何 ≤ 4 档的副本都可以），这块在原地展开，平面退后。分四股同时走，全部用 Web Animations：

| 时刻 | 平面 | 窗口 | 同名元素 | 其余 |
| --- | --- | --- | --- | --- |
| 0 | 缩到 0.94（以这块为中心）、虚 2.5px、压一层本区底色（随笔 / 项目 50%，瞬间 / 关于 35%），820ms | `clip-path: inset()` 从方块轮廓展开到阅读栏（随笔、项目：居中 880 宽整高；瞬间、关于：全屏），720ms | 标题、日期、描述、配图从方块里的位置 FLIP 到阅读层里的位置，720ms | — |
| 40–460ms | **向外再忘一档**：屏上其他方块按到这块的距离依次降一档（0.32ms/px，封顶 420ms），原件也会暂时变成 1 档的样子 | | | |
| 300ms | | | | 标题下的短线从左向右长出，760ms |
| 360ms 起 | | | | 正文逐段浮起（上移 14px + 淡入，640ms），每段错开 48ms，前 10 段之后不再错开；首屏外的段落 700ms 时直接淡入 |
| 480ms | | | | 「返回」淡入 |

- 缓动：展开 `cubic-bezier(0.32, 0.72, 0, 1)`——起手快、收尾很长，点下去立刻有回应，落定时很慢。
- 从远处的副本打开时，配图先以那一档的粗像素出现在大图上，260ms 起用 640ms 淡出——图是一路被想起来的。标题也是从截短的样子飞过去、在路上补全。
- 阅读层是 `role=dialog`，焦点落在标题上；平面 `inert`。

**收回**（Esc、「返回」、点阅读栏以外、浏览器后退）：

| 时刻 | 动作 |
| --- | --- |
| 0 | 正文、短线、「返回」一起淡出，200ms |
| 110ms | 窗口收回方块**此刻**的轮廓；同名元素从当前位置（含已滚动的距离）飞回方块，600ms，`cubic-bezier(0.45, 0, 0.2, 1)` |
| 110ms | 平面放大回 1、去虚、去暗，680ms |
| 220ms 起 | 就近先想起：方块按距离依次回到原来的档（0.22ms/px，封顶 360ms） |
| 710ms | 移除阅读层，方块显形，焦点还给原件（不再移动镜头） |

- 方块在后退中被缩放过，收回时用「未缩放的方块框 ÷ 实测框」把实测位置换算回去，所以落点是准的。
- 瞬间里切换同一则的其他图后，收回会落进同一周期里对应的那一块。
- 历史：打开时 `pushState('#/a/…')`，后退即收回、前进再展开；直接带着路由进来时，先垫一条平面的历史再打开，「返回」回到平面而不是离开。
- 阅读层里的站内互链（关联篇章）：先收回，镜头飞到那篇的原件，再从那里展开。

## 无障碍与无脚本

- 原件是 `<a href="#/…">`，按版块顺序常驻 DOM，Tab 只经过它们（品牌 → 目录 → 醒梦 → 随笔两篇 → 项目两件 → 瞬间 → 关于）。获得焦点的原件若在视口外，镜头会飞过去。
- 副本一律 `aria-hidden`、不可聚焦，随视口回收（DOM 复用池，按方块分池）。
- 「目录」是一份静态的线性名录，写在 `index.html` 里（由 `build-data.mjs` 生成）；**无脚本时它就是整页**，平面不出现（见 `.shots/60-nojs.png`）。
- 焦点环沿用全站的琥珀色。

## 性能

- 平面容器只改 `translate3d`；底色层是一张平铺小图，只改 `translate3d + skewY`；发丝线是视口里的两三条 SVG line，每帧改端点。
- 只渲染视口外扩 260px 内的副本，桌面一屏最多约 34 个节点（含 15 个常驻原件），节点复用不重建。
- 实测（无头 Chrome，1440×900）：每帧 `render()` 中位 < 0.1ms、最大 0.4ms；连续滚轮平移帧间隔中位 16.7ms、P95 16.9ms。
- 展开时对整个平面层挂了一次 `blur(2.5px)`，只在过渡里存在；低端机上这是最可能掉帧的一处。

## 没解决的

1. ~~明暗交界太显眼~~ → 已改成 14° 斜切 + 利落的边 + 发丝线（见「版图 · 14° 斜切与交界」）。新的小问题：亮带里浅梦→晨光的横向渐变有极淡的竖条（8 位色阶被拉宽），grain 层盖住了大半；底色层与发丝线不在 `#recede` 里，展开时不跟着平面后退变虚（旧版的底色也是这样）。
2. **非像素画的图降成马赛克时有一点「打码」感**（Lacuna 那张）；NEXUS 那四张本身是像素画，降档反而很协调。或许 2–3 档对照片改用「更柔的低清 + 颗粒」而不是硬像素。
3. 品牌名、右上按钮按底色深浅切换两套墨色；交界变利落后基本不再取到中间调，但发丝线正好穿过品牌名时，半边字仍会落在另一侧。
4. 没有双指缩放；触屏没有悬停，手机上看不到「被想起一档」的那一下。
5. 阅读层打开中途改变窗口大小，收回时的落点用的是打开时测的位置，可能偏一点。
6. 醒 / 梦只是一个开关，没有接全站的长按入梦检验与逐字乱码换面。
7. 只在无头 Chrome 里量过帧时；真机（尤其中低端安卓）上展开时的整层模糊需要实测。
8. 标签页（随笔 / 标签同属浅梦）没有进平面。

## 搬进 Astro 需要什么

- **路由用真地址，不用 `#/`**：原件改成 `<a href="/articles/<slug>/">`，展开时 `pushState('/articles/<slug>/')`；文章、项目、瞬间、关于各自的静态页照旧存在，直接访问或无脚本时就是现在的阅读页（带导览轨）。平面只是首页（或一个独立入口）上的一层。
- **无脚本兜底**：首页 HTML 里直接输出这份线性名录（现在 `index.html` 里的 `#toc`，链接指向真页面），平面脚本加载后才把它收进「目录」薄片——即现在 `html:not(.js)` 的那套规则。
- **数据**：构建期从 content collections 生成平面所需的 JSON（标题、日期、描述、配图的两档 URL、宽高），内联进 `<script type="application/json">`；正文不进 JSON——展开时 `fetch` 对应的静态页，取出正文节点塞进阅读层（同源、可缓存，正文的两态与行内光景标记原样带过来）。
- **配图**：`astro:assets` 出 m / l 两档；像素降档仍在客户端画（几十毫秒），或在构建期用 sharp 预烘成极小的 PNG。
- **两态**：版块名与阅读层改用站内的 `data-morph` 双文案元素，接 `reality.ts` 的入梦检验；平面底色的梦面偏移可以跟 `--reality-mix` 插值，而不是现在的硬切。
- **色板**：四个时辰的色值从 `hours.css` 的变量读，不再写在脚本里；`night.ts` 的时间轴若要驱动平面，可以把「当前时刻」映射成底色的整体偏移。
- **字体**：界面新增的字（「回到中央」「返回」「目录」等）要加进 `scripts/fonts.mjs` 的切分取字范围。
- 交互脚本约 1100 行、无依赖，可作为一个 `<script>` 岛挂在首页；阅读层的样式应复用 `global.css` 的正文排版，而不是现在这份简化版。
