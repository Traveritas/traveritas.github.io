# 无界平面 · 发散方向

> 2026-10-17 记。每个方向都做几个 mockup，看过再收敛。全部建在 `js/kernel.js` 的内核上，
> 变体用地址参数切换，互不覆盖；截图进 `.shots/<方向>-<编号>/`。

## A · 点开之后：详情怎么展示

| 编号 | 名字 | 一句话 |
| --- | --- | --- |
| A1 | 窗口展开（现状） | clip-path 从方块轮廓展开到阅读栏，平面后退、变虚、向外再忘一档。基线 |
| A2 | 斜栏 | 平面不退，详情是一条沿 14° 交界滑入的栏，平面在旁边仍然可拖 |
| A3 | 镜头钻入 | 不开新层：镜头飞向方块并放大，方块在平面里原地长大成阅读页，四周的副本被推开 |
| A4 | 霜里析出 | 借 depth：整屏起霜，标题、正文按记忆档从霜里分几次显影 |
| A5 | 原地展开成命题 | 借 tractatus：方块在平面上向下展开成编号的小节（1.11、1.12…），邻居被挤开，不离开平面 |
| A6 | 翻面 | 方块绕 14° 轴翻过来，背面就是内容，背面再放大到阅读尺寸 |

| 编号 | 名字 | 一句话 |
| --- | --- | --- |

| B2 | 无卡片 | 去掉卡片，字直接排在底色上，只用发丝线分隔；版面靠排印本身 |

## C · 结构上翻新的机制

| 编号 | 名字 | 一句话 |
| --- | --- | --- |
| C1 | 平面叠层 | 每个版块是一张自己的无界平面，平面之间按景深前后叠放；拖动在当前平面里走，滚动在平面之间穿行 |
| C2 | 读者的记忆 | 记忆属于来访者：没去过的地方模糊，走过的路被踩亮，打开过的副本变清晰；存 localStorage，再来时平面是上次的样子 |
| C3 | 双曲平面 | 庞加莱圆盘：越往外空间越多、东西越小，不靠重复也走不到边 |
| C4 | 语义缩放 | 双指 / Ctrl+滚轮缩放；最远只剩四个版块，放大一级出现条目，再放大出现小节（＝ tractatus 的位数） |
| C5 | 非周期铺排 | 没有两份副本完全一样：每份副本里方块的组合、错位各不相同 |
| C6 | 时间坐标 | x 是日期、y 是版块，平面就是档案；底色按真实的夜色时刻铺开 |

## 剩下的：大致设计（2026-10-17）

执行者一栏是预估：H = Haiku，S = Sonnet，我 = 主会话。

### A · 详情
- **A3 镜头钻入**（我）：不开新层。镜头飞向方块并把 z 从 0.88 推到使方块宽 ≈ 阅读栏宽（≈2.2）；方块在平面里原地把高度撑开成整篇（正文直接塞进方块，平面坐标里长高），同一列下方的方块被推开（只在视觉上平移，不改版图）。滚轮在钻入态下滚正文；Esc 时 z 退回、方块收回原高。需要内核支持「阅读时镜头可控 + 单块尺寸覆盖」。
- **A5 原地展开成命题**（S）：借 tractatus。方块向下展开出编号小节（1.11、1.12…取自文章 h2），每节一行标题，点某节再展开那一节正文；整个展开在平面里发生，邻居让位。和 A3 共用「单块撑高 + 邻居让位」的内核能力。
- **A6 翻面**（H）：方块绕一条 14° 的轴做 rotate3d 翻转，翻到 90° 时换成详情内容的背面，再从方块大小放大到阅读栏；收回反过来。纯 presenter，不用改内核。

### B · 视觉
- **B4 实体纸片**（H）：卡片有厚度：底边 + 右边各一条 2–3px 的侧面（比正面暗 8%），投影方向按所在带决定——亮带投影落向下方交界（向下 18px、很柔），暗带改为边缘一道很细的反光（上沿 1px 亮线）。悬停原件时纸片微微抬起、侧面变厚。
- **B5 实色面**（H）：每块是时辰色的实色面（比底色深 / 浅一档），无阴影无玻璃；字用底色「挖」出来（文字颜色 = 底色，或 `mix-blend-mode`）。远处档位色面变淡、字先消失只剩色面。

### C · 结构
- **C1 平面叠层**（我）：每个版块一张独立无界平面（随笔 / 项目 / 瞬间 / 关于），四张沿 Z 叠放（借 depth 的透视、雾距、近处 backdrop 远处 filter 的分档）；拖动在当前平面里走，滚轮 / 捏合在平面之间穿行，非当前平面虚化退后、只露边缘的色带。周期、14° 交界在每张平面内部仍成立。内核要从「一个 world」变成「多个 world + 一个 Z 相机」，改动最大。
- **C3 双曲平面**（我）：庞加莱圆盘。内容排在一棵 {p,q} 镶嵌（例如 {7,3}）的胞腔里，原件在中心胞腔，相邻胞腔放副本；拖动是 Möbius 变换（不是平移），越往盘边胞腔越小、越多。记忆档可直接用「到中心的双曲距离」。需要一个新的坐标层，方块按胞腔中心缩放。
- **C4 语义缩放**（S）：Ctrl+滚轮 / 双指捏合改 z（0.25–1.6）。z 低于阈值时方块换成更粗的表示：< 0.5 只剩版块名（四个整数命题），0.5–0.8 是条目标题，> 1.2 时文章方块露出小节编号（1.11…）。用 tiers 之外的另一套「按 z 选写法」，可做成机制。
- **C5 非周期铺排**（S）：每个副本周期用 hash(i, j) 选一种排法变体：方块顺序轮换、错位方向翻转、某块缺席、两块互换位置；原件周期不变。规则层 + world 层各改一点，place / box 里按变体偏移。
- **C6 时间坐标**（我 / S）：x 轴 = 日期（每天固定宽度），y 轴 = 版块带；没有周期复制，平面向过去无限延伸（空白处只有底色与日期刻度），向未来止于今天。底色按「那一天的夜」铺：每天一段从浅梦到晨光的渐变。内容少时会很空——它是为内容变多准备的方向。

### D · 小机制
- **D2 关联的线**（H）：文章 related 之间、同一则瞬间的几张图之间连 1px 曲线（屏幕空间 SVG，同发丝线做法）；线的不透明度按两端较清楚那一端的档位定，远处方块淡成色块后线仍保留一点——关系比内容留得久。
- **D3 时刻底色**（H）：按访客本地时间把底色整体偏移：23–01 点偏浅梦冷、01–03 偏深、03–05 偏异相紫、05–07 偏晨光暖；只是 oklab 里 6–10% 的混色，field.paint 时传入。可加 `?hour=` 预览。
- **D4 照片柔化**（H）：tiers 的配图降档对非像素画改成「低清 + 高斯 + 颗粒」：1–3 档分别降到 1/6、1/12、1/24 再平滑放大，叠一层 8% 噪点；像素画（NEXUS 那四张）保留硬像素。按图在 data 里标 `pixel: true`。
- **D5 侧看**（S）：一个键 / 按钮让平面 rotateX 到 ~72°（掠射角），方块变成一道道竖起的脊，脊顶写标题，脊的排列就是目录；点脊飞回正面并对准那块。借 depth 的「侧看＝目录」。
- **D6 空间声音**（S）：四个时辰各一条环境声底（复用 design/audio 的素材方向），音量按镜头中心处的时辰权重（就是底色的那套权重）混；跨 14° 交界时交叉淡化。默认静音，右上加开关。
