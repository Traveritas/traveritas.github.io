# p15-b「谐波残影 · Harmonic Echo Waves」— 设计说明与实测

**主张**：不改脑电的种类，改它的**采样率与声部**。醒＝线上那条平滑低幅发丝线（什么都没多）；梦＝同一条线被采样并保持成直角阶梯，再在其后方分离出 3 道**带时间延迟、采样更粗、冷暖分层**的声部，同时四道同轴虚线谱带从轴上展开。两态差不是「多了一件东西」，而是**同一条线被读了几遍**。

## 醒
- 脑电逐字等于线上（`AMP 3.6 / FREQ .5 / SPD 2.6 / 26px / 14°`）：本稿 `voicePath(ph,0)` 与线上 `Eeg.astro` 那 8 行**字符串完全相同**（3 个相位实测 identical＝863 字符）；梦度 d<.02 时连残影的 `<path>` 都不构建。
- 背景层（回波谱带）`--still=0` → 法向位移 0、不透明度 0、四道线塌回 14° 轴上：「本层开」与 `?bg=off` 在版心内**逐像素零差**（三 zone changed＝0）。醒态本层 animation＝0（全页只剩外壳缝线锚点那 1 条既有呼吸）。

## 梦
- 主波：4px 量化格 × 三档分级（3 秒换档，与 brand.ts 呼吸同源）+ 零阶保持（同级平台并成 `H`）+ 2.4 倍分级增益 → 直角阶梯（实测**竖段 15 / 平台段 69**；醒态 0 / 0）。
- 三道残影（3 只 `<path class="eeg-ghost">`，插在主波之前，每帧重写 `d`，复用外壳那一条 30fps rAF）：同一波形的**延迟副本**——延迟 0.10/0.22/0.36 s、采样步长 ×2/×3/×5（52/78/130px）、格 4/5/6px、相对增益 0.90/0.62/0.42、法向分离 −21/+19/−41px、色 `--amber`/`--wake`/`--dream`（暖—冷—暖），另各带一条 ±1~3px 的 `steps(1,end)` 整数像素游走。
- 回波谱带：四道 1px 虚线（节距 26px＝脑电自己的采样步长；梦态 `scaleX(2.4)` 拉粗到 62px），沿法向展开 ±12/±38px、暖冷交替、按 `steps(1,end)` 逐格爬行；只吃 `--still / --amber / --wake / --dream`，零 JS。
- 无缝：分离距离 / 量化程度 / 零阶保持 / 延迟 / 增益没有一处是开关，全由 `--reality-mix` 连续解析；`?mix=0.5` 是「开始分裂但还没散开」的可信中间态（3× 裁片 `96-zoom3x-deep-mix05.png`）。

## 与上一轮 P14-B 的差别
p14-B 的残影是**一道被冻结的基频**（静态路径；它自己标注「延迟快照要按节拍重写路径，就不是零成本了」）——谐波的分裂与延迟正是它明说没做的。本稿把它补成 3 道**每帧重算**的延迟声部（延迟＝相位，量化/保持/增益同样随梦度连续解析），并新增「同轴长出一张谱」的空间层。
**只留主波的量化保持、去掉全部残影与谱带**（`?echo=off&bg=off`）：两态差仍 100% 成立——就是 p14-B 被点名的那一件（竖段 0→15、增益 2.4×），版心内最亮处 9.9%（deep）/ 66.5%（light）/ 71.7%（paper）；补上残影与谱带后是 11.3% / 53.7% / 58.2%。**残影与谱带买的是纵深、冷暖与「合唱」，不是两态差本身。**

## 最不放心的
- **密**。梦态在这条轴上同时有：主波 + 3 残影 + 4 谱带 + 缝线 ＝ 9 条同轴线索，1× 全图读作「一束展开的谱」——这正是要的两态差，但「密」不完全等于「亮」：亮度实测只有全栈 11.3%（deep），若判读者觉得吵，减谱带（4→2 道，只留 ±38 外档）是最小改动，残影不动。
- **浅底面上的两态差偏「冷」**：light/paper 下暖色残影几乎看不见，两态差主要由主波的阶梯与亮度承担；deep 面才是「合唱」读得最全的一面。三段底色里 light 是最弱的一档。
- **残影的逐格游走幅度（±1~3px）远小于波自身的横向流动（相位传播约 16px/帧）**，所以「抽帧」的时间感主要来自 3 秒换档与谱带 dash 的爬行；三条 `echo-walk` 更接近一点抖动，删掉不损失结构（animation 7→4）。
- **顶点数 2.56× 超出简报的 ~2× 口径**（按字符/耗时则不超）。要严格满足只能砍到 2 道残影且都用 ≥104px 采样步长，代价是残影不再能被认成「同一条波」。我选了保留 3 道声部，把超出量如实写在这里。
- 三 zone 的 53–58% 与「≤35% 红线」并列时容易被误读为踩线；若要把它压下去，唯一办法是把主波在梦态的描边透明度从 0.62 降到 ~0.5（会偏离「醒态与线上逐字一致」之外的梦态自由，但梦态本来就自由）——这是一个需要裁决的取舍，我没有替它做。
