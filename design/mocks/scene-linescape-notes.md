# 场景原型 · linescape（线景）

页面：`/mock/scene-linescape/`
文件：
- `src/pages/mock/scene-linescape.astro`：复制自 `new.astro`，排版网格沿用 hero-quiet，只重做场 0。
- `src/scripts/proto/scene-linescape.ts`：主线程脚本，复制自 home-storyboard，去掉大字那一套。
- `src/scripts/proto/scene-linescape-worker.ts`：地形与圆环的离屏绘制。
- `design/mocks/.shot-scene-linescape.cjs`：截图与测量脚本。

共享文件一律未改。

## 思路

全站那一根脑电线在开屏就是**地平线**。地平线下方展开一整片线织地形，每一排都是同一根线的一次回声：

- **同一条算式**：每排的波形用的就是 `eeg-wave.ts` 的 `waveAt`，AMP、FREQ、SPD 都相同。区别只在于读得更晚：越近的一排相位越落后（0.35s 到 2.75s），所以波看起来是从地平线一排排传到眼前的。
- **透视**：每排的法向偏移是 `o = Rm·t^2.7`，`p = o/Rm` 当作透视比例。
  - 远处的线细（0.42px）、密、淡，屏上的波长被压短（世界坐标 `xw = (s−c)/p`）。
  - 近处的线粗（约 1.2px）、间距大、起伏大。
- **地势**：世界坐标里叠几道正弦，再加一座中景偏右的缓丘。地势的纵向坐标按排走，所以山脊会斜着穿过各排。
- **遮挡**：每排画完后，把它下方一条带擦掉九成（destination-out）。近处的脊因此能挡住远处的线，被挡的线还会像隔着一层树脂那样透出一点点。
- **雾与景深**：远排的透明度淡进地平线；画面下沿用纵向渐变描边，让最近的几排退进雾里，视线停在中景，整片地形像是浮着的。地平线后方还有一道静态的微光带（`.ls-glow`，固定层，位于画布之下）。
- **梦态**：同一片地形换一种读法。每排按格量化、零阶保持，起伏变成一级级台地，颜色从冷墨转向暖沙。颜色读的是 reality.ts 混出来的 `--umber / --wake / --dream`。
- **圆环**：天上三枚细线圆环：一枚竖立的圆、一枚顺着地平线平躺的椭圆、一枚很小的圆。竖立那枚会轻轻浮动。
- **不合理处**：竖立那枚圆环在地形上有倒影，但倒影沿地平线错开了约 7.5vw，而且圆环浮动时倒影纹丝不动。倒影是一圈窄环带，地形线穿过它的那几小段会被改写：
  - 梦面：这几段被照亮，呈琥珀色。
  - 醒面：这几段反而断开，只剩一圈空缺。醒面本来没有异色，所以倒影以「缺席」出现。
- **排版**（三级，全部压在天空一侧的左上，地形一侧不放字）：
  - 等宽小字「入夜 · 23:07」。
  - 问句两行，第一行用次墨。
  - 一行小注「随笔、项目，与正在成形的东西」。
  - 以上都对齐页头那条 42rem 中栏的左沿。线尾的中栏右沿躺着一枚「00 / 05」。
- **交接**：开屏滚过 0 到 0.3 幕时，地形一排排贴回地平线、淡出，圆环上浮、淡出（`fold`）。到第 1 幕时画面里只剩那一根线，线随即按主稿的姿态弯成竖线。收拢到底后，Worker 画一帧空白就停。

## 性能

在 dev server 上测，1440×900，醒面，入场结束后静置 3 秒：

| 项目 | 数值 |
|---|---|
| 主线程样式重算 | 0 次 |
| 布局 | 0 次 |
| 脚本 | 0.1–0.3ms |
| 全部任务 | 约 10ms（全站共享的页头动效等，与原型无关） |
| Worker 每帧绘制 | 平均 3.7ms，峰值 6ms，30fps |
| 每帧点数 | 约 4.9k |

- **为什么能做到零开销**：主线程只在滚动、尺寸变化和入场时给 Worker 发骨架与收拢度，静置时没有 rAF。
- **Worker 端的预算手段**：
  - 行数为桌面 34、窄屏 28。
  - 每排的步长按屏上波长给，每个周期至少 12 个点，取值在 5 到 22px 之间。
  - 视口裁剪：每排只进出画面一次，离屏的点不算。
  - 遮挡只擦带状区域，不擦整片下半屏。
- **优化过程**：第一版每帧 1.8 万个点、绘制 8–10ms。地势本身不变；减到现在这个水平靠的是三项：按波长定步长、视口裁剪、骨架游标代替二分查找。
- **减动效**：Worker 只画一帧静帧（地形全展开、圆环不浮），CSS 入场动画也关掉。
- 页面不可见时 Worker 跳帧。

## 已知问题

- **观感**：醒面仍有一点「波浪线纹理图」的既视感，缓丘与遮挡的层次比预期弱，山脊斜穿各排的效果要凑近看才明显。要再往前推，可以把地势做得更有结构，比如一条蜿蜒的谷地。
- **倒影**：在醒面很含蓄（只是一圈断口），第一眼不一定看得出来。
- **动效的视觉效果没有亲眼看过**：动效（波从地平线一排排传来、入场时地形从地平线往下铺开、圆环浮动）只在截图静帧里确认过构图，动态观感需要在浏览器里看。
- **圆环组合**：竖圆与平躺椭圆放在一起，个别人可能会读成「行星与光环」。
- **原稿里的一个 bug**：减动效模式下，原稿脚本会在 `kick` 定义之前调用 `onBooted()`，撞上暂时性死区报错（home-storyboard.ts 同样的顺序，主稿 `/new/` 在减动效下应该也会报 `Cannot access 'kick' before initialization`）。本原型里已改为 `queueMicrotask(onBooted)`；共享文件未动。
- **未做的验证**：没有跑 `npm run build`（按约定）。原型的两个脚本用 tsc strict 单独检查过，无报错。

# 第二轮（v=a / v=b / &pins=1）

页面：`/mock/scene-linescape/`（默认 v=a）、`?v=b`，两者都可加 `&pins=1`。
新增 `src/scripts/proto/scene-linescape-terrain.ts`：地形几何（Worker 与主线程共用）；截图脚本 `design/mocks/.shot-scene-linescape2.cjs [tag]`。
变体与 pins 由页头一段内联脚本在首帧前写到 `html[data-lv] / html[data-pins]`，不跳版。

## 改了什么

- **天空只留一样东西，且与线有关**
  - **v=a 线圈 + 光**：三枚圆环删掉，换成同一根线（`waveAt`）绕成的一枚闭合大圆（桌面约 30vw 直径）。下半截沉到地平线以下，从 `kFront` 那一排起的近排从它前面经过、把它挡住。圆后一团预渲染圆光（`.ls-sun`，固定层，几何与 Worker 同一份），经过光里的地形线用径向渐变略提亮。倒影错位的悖论保留（不随圆浮动）。梦面不再量化圆周（上一版的台阶缺口看着像故障）。
  - **v=b 回声飘起**：天上无天体；最远十来排越过地平线向天空极淡地延伸、渐隐。
- **文字减法**：只留问句，一种颜色一个字号。a 横排两行在左侧天空（42rem 中栏左沿）；b 竖排三列在右侧天空，右沿对齐导航、列脚沿地平线抬高。副标题移入 sr-only，「入夜 · 23:07」「00 / 05」删去。
- **等高线标注**：`23:07` 嵌在地平线上（另一张画布上的线用一块底色小晕遮出断口），`06:31` 嵌在最近一带的某条线上（Worker 在此断线）。字沿线方向、等宽、9.5px。远是入夜，近是天亮。
- **测量点（&pins=1，接入 floatwin）**：随笔 / 瞬间 / 项目 / 关于（梦面 断章 / 闪念 / 造物 / 此身）四粒点钉在中近景几条等高线上，旁边一行小字 + 数量。hover / 键盘焦点 / 点按时，floatwin 式小窗从点上方浮起（opacity / transform）；Esc 收起并把焦点还给点；点空白收起；一扇窗打开时其余标签隐去。
  - 定位：主线程只在尺寸变化时用「静止地形」算一次锚点，Worker 在锚点附近把波形压平（`CALM` 64px 高斯），所以 DOM 上的点始终落在线上，却不用逐帧挪。
  - 标签统一沿地平线方向（各排局部角度不一，跟着歪显得乱）。

## 迭代

- **接手时的状态**：Worker、几何模块、页面结构与样式都已写好，但主线程从没调用 `placeMarks()`，也没把 `anchors` 发给 Worker，所以标注与测量点不显示。补上后能跑，无报错。
- r1：标注 / 测量点不显示（上一条）。
- r2：功能齐；问题是测量点标签角度 8°–23° 不一、锚点处压平太陡出现小台阶、梦面圆周有台阶缺口、窄屏小窗透出底下其他标签。
- r3：标签统一 14°、`CALM` 34→64、圆周去量化、小窗不透明度提高。
- r4 / 定稿：小窗近乎不透明，打开时其余标签隐去。

## 性能（dev server，1440×900，醒面，入场后静置 3 秒，带 pins）

| 项目 | v=a | v=b |
|---|---|---|
| 主线程样式重算 / 布局 | 0 / 0 | 0 / 0 |
| 主线程脚本 | 0.2ms | 0.2ms |
| Worker 每帧绘制（30fps） | 平均 4.5–6.2ms，峰值 6.6–9.9ms | 平均 5.2–6.9ms，峰值 7–10ms |
| 每帧点数 | 约 5.6k | 约 7.4k |

Worker 比第一轮（3.7ms）略重：a 多了圆周和逐排的光照渐变，b 多了十来排蜃景。测量值在几轮间浮动 ±1.5ms（无头 Chrome，同机另有 dev server 在跑）。
