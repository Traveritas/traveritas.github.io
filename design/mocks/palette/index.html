醒与梦 · 背景配色

随笔 / 瞬间 / 项目 · 四案

三个目录页的底色（三栏的光）在四套「和谐」方向下并排。每栏四档＝着色器里的底 / 中 / 光带 / 亮芯。

看真页面：先 node design/mocks/palette/serve-palette.cjs，再把这个地址带上 ?p=now|a|b|c|d 打开任意目录页，例： /articles/?p=a、/projects/?p=c、/moments/?p=d。 切换方案不影响站点本身（原型只在注入层里生效）。
改配色：只改 gen.cjs 里四栏的「底色 + 亮芯」两个 OKLCH 点，跑 node design/mocks/palette/gen.cjs，字墨与对比度自动重解，本页与真页面同时更新。

阶律一览

明度 / 彩度上限

「和谐」的核心是明度阶律站得住：三栏的可见底要有清楚的上下关系，彩度上限一致，色相差落在同一小段（或按用途拉开）。

生成器 design/mocks/palette/gen.cjs · 预览服务 serve-palette.cjs · 运行时注入 inject.js。数据源与取舍理由见同目录 NOTES.md。

对比度按 WCAG 相对亮度，对「可见底」（底与中的中间值）计算；正文墨 ≥ 7、次墨 ≥ 4.5、微墨 ≥ 3、强调墨 ≥ 4.5。
