# 「背景配色」四案 · 原型笔记

> 交付物：`gen.cjs`（方案生成 + 对比度自解）、`palettes.js`（生成产物）、`index.html`（方案总览）、
> `serve-palette.cjs`（真页面预览服务）、`inject.js`（运行时换色）、`.shots/`（并排截图）。
> **一个字没动 `src/`、`public/`、`dist/`**，也没有 commit。方向不由这份原型定稿。

## 0 · 怎么复核

```bash
npm run build                                   # dist 不存在或 src 改过时
node design/mocks/palette/serve-palette.cjs     # 打开打印出来的地址
```

- 方案总览：`http://127.0.0.1:4398/__palette/index.html`（见 `.shots/overview.png`）
- 真页面：任意目录页带 `?p=now|a|b|c|d`，例 `/articles/?p=b`、`/projects/?p=c`、`/moments/?p=d`
- 选择记在 cookie（`palette_p`）里，站内跳转不用再带参数；不带参数时是 `now`（现状）

改配色只改 `gen.cjs` 里每栏的两个点（底色 / 亮芯，都是 OKLCH），再跑
`node design/mocks/palette/gen.cjs`：四档 sRGB、卡片字墨、对比度、总览页与真页面同时更新。

## 1 · 先看清楚现状：不和谐在三处

三栏的底色不是一块平色，是 `src/scripts/wander/light.js` 里 `uP` 那 48 个 float（4 区 × 底 / 中 / 光带 / 亮芯）
混出来的。现在三栏的实际底色（`wander.css` 的 `--w-bg`）与对应 OKLCH：

| 栏 | `--w-bg` | L | C | H |
| --- | --- | --- | --- | --- |
| 随笔 | `#c6ced9` | 0.849 | 0.018 | 256 |
| 瞬间 | `#1d1729` | 0.221 | 0.035 | 299 |
| 项目 | `#0d1524` | 0.196 | 0.033 | 262 |
| 主页 | `#0e0f1d` | 0.175 | 0.029 | 280 |

诊断：

1. **明度断崖**：一块 0.85、两块 0.20 上下，中间什么都没有。检索视图看着像「一页白纸 + 两页黑纸」。
2. **两块黑分不开**：瞬间与项目只差 △L 0.025、△H 37°，还要靠光带一暖一冷来救。
3. **光带方向相反**：项目偏青蓝（H 200）、瞬间偏橙（H 35），同一片光在两个栏里往两个方向跑。
4. 顺带一个实测：现状随笔那栏的 `--w-faint`（`#8a94a2`）对底只有 **1.93**，
   `.row-date` 那类小字在浅栏上几乎看不见——四案都把它提到了 3.6。

## 2 · 四案（`now` 之外的四支）

四案共用一条原则：**明度阶律先成立，色相只做很小的位移**。每栏只写两个 OKLCH 点
（底色 + 亮芯），中间两档由 `stops()` 在 OKLCH 里插出来，超出 sRGB 时按「保 L、保 H、收 C」处理。

| 案 | 一句话 | 随笔 L / 瞬间 L / 项目 L | 彩度上限 |
| --- | --- | --- | --- |
| **A · 同阶冷夜** | 结构不动，只理秩序：三栏回到同一条阶律，两块黑各抬一档并拉开，彩度统一收到 0.030，亮芯从冷白走到淡玫瑰 | 0.862 / 0.300 / 0.222 | 0.028 |
| **B · 降饱和近似** | 彩度全线压到 0.010–0.014，色相挤在 258°–276°，靠明度与光带分开（你点名的那一支） | 0.845 / 0.272 / 0.218 | 0.011 |
| **C · 全线提亮** | 三栏都抬到浅色，深色只留给主页；阅读最舒服，但目录页不再有夜色 | 0.918 / 0.905 / 0.898 | 0.019 |
| **D · 全夜同源** | 随笔也进夜里，三栏全暗、同一束暖白月光从三栏上流过；夜最完整，代价是没有一块亮地 | 0.330 / 0.268 / 0.212 | 0.022 |

色值表、四档、字墨、对比度全部在 `index.html`（浏览器直接打开）与 `palettes.js` 里，这里不重抄。

**V 阶律（L 跨度）**：现状 0.653 → A 0.640 → B 0.627 → C 0.020 → D 0.118。
A / B 是「保持现有明暗骨架、把断崖补上」的那一类；C / D 是把跨度整体压小，
前者压到「几乎一样亮」，后者压到「几乎一样暗」。

## 3 · 对比度（自动解出来的，不是手填的）

`gen.cjs` 对每栏的「可见底」（底与中的中点）解出四档字墨，门槛：正文 ≥ 7、次墨 ≥ 4.5、
微墨 ≥ 3、强调 ≥ 4.5。四案全部达标，实测都落在 12.4–12.5 / 6.6 / 3.6 / 5.0 这一档（设计上就是让它稳在门槛之上）。

瞬间 14.64 / 8.26 / 4.36 / 6.10、项目 15.24 / 8.67 / 4.77 / 5.83。

## 4 · 为什么原型要拦 WebGL

CSS 的 `--w-bg` 只盖到覆盖层（`#w-veil`、退化的 CSS 渐变），改不到光本身——光在着色器里。
所以 `inject.js` 做了三件事：

1. **拦 `getUniformLocation` / `uniform3fv`**，命中 `uP`（48 个 float）时换成新案的 12 个值；
   醒 / 梦两态按 `--reality-mix` 现算（醒面把彩度朝中灰收 12%，明度不动——站点的醒面本来也是「同一片光更灰」）。
   主页那一区**不在这次范围**，一律回退成 `light.js` 原来的 DREAM 值，所以「主页 → 下沉进三栏」那条路仍然从原来的靛夜接上。
2. **卡片字墨**：`faces.js` 的 `INK` 是模块内常量，拿不到引用；但它是画进 canvas 的，
   于是拦 `CanvasRenderingContext2D` 的 `fillStyle` / `strokeStyle`，按「旧色 → 新色」对照表换（只认那六对颜色）。
3. **CSS 变量**：`--w-*` 一族、阅读窗的 `.w-rd` 令牌、卡片纸那层值偏移。选择器都带 `html` 前缀——
   本样式插在 `<head>` 最前（比站点的 `<link>` 早），同权重时后加载的赢，所以每条都要高一级。

**做不到的**：`ink.js` 的两态墨（浅墨 `239 234 244` / 深墨 `30 34 44`）写死在模块里，
渐变直接写进 inline `background-image`，本原型只能事后在 rAF 里做字符串替换，且只对**已经画出来的**那些字生效。
另外真页面的目录页在 headless 里没有启动 WebGL 光（`startLight` 落在 `grain-boot.ts` 的回调里），
所以 `ink.js` 的换墨在原型里看不到——截图里栏头的墨色是 CSS 的 `--w-fg` 与 `--w-faint`，不是 `ink.js` 的结果。
**定稿时这两处必须改到 `ink.js` 本身**（两态跟着栏走），不能指望注入层。

## 5b · `hours.css` 已撤（同日）

追查后发现「版块＝时辰」这套机制只兑现了两个页面：`/tags/`（浅梦灰蓝）与 `/gate/`（晨光暖砂）。
其余版块页的底色早就被 `wander`（目录页）与 `mist`（阅读页）接管了，
`hours.css` 第 4 节还得专门把 `--bg/--fg` 掰回全站默认色才不至于把浅雾上的字变成浅色。
它当初只写进了 `design/mocks/hours/` 的原型，任何 docs 都没有记录，所以站长不记得有这个东西。

撤掉的范围（实测：去掉 `data-hour/data-tone` 后只有 `/tags/` 与 `/gate/` 两页会变，其余逐像素不变）：

- 删 `src/styles/hours.css` 与 `BaseLayout.astro` 里的 `HOURS` 路由表、`data-hour` / `data-tone` 属性。
- `Ave.astro` / `Toolstar.astro` 里跟着暗底走的 `html[data-tone='dark'][data-hour]` 分支一并删；
  `--frost*` / `--hour-ink` 再没有消费者，`wander.css` 阅读窗里那两根也清掉了。
- `wander.css` 里「主页地面先垫夜色」那条原本挂在 `[data-hour='home']` 上，改成
  `html.w-on body:has(.w-host[data-scene='home'])`（与仓库里已有的 `:has()` 用法一致）。
- `body[data-mist]` 那条属性也一起删了——它唯一的消费者就是 `hours.css` 第 4 节。

结果：`/tags/` 回到 `tokens.css` 的 `#f0f3f6`；`/gate/` 回到同一张底（它自己的天与水分层画在
`.about-stage` 里，不受影响）。`design/mocks/hours/` 整份原型原样留着当历史记录，里面 `hours.css`
与它那份 `NOTES.md` 仍然可读。

## 6 · 已知的边界

- 原型只在**梦面**截了图；醒面按「彩度收 12%」推的，没有逐案核对。
- 移动端（390px）没重新截；三栏在窄屏会折叠，配色判断不受影响。
- `?p=` 在阅读窗里会被 `replaceState` 冲掉，所以方案号同时写进了 `<html data-palette-request>`。
- `now` 这一支的 `--w-faint` 1.93 是**站点现状**，不是原型算错的；四案都修了。
