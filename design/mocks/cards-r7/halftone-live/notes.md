# 甲 · 网点（活）`halftone-live`

> 底子是 `cards-r6/halftone`：4×4 Bayer、5px 格、卡角落在 5 的倍数上。
> 这一版没有重做那套网版，只在它上面加了「会变的数」和一次展开。

## 0. 先把 tile 抽成纯粹的 mask

r6 的 20×20 tile 是**烘好的 alpha**（每格 = 档位/15 × A × mask），所以墨色写死在
`background-image` 里，改不了、也过渡不了。活版把它拆成两层，还是一张 tile：

```
.face::before{
  background-color: var(--ink);                        /* 墨色：可以过渡 */
  mask-image: var(--mesh),                             /* 塔：15 档，alpha = 档/15 */
              linear-gradient(180deg,
                rgba(0,0,0,calc(var(--A)*var(--s0)*var(--k))),
                rgba(0,0,0,calc(var(--A)*var(--s1)*var(--k))));
  mask-composite: intersect;
}
```

每格墨 = `档/15 × A × s × k`。三组数照抄 r6（亮栏 `A.150 / s0.28 / s1 1`，
薄暮 `A.155 / 1 / .30`，深蓝 `A.160 / 1 / .30`），`--s0/--s1/--k/--A` 用 `@property`
注册成 `<number>`，于是**密度能过渡**；墨色是 `background-color`，于是**墨能反号**。
格本身一格没动：5px、20px 周期、对齐都没变。把两版的 list 叠起来，网点几乎逐像素重合（剩下的差在字的次像素抗锯齿上，两版截图脚本的 GPU 开关不同）。

## 1. 悬停：只把网点压浓一档，180ms

`--k: 1 → 1.5`，`transition: --k .18s ease`，只改 mask 里那两端的 alpha。
单格最浓从 .150 → .225（薄暮 .155→.233、深蓝 .160→.240），平均上墨 +50%。
实测（1440 下把 01/02 相减）：整张卡平均 ΔL\* **1.4**，下半（字少的一带）1.86，
最浓一格 4.8；旁边的第二张卡 ΔL\* = 0.0。

不位移、不缩放、不换形状、不加边——动的只有那层格子。

## 2. 展开：60ms 定影，然后同一张网版从卡片矩形长出去

**定影 60ms。** 点下去先把 `--s0/--s1` 都推到 1（`.04s`）：上淡下浓的坡被抹平，
整张卡露出这张网版自己的满档（单格 .15），像印张「定」住的那一下。同时卡上的字
`.15s` 退掉——字不是材料，材料留下。

60ms 后 `#sheet` 这块**同一个 `.face`** 接手：先摆到卡的矩形上（测得
`130,135,260,225`），再 WAAPI 动 `left/top/width/height` 到 `620,120,720,670`
（都是 5 的倍数），**720ms，`cubic-bezier(.34,.06,.2,1)`**——起手慢一点、中段拉开、
末尾贴住。格宽不缩放，所以「长」的是这张网版被切的边，不是里面的点。

飞行中另外两件事：墨色 `#171c28 → #d8d4e6`（`.30s linear`），因为纸从亮的那半
走到了夜的那半；坡从「平的」回到「上浓下淡」（`.60s`）。字在 600ms 才浮上来
（`.22s`），落定时刚好齐。

## 3. 收起：反向落回那张卡，落点按当时的 rect 量

`—` 或 `Esc`。收起时重新量一次那张卡（不是复用打开时的坐标），从当前矩形
360ms 回到它，`cubic-bezier(.42,0,.6,1)`；墨与坡同步回卡的那一组（`.34s`），
卡本身在收起的第一帧就开始显影（`.15s`），所以往回缩的这张纸是落在一张
「已经在等它」的卡上。最后一帧把 sheet 隐藏、把卡交回去——**06 与 01 逐字节相同**。

焦点在收起结束时回到那张卡；鼠标点开、Esc 收的，不给焦点环（`.quiet`），
键盘开的，环留着。

## 4. 焦点：卡片是 button，环画在 5px 格外

六张卡都是 `<button>`，Tab 顺序就是 DOM 顺序（按栏、自上而下），Enter / Space 是原生行为。
`:focus-visible` 时：1px `rgba(154,134,196,.7)` 环、`outline-offset: 5px`（还是落在格线上），
外加和悬停同一档的密度（`--k:1.5`）。打开后焦点进面板，停在 `—` 上；Tab 被收在面板里
（只有这一处可停），Esc 收起并回卡。

## 5. 最容易被否的地方

- **定影那 60ms 在任何一张帧里都看不见。** `frames.cjs` 的 03 名义上是 80ms，
  实际抓在 60–110ms 之间（截图本身有几十毫秒延迟），所以 03 要么正好停在
  「坡抹平、字刚退」的那一下，要么已经长出十几像素。它不是一个能当证据的帧，
  只能自己点一下看。
- **飞行中有一段「玻璃」。** 纸从亮的一栏飞到夜的一栏，中间必然有一半的墨和它
  下面的底同号——那一段网点几乎看不见，只剩两条 0.6px 的边。墨色用 `.30s`
  较快地翻过去，就是为了把这段缩到最短；04 里能看见格，但它确实不是「整段都浓」。
- **落点准不准，全看那一刻的 rect。** 桌面不滚动，所以是准的；窄屏列表会滚，
  收起时如果视口变了，是照着量到的新位置落，不是原来的位置。
- **窄屏阅读页铺了实色夜面**（`#0d1424`）。底图是一张固定高度的图，全屏面板一定跨
  亮暗两半，一张网版托不住两种墨——这一处的「值偏移」是断的，和 r6 一样。
- **「同一张网版」只对到格。** 底图的抖动跟着画走，没有全局相位；卡里是同一张
  有序网版，能成立的是 5px 格、15 档和墨，不是每一格的明暗。
- **非文章的面板偏空。** 项目两条只有一行简介 + 一个链接，瞬间两条靠一张图撑。
  内容只能取 `shared/fixture.md`，没有更多正文可放；这是资料的问题，不是版的问题。
