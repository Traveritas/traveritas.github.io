# 乙 · 基准 · 活的 `value-live`

> 底子一个字没动：面还是底图的一次值偏移，边还是上亮下暗两条 .6px 加一圈 .5px 收口，
> 字还是栏自己那一套墨。这一版只多了一件事——**这三样各有三个状态**。
> 回答的是那一个问题：没有网点可借，这张几乎看不见的卡，凭什么让人知道它活了。

## 1. 悬停：近边抬起，脚沉下去

没有位移、没有缩放、没有投影，所以「抬起来」只能靠值：

| 栏 | 面（顶 → 底） | rest | hover | 差 |
| --- | --- | --- | --- | --- |
| 随笔 | 墨 | `.018 → .092` | `.006 → .118` | 卡内跨度 4.3 → 5.8 L\*，顶贴回纸，脚再沉 1.7 |
| 瞬间 | 白 | `.118 → .022` | `.150 → .014` | 顶多提 3.7 L\*，底再让 1.6 |
| 项目 | 白 | `.092 → .014` | `.120 → .008` | 顶多提 2.8 |

方向是「顶变轻、底变重」——一张纸的近边被指头挑起，远端压得更实。整个过程 180ms 进、220ms 出。

光靠面还不够：亮栏顶部那 1.8% 的墨压在近白的纸上，卡顶只比纸低 1 L\*。所以第二只手是**边**：

```css
.card::before{                     /* 顶边那一条，只有左 62% */
  background:linear-gradient(90deg,
    rgba(255,255,255,.94) 0%,
    rgba(255,255,255,.58) 26%,
    transparent 62%);
}
```

悬停时它淡进来，和下沿的 .27→.36 一起把形闭住。**亮的是一段，不是一圈**：光从左边来，走到 62% 就化掉，
右半边的顶沿仍是那条 .46 的旧线。这是「边」这一栏里唯一允许的局部变化，也是最不容易看腻的做法。

第三只手是**字**：标题 `.015em → .030em`、日期 `.10 → .125em`、标签 `.07 → .095em`，
墨从 `#232830` 提到 `#14181e`、`#49525f` 提到 `#333c48`。字往外松 0.01em 是「呼吸」，
不是「放大」——三行的字号一个没动，行高一个没动，所以卡里没有任何东西位移。

一眼能看出来吗？能：截图差分里 2.5 万个像素变了，全部落在卡的矩形内（128–476 × 144–368），
卡片框外一颗像素没动。

## 2. 展开：同一块面被拉出去

**60ms 落定。** 点下去不是马上长，先把纸按平：值偏移收拢成 `.030 → .120`（比 rest 更沉、更平），
顶沿推到 `.80`，字在 60ms 里沉进面里。60ms 是四个帧——快到你只看见「一闪」，但足够让这一下有个落点。

然后面脱手。展开不是新开一块，是**那个 `.reader` 元素先被摆回卡片的矩形**：

```js
setRect(reader, card.getBoundingClientRect());   // 128,144,348×224
setVars(reader, getComputedStyle(card));         // 连那三条边的颜色一起
void reader.offsetWidth;                         // 让这一帧真的算成「起点」
card.classList.add('is-gone');                   // 卡退场，面已经在同一个像素上
clearRect(reader); clearVars(reader);            // 撤掉内联值 → 过渡从这里起
```

所以 t=0 时那块面和卡在屏幕上完全重合（同一个矩形、同一组渐变、同一条 .6px），
之后长到 620,112 · 700×690。四条边同一条曲线 `cubic-bezier(.45,.05,.42,1)`，640ms：
**慢起**（前 100ms 只走 7%，所以「落定」看得见）——中段一口气铺开——尾上放缓。
宽高 .64s、左沿 .66s，差 20ms：右沿先伸手，左沿随后跟上，不是整块平移。

面在长的路上换方向：它从随笔栏的墨，翻成夜那半边的白（`.115 → .028`）。这一翻延迟 200ms、用 240ms，
正好在它跨过底图那条斜界线的时候。翻到一半时它是中灰——**在亮那半边读作一层薄雾，在夜那半边才开始有身体**。

字最后才显影：展开走到 480ms（矩形还差最后一截），`reader__inner` 淡进来 160ms，标题字距同时从 `.062em` 收到 `.030em`。
字距这一下是「对焦」，不是动画——31px 的字，九个字距一共收 9px，眼睛只会觉得它刚刚清楚。

`#detail` 这次不再放大：700×420 按阅读尺寸重排一遍，`620 + 700 = 1320 < 1440`，
整块落在夜面里，简介一个字不少。r6 那个 3.4 倍（1183 宽、右沿出画、描述断在画外）没有重犯，
也没有用 scale 去糊——**放大是重排，不是变换**。

## 3. 收起：落回那张卡，一颗像素不差

`—` 或 Esc：字先退（100ms），面同时往回走（360ms）。回程的目标不是「大概那个位置」，
是 `card.getBoundingClientRect()` 当场量的矩形；回程用的面色也不是 rest，是卡片此刻的 **fix** 值
（它从点下去就停在那儿，一直没松）。

于是落地那一帧：面板的最后一次绘制 = 卡的 fix 值，卡在同一帧被放出来、同一个矩形、同一组值——
**两次绘制之间没有缝**。放出来之后才松开 `.is-fixing`，从 fix 松回 rest，边上的顶沿从 .80 退到 .46，
字浮回来：落地后还有一口呼吸，不是「啪」地换回原样。

1× 实测：帧脚本的 `01-list` 和 `06-closed` 两张 PNG **逐像素相同**（diff bbox 为 null）。
证据在 `data-hold`：鼠标收完之后还压在卡上，按道理该立刻重新亮起悬停。这里故意压住不亮，
等下一次 `pointermove` 才恢复——否则「收」的动作会被一张自己亮起来的卡抢掉，
而且 06 会和 02 一样，看不出「回到了原位」。

## 4. 焦点：四角裁切标记

键盘 Tab 进来，卡片四角亮出四段 11×0.8px 的短线——像印厂在纸边上打的裁切标记。
它只用「边」，不引入第五种材料，也不会和悬停混：悬停亮的是顶沿左边那一段，焦点亮的是四个角。

```css
.card:focus{outline:none;}                       /* 浏览器默认那圈框一律不要 */
html[data-kb="1"] .card:focus-visible::after{opacity:1;}
```

`data-kb` 由 JS 记：按过 Tab 才置 1，`pointerdown` 就归零。这一步是必需的——
Esc 之后浏览器会把 focus-visible 重新算成真，默认 outline 会在一张几乎看不见的卡上
画出一圈 1px 的黑框（试过，很难看），而「焦点回到卡上」又是硬要求。所以：
**焦点一定回卡，但那圈框只在键盘用户手里出现**。四条标记的 alpha 也给到了 .62 / .72，
在近白的纸上对底色约 3.8:1（WCAG 的 3:1 是够的，但它们只有 11px 长，是这套里最不响的一处）。

Enter 是 `<a>` 自带的；Space 另外接。开面板时焦点进到 `—` 上（dialog 该接管焦点），
打开期间六张卡 `tabindex="-1"`，Tab 不会掉到背后的列表里；收起来时焦点回卡。

## 5. 最容易被否的地方

1. **悬停偏静。** 亮栏的顶只轻 0.2 L\*、整卡的跨度只多 1.5 L\*，真正让人看见的是那条顶沿的光和字距。
   如果评审要「一眼就知道能点」，把顶沿 .70 提到 .85、面跨度再拉 3 L\* 就够——但那就开始吵了，我没动手。
2. **640ms 的长，是给帧脚本拍的。** 03 拍在长出 3% 的地方（还是那张卡），04 拍在 78%、
   05 拍在落定之后——三段刚好各占一个阶段。真要手感更快，把 `.64s` 改成 `.42s`，代价是
   04 会拍在 97% 上，中间那段就看不见了。这是一个折中，不是定论。
3. **`@property` 是这一版的轴承。** 面、边、收口都注册成了 `<color>`，才能像普通属性一样插值；
   Chrome / Safari 16.4+ / Firefox 128+ 之外，hover 和展开里的面色会直接跳变（几何和字仍然对）。
   这是唯一一处「现代浏览器才行」的地方。
4. **六张卡都开同一篇。** 面板里只有《在显影处：三个声部》的正文，所以点「瞬间」或「项目」也是这一篇。
   原型里这是省事——真实站点里瞬间卡该开灯箱、项目卡该去 GitHub，那是另一套交互。
5. **长的路上，另一张随笔卡会从面里透出来。** 它退到 .12，面是半透明的，前三成的路程里两者叠在一起。
   要干净就把亮栏整栏收到 0，代价是左半边彻底空掉——我留了那点影子，是「从哪来」。
6. **细看能看出的破绽：** 面板和卡在角上的圆角差 1px（4 对 3）。整块面在生长时角是 4px、
   落地时是 3px，肉眼看不到，但它是这套「同一块」里唯一不自洽的数。
