# cards-r7 · 让它能点：两个可交互原型

> 2026-11-02。网点那条被认可了「有意思」，基准那条要「进一步做」。
> 这一批不再是静态稿：**悬停、展开、收起都是真交互**，整页要像真的网站。

## 两条

### 甲 · 网点（`halftone-live`）
底子是 `design/mocks/cards-r6/halftone/index.html`（4×4 Bayer 网版、5px 格、所有卡角对齐 5 的倍数、
卡内不铺平涂、只用 mask 改每格墨的浓淡）。**在它上面加交互**，别重做那套网版。

### 乙 · 基准（`value-live`）
底子是 `cards-r6/value/index.html`（值偏移 + 上亮下暗两条 0.6px + 极淡闭合）。这一条要**再往前一步**：
没有网点可借，那就回答一个问题——**悬停和展开时，这张「几乎看不见的卡」靠什么让人知道它活了？**
可用的手段：面（值偏移的跨度）、边（哪一段亮起来）、字（字距/明度）；不许位移、不许缩放、不许投影。

## 交互规格（两条共用，必须做到）

| 动作 | 要求 |
| --- | --- |
| 悬停 | 约 180ms；**只改密度或明度或边**；不位移、不缩放、不换形状 |
| 点击卡片 | 先「定影」约 60ms，然后从卡片矩形长成阅读面板（同一块材质，不是新开一块） |
| 阅读面板 | 700–760 宽，内容用 `shared/fixture.md` 里那篇文章的开头；有 `—` 或 `Esc` 收起 |
| 收起 | 反向落回卡片原位；落点要准 |
| 键盘 | Tab 能聚焦卡片并有可见焦点；Enter/Space 打开；Esc 收起 |
| 退出 | 焦点回到那张卡 |

- 卡片带 `data-card` 属性（帧脚本靠它找第一张）。
- **底图不许改、不许盖**：`shared/plate-1440.png` / `plate-390.png`，栏头与左下星都在里面。
- 不装依赖、不跑 build；纯 HTML/CSS/JS；只用站内字体与 `shared/fixture.md` 的文字。

## 像真的网站

- 三栏、栏头、右下「漫游 / 检索」、左下星都在底图上——不要重画，也别挡。
- 页面不许滚动（1440×900 一屏）；窄屏 ≤720 换 `plate-390.png`，一列。
- 小心性能：网点用一张 tile + mask，不要每帧 canvas 重绘。

## 交付

1. `index.html`（含 JS）+ `notes.md`：五段——悬停怎么变、展开怎么长、收起怎么回、焦点怎么做、最容易被否的地方。
2. 静态四态截图：
```bash
node design/mocks/cards-r7/shot.cjs <case>       # list / open(#open) / detail / mobile
```
   `#open` 可以保留成「直接打开」的深链，方便截图。
3. 交互帧（**必须自己看一遍**）：
```bash
node design/mocks/cards-r7/frames.cjs <case>     # 01-list / 02-hover / 03-open-80 / 04-open-240 / 05-open-600 / 06-closed
```
   帧脚本会：移到第一张卡上 320ms 拍悬停 → 点一下 → 80/240/600ms 各拍一张 → Esc → 拍收起。
   **看完要回答：这六张连起来像不像一次自然的开合。**

## 判据

- 像真站：不知道这是 mockup 的人看不出哪一块是假的。
- 悬停要「看得出来但不吵」；展开要「从这张卡里长出来」，不是「弹出一块」。
- 收起后要和悬停前一模一样（帧脚本的 01 和 06 应该几乎相同）。
