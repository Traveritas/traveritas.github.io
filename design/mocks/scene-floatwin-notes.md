# 场景原型 · floatwin（悬浮窗）

页面：`/mock/scene-floatwin/`（`src/pages/mock/scene-floatwin.astro`，脚本 `src/scripts/proto/scene-floatwin.ts`）
截图：`design/mocks/_shots-scene/floatwin-r{1,2,3}-*.png`；重拍 + 静置测量：`node design/mocks/.shot-scene-floatwin.cjs r4`

## 思路

首屏即入口：随笔 / 瞬间 / 项目 / 关于各一扇半透明小窗，挂在开屏那根 14° 线上，背后一轮极淡的圆光。
窗不是贴在画面上的卡片，而是被那根线「串」着：每扇窗垂下（或吊起）一根细吊线，落在线上一粒小珠。
漂流方向就是线的方向，所以吊线的下端始终落在线上，像同一夜里挂着的几扇窗。

对参考 p5-floatwin 的修正：

- 窗与问句不再互相遮挡：问句独占左下（中栏左沿，三行），窗全部沿线排在右上 / 右下；
- 不用写实百合，只留圆光 + 线 + 窗三种抽象元素；
- 去掉「这里不是梦，也不是现实」，问句沿用 manifesto；
- 不用 backdrop-filter（线在窗后流动，大面积背景模糊会逐帧重算），窗的「树脂薄片」质感用两层渐变 + 只亮上沿 / 左沿的边线模拟；
- 不做假窗口装饰（红绿灯、标题栏按钮）。

## 层次（自后向前）

1. `.atmo` 雾（主稿原样）
2. `.orb` 圆光：醒面冷白、梦面淡桃，两层按 `--reality-mix` 交叉淡化；z 与雾同层，在线画布之下
3. 线（EEG Worker 画布，主稿原样）
4. `.qset` 问句 + 两行元信息（层级：问句 > 窗名 > 等宽小字）
5. `.fwins` 四扇窗（`<nav aria-label="版块">` 里的四个 `<a>`）：编号 · 窗名（`data-morph` 双态：随笔/断章、瞬间/闪念、项目/造物、关于/此身）· 命题徽标；最新 1–2 条；条目总数

景深 `--z`（0 近 … 1 远）：越远越小（以珠子为原点缩放）、越淡、影越散。随笔最近、关于最远。

## 动效与性能

- 入场：线画出后，窗按序显影（opacity），问句逐字落定（主稿手法）。
- 静置：只有窗沿线的 ±7px 漂流（transform 关键帧，四扇周期 17/19/23/29s 互不同步）与圆光极慢的呼吸（scale）。全是合成层动画，主线程每帧零写入。
- 滚动：`--cp` 由场 0 的 `--p` 算出，窗以自己的珠子为原点缩回线上，同时沿线左移一小段、淡出；圆光同步淡出。
- 离开首屏（pos > 1.02）给 html 挂 `fw-off`，漂流与呼吸全部 `animation-play-state: paused`（只在跨界时写一次 class）。
- `prefers-reduced-motion`：圆光、窗、问句一律静帧直接显示。

实测（headless Chrome，1440×900，dev server，入场结束后静置 3s，CDP Performance）：

| 页面 | 样式重算 | 耗时 | 布局 |
|---|---|---|---|
| scene-floatwin | 4–6 次 | 1.6–1.9ms | 0 |
| scene-floatwin（关掉窗 / 圆光动画） | 4–5 次 | 0.4–0.6ms | 0 |
| hero-quiet（基线） | 0 | 0 | 0 |
| scene-floatwin 滚离首屏后 | 0–2 次 | ≤0.3ms | 0 |

偶发一次 100+ 次重算的采样在关掉本页动画后同样出现，应来自全站共享部分（双文案走神 / 页头），不是首屏。

## 窄屏（390×844）

问句移到页头下；四扇窗两两夹住线（上：随笔、瞬间；下：关于、项目），吊线在窗宽 30% / 70% 处错开，避免上下两颗珠子叠在一起；只留窗名与最新一条（两行截断）；元信息落页脚。

## 已知问题

- 醒面圆光外圈的白色光晕让它偶尔读成一块「浅色圆盘」而非光，还可以再虚；
- 远处的窗（关于、项目）按景深缩放，文字有轻微的亚像素发虚 —— 当景深读还算成立，挑剔的话改成只调字号 / 透明度；
- 窄屏下随笔窗标题折行剩一个字（「张」）；窄屏底部仍有一段空白；
- 窄屏页头导航被挤成竖排，是共享页头的问题（`/new/` 同样），不在本原型范围；
- 截图只覆盖开屏与收拢中途帧，后四幕未逐幕核对（未改动）。
