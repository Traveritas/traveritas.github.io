# B · 树脂（半透厚片）

**材质**：框是一块封住了光的树脂。没有边框线，形只由「边缘的厚度」给出。
**怎么画**：体 = 一层薄乳浊（`linear-gradient(180deg, #f1f7fe 66%, #e3ecf9 78%×hue 76%)`，深底换 `#0d1624` 系），
四角再叠四枚 `radial-gradient(at 角, …, transparent 72%)` 当浇铸积料；上缘 `.a-card::before` 两层梯度求交
（1.6px 冷白全宽 + `radial-gradient(30% 3.4px at 34% 0)` 中段加厚到 ≈2.8px），横向 `mask` 让中段最实、往两端化掉；
下缘 `.a-card::after` 同理，`--m-hue-2` 混一点 `--m-fg`，2.2px 往上化进体里。圆角 5px，全程无 border / blur / 投影。
**数值**：上缘 1.4–2.8px · 下缘 2.2px · 角积料 27–34px 扇形 · 体色 α 0.62–0.80 · 头像 50×50（窄屏 40×40）。
**实测对比度**（卡内空白区 vs 该页 `--m-fg`）：`bg-list` 6.46:1 · `bg-explore` 11.1:1 · `bg-dusk` 12.9:1。
**最容易失效的地方**：`bg-list`（深底）——体色只要再透明 5% 就掉到 5:1 以下，且「块」的形散了；
上缘冷白在浅色底（`bg-explore`）几乎看不见，只剩形，那里是纯靠四角与下缘立的。
**与现行最大的不同**：去掉 1px `clip-path` 边环、两条斜切、blur 磨砂、右侧晶柱、名牌楔口；轮廓从折角多边形改成矩形 5px 圆角。
**取舍**：晶柱 / 四芒星先砍了（保留部件里没它）。要留建议挂在名牌右端，不占字位。
