# A · 纸（与卡片同门）

**材质**：一张几乎看不见的纸。无磨砂 / 无投影 / 无折角 / 无晶柱，轮廓退回矩形，圆角 3px。语言与 cards-r9 的卡片同一套：面是一次值偏移（上轻下重），形只由三条边给出。
**关键 CSS**（`a-paper.css`，全部在 `.a-card`）：`background-image: 她的颜色 3.5%, linear-gradient(180deg, face-a, face-b), linear-gradient(180deg, paper-a, paper-b)`；`box-shadow: inset 0 .6px 0 hi, 0 .6px 0 lo, 0 0 0 .5px ring`。
**面（值的两个值）**：亮底 `.014 → .082` 压暗；暗底 `.075 → .014` 提亮。
**边（alpha）**：亮底 hi `.78` / lo `.30` / ring `.12`；暗底 hi `.26` / lo `.24` / ring `.07`。
**纸色 / 浓度**：亮底 `#eaf0f8 → #d5e0ec`，`.82`（探索 `.78`）；暗底 `#2b3247 → #1a2030`，`.97`。
**其余改动**：名牌退成头像小方块下的一行 9px 小字 + 5px 空心菱；头像 = 印在纸上的小方块（浅纸 multiply、深纸 screen，无玻璃边）；台词 15px / 行高 2（窄屏 14px）、逐字 span、7/4/2px 碎屑未动；晶柱与四芒星删掉。
**在哪失效**：① 第三层「纸」是唯一的让步——对话框落在 bg-list 右下深栏（L≈28）上，只靠 8% 值偏移深字只有 CR 4.2，读不出来，所以必须有纸；它一上来就不可能真的「看不见」，这是本方案最需要作者拍板的一处。② 暗底要到 `.97` 才盖得住深夜页背后的设置面板（`.66/.86/.93` 滑块与按钮描边都还是浮出来），此时它其实是一块深色薄板，只是没有投影。③ `bg-explore.png` 参考图右下角本来就带着旧 Ave 的截图，02 帧上的影子不是这支 mockup 的层。
**与现行最大的不同**：现行靠 blur + 折角 + 晶柱 + 她颜色的一层雾跟底图拉开；A 把这三件全拆了，露出的是底图自己的一次值偏移，所以读起来是「纸上的一行字」，不是「一块浮在上面的玻璃」。
