## 一、现状（0 · 对照）

现行的是「细边磨砂薄片 + 折角轮廓 + 伸出框沿的深色名牌 + 右侧晶柱」：

- 面：`backdrop-filter: blur(16px)` 的玻璃，上面铺一层她自己的雾蓝 / 薄暮紫；
- 边：`clip-path` 画的 1px 边环（`evenodd` 两个轮廓之间那一圈）；
- 轮廓：上沿在头像栏那段平，过竖刻线起坡，坡顶在字栏上方，到晶柱的缝落下，左下切 7px；
- 名牌：`--umber` 深片伸出框沿，左下一枚楔口，里面一颗空心菱；
- 晶柱：右侧 22px，上端关闭、下端四芒星；
- 字：逐字揭开，每个字底下一小段线，最后两字是她的颜色的线头（2px），念完在句尾碎成三截。

对照物就是按这一版复刻的 `0-current.html`（CSS 在 `base.css`，数值取自 `Ave.astro`）。

## 二、必须保住的东西（做什么方向都不能丢）

1. **头像槽**（50×50，窄屏 40×40）。现在是像素流光占位（`ref/faceflow.png` 是一张截图裁下来的真样子，可以直接当图片用），
   她自己的配色：黑白灰 + 低饱和的紫 / 蓝，**不要黑**。
2. **名牌「Ave」** + 一颗空心菱饰，认出是「谁在说话」。
3. **逐字揭开的那条线**：念到才长出来，最后两个字换她的颜色当「线头」。这是她说话的节拍，不能只当装饰砍掉。
4. **句尾三截碎屑**（7 / 4 / 2px 竖条），说完才出现。
5. **收起 ×**（平时 55% 不透明度）。
6. **台词是主体**，字号 15px / 行高 2 不动（14px 窄屏）；框会在 220–380px 之间伸缩，最长两行。

## 三、可以完全重画的

外轮廓、面的材质、边的画法、名牌的形、头像槽的框、线头与碎屑的画法、晶柱 / 侧栏留不留、
说话时的微动（只做静态示意）；框里也可以更空。

## 四、红线（来自 AGENTS.md 与这一处的具体判断）

- **不许**堆投影、发光光晕、双层描边、粗描边、把圆角开到 12px 以上那种「APP 卡片」感、在框里加按钮 / 图标 / 装饰文字（× 与她的名字除外）。
- **不许**「梦」的自标榜：不要星云、不要飘浮粒子、不要「梦境」字样。
- **不许**生活化 / 手工作坊隐喻（针、线迹、缝、贴布、裁缝）、审计台账词汇、程序员中二隐喻。
- **字必须读得出来**：这一块最重要的验收项——浅纸栏（`bg-list`）与深色漫游（`bg-explore`）两张底图上，正文都要稳稳地读得出来。
- 不要为了「有质感」把材质做厚：她只是一句旁白，不能比正文重。

## 五、四个方向（各做一支）

| 字母 | 材质母题 | 一句话 |
| --- | --- | --- |
| **A** | 纸（与卡片同门） | 把材料降到「一张几乎看不见的纸」：面是底图的一次值偏移（上轻下重），形只由上亮 / 下暗两条 0.6px 与一圈 0.5px 收口给出；没有磨砂、没有投影。她的颜色只留三处：名牌、线头、碎屑。 |
| **B** | 树脂（半透厚片） | 框是一块封住了光的树脂：中心几乎全透，形由边缘 2–3px 的「厚度」给出（上缘一道冷白、下缘一道她的颜色），四角一点点厚度楔形；没有边框线。 |
| **C** | 无面之雾 | 不放面：只有一块边缘完全化掉的极淡雾垫在字底下（径向，中心一点点浓度），没有轮廓、没有边。名字牌、线、碎屑照旧。最考对比度控制。 |
| **D** | 像素场（与头像同源） | 她的像素流光向内延伸成一片薄场：边缘用 Bayer 抖动逐格衰减出形，格 5px（头像同一个格），中间几乎全透。与 `wander/light.js` / `ave-flow.ts` 同一门语言。 |

## 六、做法与交付

1. 拷 `0-current.html` 成 `<字母>-<名字>.html`，CSS 自己写一份 `<字母>-<名字>.css`（`kit.css` / `overlay.css` / `base.css` 是共用的，**别改**）。
2. 用 `shot.cjs` 拍五帧看效果，至少迭代两轮（第二轮针对第一轮看到的问题改）：

   ```
   node design/mocks/ave-r1/shot.cjs design/mocks/ave-r1/a-paper.html --frames
   ```

   产出在 `design/mocks/ave-r1/shots/a-paper/`：`01-list`（浅纸页，说完）、`02-speak`（深色漫游，正在说）、
   `03-night`（深夜主页，说完）、`04-anchored`（贴着元素说）、`05-narrow`（390 窄屏），每张另有一张 2× 的 `-zoom`。
   直接浏览器打开 html 也能看。
3. 写一支 `design/mocks/ave-r1/<字母>-NOTES.md`（≤ 12 行）：材质是什么、怎么画的（关键 CSS 一两句）、在哪失效。
4. 有第二方案就再做一支 `<字母>-b-<名字>.html`（同字母的另一种解），别超过两支。
5. **不要**跑 `npm run build`、不要碰 `src/`、不要 `git commit`。
