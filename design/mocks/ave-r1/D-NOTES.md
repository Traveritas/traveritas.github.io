# D · 像素场（与头像同源）

**一句话**：头像里那套 5px 格 / Bayer 抖动的语言从她槽里流出来，铺成一片托住整句话的格。

**怎么织**：一张 20×20 的 SVG 平铺 = 4×4 个 5px 方块，每格 alpha 按 Bayer 4×4 矩阵给；再用 `clip-path: polygon(evenodd, …)` 夹成三层 —— L1 实心像素矩形（右上切一格、左下切两格），L2/L3 只留矩形外 6px 一带，分别换成四取一、八取一。平铺的 `mask-position` 钉在头像槽左上角，场是从她那一格长出来的。

**数值**：格宽 5px（同 `ave-flow.ts` 的 `CELL`），相位对齐 `ref/faceflow.png` 实测的格原点 (8,4)；衰减只有三级 16/16 → 4/16 → 2/16（靠 clip 宽度分圈，不是 alpha 渐变）；浓度 L1 每格 0.90–1.00、L2 0.42、L3 0.20；面底色 `color-mix(--m-hue 24%, #edf2fa)`。

**在哪失效**：`bg-list` 是硬约束——卡压在近黑底（#0a141d）上，正文 #232830 原本只有 1.25 对比，所以 L1 必须近乎不透明（实测各帧正文 6.3–11.3），这跟「中间几乎全透」直接冲突；框宽到 380px 或窄屏 390 时 L2/L3 的 6px 带看不出分圈，退化成「一圈小点」；这是静态图，真站底图在动，半透明面观感会和截图不同。

**与现行最大的不同**：现行的细边磨砂薄片 + 折角轮廓 + 伸出框沿的名牌 + 右侧晶柱四样全去掉，只留一个像素台阶边的实心格面——无 1px 描边、无 backdrop-filter、无圆角，名牌缩成一行低对比像素小字。

**需作者拍板**：L1 的「不透明」程度。要不要为守住「中间几乎全透」，接受 `bg-list` 那条近黑底上正文掉到 3:1 左右？
