# C · 无面之雾（c-mist）

**雾怎么画的**：没有面、没有边、没有唯一轮廓。`.a-card::before` 上叠 **六枚不同心的 `radial-gradient`**，浓度直接写进每枚的 stop（`rgb(... / --mist-aN)`），最外圈是 `transparent` —— 所以雾在盒子之内就已经是 0，**边是化掉的，不是裁掉的**。主团横铺整句，两端各补一团（左下最厚、右上最薄），下缘再加一枚拖住第二行。

**各场浓度**（`--mist-a1`…`a4` ＝ 下缘 / 两端 / 次团 / 主团；正文底**最低**对比是实测值）：
- `bg-list`：`242 245 248` → .34 / .46 / .56 / .64 —— **6.64:1**（全支最险的一场）
- `bg-explore`：同上 → .50 / .56 / .62 / .68 —— 11.00:1
- `bg-dusk`、`bg-dream`：换暗雾 `12 15 24` → .66 / .74 / .82 / .90 —— 15.35:1

**在哪失效**：① `bg-list` 最险——对话框正好压在右侧「造物」栏的深底上，而这一页台词是深墨，雾不实打实提亮就读不出来；② `bg-explore.png` 与 `bg-dusk.png` 的**右下角本身就印着上一版 Ave 卡片 / 一块带按钮的亮面板**，正好落在雾下面，要把雾摊到 150px 宽去洗它，否则台词背后会穿出旧台词与「重载」按钮的描边；③ 试过 `backdrop-filter + mask`：**这个 Chromium 里 mask 一上，backdrop-filter 会被整条丢弃**（只剩一块透明），所以最后没用糊，只用分层渐变。

**与现行最大的不同**：现在是一块**看得见的面**（玻璃 + 1px 边环 + 折角 + 深色名牌底片 + 晶柱）；这一支把面整块删掉，只剩一片没有边界的中性雾，字直接落在页面上，她的颜色只剩线头、句尾碎屑与名牌那一枚空心菱。

**附带**：`c-shot.cjs` 是 `shot.cjs` 的副本（原文件没动）。原版量 `.ave` 包围盒时偶尔会量到整页（1418×842），2× 放大图就成了整屏；我加了「量到稳定且小于视口」的重试，另多一个 `--only <帧名>`。
