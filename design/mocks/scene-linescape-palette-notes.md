# 原型 · linescape 首屏配色（/mock/scene-linescape-palette/）

以 linescape v=a（线圈 + 光 + 圆的回声圈）为底，做三套整体配色，`?pal=1/2/3` 切换，`?pal=0`（默认）为现状对照。
页面固定 `v=a`，可叠 `&pins=1`。原 `/mock/scene-linescape/` 与共享文件都没动。

| 用途 | 路径 |

| 页面 | `src/pages/mock/scene-linescape-palette.astro` |

## 做法（三层，都不增加逐帧开销）

1. **天空层 `.ls-sky`**（新增，z −4：在全站洗染之上、雾 / 光 / 地形之下）：一张静止渐变，醒梦两张按 `--reality-mix` 交叉淡化（只动 opacity）。
   - 主渐变方向 194° ＝ 地平线法向，色带与地平线平行：天顶 → 天空 → **地平线雾带（最亮）** → 近地 → 画面下沿。
   - 一枚径向光落在圆那一侧（右）：空气透视 —— 离光近的一侧更白、带一点方案的异质色。
   - 整层按 `--sky` 淡出（脚本只在滚动时写，第 0 幕 pos 0.25→0.85），交给 `--bg`。
2. **地形 Worker 的线色**：`init` 消息新增可选 `pal`（近 / 远 / 光 / 梦面倒影，醒梦两端各一组），Worker 按梦度 `d` 插值；没有 `pal` 时照旧读全站强调色。
3. **第 0 幕色板起点**：方案替换 `PALETTE[0]`（`--bg / --fg / --fg-soft / --glow`），从它插值到第 1 幕现有色板 —— 不改第 1 幕之后的任何一档。
   问句、等高线标注、测量点的色用 `html[data-pal]` 的 CSS 变量，以 `color-mix(… var(--reality-mix) …)` 跟醒梦走。

## 三套方案

### ① 雾蓝晨前（`?pal=1`）—— 冷、空气感强；异质色淡金只给光

理由：蓝＝距离 / 清醒，用在天顶与远线上，地平线处褪成近白的雾；醒面唯一的暖是圆里那团淡金，像天亮前从地平线下渗上来的光。梦面不走粉：天顶仍是冷的远，地面换成暖沙，光变成更浓的金 —— 「同一片天，地变暖了」。金与全站唯一强调色琥珀同族，全站那条线在梦面是琥珀 / 赭，正好合拍。

### ② 灰粉梦温（`?pal=2`）—— 暖灰底，粉在雾里；异质色极浅紫

## 迭代

- **r1**：三套都成立，但 ① `23:07` 标注的托底用的是 `--bg`，在天空层上露出一块异色的圆斑；② 梦面倒影段（地形线穿过倒影环带的那几小截）在 ②③ 里是饱和的紫 / 绿，读成故障；③ 方案 1 的梦面成了「蓝天粉地」，与方案 2 太近。
- **r2**：托底改用天空在地平线处的雾带色（`--ls-hz`）；倒影色降饱和、贴近远线；方案 1 梦面地面改暖沙、近线改暖墨，光留金 —— 与方案 2 拉开。

## 已知问题

- **全站那条线（Eeg，地平线）不跟方案走**：它的色来自全站强调色（梦面是赭 / 琥珀的台阶线 + 一根琥珀细线）。在 ① 里正好同族；在 ②③ 的梦面略显突兀（紫 / 绿的世界里一根赭线）。要跟方案走得改共享的 Eeg / reality 色，原型里没动。
- 测量点小窗（`.pw`）的底色仍是原来的白 / 淡粉，没随方案细调。
- 动态（交叉淡化时的过程、圆光入场）只看了静帧。
- 顺手修了副本 Worker 里一个越界：倒影内环半径在极小视口（截图裁切时会触发）下变负、`Path2D.ellipse` 抛 `IndexSizeError`；已加下限。**原 `scene-linescape-worker.ts` 里同一行未修**（`reflBand.ellipse(rx, ry, ex - 4.5, ey - 2.6, …)`）。

## 推荐

**① 雾蓝晨前。** 醒梦分工最清楚（蓝＝远与清醒，金＝光与梦），梦面不靠粉、靠「地变暖、光变浓」，避开了蓝粉渐变的俗套；金与全站唯一强调色琥珀同族，全站那条线、测量点、倒影都不打架；第 1 幕本身是冷蓝，交接最顺。
③ 记忆点最强、最「留白」，适合想要更有辨识度时作备选，但要接受一种新的异质色（冷绿）进入全站色彩体系，并处理梦面那根赭色地平线。
