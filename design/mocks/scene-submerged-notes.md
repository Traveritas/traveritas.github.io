# 场景原型 · submerged（没入 / 水面）

- 页面：`/mock/scene-submerged/`（`src/pages/mock/scene-submerged.astro`），只重做场 0，其余四幕同 `/new/`
- 脚本：`src/scripts/proto/scene-submerged.ts`（复制自 `proto/hero-quiet.ts`）
- 截图 / 测量：`node design/mocks/.shot-scene-submerged.cjs <tag> [--compare]`，输出 `design/mocks/_shots-scene/submerged-*.png`
- 参考：`design/index-shots/p5-submerged.jpg`（取其气质：浅青灰水体、光柱、悬垂的半透明板、水中立柱；不取其文案）

## 思路

那根线是一道水面。开屏姿态从 14° 斜线改为一条水平线（高 `--wl-css`：桌面 46svh、窄屏 42svh），脑电线的起伏就是水面的微澜。

- **水上（留白）**：雾、极淡的天光（右上方落下）、两团贴水漂移的水汽；问句在中栏左沿，底边离水面一个 `--gap`。
- **水下（世界）**：上浅下深的浅青灰水体；四道斜射光柱；三块不规则的半透明板（近 / 中 / 远，越远越淡、越糊）；六根深处的细立柱；几粒上浮的微光；贴水面一窄条亮与疏密不匀的水纹。
- **知觉悖论**：问句在水下有一道倒影，倒影里「成形」与「融化」换了位置。不点破，倒影本来就难读，留给看得仔细的人。
- **小注**：醒（06:31）在水上、梦（23:07）在水下，同一条竖线上，像彼此的倒影；当前所在的一面那个字是实的。
- **滚动**：场 0 进度 0.08→0.38 时水面上漫 0.14 屏（线与水体同一个公式），0.22→0.42 水层淡出，线随后交给第 1 幕的竖线。

## 双态

- 醒面：冷青灰的水、白光柱、冷白天光。
- 梦面：水换成灰粉到淡紫（`w-dream` 叠层，opacity 跟 `--reality-mix`），光柱染一点暖白、整体压暗 28%，天光偏暖。

## 层次与性能

| 层 | 内容 | 动不动 |
|---|---|---|
| `.sea`（fixed，z −3，在脑电线之下） | 天光 / 水体 / 水纹 / 立柱 | 静态；滚动时整块 `translateY(-rise)`（`will-change: transform`） |
| 光柱 ×4 | 渐变 + 静态横向 mask | `opacity` + `transform` 动画，13–17s |
| 悬板 ×3 | 内联 SVG（远处两块的模糊在 SVG 内，只栅格化一次） | `transform` 起伏，19–27s |
| 微光 ×6、水汽 ×2、倒影 | — | `transform` / `opacity` 动画 |
| 文字（舞台内，线之上） | 问句、小注、序号、元信息 | 入场一次性 CSS |

- 不改 clip-path / mask / filter；无 backdrop-filter；静置时没有 rAF。
- 脚本只在滚动 / 尺寸变化时写 `--s0`、`--rise` 和 `html.sea-off`（场 0 离场后整层 `visibility:hidden` 并暂停动画）。
- 减动效：水里所有动画关闭，倒影直接显示，画面为静帧。

**实测**（dev server，1440×900，醒面，入场结束后静置 3 秒，CDP Performance.getMetrics 差值）：

| 页面 | 样式重算 | 重算耗时 | 布局 | 脚本 | 主线程任务 |
|---|---|---|---|---|---|
| `/mock/scene-submerged/` | 0 | 0ms | 0 | 0.2ms | 6.3ms |
| `/new/` | 90 | 47.9ms | 0 | 41.2ms | 260.5ms |

GPU 合成开销没有单独测量（约 16 个小合成层在动）。

## 已知问题

- 梦面的脑电线是全站的梦态画法（阶梯状多股线），压在水面上不像水面，像一道刻度。要么场 0 让线在梦面也保持平滑，要么接受。
- 水面上漫只有 0.14 屏，「没入」的感觉偏弱；加大需要同步调交接时序。
- 交接中段（场 0 进度 ~0.5–0.9）水已淡尽、线还在转向，画面只剩一根斜线，与 quiet 原型相同。
- 窄屏页头导航被挤成竖排，是共享页头的问题（`/new/` 同样）。
- 未跑 `npm run build`（按约定由主会话统一构建）；`tsc` 对本原型无报错。
