# below · 检索页再往下（2026-11-03）

不沿用 `somewhere/` 的 shell / shell2 / room 底子（用户：之前的尝试都不好）。只保留流光着色器（`light.js` 是 `src/scripts/wander/light.js` 的原样副本），因为转场必须从检索页本身开始。

运行：`node design/mocks/somewhere/server.cjs` → http://localhost:4640/below/
截图：`node design/mocks/below/shot.cjs "resin.html?at=1" tag "2000"`（`SHOT_W/SHOT_H`、`RM=1` 可选）

## 一 · 底下（under）

- CSS 3D：玻璃板 = 检索页的 DOM 原物（流光 canvas + 栏头 + 卡片），地面 = 2D canvas，每帧自算相机给 matrix3d。
- 起点与检索页逐像素一致（相机在 P·K 高处正俯视）；俯身越来越快 → 穿过那一下只剩糊开的三色光（haze）→ 底下抬头。
- 头顶：那一页的背面，磨砂、字是反的；地面：光透下来（同一张流光糊开），卡片与字投下影子，影子是正的。
- 弱点：终点构图偏闷——玻璃与地面中间是一条暗带；低头看地那一刻偏暗（瞬间 / 项目两栏本来就暗，透下来的光也暗）。

## 二 · 树脂（resin）

- 着色器时间逐渐停住；三栏色借着色器的醒/梦混合槽（WAKE 填成树脂色）并成一种色。
- 两条分界 = 过原来眼睛的平面，正对着看恰好是检索页上那两条线；镜头一离开就露成薄膜，原分界留成膜上一道亮线。
- 卡片与栏头在凝住前各自沉、偏一点，停在不同深度；气泡按各自时刻析出。
- 静止的流光天然满足 reduced-motion（somewhere 那一轮遗留的无障碍问题在这里不存在）。
- 弱点：窄屏仍用竖分界（线上窄屏是横分界，没做）；卡片在右侧偏挤；还没有任何小交互。

## 三 · 院落（court）— 用户选了「能放东西」的 A 方向，天改成纯色流光

- 转场：起点 = 抬头看着检索页（三栏 + 卡片）；颜色借着色器醒/梦混合槽并成一种天色，卡片往上飘走；低下头（pitch 90° → 0），院墙从画面下沿升起。
- 院子：方格上的 5 间房（`ROOMS`），墙长在「两边不是同一间」的格线上，门洞在 `DOORS` 里留空、上面压一道门楣；墙头一道压顶。加一间院子 = `ROOMS` 加一行 + `DOORS` 加一个门。
- 水：半透明水面 + 水下整组倒置的墙与东西（`mirrorRoot.scale.y = -1`），天的倒影就是透过水看到的那片流光（流光没有上下方向，正反看不出来）。涟漪在水面着色器里（脚步、NPC、球、点击都会起）。
- 东西：`THINGS` 注册表，一样一行：`build() → { obj, hits, update, click }`，倒影自动生成。现有三个占位：北院会走会停下说话的（点它换一句）、东院的球（走过去碰开、点它踢、撞墙反弹）、最里间的一件东西（点它转快一下）。西院空着。
- `?sky=day` 白天版（随笔那一栏的浅色做天）。`?pos=x,z,yaw` `?pitch=` 截图定位。
- 两个 WebGL context（流光 + Three）；正式落地可以把流光改成 Three 里的一张全屏底片。
- 未做：墙面细节（只有明暗与压顶）、东西都是占位造型、移动端只放宽了视角。

## 四 · 院落 II（court2）— 点击式 + 窗式墙面

用户要求：点击式（每间四面，点左右换面，视角随鼠标动，点上方回到正常页）；墙不要像普通 3D 迷宫。

- 导航：`standAt(room, face)`——看哪一面就退到这间靠另一头的地方，隔着整间院子看过去；转身时位置与朝向一起过渡。
  点击优先级：东西 > 上方 16%（回到检索）> 正对墙上的门洞（投影出屏幕矩形）> 两侧 22%（转身）。
  键盘 ← → 转身、↑ 穿正前方的门、Esc / PageUp / 滚轮往上 回到检索；在检索页滚轮往下 / ↓ / 上划 进来。
  转场可来回：`arrive` 朝 `want` 走，进出用同一组曲线（回去时颜色重新分栏、卡片原路落回）。
- 墙：不打光。片元按屏幕坐标取 #light 那张画布（CanvasTexture，Nearest），放大 0.56 倍取样（像素格变粗），
  亮度经 `uLum` 映射到一套浅色（`lo → hi`）；面与面只差 ×0.9 / ×1.1；外加 EdgesGeometry 细轮廓。
  效果：流光连贯地流过几面墙，墙读成「窗」而不是「体积」；夜里那片光暗时墙也跟着暗。`?wall=plain` 对照。
- 院子放大（14×13 起），墙压低，站定时视线上抬约 6°，保证天始终占画面上部。
- 交互用 `CLICKS` 实测过：转身、穿门（落脚院 → 东院）、点上方回到检索，均正常、控制台干净。
- 未做：门洞悬停只有「过去」小签；东西还是占位造型；转身/穿门的时长在慢机器上会被拖长（按帧时钟）。

## 五 · 界（bound）— 不是墙还能是什么

用户：court2 的窗式墙「只是加了一个叠层」。原因：按屏幕坐标取样，图案不贴在墙上，转身时墙动图案不动 → 读成蒙在上面的一层膜。
结论：以后材质一律贴在物体本身上。天也改为 Three 场景的背景贴图（同一个场景，玻璃能透过它、水能倒映它）。

三张对照（同一片天、同一组占位东西）：
- **磨砂玻璃**（`?kind=glass`）：玻璃从远到近逐片烘焙——每片取「它身后（含更远玻璃）」的画面、四分之一分辨率高斯两趟。
  隔一层是影子，隔两三层只剩一点光，没隔的清楚。最成立，白天版最好。已知：玻璃后东西的倒影没被玻璃倒影磨糊。
- **光幕**（`?kind=light`）：竖直平面 + 往下淌的 fbm 条纹，叠加混合，上沿融进天。氛围最强，但条纹偏密，白天偏曝。
- **方台**（`?kind=isles`）：最普通，读成一堆 3D 方块；侧面有层叠纹。

## 六 · 会翻的房间（tumble）— 用户要「无厘头但很哇塞」

- 立方体房间（边长 7m）绕视线方向翻；人与重力不动。点左右 = 整间房翻 90°（不是转身）。
- 散着的东西在房间坐标里算物理：只把重力转进房间坐标，它们就自己滑、滚、落到新地上；球有浮力。
- 水：水面永远水平；每帧按二维截面面积守恒（正方形 ∩ 半平面，二分求水位）重新求水位；房间角加速度踢一下晃荡弹簧；
  六个面做裁切平面。水线（水面与四壁相交的一圈）是让人看得出「有水」的关键。
- 长在某一面的东西是房间子节点：右墙上住着的那位（翻时晃、嘟囔；右墙做地时「终于站正了」）、天花板上倒挂的那件。
  左墙有圆洞：翻到底下时，脚下的水里透出外面的天。背墙一扇圆窗。
- 进来：卡片往上飘走，房间从天上落下扣住你（落地时水晃一下）；点上方 / Esc / 滚轮往上：房间升回去，回到检索。
- 默认夜里（白天偏白偏平）。真实点击测过：右翻、左翻、台词、东西滚落，控制台干净。`?flips=1,-1` 自动翻。

## 七 · 零件巨构（giant，静态）

- 卡片 = 楼（canvas 画卡面，空白处一排排极淡的窗格）、栏头 = 悬空招牌、六芒星 = 天上慢转的星形、鼠标指针 = 远处的灯塔，倒映在浅水里。
- 只验证「尺度荒唐」成不成立；没有交互。指针灯塔的朝向还要调（现在侧面对人，读不出是指针）。

## 体验小样（2026-11-04）— 用户：要的不是「有什么东西」，是「有什么体验」

方向转了：不再造空间，而是换掉「往下滚」这个动作的意思。共用 `scrub.js`：第一屏是检索页，往下滚它像普通网页一样被推上去，
下一屏接上来；再往下，滚动交给体验（`depth`）。`?p=` 定位截图；`x.css` 共用样式。

- **时间摊开**（x-slit）：slit-scan——每一处的时刻 = 此刻 + 沿某方向的距离 × 摊开长度。六芒星、绕圈的光点、摆线、走过的人都被摊弯。
  四个里画面最新、最「哇」。鼠标左右改方向、上下改长度，形状实时重扭。
- **切面**（x-slice）：三维噪声在 z 处的切片做底，SDF 物体只画截面轮廓 + 下一层 0.45 处的淡预影。右侧「深」读数。
  拧方柱（转动的方块）和弹簧（绕圈的点）最好读；物体之间留了空。
- **钻进一个像素**（x-pixel）：粗细两层、9×9 嵌套、f 绕回时细层变粗层；每格值 = 0.55·父格 + 0.45·自己。每三层藏一个 9×9 位图（小人 / 六芒星）。
- **闭上眼睛**（x-dark）：五个 WebAudio 合成声源（嗡、叮、水、哼、颤音），鼠标距离控制音量与声像，近处浮出对应轮廓。
  声音只能人工听，截图只验证了画面。

## 时间摊开 · 纸片（x-flat）— 用户要放的是平面的东西（类似 ENA 里那种平面物件），不一定是 3D

- 东西 = 一张平面图（`src` 给 PNG/SVG，或 `draw()` 用代码画）。注册表 `THINGS` 一行：图、宽高比、`from/to` 出现的时间段、`at(t)` 动法、`say` 台词。
- 运动在载入时按 4096 个时刻烘成 RGBA32F 数据贴图；着色器按每个像素自己的时刻 texelFetch（两帧线性插值），所以任何 JS 写的动法都能被摊开。
  纸片全部进一张图集。最多 8 样（`MAXI`，可调）。
- 按住：指针周围 `exp(-d²/0.045)` 范围内时间合拢到「此刻」，纸片恢复原形；轻点（<260ms）：在「此刻」做一次命中测试，说一句。
- 占位纸片（平涂 + 墨线 + 错开纸影）：走来走去的纸人、转着的六芒星、冒热气的杯子、一张「碎碎念」卡片、游过的鱼。台词都是占位。
- 实测：多样纸片同屏被摊开、按住合拢、轻点星星出气泡，控制台干净。
