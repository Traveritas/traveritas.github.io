# 磨砂玻璃棱面 · a-frosted-facet

## 一句话

每枚图标是一小块**被光照着的磨砂实体**：由两到四个棱面拼成一个简单几何体，靠**接缝里漏出来的一线光**、下缘的一薄条虹彩、和底下的一小片影，交代「它是一块东西，而且光从它里面过」。

## 形的来处

统一光向：光从左上略偏前来。于是每个面的明度有固定次序——朝上的面最亮（`--g0`），朝左的次亮（`--g1`），朝右的偏深（`--g2`），背光与腔体最深（`--g3`）。整套共用四级明度，所以十枚摆在一起像同一批材料做的。

| # | 图标 | 形从哪来 | 层次怎么做的 |
|---|------|----------|--------------|
| 1 | 站点标记 | 一片**立着的棱面**，底部削平当脚，所以它能站住 | 被 14° 的缝斜分成两半（左醒右梦），右片向右上错开 0.9 单位，缝里垫一条白色渐变；顶端一小块斜切棱面，底脚一道倒角暗带 |
| 2 | 主页 | 一块**悬浮的板**，上面立着一片微倾 14° 的棱面 | 板分顶面 / 左厚 / 右厚三层；板的前缘漏一条光；棱面自己再分正面、侧厚、顶面，中间一道内反射亮带 |
| 3 | 随笔 · 断章 | **三片叠着的薄棱面**，一片比一片往右上挪，最上一片滑开并缺了一角 | 三片之间各留 1 单位空隙，缝里各透一条亮线；三片明度依次是 g3 / g2 / g1，越上越亮 |
| 4 | 瞬间 · 闪念 | 一枚**实心的四角棱体**（不是线稿星形），右下角留一枚刚脱开的小碎屑 | 星体按四个象限切成四个面，左上最亮右下最深；中心一枚内芯的微光 |
| 5 | 项目 · 造物 | **等轴棱块**，顶面正被放上去——浮起 3.2 单位、偏转 9° | 顶面 / 左面 / 右面 / 腔体四级明度；腔体内壁透出一条光，说明顶盖还没合上 |
| 6 | NEXUS | 两片立着的棱面夹一道楣，构成一个 **Π 形的门** | 门里不是空的：一整条透射光带 + 一条地平线，读作「门后面有远处」；门里浮着一枚小棱面当交汇点；门槛外溢一条光 |
| 7 | 寻找 | 一片**被磨出棱面的镜片** + 短三棱柱的柄 | 镜片被 14° 的缝分成上下两半，下缘再削一道月牙倒角；柄的左上沿一条亮棱、右下沿一条暗棱；镜片里嵌着一枚小碎屑（在找的那个小东西） |
| 8 | 换面 | 一片**棱面圆盘被 14° 的缝分成两半，两半沿缝的法线错开** | 缝里一条亮带；上半用 `--gu`、下半用 `--gl`——**同一枚里就带着醒与梦两种温度**；梦态缝张得更开 |
| 9 | 环境声 | 一圈**棱面环**（环是站点母题之一），环里立着三根小柱 | 环被 14° 的缝切成上下两段；柱的底端被环的内壁盖住，读作嵌在里面 |
| 10 | 本页 · 目录 | 一根**立着的棱柱轨**，左侧一道进度亮带，右侧三个嵌进去的节点 | 轨分正面 / 右厚 / 顶面；进度亮带停在中间节点的高度；当前节点比另外两个大一圈，并垫一枚内芯微光 |

## 醒 / 梦差在哪

**形一个像素都没动。** 差的全在材质与光：

| | 醒 | 梦 |
|---|---|---|
| 色 | 冷灰四级 `#dfe8f0 → #8292a3`，像一块被磨平的窗玻璃 | 薄暮紫 `#eee7f8 → #8a79b0` |
| 边线 | `--ink:#5f6d7c`，缝的描边 48% | `--ink:#6b5d92`，描边 42% |
| 虹彩 | 16% | 34%（更上浮） |
| 内芯 | 50% | 62% |
| 轮廓 | 只有磨砂颗粒 | 颗粒之上再叠一层很慢的位移（`feDisplacementMap`，scale 0.55），边缘像在化开 |
| 换面的缝 | 1.15 单位 | 1.75 单位 |

两态共用同一个 `--reality-mix` 的思路：醒梦不是两枚图标，是一枚图标的两组变量。整套色板只有 8 个变量（`--g0..--g3 / --ink / --gu / --gl`）+ 5 个强度变量（`--hl / --irid / --core / --trail / --sh`），换态就是换这些值。

## 16px 与单色下退化成什么

**16px（本套的实测做法：关掉颗粒）**

- `--frost-f:none`，同时 `--sw` 从 0.5 加重到 0.8、缝的描边从 44% 收到 34%。
- 结论：**形和「光从缝里漏出来」这一条活下来，磨砂颗粒与虹彩全部丢**。
- 十枚里九枚在 16px 仍能认出来（标记、瞬间、项目、NEXUS、寻找、换面最稳）。**唯一一枚层次全失的是「随笔」**：三片薄棱面在 16px 会并成一条斜条，片间缝与缺口都看不见，只剩「一叠东西」的语义。这是这套风格在 16px 上最大的隐患，也是唯一一处我认为需要另画小尺寸变体的地方。
- 第二处隐患是「本页」：三个节点在 16px 各只有 1.3px，会糊成轨上的一排虚点。
- 反过来，**颗粒在 16px 是负资产**：噪声周期已经细到亚像素，只会把棱面的分界糊掉，还让图标看着脏。所以建议是 **32px 以上才开颗粒，24 / 16px 一律关**。

**单色（`currentColor`）**

- 不是把颜色抽掉，而是把色板换成**一种墨 + 四个明度台阶**（`fill-opacity` 34% / 52% / 72% / 100%）。
- 棱面的分界靠台阶活下来；透射光、虹彩、内芯、颗粒、小碎屑全部归零（`--hl/--irid/--core/--trail` = 0）。
- 最妙的一点：**接缝错开的那道缝露出来的是底色，所以它不需要任何颜色也自己会亮**——「换面」的上下两半在单色下仍能分开，靠的就是那道缝。整套在 32px 单色下十枚都还认得出（见 sheet 第 04 段）。
- 唯一在单色下变弱的是「换面」的上下温度差：`--gu` 与 `--gl` 都成了同一种墨，只剩错开的缝在说话。可以接受。

## 小巧思

1. **接缝即身份。** 站点有一条 14° 的发丝线（`--seam-angle`）。这套里 14° 不是装饰：标记、寻找、换面、环境声四枚的**结构线本身就是 14°**——标记与寻找是「被 14° 的缝分成两半」，换面是「两半沿 14° 的法线错开」，环境声是「环被 14° 切开」。所以这组图标放大看，和站上那条发丝线是同一个角度。
2. **光从缝里漏出来，而不是画在表面上。** 每处「亮线」都垫在形体底下，靠两片棱面错开 0.5–0.9 单位露出一点点。白线在昼底几乎不显（缝里本来就是亮的），在夜底才发光——同一条线在两个底上各自成立。
3. **换面自带两种温度。** 这枚图标里，上半永远偏冷（`--gu`）、下半永远偏暖（`--gl`），连醒态也是。它自己就是那道缝。
4. **梦态的「化开」不是模糊，是位移。** 用的是低频 `feTurbulence` + `feDisplacementMap`（scale 0.55），轮廓会不规则地起伏——不是变糊，是边缘在轻微地游移。
5. **底下的影离形体 0.8 单位。** 它浮着，但不悬空。

## 风险 / 不确定

- **颗粒是分辨率绑定的。** 噪声定义在图标自身的用户单位里（`baseFrequency 2.2` / 32 单位），所以它会随图标一起缩放：160px 时约 2.3px 一个噪点，64px 时约 0.9px，16px 时 0.23px（亚像素，必关）。也就是说**这套的「磨砂」在手写 SVG 里没法自适应，必须由组件按尺寸切 `--frost-f`**。高 DPI 下颗粒会更细、更接近真实磨砂，这是好事。
- **滤镜开销。** 每枚图标一个 `feTurbulence`，一页几十枚图标（比如全站工具栏 + 目录）会持续重绘。落进站点前建议：①小尺寸一律关；②大尺寸静态图标可以预渲染成一张 PNG 雪碧图。
- **轮廓描边在 160px 略重。** 为了让 16px 站得住，我把描边加到 0.8（小尺寸）；大尺寸保持 0.5。放大看会觉得轮廓偏「清楚」，不太像磨砂。可以按尺寸调 `--sw`，但别调到 0——一调到 0，16px 就散了。
- **「主页」与「本页」的辨识度最弱。** 主页是「一块板 + 一片立着的棱面」，语义要靠站点的世界观（归处 = 平台）来补；本页是「轨 + 三个节点」，在 16px 只剩一条带点的竖条。这两枚我建议在真稿里再收一轮，或者给它们换更明确的现实物（比如主页用一扇独立立着的门、本页用一叠错开的薄片）。
- **「环境声」的三根柱**在 24px 以下会连成一团，读起来像「音量旋钮」。若这枚最终要常用，建议改成环里一枚小碎屑 + 两道弧。
- **换面的呼吸是可选层**，7.2s 一个来回，`--split` 在 1.45 ↔ 2.15 之间。它需要 `@property` 注册才能平滑插值（不支持的浏览器会跳变，但不会坏）。sheet 里那一格是 `animation-play-state:paused` + 负延迟定格的，不是实时动画。
- **没有做的事**：没有做 hover / 焦点态，没有做禁用态，也没有把图标真的接进 Toolstar / Gauge。这套只回答「手感」。


- `shots/sheet.png` —— 整页（1200×3610 @2x），页面无报错、无横向溢出。
- `shots/contact.png` —— 首屏（1200×900 @2x），触点图那一屏。
- 自检看过：触点图 64px 醒/梦对照、24px 与 16px 四个底、160px 手感放大、16px 加粒/去粒的像素检视、单色三排、两格语境、换面呼吸定格。修过的问题：磨砂滤镜的噪声原来溢出到形体之外（`feBlend` 在透明底上会漏出噪声，补了 `feComposite operator="in" in2="SourceAlpha"`）、颗粒原来过粗（`baseFrequency 1.1/2 octaves` → `2.2/1`）、醒面色板原来在昼底对比不足、本页原来是一根斜的细轨（读起来像刀）。
