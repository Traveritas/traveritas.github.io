# 图标风格 mockup · 共用简报

给并行子智能体的统一上下文。**每一批三个风格方向，各写各的，互不参照。**
不要去看 `design/mocks/` 下的任何既有图标 / 光标 / hero 稿（会互相污染），只读本简报点名的三份源文件。

---

## 1. 站点基调（必读源文件）

- `docs/design/aesthetic-direction.md` —— 《醒梦》审美方向，最重要的一份。
- `src/styles/tokens.css` —— 设计令牌（颜色、字体、14° 发丝线、醒梦总闸）。
- `AGENTS.md` —— 文风与工程红线。

气质：神秘 / 朦胧 / 安静 / 磨砂玻璃 / 半透明树脂 / 大面积留白 / 低饱和微温。
材质：磨砂玻璃 + 半透明树脂 + 柔和哑光。禁止铁锈、裂纹、污泥、重工业、密集机械细节。
颜色分工：**蓝 = 距离 / 空间 / 清醒；粉 = 温度 / 梦 / 记忆；黑白灰 = 结构 / 秩序**。
少量克制的异质色（淡金、极浅紫、冷绿）作记忆点。不能所有东西都是蓝粉渐变。

**红线（违反即废稿）**：严禁针 / 缝 / 穿针 / 针脚 / 起针 / 落针等裁缝语汇；严禁"这是梦 / 你在做梦 / 快醒了"这类出戏标签；严禁账目 / 台账 / 案号 / 可核验等审计黑话；严禁"白昼写代码夜里构筑世界"式中二极客梗。

## 2. 要设计什么

网站的**图标**。同一套风格下画下面这一组（核心 8 枚，另可自行加 1–2 枚小巧思）：

| # | 名称 | 用途 | 梦态名（可作命名灵感） |
|---|------|------|------------------------|
| 1 | 站点标记 | 站标 / favicon，也当 OG 小图 | — |
| 2 | 主页 | 回主页 | — |
| 3 | 随笔 | 文章索引 | 断章 |
| 4 | 瞬间 | 短记 / 闪念 | 闪念 |
| 5 | 项目 | 作品 | 造物 |
| 6 | NEXUS | /gate 那一处 | — |
| 7 | 寻找 | 检索 | — |
| 8 | 换面 | 醒 ⇄ 梦 切换 | — |

可选加：环境声、设置、本页（目录）、去处（外链）。

**硬性要求**

1. **每枚都要有醒 / 梦两个变体**。站点有个全局量 `--reality-mix`（1 = 醒，0 = 梦），醒面冷灰克制、梦面薄暮浮起。两个变体要能一眼看出是一枚图标的两种状态，而不是两枚不同的图标。
2. **16px 下要立得住**。整组必须给出一排 16px 的小样；小尺寸糊成一团的方案直接改。
3. **单色可退**。至少说明这套在只有一种墨色（`currentColor`）时还成不成立、退化成什么。全站图标最终多半要跟 `currentColor` 走。
4. **矢量 / 无外部资源**。成品要能落成内联 SVG。栅格纹理可以用，但要说清它在 16px 与高 DPI 下怎么活。
5. 不要求动效，但如果你给某个变体加了一点克制的动效（呼吸、缓慢自转、微光扫过），要在 notes 里说清触发条件与时长。

## 3. 交付物（每套风格一个目录）

```
design/mocks/icons/batch-01/<你的 slug>/
  index.html   自包含单页：内联 SVG + CSS，无外部资源、无构建步骤。双击能开。
  notes.md     设计说明（见下）
  shots/       你自己跑出来的截图
```

`index.html` 里至少要有这几段（版面顺序随你）：

- **触点图**：8 枚在 64px 上排开，醒 / 梦两列并排对照。
- **小样**：同一组在 24px、16px 各一排，背景分别是昼面 `#f0f3f6` 与夜间深底。
- **材质 / 放大细节**：挑 1–2 枚放大到 160px 左右，把你这套风格的"手感"交代清楚。
- **单色退让**：整组用单一 `currentColor` 再排一遍，看还认不认得出。
- **一格语境**（可选，很加分）：把图标放进真实的界面位置看一眼——比如贴在站点左下角那颗星旁边、或贴在一条 14° 发丝线上。

`notes.md` 写清：

- 风格一句话（这套风格的内核是什么）。
- 每枚图标的形从哪来、为什么这么画。
- 醒 / 梦两态在你这套风格里差在哪（色、材质、光、还是形态本身）。
- 在 16px 与单色下会退化成什么。
- 有没有"小巧思"（一个别人不会想到、但很贴站点的细节）。
- 风险 / 你不确定的地方。

## 4. 截图

统一用这支脚本（puppeteer-core + 本机 Chrome，已经能用）：

```bash
node design/mocks/icons/.shot.cjs design/mocks/icons/batch-01/<slug>/index.html design/mocks/icons/batch-01/<slug>/shots/sheet.png 1200 1400
```

参数：`<html> <out.png> [宽] [高] [--full]`。`--full` 截整页。脚本会等字体与首帧稳定。
**每套至少跑一次截图，自己看过 PNG 再交**（看有没有溢出、糊掉、颜色跑偏）。notes 里写下你实际跑的命令。

## 5. 自由度的边界

风格方向由你收到的任务描述给定，**其余全放开**：构图、材质做法、命名、是否加动效、是否引入一个自创的视觉母题，都随你。
鼓励"小巧思"——一个克制但让人记住的细节，胜过十处平均用力的装饰。
但**不要**为了炫技把图标做复杂：图标要在 16px 里被认出来。
