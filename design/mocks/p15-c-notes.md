# p15-c 磨砂晶面与光折（Frosted Prisms）· 自验收笔记

**主张**：正文与底色之间常驻两片超大圆角晶面（互相重叠）；两态的差别不是「有玻璃 / 没有玻璃」，而是**同一组几何被两种方式读出**——醒态它退成 1px 边界线＋四角标记＋重叠处的分界线（静止、可读、不隐身），梦态同一组线变成 1px 亮边＋沿边折光带，晶面之间填进磨砂板面，并且 14° 缝线在晶面内部**多出一段被平移的延续**（光折段＋阶跃记）。

**醒**：`.p-edge/.p-body/.p-ray` 的强度全部 ×`--still`（opacity/transform，非 display:none），`--still=0` 时只剩 `.p-plate` 的 `inset 0 0 0 1px`（`--fg` 16%）＋四角标记（`--fg` 21%）＋重叠区两条 14° 斜记（27%）。零动画（animation 声明挂在 `body[data-reality='dream']` 上，醒态连声明都没有）。版心内平均新增 ΔL = 0.0%。

**梦**：① 磨砂体＝`color-mix(--ghost-ink/--umber/--amber …)` 的三停渐变（**不是柔光带，是有边界的板**，版心内平均 +1.7%）；② 1px 亮边（`--amber` 32%）＋2px 环（8%）＋沿边折光带（宽 4px、22%，19s 换挡）＋对侧 5px 暗带（`--umber` 20%）——色相由外壳逐帧插值的 `--amber` 连续转暖；③ 时间：13s、六拍 `steps(1,end)`，姿势全部是**沿 14° 轴的整像素**平移（0,0 → 4,1 → 8,2 → 4,1 → −4,−1 → 0,0）。沿轴平移不动法线距离，因此光折段的对齐不会被它破坏；④ 重叠区（218×531，整块在右栏）多一层 `--amber` 8% 的色阶＋自己的一条分界线（21s 整像素阶跃）。
**光折段**：在「原点＝视口中心、旋转 14°」的坐标系里画一条水平线就是缝线本身，把它沿局部 y 平移 9px 再被晶面 `overflow` 裁掉，就是它的折射延续段——角、平行、与边界的交点全是构造出来的；阶跃记（3px 宽、长 9px、垂直于缝线）两端正好落在真实缝线与光折段上。

**与上一轮 P14-C 的差别**（上一轮被裁定"最安全但最弱"）：p14-c 醒态整层撤回（全幅平均 ΔL=0.0000），两态差＝有柔光带／没有，与站点已有的 7% `--wash` 同类。本稿多做了四件事：① 醒态给出**自己的、静止的、可读的几何**（6 条边界＋4 组角标＋2 条斜记＋重叠窗，页边处 50–62% 墨色差）；② 引入新语法「光折段」——不是折光模糊，而是同一束光在玻璃里被平移的那一段；③ 重叠区有第三处理（更实＋分界）；④ 梦态位移**只沿缝线方向**，所以①②③在动的时候仍然对得上。

**实测**（1440×900，`?freeze=1&ui=0`，滚到 `#ns-essays`，逐像素 on−off 差 ÷ 相邻墨色亮度差；口径与 p14-c 一致）

**最不放心的**
1. 醒态几何压在 16% 墨色（与站点既有 `--line` 发丝同级）：这是为了守住 35% 红线留的余量，代价是"看得见"这一侧不宽裕。若判读认为仍偏静，第一顺位是把边界提到 22%（版心内约 28%），而不是加动画。
2. 版心内的强调层靠 mask 降到 18%：乙的顶边表现为"暖色带在正文列上方变淡"。我读作"玻璃让位给文字"，但这是本稿最主观的一处（见 `extra/m-deep-dream-on/off.png` 与 02 的中段）。
3. 共用脚本的 09 机位是固定的文档坐标 (430,250)，落在首屏，拍不到右栏的几何；细节证据我另出了 3×/6× 裁片（`extra/crop-*`），其中 `crop-jog-B-6x`（梦）与 `crop-jog-B-6x-wake`（醒）是同机位的两态对照，光折段的出现／消失可以逐像素看。
4. 长按的第二、第三次按压会被外壳 `latch()` 未复位 `src` 吃掉（线上 `src/scripts/reality.ts:396` 有复位）——外壳的转录疏漏，四稿共用，本稿不碰外壳；因此交互验证每次按压都新开一页。
5. ≤720px：甲移到右半幅、强调层加右侧遮罩，窄屏退化成"一块磨砂板＋一条横线＋一条光折段"，两态仍可分但不如桌面（见 10-mobile）；且重叠区／角标全在右栏，这依赖版心 42rem 居中的前提。
6. 光折段与脑电发丝在空间上相邻（脑电摆幅 ±5px），9px 是刻意避开它的取值；若线上脑电振幅改了，这个数要重算。
