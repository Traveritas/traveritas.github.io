# p18 · 构块场（三态运动）× 定距回溯 × 一拍脑电（1s → 站点落地收紧到 0.5s）

## 主张
两态差不是「换一件东西」，而是**同一片流动被两种速率读出**：醒＝整片构造体沿 14° 朝右下**连续匀速**流动、块与块均匀留 1–2px 缝（读得出「拼接」）；梦＝**同一片场停住**（paused 冻结在当前进度），只剩原地整数像素浮动、接缝裂开、交叠处只留 1px 琥珀细边（**填充为空**，见改动 7），脑电同一条波改按**每拍采一次样**（一拍 = `--fld-beat`）。切换＝精确 −260px（入梦）/ +260px（回醒）的一次滑移。

## 醒
- 三档视差 104/84/66s（23.1/28.6/36.4px/s，沿 `--seam-angle` 14°）+ 2400px 周期**单向**漂移：每档内容生成一份 → 复制两份、第二份整体位移 −(2329,581) ⇒ t=1 帧里走出画面的正是 t=0 帧候在屏外的那份（首尾逐像素同帧，不需要任何 JS，本稿未改）。
- 本层唯一在醒态生效的位移是 `.fld-pan`（实测 matrix (84.3,21.0) / (104.4,26.1) / (132.9,33.2)）；`.fld-step / .echo-crawl / .echo-walk` 共 10 条在跑但振幅含 `--still` ⇒ 恒等变换（实测 0 位移）。
- 拼接几何生成期烘焙：渲染尺寸 = 格距 m − 缝宽 g（远 1px、中/近 2px），相邻两块间隙恒 = g、整数像素；tiled 与 loose **同一套尺寸** ⇒ 过渡只动 transform。
- 并进来的 P15-B 那层在醒态「什么都没多」：四道谱带 / 三道残影有 vs 无，逐像素 **0/1 296 000 差、最大通道差 0**。

## 梦
- **停住**（Part A）：`body.reality-holding .fld-pan, body[data-reality='dream'] .fld-pan { animation-play-state: paused }` —— 冻结的是动画的**当前时间**，不归位到生成原点、无跳变；回醒时从暂停处继续。
- 只剩**原地浮动**：7 档整数像素阶跃，节拍 = p16-b / p15-d 原设定 `--fld-sdur` 12.5 / 11.0 / 9.5s + 各档错相 `--fld-sdel` −1.5 / −4.0 / −6.5s（8 站里每站 10% ⇒ 7 档 + 30% 停歇，与 brand.ts 同拍）。
- 回溯：`.fld-rewind` 恒退 (252, 63)px（= 260px 沿 14° 反方向），幅度 = `smoothstep(--still)`；松弛：每块沿它挑中的共边法向滑开 0.30–0.52 格距 + ±0.12 格距切向错开，交叠解析求交 → 1px 琥珀窗。
- 脑电主波**每拍采一次样**（只在梦态，见改动 5 / 7），三道残影是同一条波的相位延迟副本 ⇒ 跟着变；延迟按拍长绑定（≥1 拍）。

## 本轮的六处改动各自落成什么
1. **A · 梦态停住整体漂移**（用状态类 paused，不是缩幅度）⇒ 最终三态：**醒＝沿 14° 连续流动；切换＝精确 ∓260px 的滑移；梦＝原地浮动**。顺带把上一稿「247/224px、±14px 余量」消掉：入梦两次读数（含醒态先漂 20s）逐分量最大差 **(0.00, 2.00)px**。
2. **B · 删掉 `.fld-quant`**（CSS 规则 / `fld-saw` keyframes / `--fld-vx`、`--fld-vy` 计算 / DOM 节点，全去）：`quant: 0`，本层动画 16 → **13 条**，漂移恢复成一条纯 `linear infinite`。
3. **C · 方块抽帧回到 p16-b / p15-d 原样**：computed 实测 `12.5s/-1.5s`、`11s/-4s`、`9.5s/-6.5s`；**方块抽帧只有这一处旋钮**（生成器 BANDS 表的 sdur/sdel 两个数）——想回到「一秒一拍（齐拍）」把三档 sdur 全改 **10**、sdel 全改 **0**（10 站 × 10% = 一站 1 秒）即可。**本稿选的是原设定那一版**。
4. **D · 方块加大 ~30%、每档 8→6**：边长（同一个数 = `dataset.b` 的第三个数）**档1 77–113（均 85.3）/ 档2 81–98（均 91）/ 档3 97–115（均 108）**；同口径重跑 p17 为 66 / 69.3 / 85 ⇒ 均值 **+27.7% / +31.3% / +27.1%**、中位 +31.7% / +32.4% / +31.3%；总块数 222 → 180。`m` 上下界 [34,118] → [44,146]，**边缝仍 1–2px（未随尺寸加粗）**。
5. **E · 脑电一拍抽帧（只在梦态）**：`f = 梦度`、`q = floor(ph/T)·T`（T = 一拍）、`phUsed = q + (1−f)·(ph − q)` —— f=0 直接取 `ph`（与线上逐字一致），f=1 每拍采一次样，中间连续收紧（不是开关）。只在 phUsed **或梦度 d** 变化时重绘 ⇒ 梦态从 30fps 逐帧变成**每拍一次重绘（比 p17 更省；单比 phUsed 会漏掉「停在一拍上、线还是醒态那条」这一帧，已修）**。四道谱带（7 档）与三道残影（5 档）同拍、`animation-delay` 为 1 拍的整数倍（0s）。**原稿 1 拍 = 1s；站点落地改为 0.5s（改动 7）。**
6. **F · 保持不变**：`--fld-rewind: 260px`、醒态漂移机制与速度、1–2px 缝、1px 琥珀框、两个 `smoothstep`、三段底色、**零新增 rAF / 零新增监听**（9 条 addEventListener 全来自外壳）。diff 取证：p17 的 `head 1–310`（tokens/底色/chrome/页面骨架/特效/角标）与 `tail 1237–end`（脑电 tick、状态机、调试角标、启动）对 p18 逐字节 `cmp` 通过；改动只落在 p17 的 **311–610**（BG SLOT 注释 / CSS / 谱带规则）、**715–730**（格距 m 上下界）、**793–945**（生成器落 DOM + 断言 + `window.__p18`）、**1142–1236**（EEG SLOT）四段。

## 最不放心的
1. **「±1–3px 抖动」的口径对不上**：p16-b/p15-d 的阶跃幅度是「系数 1/2/3px × 档倍率 `--fld-amp` 2/2/3」⇒ 实际偏移 ±2–6px（远/中）、±3–9px（近），不是字面的 ±1–3px；我按「幅度不变」保留原值（梦面 10s 内 x/y 包络 9×15px 即由此来）。**要压到字面 ±1–3px，只动 BANDS 的 amp（2/2/3 → 1/1/1）**。
2. **两个 CSS 动画组与主波采样网格差 ~117–200ms**：`.esb` 的动画 startTime 86.6ms、`.eeg-echo-*` 是 393.9ms（两组元素首次样式解析的时刻之差，生成器脚本夹在中间）× 主波用 rAF 时钟的整秒。三者速率相同、组内完全同相、delay 全是整秒，但这一相位差是**装载期常数**，不新增 JS 读不到也钉不住。
3. **梦态「一拍」冻的是内容、不是画面**：`d` 每秒重写一次，但 14° 旋转与残影/谱带的游走仍是 CSS 动画在逐帧跑（1 拍 1 跳）。
4. **生成成本变高**：大块更难落位（`h_uClip: 9`、781 次试错），生成从 p17 的 53ms 涨到 34–144ms（冷启动最坏）；构体恰好 18/份（请求 18）。
5. **醒态帧数两套口径不一致**：本层可见时 3s 181 帧 / 无层 180 帧（与 p17 同）；但在页面里自开 rAF 计数（与外壳 30fps 循环抢帧）的那次对照读到 p17 100 / p18 102、梦态 p17 55 / **p18 116** ⇒ 梦态更快（漂移停住 + 脑电每秒一次重绘），醒态与 p17 持平、不算回退。
6. 共用脚本 09 号裁片是文档坐标（四稿同病）；缝的 3× 裁片与剖面另出在 `.shots-p18-extra/zoom3x-wake-seam.png`。
7. 全流程唯一的 console error 是 `/favicon.ico` 404（p17 及更早各稿同病，与本次改动无关）。

**两处小改动**（mock 已同步回写，HTML 里各有注释）：

1. **交叠窗去掉填充**：`background: var(--fld-cut-fill, transparent)`（默认为空）＋ 保留那圈
   `inset 0 0 0 1px 40% 琥珀`。交叠处从此读作「浓度叠加 + 一圈琥珀细边」，不再是挖出来的亮洞。
2. **脑电一拍 = 0.5s**（原稿 1s）：`T = --fld-beat = 0.5s`，`phUsed = floor(ph/T)·T + (1−f)·(ph − floor(ph/T)·T)`；
   f = 0 时**直接取 `ph`**（不做 floor+余量的再求和，免得浮点重结合改末位 —— 醒态要求与线上逐字一致）。
   谱带 7 档 = 3.5s、残影 5 档 = 2.5s、delay 为 1 拍的整数倍。
   **代价（必须一起改）**：一拍一采（零阶保持）之后，小于一拍的相位延迟会让三道残影在同一拍里与主波重合、
   合唱闪烁 —— 三道残影的延迟从 0.10/0.22/0.36s 拉到 **0.52 / 1.05 / 1.57s**（= 1.04 / 2.10 / 3.14 拍，
   带微差免得三声部同相），延迟与拍长绑定（`beats × --fld-beat`）。合唱因此比原设定更「展开」。

## 首页挂法：**below**

首屏是不透明的纸叠（`.ps-wall` −4 / 纸壳 −3）＋ 两个巨字，`through` 下场画在纸**之上**（对照截图
`.shots-p18-site/ab-wake-through.png` vs `ab-wake-below.png`）：纸被读成格纸、边角的方块还会被读成
多出来的纸片 —— 这一层与「千层纸」的母题**撞车**，也正落在红线「不压过纸面」上。故首页
`<BaseLayout constructs="below">`：与纸同层（z −3）、DOM 在前 ⇒ 被纸完全遮住，滚过首屏才浮现；
**内页沿用默认 `through`**（第一屏就是内容，场是「地面」）。
实现上没有新增第二套机制 —— `layer` 只切一个 `z-index`，其余逐字节相同。

## 与 mock 的差异 / 还没钉死的

1. **E 的醒态残影差**：mock 量到 0/1296000（同页冻结帧），站点在缝线的 AA 上留 ≤8/255、~444px
   （跨装载底噪本就 362px/≤2）。**墨迹为零是确定的**（opacity 0 + 空 `d`）；剩下的抖动来自
   合成器：`.esb` 带 `will-change`（4 个满幅元素被提成合成层）与缝线自身的 `scaleX(--draw)`
   叠在一起。要彻底归零，可去掉 `.esb` 的 `will-change`（阶跃动画本来也不需要提层）—— 本稿按
   mock 原样保留，留待决定。
2. **F 的「≤30% 目标」在 light/paper 的梦面是 32.1% / 31.7%**（红线 35% 以内）。站点的文字列是
   `.container-wide` 56rem（mock 是 42rem 的 `.container`），框更宽 ⇒ 更容易框到场的亮处；
   同一口径下醒态与 mock 几乎逐数相同。
3. **一拍 0.5s 之后，梦态是「每拍一跳」的谐波束**（实测 470–507ms 一拍）；`--fld-beat` 是这一拍的
   唯一旋钮（CSS 里 `.eeg-group` 与构块场的注释都写了它派生什么）。
4. `.p18-verify.cjs` 的第 2 节用 `__p15.setMix()` 钉醒度，**那一步不会加 `reality-holding` /
   `data-reality='dream'`**，所以它量到的切换位移（295.8 / 309.7px）含「漂移没停」的部分，不是
   定距 260px 的口径；走真实手势（`__p15.hold()`）时 mock 仍是 `matrix(1,0,0,1,-252,-63)`，
   站点亦然（本表 B）。
5. 生成成本 127ms（dev、冷、1440×900）是**每个页面装载一次**的固定开销（内页同样有这一层）；

## 站点修订（同日）：删谱带 + 残影分「读法」

**缘起**：梦面那束线里最容易被读成「碎线 / 毛刺」的，是四道谱带被 `scaleX(2.4)` 拉开后散在
空白背景上的孤立小横段（6px 段 / 62.4px 节距 / 不透明度 0.26–0.28，脱离主线、四道各在一处）。
裁定：谱带整组删掉，残影按「读法」分成两组。

| 项 | 改动 |
| --- | --- |
| 四道谱带 `.echo-stave` | **整组删除**：DOM（4 × `<i class="esb"><b>`）+ `.echo-stave` / `.esb` / `.esb-1..4` / `@keyframes echo-crawl`。本层 CSS 动画 **13 → 9 条**（−4 `echo-crawl`，另 `echo-walk` ×3 → ×1、+2 `echo-drift`） |
| 灰调两道（主波 umber + `.eeg-echo-2` wake） | **保持原设计**：跟**拍钟**（位置每 0.5s 跳一格）+ 零阶保持的阶梯路径 + 阶跃游走 |
| 有色两道（`.eeg-echo-1` 琥珀 / `.eeg-echo-3` 暖沙） | **不跟拍钟**：相位取秒针 `ph`（逐帧推进，不是每拍采一次样）⇒ 一直在流；同时**不采样不量化**（JS 的 `smooth`：`q = 0` 与 `hold = 0` 把阶梯退化成普通折线）⇒ 连续曲线；游走改 `echo-drift`（8 档 × 1 拍 = 4s、linear，无 `steps()`） |
| 最淡的一道 `.eeg-echo-3`（暖沙，op 0.19） | **改虚线** `stroke-dasharray: 5 7` |
| 四道的法向偏移 `dy` | 改前 −41 / −21 / **0**（主波）/ +19，四条线整体偏上约 11px ⇒ 改后**四道一律 0**：四条线**各自的中心都落在轴线上**，谁都不横移。四道的差别只剩读法（相位延迟 / 步长 / 量化 / 虚线）——**束是四种读法在同一根轴上互相穿插出来的，不是摆开的四条**。`dy` 仍乘梦度（`dy × d`）⇒ **醒态四条照样精确重合在缝线上**，醒面逐像素口径不变 |

`dy` 保留在算式里当唯一的位置旋钮：将来若要让某一道单独离开轴线展开，只改它自己的 dy 即可
（乘梦度，醒态照样塌回轴上）。

**梦态振幅 ×2**（同日追加）：`GAIN_D` **2.4 → 4.8** ⇒ 梦面四道摆幅整体翻倍（主波
8.64 → 17.28、琥珀 7.776 → 15.55、wake 灰 5.36 → 10.71、暖沙 3.63 → 7.26）。算式上是**精确**
的 2 倍（A ＝ AMP × GAIN_D × 各道 gain）；醒态不受影响（`d = 0` 时 A 恒为 AMP，与 GAIN_D 无关）。

`draw()` 因此有两个时钟：拍钟 `phUsed`（`floor(ph/T)·T + (1−d)·frac`，只有主波与灰道跟它）与
秒针 `ph`（有色两道）。重绘节流也随之分开：主波/灰道只在拍钟走格时重写，有色两道逐帧重写。
