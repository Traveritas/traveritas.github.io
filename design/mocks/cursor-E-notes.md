# 方案 E · 菱芯光圈（The Diamond Aperture）· 实测笔记

## 主张
4 个发丝级（1px）折角拼合菱格 + 1 个 1:1 热点微核：平时是呼吸感的空心菱形 ◆，长按时裂开成引线导轨，按满瞬时向内强力坍缩熔铸为全站实心结 ◆。「光标从一开始就是那个未闭合的结，长按是拆线与重新扎紧」。

## 醒 / 梦 各自的机制与关键参数
- 元素恒为 `.da-core`（2px 实心方块/微核，1:1 同帧零延迟）+ `.da-iris`（4 个 1px 发丝折角，臂长 3.5px，节点池固定 6 个）。
- 静止开合半径 $R_{rest} = 4.8\text{px}$，旋转基准角：醒 $0^\circ$（正对坐标轴）、梦 $+14^\circ$（对齐全站缝线倾角）。
- 醒：阻尼 $\tau = 70\text{ms}$，临界硬朗，运动后 0.4s 完全收敛，**0 过冲**；各角标与微核严谨对称，冷灰墨色。
- 梦：阻尼 $\tau = 140\text{ms}$，柔和微欠阻尼；静息时由纯 CSS `daBreathe` 驱动 4.2s 低频微动（消费 `--still`，静止不占 JS rAF）；微核与角标淡化约 20%。
- 静止帧差（`?freeze=1`）：醒态（`01-home-wake.png`）为 $0^\circ$ 严整正菱形，梦态（`02-home-dream.png`）整体旋转 $14^\circ$、色彩微暖微透——角度与质感一眼可辨。

## 与其余四稿的机制差异
- **vs A 残点**：A 是离散粒子拖尾，停下手就空；E 拥有自洽的**平面几何实体**，静止时透气优雅，移动时光圈随速度膨胀开合（Iris Aperture）。
- **vs B 四点环**：B 是圆弧围成的圆形环，易产生准星/雷达感；E 是纯粹的**微型菱形与折角系统**，与准星彻底划清界限。
- **vs C 悬丝**：C 单根 9px 斜毛存在感极弱（8× 下近乎不可见）；E 有清晰的对角构架与微核定锚，既轻灵又有笃定体量感。
- **vs D 错位双影**：D 只有两个方点的平移错位（单薄）；E 在链接时展开为取景框 `⌜ ⌟`、正文时合拢为极细 I-beam、长按时长出引线导轨，拓扑形变完整连贯。

## 实测
- **控制台错误 0 · 页面错误 0 · 失败请求 0**（`.shot-cursor.cjs` 实测）。
- **热点同帧偏差**：`dx: 0 · dy: 0 · dist: 0.00px`（同帧口径，采样龄 753ms）→ **0 帧延迟**。
- **静息性能**：移动后静止，`rafLast5s` 停止增长，静息 `will-change = auto`（动时提合成层）。
- **逐帧写入属性**：严格只写 `transform`（translate3d / rotate）与 `opacity`，**零**颜色/尺寸/边框/filter/shadow 逐帧写入。
- **状态矩阵覆盖（实测定格图与机制）**：
  1. `rest`：4 折角旋 45° 围合成空心菱形 ◆，微核悬浮中央；
  2. `move`：随速度开合半径由 4.8px 扩展至 7.2px，光圈微滞后 ≤2px；
  3. `hover-link`：4 折角由 45° 顺滑旋转至 0° 并滑开至 12px，变体为全站取景框 `⌜ ⌝ ⌟ ⌞`，微核淡出（图 `05-hover-link.png`）；
  4. `hover-text`：左右角淡出，上下角聚拢成细竖线插入标，让出字面（图 `06-hover-text.png`）；
  5. `input`：更细致的文本插入符，微核低淡墨；
  6. `drag`：角标展开并向外抓取，微核保持高反差；
  7. `click`：4 角标在 40ms 内向内骤缩至 2.4px，180ms 弹性回弹，手感清脆；
  8. `hold1300 / hold2200`：4 角标旋转至 −4°，上下角标沿法线裂开为导轨通道，全屏抽线正是从微核发端抽出！（图 `07-hold2200.png`）；
  9. `latch`：按满瞬间（60ms），4 角标向内超速坍缩锁死，紧紧包裹微核熔铸为实心结 ◆！（图 `08-latch.png`）；
  10. `scroll`：角标向内轻微稳定收拢；
  11. `leave`：随外壳 `fx-cursor-out` 淡出；
  12. 降级：`?cursor=off`、`?reduced=1`、`forced-colors`、触摸事件全线安全回退系统原生光标。

## 最不放心的
1. 链接悬停态把 45° 旋回 0° 展开为取景框时，若指针在密集的小图标间快速掠过，频繁的 45° 开合旋转需要较短的过渡时间（当前设为 70ms 阻尼，实测利落不晃）。
2. 长按时抽线由外壳 `.thread` 生成，光标微核必须严丝合缝位于抽线起点；实测同帧 `(px, py)` 完全重合。
