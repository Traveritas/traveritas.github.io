## 定下来的

- **入口**（本稿未做）：关于页梦面的 `25:61` → `/2561/`。醒面干净，RSS / 读屏 / 无 JS 看不到。
- **场景**：A 站台（只留站台，不接列车）+ C 巨环与百合温室。架空、抽象，亮面低模（平直着色、低粗糙、不金属）。

  形态依据只取 OC 的灰白 / 近黑 / 长春花蓝配色与菱形纹样，设定图上的文字一概不用。

## 形式上的决定（可推翻）

- **异质色换成长春花蓝**：全站的异质色是琥珀，这一页换成 OC 配色里的长春花蓝，只用在光点、斜光、她的菱形上。
  理由：彩蛋页是「另一个世界」，换一个异质色能让它和主站分开；琥珀一处也没用。
- **细环斜 14°**：巨环外侧那道近黑细环、温室斜光都取全站缝线的 14°，是与主站唯一的暗线联系。
- **轨道不接列车**：两条轨道浮在水面上，过了巨环逐段变短、断成点，消失在雾里。
- **水面倒影**：整个场景沿 y 翻一份放在半透明水面下（灯光、光点、微尘不进倒影）。
  倒影放在单独的图层、单独渲染一遍，并用裁切面切掉 y > 0 —— 否则伸到水下的东西（巨环底部、细柱）
  翻上来会从水面冒出一截。第一轮就是这样：巨环的倒影在第 2 站横成一道弧，挡住了通往温室的路。
- **百合（抽象，第二轮）**：六枚沿长轴折起的菱形瓣（4 点 2 面），磨砂树脂半透明，根部微粉、瓣尖近白；
  外三瓣仰约 36°、内三瓣约 57°，花头近乎朝天。茎是一根发丝，高株才有一枚细长菱形叶。
  花心上方悬着三粒互不相连的近黑点（原先的花蕊）。没有卷瓣、叶脉和绿色。
  第一轮是写实的六瓣卷瓣 + 绿茎绿叶，用户评「过于贴近现实」。

## 已知问题 / 进生产前要做

1. **绘制调用**：抽象百合后第 0 站约 480 次（第一轮约 1060），温室内 100–220 次。倒影仍让一切翻倍；生产时按材质合并几何体。
2. **站台面偏白**：大面积平面在主光下接近纯白、看不出面。可以再压一档亮度，或给台面加一点极淡的分块。
3. 可点物（站牌、托特包、她的菱形）目前只有鼠标 / 触摸能点，键盘用户只能走站。进生产时给每站的可点物配按钮。
4. 没有音乐。简报里的「极简电子 + Ambient，维持状态而非推动」可以之后单独做。
5. 立绘 / 模型放进第 4 站空地：按设定图三视图，远景平面精灵按机位选正 / 侧 / 背一面；或者之后的低模。
