稿件：`design/mocks/p22-highkey-album.html`（双击即可在任意浏览器直接打开查看，或在本地服务中浏览）  
实测截图：`design/mocks/.shots-p22/`

## 解决的核心问题

1. **破除死黑与压抑感**：原版主页中段（随笔 `#171b24`、项目 `#131824`、试验场 `#191522`）亮度全在 11% 左右，不仅像一块毫无区分度的死黑铁板，而且与首尾浅色形成生硬的“白-黑-白”夹心。
2. **重拾《醒梦》高调微光世界观**：回归设计指导（`docs/design/aesthetic-direction.md`）中的**“低饱和偏浅色系”**与**“大面积留白与呼吸感”**，不再强行把夜间做成沉重的暗黑模式。
3. **真实还原半透明树脂与磨砂玻璃**：在浅色基底上，磨砂高透玻璃（`GlassChip`）与半透明树脂板的磨砂漫射和微光折射才能展现出晶莹通透的质感。

## 随笔与项目的区分调优（三种解法对比）

针对“随笔和项目的颜色有点太相近”的反馈，原型内已内置三种解法，可在底部工作台一键切换对比：

| 方案 | 随笔（浅梦）底色 | 项目（深眠）底色 | 设计逻辑与视觉体验 |
| :--- | :--- | :--- | :--- |
| **2B · 矿物青瓷<br>（色相分流 · 推荐）** | **`#dce6f2`**<br>*薄雾天青 · 90%* | **`#cfdbd5`**<br>*矿物青瓷灰 · 84%* | **色相独立**：随笔是通透水浅葱，项目转向沉静的矿物玉竹灰（冷青），五阶段自然流转（银白→天青→青瓷→薄藤紫→暖宣白），层次极佳。 |
| **2A · 沉降铅灰<br>（加大明度阶差）** | **`#e0e8f2`**<br>*浅水蓝 · 91%* | **`#c4ceda`**<br>*沉深铅石 · 79%* | **明度落差达 12%**：同色系内加大明暗落差，滚动到项目时有非常明确的“下潜到深眠结构”的厚重沉静感。 |
| **2C · 砂岩白垩<br>（冷暖对冲）** | **`#dce6f2`**<br>*冷雾天青 · 90%* | **`#e4ded4`**<br>*砂岩暖灰 · 87%* | **醒冷梦暖**：随笔走醒意冷调，项目走梦侧暖沙（呼应 `--dream: #c2a382`），对比最强烈鲜明。 |

## 原型特性与交互功能

- **多方案一键实时切换**：底部的浮动控制条支持一键在 **【2B 矿物青瓷】**、**【2A 沉降铅灰】**、**【2C 砂岩暖灰】** 与 **【原版黑底】** 之间实时无缝切换。
- **阶段直达锚点**：控制条支持直接跳转查看任意板块（Hero、随笔、项目、试验场、关于）。
- **实时色值与明度指示**：滚动时指示器实时显示当前视口所处阶段的底色色值与明度特征。

## 2026-09-28 修订：中间三段改为「一体灰阶」

用户反馈：随笔 / 项目 / 试验场三段的颜色**都不喜欢**。复查后确认问题不在"深了一点"，而在**色度**与**色相**两个层面 —— 2A 当初为了拉开随笔与项目的辨识度，是把色度与色相一起用掉的，代价就是这三段成了三张彩色粉彩卡。

### 实测（OKLCh；全站令牌的色相只有冷侧 245–248° 与暖侧 35–87° 两族）

| 段 | 2A（旧） | L | C | H | 一体灰阶（新） | L | C | H |
| :--- | :--- | --- | --- | --- | :--- | --- | --- | --- |
| Hero | `#f0f3f6` | 96.3 | 5.1 | 248° | 不动 | | | |
| 随笔 | `#e0e8f2` | 92.8 | **16.1** | 254° | **`#e1e6ea`** | 92.2 | 7.7 | 242° |
| 项目 | `#c4ceda` | 84.7 | **20.0** | 253° | **`#ced5da`** | 86.9 | 10.3 | 239° |
| 试验场 | `#e5dfea` | 91.2 | **16.1** | **310°** | **`#eae5e0`** | 92.4 | 8.7 | 68° |
| 晨醒 | `#f5f2eb` | 96.2 | 9.8 | 87° | 不动 | | | |

三条问题：

1. **色度是站点浅底的 3–4 倍**。`--bg` 在 L96 上只有 C5.1，而旧随笔 / 项目在相近明度上放着 C16–20。同一个色度值放在深灰上读作"灰"，放在 L92 的浅底上就直接读作"这是蓝色"。
2. **旧试验场 `310°` 是全站唯一一个紫色**（冷侧 245–248 / 暖侧 35–87 之外没有第三族），读起来像贴上去的。
3. **色温与语义反着走**。随笔（浅梦）/ 项目（深眠）/ 试验场（异相）语义上全是梦侧，而梦 = 暖沙（`--dream`，h68）；旧方案这三段全是冷蓝，暖色只在最后"晨醒"出现一次。

### 新方案的两条内部一致性

- **色相 248 → 242 → 239 → 68 → 87**：单向从冷走到暖，穿过中性，不折返。试验场的 68° 不是凑的，就是 `--dream` 的色相 —— 等于把暖沙稀释到浅灰，梦最盛的一段让暖回来，接住下一段的破晓暖宣。
- **明度 96 → 92 → 87 → 92 → 96**：先沉后升，保住了 2A 想要的"下潜再回升"，只是把下潜的表达从**色相**改回**明度**。

墨色对比 11.8 / 10.0 / 11.8（要求 ≥4.5），正文可读性没有退化（旧值 12.0 / 9.3 / 11.3）。

### 落地位置

`src/components/home/StageBackdrop.astro`。该层是全页唯一的地面：首页 `body` 是 `background: transparent`（index.astro 设的），`data/night.ts` 的 `ZONES` 已无消费方（styleguide 里记着）——所以改底色只需要改这一个文件。

**本稿 `data-palette="depth"`（2A）分支保留原值不动**，作为探索过程存档；站点上线的值以组件为准。2B / 2C 同理留档。

## 2026-09-28 修订二（当日更晚）：中段三段收成**同一个极淡的灰**

上一条的「一体灰阶」仍保留了明度下潜（L96→92→87→92）与末端回暖。当日更晚用户要求再退一步：**随笔 / 项目 / 试验场三段用同一个极淡的灰色**。于是中段三段同值：

| 段 | 一体灰阶 | L | C | H | 中段同值灰（现行） | L | C | H |
| :--- | :--- | --- | --- | --- | :--- | --- | --- | --- |
| Hero | `#f0f3f6` | 96.3 | 5.1 | 248° | 不动 | | | |
| 随笔 / 项目 / 试验场 | `#e1e6ea` / `#ced5da` / `#eae5e0` | 92 / 87 / 92 | 7.7 / 10.3 / 8.7 | 242 / 239 / 68° | **`#e4e7ea`**（三段同值） | 92.7 | 5.2 | 248° |
| 晨醒 | `#f5f2eb` | 96.2 | 9.8 | 87° | 不动 | | | |

取 `#e4e7ea` 的理由：

- **色相 248°、色度 5.2 ＝ `--bg` 自己**（`#f0f3f6` 是 h248 / C5.1）—— 中段不是"另一种颜色"，就是同一片底子压深一档。
- **比首屏深 3.6 个 L** —— 跨进随笔时读得出一档落差（第一版 `#ebedef` 只深 1.8，落差几乎看不见，当日即加深至此）。
- 墨色对比 11.9（要求 ≥4.5）。

**代价（已知并接受）**：全页只剩两处换色（首屏→中段、中段→晨醒），段的区分完全交给 StitchHeader、夜轨与 14° 发丝线，底色不再承担分段职责。三层的 DOM 结构与级联开关都没动（同色三层互相淡入淡出＝看不出变化，机制不必改）。

### 关于这个值

非手调，取的是「与 `--bg` 同色相、同色度、明度降约 3.6」的位置。若日后要再调浓淡，只改 `StageBackdrop.astro` 里那一条并列选择器（三条规则已并成一条，一个数）。
