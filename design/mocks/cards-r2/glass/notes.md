# A · 玻璃实体

1. **料**
   一块浅青的厚玻璃板：面是透的（压着一道窗外暗部的斜反光），底边露出 10px 磨出来的侧面，字刻在面上，图封在背后。

2. **边怎么成立的**
   底边 10px：上缘 1px 白棱（磨口）→ 1px 暖 + 1px 冷（1–2px 色散）→ 青灰侧面（`rgba(52,80,84,.66)` 到 `rgba(158,182,186,.20)`，4px 处一条错位的远缘亮线）→ 最下 1px 亮唇。玻璃外 4px 落一条 5px 高的焦散，先压 1px 深接缝。上/左/右三边是 1px 亮棱 + 1px 暗缝（上缘再叠一层很淡的暖/冷），上边内 8px 还有一条远端棱线。面上是 4% 的周缘沉、一道斜的暗反光（白 .24 / 青灰 .05）和 128px 的灰尘点（2% 密度，alpha 8–34，`grain.png`）。
   **字在面上，不在玻璃后面**：10px 的厚度配 1–2px 色散，字若在背后会被重影吃掉，浅底上先输掉可读性；图在背后则正好——照片底部化进玻璃，边缘没有框。

3. **字怎么排的**
   卡片 405×304，三栏 405 / 栏距 34 / 行距 26，版面 1440×900。
   标题 Noto Serif SC 600，20px / 1.5 / 字距 .035em；简介 sans 12.5px / 1.76 / .015em，宽不超 24em。
   日期 IBM Plex Mono 10.5px / .06em；字数 serif 11px / .10em；标签 10.5px / .09em，中点左右 .62em。
   栏头：编号 mono 10px / .12em，名字 serif 14.5px / .34em，拉丁 9.5px / .24em，条数靠右 10px / .10em。
   放大态整卡 `zoom:1.68`（厚度、色散、灰尘一起变大，不是另画一张）；阅读片 700×760，正文 14.5px / 2.0 / .015em，行宽 572px。

4. **展开怎么从卡片来到这里**
   同料放大：三栏退到 5.5% 变成玻璃背后的影子，阅读片是同一块料做到 700×760、厚 14px，字还刻在面上；不换页，只是玻璃变大。detail 是同料的 1.68 倍，居中，边上留一句版块标注。

5. **最容易被否的地方**
   底边那 10px 侧面在 1x 下离「一条厚下边框」只有一步之遥——读成 bevel 就整案输掉。第二是灰尘点，浅底上退远可能像脏（已压到 2%、最大 alpha 34）。第三是瞬间卡上的日期压在人像上（moment-2 压在她头发上），按「字在面上」成立，但可能被看作硬贴上去的字。
