# 印相纸 · print

## 1. 料

一张刚从定影液里晾干的 35mm 印相：暖灰、低对比、极轻的颗粒，摊在浅色台面上，比台面亮一档、暖一档。

## 2. 边怎么成立的

- 没有框。相纸的边就是它的边界：里面 .5px 的暗线（纸的切口），外面 .5px 更实一点的接缝、2px 的暖光（光从纸的厚边折过去）、1px 的接触影，再往下一团 34px / -26px 的冷软影。亮的是纸面，边只在受光处亮一档。
- 照片只铺到相纸的上、左、右三条边，下沿留 96px 白边做题注。照片与白边之间不是切线：下沿最后 30px 用 mask 化进纸里，所以是「印到这儿」而不是「贴到这儿」。
- 空白相纸（随笔 / 项目）没有照片，只有纸：一道 112° 的宽受光斜过纸面，右下角沉一点、冷一点，纸里压着 1% 上下的涂布不匀和同一层颗粒。
- 颗粒只有一层，盖住照片和白边；`multiply`，SVG fractalNoise 二值档，落在 0.96–1.0。它跨过照片边界，这一条比颗粒本身更重要。

## 3. 字怎么排的

- 题注永远在纸的下沿：左右各 24px，标题 21.5px / 1.46 / 字距 .045em（照片卡 17.5px，让位给画面）；简介 11.6px / 1.86 / .028em，颜色 `#6e675b`；标签 9.5px / .08em。
- 四个角是纸上的边注，不是界面：左上 `1 / 2`、右上 `1923 字`（项目卡换成状态花字）、右下日期，都是 8px IBM Plex Mono / .16em / `tabular-nums`；左下是 9.5px 标签或「— GitHub 仓库」，唯一一处带一道 13px 细线的元素。
- 栏头：9px 编号 + 13px / .34em 名字 + 7.5px / .22em 拉丁 + 9px 条数，底下一道 1px、从 14% 淡到 1% 的暖线。
- 长简介手工断行（「…Unicode / 文本形态…」「…智能体 / 各自留下…」），不留四五个字的孤行。

## 4. 展开怎么从卡片来到这里

- 同一张纸放大成整页：`inset: 22px` 的相纸页，照片从卡片里的 228px 长到 400px、铺满页宽，下沿是一条印出来的硬边（不是渐隐）。
- 正文落在照片下方那张纸上：42px 标题、两栏 14.8px / 2.0、栏距 56px、一道 6.5% 的栏线；正文末尾自然被页底裁掉，像书页。
- 相册的语言没换：台面、纸的光、同一层颗粒都在，只是尺度变了。

## 5. 最容易被否的地方

- 四张空白相纸就是四块空纸。它们全靠光、颗粒和切边撑住；远看如果像没加载出来，这条就倒了。我承认这是最险的一处。
- 两张照片本身是很浅的粉彩，压暖压灰之后可能被读成「褪色滤镜」。我的目标是「印出来的」而不是「洗淡的」，但这一步全看屏幕。
- 细节页只有一张纸和几行字，克制到接近空。如果判据是「一眼要被抓住」，它会输给任何有画面的方案。
