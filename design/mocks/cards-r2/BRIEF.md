# cards-r2 · 好看优先

> 2026-11-02。上一批三条（雾片 / 斜切 / 开口）被一句话否了：**概念成立，但不好看。**
> 批一的毛病是拿概念当卖点，工艺没跟上。这一批不换概念，只比工艺。

唯一的判据：**好看。**

## 怎么算好看（可验收的四条）

1. **材料本身值得看。** 边、光、厚度、纸感——凑近看有东西，退远看是一整块，不是「一块矩形加了点效果」。
2. **字是排过的。** 标题、日期、标签、字数之间的关系一眼有秩序；字距、行距、字号不是浏览器默认值。
3. **图像不是贴上去的。** 上一批唯一被认可的就是「开口」处理图片的方向：照片融进卡里，没有框，边缘有过渡。保留这一点。
4. **远看不碎。** 三张并排时是一个安静的版面，不是三个抢眼的东西。

共同底线：
- **浅底为主。** 站的主调是醒面（冷灰、近白），不要再用整页夜色去撑效果。
- 不做大块模糊当装饰（批一的死因之一：糊成一团，看着像没加载完）。
- 不做发光边、不做胶囊标签、不做重投影、不做玻璃拟物的老套高光。
- 极简不等于空：要有材质、空间、光的关系。

## 站内已有的标尺

左下角那颗星（`src/components/chrome/Toolstar.astro` + `src/scripts/toolstar.ts`）和阅读页的导览轨是全站最精致的两个部件：1.25px 的线、克制的刻度、没有一滴多余的光。
**卡片要配得上那支笔。** 如果你做出来的东西挂在星星旁边会显得笨，那就是没做完。

参考：`design/_shots-accent/50-list-essay.png`（现在的检索视图）、`design/_shots-accent/50-read.png`（现在的阅读页，如果存在）。

## 三条材质（各做一条，不要互相借）

### A · 玻璃实体 `glass`

一块**有厚度**的玻璃片，不是一张白卡。

- 边不是描出来的，是折射出来的：内侧一道极细的亮/暗、边缘 1–2px 的色散、底下一点很淡的焦散。
- 表面有几乎看不见的起伏与灰尘级的杂点（极克制，别做成毛玻璃噪点滤镜）。
- 字可以在玻璃后面（被折射），也可以在玻璃表面（清晰）——选一个并说清为什么。
- 危险：滑向「磨砂玻璃拟物」。判据是远看安静、近看有物理。

### B · 图纸/仪器 `drafting`

像一张**贴在空间里的图纸**。

- 1px 细线、刻度、索引号、精确字距的小号大写拉丁；没有阴影，只有线与字的密度。
- 纸是半透的浅色，几乎贴着背景，靠线的疏密和字的位置成立。
- 展开＝这张图纸变长（栏线延伸、刻度继续），不是换一页。
- 危险：变成「技术文档」。判据是有没有那点温度——留白、字重、线断的位置。

### C · 印相纸 `print`

一张 **35mm 印相**。

- 低对比、暖灰、极轻的颗粒；照片是主平面，文字是相纸边缘的题注（小、靠边、克制）。
- 卡片没有框：只有照片的边缘和一点点纸的绕射；有些条目没有照片，那就是一张空白的相纸，字压在上面。
- 展开＝照片放大成整页，正文落在照片的暗部或下方，像相册里的一页。
- 危险：变成「复古滤镜」。判据是它像不像真的印出来的，而不是加了 grain。

## 硬约束

**范围**
- 只写 `design/mocks/cards-r2/<你的案子>/`。不动 `src/`、不动 `shared/`、不装依赖、不跑 `npm run build`。

**内容**
- 只用 `shared/fixture.md` 的真内容。**不要自造标题**——站内字体按站内用字切分，新词会缺字。

**文字红线**
- 不写「这是梦 / 你在做梦」这类自我标注；不写台账、审计、核验词汇；不写极客中二。

**固定件**
- 左下角的星不改，也不要在画面里画一个假的：留 120×120 空位。

## 交付

### 1. `index.html` —— 四种状态

| 状态 | 触发 | 内容 |
| --- | --- | --- |
| 检索 | 默认 | 1440×900，三栏（随笔 2 / 瞬间 2 / 项目 2），栏头编号 · 名字 · 条数 |
| 展开 | `#open` | 同一页切到阅读；背后三栏按你的语言处理 |
| 细节 | `#detail` | **把第一张随笔卡放大到 1.5 倍以上放在画面中央**，让材料能被看清（旁边可以留一句标注） |
| 窄屏 | 视口 ≤ 720 | 一列 |

- 用 `:target` 或 `location.hash` 切换，不做点击交互。
- 字体：`<link rel="stylesheet" href="/fonts/noto-serif-sc/font.css">` → `font-family: 'Noto Serif SC'`。
- 配图在 `shared/img/`（`moment-1.png` / `moment-2.jpg`）。

### 2. `notes.md` —— 五段，短句

1. 这件东西的「料」是什么（一句）
2. 边怎么成立的
3. 字怎么排的（字号 / 字距 / 层级的具体数字）
4. 展开怎么从卡片来到这里
5. 最容易被否的地方

node design/mocks/cards-r2/shot.cjs <你的案子>
