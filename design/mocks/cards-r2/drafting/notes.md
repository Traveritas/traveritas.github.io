# B · 图纸 / 仪器 · drafting

## 1. 料

一张半透的浅色纸，压在两根比纸本身更长的栏线上；没有阴影，只有 1px 的线、刻度，和落上去的字。

## 2. 边怎么成立的

- 纸只比背景亮一档（暖白压冷灰），靠纸的切边和线密度成立，不靠投影。
- 切边是两道：外一道 1px 暗线，内一道 1px 亮线——像纸的厚度，不是描边。
- 顶边是一条量带：1px 边线 + 4px 小刻（24 一格）+ 8px 大刻（96 一格），底下再压一条 1px 底线把刻度收成一条带。
- 左右各一把竖尺，3px 小刻、8px 大刻，贴在纸内的边距里；左尺在左下角提前断掉，给星星留 120×120。
- 栏线是页面级的，从屏顶一直拉到屏底，纸半透地压在上面：纸外浓、纸里淡，这是"纸是半透的"唯一证据。
- 纸的四条边长度各不相同（左边缘 70% 处开始退，底边从左下角 46px 才起笔），没有一条边是描死的。
- 每张照片无框：上下各一道渐隐遮罩 + 左右各一道，四边都化进纸里；照片 0.97 不透明度，让纸色透一点上来。
- 角上一小段 18px 的琥珀对位记是全页唯一的异质色。

## 3. 字怎么排的

- 纸角登记：`001` / `2026.09.19 — 2026.10.07`，Plex Mono 9.5px，字距 0.22em，色 #97a1ad。
- 栏头：编号 23px / 0.86 Plex Mono 淡灰（#8d97a3），名字 18px 宋体 500、字距 0.12em，英文 9px 大写、字距 0.26em，条数 9.5px 贴栏右。
- 每条一张"登记线"：序号 + 1px 细线（14% 墨）+ 日期，Plex Mono 9.5px、字距 0.1em。
- 第一篇（头条）：标题 32px / 1.32 / 600；简介 14.5px / 1.95。
- 其余随笔：26px / 1.38 / 500；简介 14px / 1.95；标签 11.5px 宋体、字距 0.06em；字数只把数字交给 mono（9.5px），"字"留在宋体。
- 瞬间：标题 21px / 1.45；图注 11.5px，前面挂 14px 细线；四张图时右上角四枚 7px 刻度，第一枚是琥珀。
- 造物：标题 23px；状态与 `GitHub 仓库 ↗` 对齐在一条 1px 细线下面。
- 每栏收口：`ESSAYS ————`，8px 大写、字距 0.3em，一条走到边的线。

## 4. 展开怎么从卡片来到这里

同一张纸变长，不是换页：

- 栏头留在原地（01 断章不淡，02 / 03 退到 0.26 还在原来的 x 上）；两根栏线里，右边那根继续向下跑，左边那根断在栏头下沿。
- 左栏长成正文：16px / 2.05、字距 0.015em、两端对齐、34em 宽；标题 34px / 1.34 / 600。
- 页面比视口长，正文在 900px 处被屏幕裁断，纸和两侧竖尺的刻度继续往下——"变长"看得见。
- 右侧 988 栏线之后是一列存目：六条，当前一条点一枚琥珀刻；顶部元信息 `随笔 · 断章 · ESSAY / 2026.10.03 / 1841 字 / 1 / 2` 压在正文上。
- 细节态：同一张卡放大 2.2 倍（字号、栏宽、字距全部按 2.2 乘），四角 16px 对位角标，上面一条尺寸线断在中间写 `× 2.2`。

## 5. 最容易被否的地方

- 整体偏淡：纸和背景只差一档，远看可能像"没上色的一页文档"。
- 第二、三栏卡片结束后到收口线之间留白较大——我把它当成纸的空白留着，但会有人读成"没排满"。
- 两张图都是浅色素材，并排时最怕糊成一片；现在靠渐隐边和 1px 登记线把它们钉住。
- 若被否，多半不是概念，是"太安静"或"太像表格"——那时的改法是加大字号对比、减少一条线，而不是加东西。
