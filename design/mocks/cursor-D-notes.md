# 光标 · 方案 D · 错位双影（醒＝对齐，梦＝差一点点）

## 主张
两个**完全相同**的 3px 平面方点：正点同帧 1:1 是热点，副本的**错位量就是它的透明度**——于是「对齐」本身成了一个可读的状态量（醒恒为 0，梦沿 14° 永不重合）。

## 醒 / 梦
- 映射（本方案的全部赌注）：`op(d, y) = 0.66 · (1 − e^(−d / 1.05px)) · y`，`d` ＝副本相对正点的错位、`y` 为让步系数。**d = 0 ⇒ op 严格 0**（不是底值）；d≈自身跨度(3px) 后饱和 ⇒ 移动时"淡淡双影"、静止时收敛。
- **醒**：底色错位 0、副本 0；移动时副本落在运动之后，残余上限 **3.0px**、褪去时常数 **75ms**（锐）。
- **梦**：静息沿 **14°**（缝线角，cos14/sin14）保持 **2.0↔1.0px**，`4.6s ease-in-out` 呼吸（CSS 动画，rAF 停）；移动时残余上限 **6.0px**、时常数 **200ms**（黏）；合成后钉住 **DREAM_MIN = 1.0px** ⇒ 残余与底色矢量相消也不会重合。
- 速度关系是**渐变**的（残余＝本帧未追上的位移），不是"抖/不抖"：实测快移中 d＝0.23–4.68px、op 0.13–0.65 连续变化。
- 呼吸的交接：静息由 CSS 的 `cd-breathe` 0% 帧（＝14°·2.0px / op 0.562，与 JS 收敛值同数）接手，`animation-composition: add`；实测停下后 366ms（醒）/730ms（梦）由 js 交棒 css，无跳（CSS 呼吸段的不透明度在两端点之间线性插值，与映射律最大差 0.02）。
- 状态表（S＝副本稳态偏移 px，括号＝醒/梦）：rest 0 / 14°·2.0 · move −运动向·min(残余,3/6) · hover-link **0**（对齐＝可去之处）· hover-text −4°·4.0（op 0.271，让步 ×0.42，正点 0.78）· input −4°·5.0（op 0.275，正点 0.56）· drag 锁定轴·≤10 · click 归位＋一次掠过正点的碰撞脉冲 `1.25px·e^(−3.2u)·cos(πu)`，260ms · hold1300/2200 沿 −4° 抽线轴 0→6 / 0→9（吃外壳长按进度）· latch 0 · scroll 0（220ms）· leave 容器淡出。

## 与其余三稿的机制差异
- **A 残点**：残影是**多个**、按行进距离落点，主角是数量与间距；D 只有**一枚**副本，量全在"错位→透明度"这一条映射上。
- **B 四点环比**：机制在**角度**（缺口开合 + 进动）；D 零旋转、零缺口，只有一条直线上的位移量。
- **C 悬丝**：一根线的钟摆角度与长度，线是独立的图元；D 是同形图元**分裂/重合**（对齐与否），与线无关；长按只是借用 C/站点的 **−4°** 抽线轴。
- 一句话：A/B/C 都在"加东西"，D 只加**一个偏移量**，并把它同时读成位置与浓度。与站点既有 `ghost-pair`（`--echo × --still`，"醒态叠影归零"）同源，是它的指针尺度版。

## 实测
- 共用截图脚本 17 张：**console 0 · page 0 · 请求失败 0**（`node design/mocks/.shot-cursor.cjs cursor-D-double-image D ...`）。
- 热点偏差（外壳同帧口径，热点元素＝正点）：17 张**逐张 dx 0 / dy 0 / d 0.00px**（采样龄 584–722ms）；正点永不移动，装饰最大偏移 = drag/hold 的 10px（＜12px 红线）。
- 静息 5s rAF：**0**（`?mix=1`/`?mix=0`/`?zone=deep`/`?zone=paper` 四种皆 0；累计 rAF 只出现在状态 settle 期）。
- 静息 will-change：槽位 `auto`、两图元 `auto / auto`（动时 `transform` / `transform, opacity`）。元素数峰值 **2**（槽位内两枚方点）。
- 逐帧写入属性：`copy.style.transform` + `copy.style.opacity`（2 条/帧）；pointermove 另同帧写 `hot/copy.style.transform`（位置）；正点 opacity 仅状态切换时写。
- 12 项矩阵（实测 gap 长度 px，醒/梦；`?state=` 强制口径）：rest 0 / **2.00** · move 2.99 / 4.27 · hover-link 0 / 0 · hover-text 4.00 / 4.00 · input 4.95 / 4.95 · drag 9.99 / 9.99 · click 1.25 / 0.75 · hold1300 6.00 / 6.00 · hold2200 9.00 / 9.00 · latch 0 / 0 · scroll 0 / 0 · leave 0 / 0（容器 opacity 0）。
- 真手势（`.cursor-D-live.cjs`，不用 `?state=`）：悬停文字链→`hover-link`、正文→`hover-text`、输入框→`input`、入口卡/导航→`hover-link` 全部靠 `pointerover`+`closest` 认出；真长按 300/700/1100ms → gap 2.15/4.62/5.80px 且**正落在外壳那根 −4° 抽线上**，闩锁拍内 d→0.11px（合一），＋300ms 后梦侧重新浮到 1.82px；真点按 60ms 时 d 0.54px（碰撞中）、380ms 归 0.01px；真拖动 d 9.95px 锁定轴向；真滚动 d 0.03px（短暂重合）。
- 降级：`?cursor=off` 与 `?reduced=1` → body 无 `fx-cursor-on`、槽位 opacity 0、body `cursor: auto`；forced-colors（CDP 模拟，matchMedia 为 true）→ 门控失败 **且** `@media (forced-colors)` 令槽位 `display:none`，body `cursor: auto`；真触摸 tap → `fx-cursor-on` 摘除、`lastPointerType=touch`、槽位 opacity 0。
- 三 zone 可见性：light（#262c33 点 + 灰副本）、deep（#e5e0d2 浅点 + 灰副本）、paper（#55503f 点 + 灰副本）在 8× 取样里都清楚、都不糊（`.shots-cursor-D/zoom-03/10-*.png`、`zoom-00-compare.png` 并排对照）。

## 最不放心的
1. **它算不算一个机制：自评 6/10。** 站得住的是"偏移量即透明度 + 对齐/不对齐可读 + 与 `ghost-pair` 同源，且长按恰好落在外壳的 −4° 抽线上"；站不住的是**成本最低**：形状只有两枚方点、无独立动力学（残余只是一帧位移的指数褪去），单看像"一个会抖的小点"，更像一条**读数律**而不是一件器具。
2. **1:1 下的两态差偏弱**（题目自身把错位限在 1–2px）：醒＝3×3 点，梦＝5×3 条且右端 0.56 灰；并排 8× 一眼可辨（`zoom-00-compare.png`），但把两张全屏截图并看时需盯着看。若裁决要求"全屏一眼不同"，本方案单用不够。
3. **`?state=` 强制口径是纯姿态**（rest 不含残余、move 用标称滞后＝该态上限）：这保证静止帧可对照，但也意味着 01/02 两张静止帧证明的是"两态的静止形态"，动了才有的残余由 `.cursor-D-live.cjs` 的真手势帧（`live-move-mix*.png`）补证。
4. **给方案 C 当梦态表达的参数建议**（若 D 只作 C 的梦态）：C 的线在梦态分裂成两笔，沿 **14°** 错开 **1.5px**（不是 2px：线只有 1px 宽，1.5px 已有可读缝）、两笔透明度按同一条映射 `0.66(1−e^(−d/1.05))` 分给"后一笔"、呼吸 4.6s 在 1.5↔0.8px 之间；醒态把后一笔的错位钉 0（即真正一笔）。这样 C 的"绷直/摆动"与 D 的"对齐/差一点"共享同一个 `--still` 输入，不新增机制。
5. 顺手记两处：外壳的 `抽线/一弹` 有、**成结 ◆ 没有**（故长按只表达在光标自身，未自造站点特效）；两处自验脚本（`.cursor-D-*.cjs`）与 `?probe=1` 下的 `__curD` 句柄是给复核用的，接入站点时删掉即可。
