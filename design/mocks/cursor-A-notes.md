# 方案 A · 残点（定距回溯）—— `cursor-A-afterimage.html`

## 主张
残点按**行进距离**落点、也按行进距离消亡（不按时间）：同一个按 px 记账的刻度场，醒沿 0°、梦沿 14° 被读出——慢＝稀疏的长寿点，快＝密集流星，静止即归零。

## 醒 / 梦
- **醒**：轴 0°；落点间隔 7px；寿命 30px（本体再走 30px 淡尽）；淡出指数 1.55（锐）；短划无取向动画。定格一帧＝4 枚 4×1 短划，跨 28px，op 0.662 / 0.377 / 0.155 / 0.015。
- **梦**：轴 14°（＝ `--seam-angle`，与全站缝线同角）；间隔 9px；寿命 52px；指数 0.78（柔）；每枚原地缓慢浮动（CSS `cur-float` 3.4s alternate，振幅 ×`--still`，0% 帧离轴 ≤1.35px）；短划取向由 CSS `rotate(calc(--still * 14deg))` 给出。定格一帧＝5 枚，跨 45px，op 0.862 / 0.718 / 0.565 / 0.399 / 0.209。
- **同一刻度场的两种读法**：`dreamT` 连续插值，闩锁后 300ms 内轴 0°→14°、间隔 7→9、寿命 30→52、指数 1.55→0.78 同步迁移；醒态 `animation:none`（精确对齐），梦态浮动随 `--still` 起落。
- 时间常数：静止判定 170ms；停手后残余按 260px/s 排空（≤200ms 清空）；`dt` clamp 1/30s；池 6 枚硬上限（复用最旧，元素数不涨）。

## 与其余三稿的机制差异
- **vs 四点环比（缺口开合＋进动）**：B 的参数是**角**（缺口宽、进动角速度），四段是同一时刻的整体刚性环；本稿参数是**距离**（7/9px 间隔、30/52px 寿命），6 枚残点是各自计龄的独立个体，且醒态**零动画**（B 醒态仍合成完整环）。
- **vs 悬丝（−4° 钟摆单笔画）**：C 只有一个装饰体，信息在**角度**（摆角、过冲）与单笔画的伸缩上，且线是站点手势的代表物；本稿是 6 个同构残点，信息在**距离与数量**上，角度只用站内既有的 0°/14° 两根轴，不摆、不伸缩。
- **vs 错位双影（偏移量即透明度）**：D 的副本与本体同形同速，靠**滞后量**（重合/错位）表达两态；本稿副本是**离散采样短划**（非连续滞后体），且梦态额外多一维「离轴浮动」（D 只沿 14° 平移、不加浮动）。

## 实测
- **热点偏差**：`?probe=1` 自检面板给出 **Δx +0 · Δy +0 · d 0.00 px（1ms 前，同帧口径）＝ 0 帧**；本体在 `pointermove` 处理器内同步写 `transform`（不经 rAF），面板采样在其后。
- **静息 rAF**：移动后静息 5.2s，`rafTotal 84 → 84`（**增量 0**）、`rafLast5s 0`、`loop 0`、`live 0`；静息 `will-change` 计算值 **`auto`**（活着时 `transform, opacity`）。rAF 由 pointermove / state 变化唤醒，收敛即 `stop()`。
- **逐帧写入属性**：残点外层 `transform`（translate3d）、内层 `opacity`；本体外层 `transform`（pointermove 同步）、内层 `transform: scale()`（仅状态变化时写一次）、内层 `opacity`（仅正文/输入态）。**无**颜色/宽高/圆角/filter/box-shadow/background 的逐帧写；短划取向与梦态浮动全在 CSS（`--still` 驱动）。
- **元素数**：`#cursor-slot` 内 14 节点（池固定：本体 2 + 残点 6×2），建一次、零每帧分配；可见图元峰值 7（本体＋6）。实测存活：醒态移动 3–4、梦态移动 4–5（寿命/间隔自然上限）、悬停链接 5–6。
- **12 态矩阵**（真实指针驱动见 `.shots-cursor-A/r01–r16`，定格样本见 `01–17`；格式：state｜live｜装饰最大偏移｜间隔｜scale）：
  1. rest｜0｜0｜7｜1（零残点、loop 0）
  2. move｜3–4（峰值 4）｜13.1px｜7｜1
  3. hover-link｜5–6｜12–18px｜3.5（×0.5 收紧）｜0.88；停住 700ms → live 0（只剩本体）
  4. hover-text｜0｜0｜－｜0.62＋op 0.55（让出字面）
  5. input｜0｜0｜－｜0.66＋op 0.55；敲字后 live 0、`value 半句`
  6. drag｜1–2｜7–25.2px｜12.6（×1.8）｜1.16（抓取态 1.06）
  7. click ≤260ms｜live 3–5｜6→0｜7｜1（一枚向前越位 11px 再吸回，`10-click.png` 可见越位那一枚）
  8. hold1300｜回流起点 4 枚 / maxOff 20px → 700ms 后 0｜－｜0.9（真实长按：`r08` 里外壳 −4° 抽线同时进行）
  9. hold2200｜同上（定格样本 `09-hold2200.png`）
  10. latch｜0（新沉积于闩锁后开始）｜0｜7→9｜0.76 收紧一帧（`11-latch.png`），400ms 后轴 = 14°
  11. scroll｜0（残点抑制 320ms，只写 opacity 0，**不为滚动开 rAF**）
  12. leave｜整体淡出（`fx-cursor-out` → 槽 opacity 0.169 → 0，CSS 220ms）
- **降级实测**：`?cursor=off` → `fx-cursor-on 0`、`cursor: auto`、槽 `visibility: hidden`；`?reduced=1` → 同上；真实 `touch`（CDP tap）→ 鼠标开门后 `afterTouch 0`、`lastPointerType touch`；`forced-colors: active`（CDP 模拟）→ `fx-cursor-on 1 → 0`、`cursor auto`、槽 hidden。
- 共用截图脚本：**console errors 0 · page errors 0 · failed requests 0**（17 张）。

## 最不放心的
1. **装饰偏移超出 12px**：单枚 7px（醒）/9px（梦）合规，但整排最远 28px（梦 45px）、链接收紧态实测 12–18px、长按回流起点 20px。§5 红线 6（≤12px）与 §3 方案 A（6 枚 × 7px 间距）自相冲突；我按 §3 实现。若 12px 是硬线，本机制只能留 1–2 枚残点（≈退化）。
2. **定格帧必须借 `&probe=1` 开门**：外壳门控要求真实 `pointermove`，而共用截图脚本只在 `probe=1` 时合成鼠标移动。因此 `?freeze=1&mix=…&ui=0` 单独用是**看不见光标**的（不造假）。两张定格帧现为 `…&ui=0&probe=1`。
3. 定格样本是**机制算出的「匀速沿轴直行」一帧**（同一条代码路径、同一落点间隔/寿命/淡出曲线），不是真实录制的运动帧；真实运动的存活数 3–4（醒）/4–5（梦），与样本 4/5 基本一致但非逐帧同源。
4. `?state=<name>` 强制态会把层锁定为定格模式（真实指针不再改写内部 hover/drag/hold 状态），只用于截图；真实交互同时给了 `r01–r16`。此锁定是本轮为拿到可比较帧而加的开关，接入站点时应删除。
5. **共用脚本的文档 bug**：其头部示例写 `node .shot-cursor.cjs cursor-shell shell`，但简报里的命令是 `cursor-A-afterimage.html`——脚本会自己再补 `.html`，于是请求 `…html.html` → 全页 404。正确用法是**不带后缀**（我用 `cursor-A-afterimage`）。此 bug 未改脚本，仅绕过。
6. 链接「落在目标上只剩本体」是「停手即排空」的自然结果，没有独立的落地相位定时器；若判定要求显式的 settle 阶段，此项算未做。
7. 「让出字面」是缩到 0.62（≈3px）＋ 0.55 不透明度，实测真散文上不遮字（`r05`），但仍属「用透明度让位」，不是让出整片字面。
8. 滚动抑制、`leave`、`latch` 均未在 120Hz / 高刷 + 触摸板惯性长滚下复测；WCAG 200% 缩放、真实屏幕阅读器（NVDA/VoiceOver）、触摸＋笔混合设备**未测**（简报列为发布前门槛，本轮 mock 未覆盖）。
