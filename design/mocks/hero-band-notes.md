# 首屏原型 band：膜只在线上

页面：`/mock/hero-band/`（`src/pages/mock/hero-band.astro`），脚本 `src/scripts/proto/hero-band.ts`。
只重做了场 0，其余四幕与 `/new/` 相同。

## 思路

大字留着，但退成背景：单层、静止、只用一种材质（实心、很淡）。醒用冷灰墨，梦用微温的赭。
「膜」不再是一条逐帧把字切开的波，而是沿 14° 线的一条静态磨砂玻璃带。字被线穿过的那一窄条
换成预先模糊、沿法向错开几像素的副本，像隔着玻璃看过去被折了一下。带外的字是清楚的。
线本身的波动交给 Worker 画布，首屏的主角是线、留白和那句问话。

## 实现层次（每个字）

```
.gw    定位；滚动时沿 14° 方向退开（醒往左上，梦往右下）—— transform，随 --p
 └ .gi 入场：opacity + 几像素位移（从膜里浮出），不再动 filter
    ├ .sharp  清晰的字，静态 194° 渐变 mask 把线附近一窄条挖空
    └ .soft   同一个字 blur(.018G) + 法向错开，mask 只露那一窄条
.veil  全宽、旋转 14° 的一条极淡雾白带，上下两道 6% 墨色发丝边（玻璃片的边）
```

- 194° 渐变垂直于 14° 线。`--lp` 是线在字层里沿渐变轴的位置：醒 70.7%，梦 30.7%。它由字框的摆位公式（线在框高 .8 / .22 处）算出，桌面和窄屏通用。
- 字层四周各外扩 .08G，因为笔画会探出行内框，mask 按盒子裁切会把它削掉。
- 双态：只用 `--still` 调两字的 opacity。醒面醒字略清，梦面梦字更暖更实。
- 去掉了 SVG `feMorphology` 外扩描边、波纹贴图、drop-shadow 和 ghost 层。

## 性能做法

- 脚本删掉了 membranes、glyphMasks、setTiles、clipMembranes 和 30fps 的 `later()` 节拍。rAF 只在入场画线（约 1.3s）和滚动后跑，静置时完全不要帧。
- 所有 mask 和 filter 都是静态值，只栅格化一次。滚动时变的只有 `.gpair`、`.veil` 的 opacity 和 `.gw` 的 transform（都带 will-change）。
- 粗测：dev 模式，1440×900@2x，静置 4s，CDP Performance：

  | | Script | RecalcStyle 耗时 | Task 总耗时 |
  |---|---|---|---|
  | `/new/` | 68ms | 140ms | 411ms |
  | band | 7ms | 77ms | 211ms |

  剩下的样式重算来自全页共享的 CSS 动画（雾、页头、提示），不是首屏。光栅化开销没有测，但首屏已经不存在逐帧重画的滤镜了。

## 已知问题

- 线进入 pos > 0.35 开始弯向场 1 之后，磨砂带还停在原来的 14° 位置，和线有一小段错位。好在带会随 --p 淡出（0.3→0.7），观感上像「膜留在原处」，但不严格。
- `.veil` 的两道发丝边让带子有点像一根「玻璃管」，偏具象，可以再淡或去掉。
- 磨砂效果只是静态模糊，不随线的波动起伏，近看能看出带子是直的。
- 问句的左下与醒字底部仍有交叠（沿用 /new/ 的排版）。
