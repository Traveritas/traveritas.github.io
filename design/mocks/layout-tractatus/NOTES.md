# 命题体 · 原型笔记

> 三个平行布局原型之一。整站是一份带编号的文本，像《逻辑哲学论》：没有卡片、没有列表页、没有跳页，
> 打开一条命题，它的内容就在原处展开。只活在 `design/mocks/layout-tractatus/`，不碰 `src/`。

## 怎么跑

```bash
# 在仓库根目录
node design/mocks/layout-tractatus/build.mjs        # 读 src/content/（只读）→ 生成 index.html、切字体、拷图
node design/mocks/layout-tractatus/serve.cjs        # http://127.0.0.1:4612/
node design/mocks/layout-tractatus/.shot.cjs [名]   # 截图到 .shots/（可只拍名字含「名」的几张）
node design/mocks/layout-tractatus/.probe-keys.cjs  # 键盘与前进后退抽查
```

- `?dream` 以梦面打开；地址可直接带 `#1.1`、`#1.13`、`#2`。
- 字体：从 `.cache/fonts/NotoSerifSC[wght].ttf`（`npm run fonts` 下载的那份）按页面用字切出 `fonts/serif.woff2`
  （约 360KB，**保留 wght 400–700 连续轴**，展开时标题墨重 500→620 是连续过渡）；Plex Mono 拷自 `@fontsource`。
- 内容全部是真的：两篇随笔全文、两个项目、三条瞬间（含 5 张原图）。文件：`build.mjs`（生成）、`style.css`、`app.js`、`serve.cjs`。

## 编号

```
（题记）在即将醒来的那一瞬，世界究竟是在成形，还是正在融化？      边距：23:07
1      能说出的，就尽量把它说清楚。        随笔 · 可言说的 SAYABLE · 23:19 浅梦
1.1      在显影处：三个声部          10.03
1.11       侧影之一：Antigravity     ← 展开后才出现：文章的 ## 小节
1.12       侧影之二：Claude
…
1.2      字面与光景 · 全样式样张    09.28
1.21       结构与小节
1.211        三级标题的层级          ← ### 再深一位
2      说不清的，就把它做出来。            项目 · 可构造的 BUILDABLE · 01:11 深眠
2.1      FancyText    2.2  AveritA的昼梦叙集
3      来不及成文的，先留下一瞥。          瞬间 · 即逝的 EPHEMERAL · 02:08 异相
3.1 / 3.2 / 3.3
4      在被叫出名字之前，世界是完整的。    关于 · 存在于此 PRESENCE · 06:31 晨光（终命题，无子项）
```

为什么这样排：

- **四个整数命题＝四个版块，顺序＝主页那一夜的顺序**（浅梦 → 深眠 → 异相 → 晨光）。往下读就是从入夜读到天亮，
  底色也就顺着走一遍，不会倒流。任务说明里「1 ＝ 关于」的写法我没照做：关于放在第一位，底色会从晨光倒回深夜、最后停在暗紫里。
- **题记不编号**：《逻辑哲学论》正文前也有一句不编号的题辞。主页的那句问句正好是这个位置；它的边距里放时刻 23:07，而不是数字。
- **条目是版块的注释（1.1、1.2），小节是条目的注释（1.11），三级标题再深一位（1.211）**——这正是原书的十进制规则：
  位数越多，逻辑分量越轻。文章内部的章节因此自然接进全站的编号里，「1.13」是一个可以直接链接的地址。
- **4 是终命题**，像原书的第 7 条，只有一句话，下面不再有子项；出口（GitHub / 本站源码 / RSS / NEXUS）作为不编号的落款。
- 局限：十进制编号在某一层超过 9 项时会断（原书也有这个问题）。现在每层最多 4 项；随笔多到两位数时，要么按年分组（1.1 ＝ 2026，1.11 ＝ 某篇），要么接受「1.10」这种写法。见「待定」。

版块句是新写的醒面，梦面各有一句（`[data-w]/[data-d]` 双写）：

| | 醒 | 梦 |
| --- | --- | --- |
| 1 | 能说出的，就尽量把它说清楚。 | 我的语言走到哪里，我的世界便亮到哪里。 |
| 2 | 说不清的，就把它做出来。 | 不能说出的，会自己显示出来。 |
| 3 | 来不及成文的，先留下一瞥。 | 每一瞬都是整个世界，下一瞬是另一个。 |
| 4 | 在被叫出名字之前，世界是完整的。 | 世界随时可能消失，又随时重新被记起。（两句都取自主页晨光一场） |

1 与 2 对应原书「可说 / 可显示」的区分（4.116、4.1212）：随笔是说出来的，项目是做出来给人看的。
徽标用 `docs/writing.md` 的版本，瞬间是 `即逝的 · EPHEMERAL`（简报写的「试验场 · 未命名的」没有对应版块，未使用）。

## 版式

- **一条编号边距 + 一条正文列**（桌面 104px + 640px，居中）。编号一律左对齐在边距里、等宽 tabular：
  位数越多，编号越伸向正文——深一层就离字近一点。**正文列不随深度缩进**，深度只由编号位数、字号与墨重表达：
  版块句 30px/500、条目 21px/500、小节 1.22em/620、三级 1.04em/600；编号对应 28 / 13 / 12 / 11px。
- 编号与文字用 grid 的 `align-items: baseline` 对齐基线，不靠手调 top。
- 日期靠右（mono），对称于左侧的编号；条目下一行是一行淡色的「一瞥」（描述 / 瞬间首句 / 瞬间缩略图）。
- 每个版块右侧有一枚极淡的巨大编号（`position: sticky`，随版块停驻、随版块离开）。1180px 以下隐藏。
- 左侧导览轨：每条命题一道短刻线（长度按深度 18 / 10 / 6 / 3px），展开的条目带出它的小节；当前位置的编号沿刻线滑动（420ms），悬停显示标题。
- 窄屏（≤720px）：边距收到 46px，日期落到标题下方，页头里品牌让位给「当前编号 + 标题」。

## 展开的编排

| 时刻 | 发生什么 |
| --- | --- |
| 0 | 编号不动，换成强调墨；标题墨重 500 → 620（可变字体连续过渡，260ms）；一瞥收起（640ms） |
| 0 → 560ms | 行下发丝线从边距的接点向右延到列尾；接点处一枚小菱形弹出（420ms，延 120ms） |
| 40 → 680ms | 展开体高度 0 → 实测值（脚本量 `.pi` 高度，CSS 过渡 640ms `cubic-bezier(.2,.72,.16,1)`），长完换回 `auto` |
| 120 → 1620ms | **显影**：蒙版前沿（注册成 `<length>` 的 `--dev`）自上而下推过 135vh，前沿带 200px 渐隐 |
| 150ms 起 | **逐块落定**：每个块从 `blur(5px)/opacity 0/下移 7px` 聚拢，760ms，块与块错 58ms（前 15 块） |
| 140 → 1240ms | 边距里的线自接点垂下（scaleY） |
| 1700ms | `.settled`：摘掉蒙版与动画，此后零开销 |

收起：420ms 高度回 0，内容 220ms 淡出，线与菱形回收，一瞥回来。
**一次只开一条**：开新的一条时，在它上方展开的那条**即时**收起并补偿滚动（目标行在屏幕上纹丝不动），下方的随动画收起。
目标行不在视野上部时，用 820ms 的缓动把它带到距顶 16% 处。读完点「1.1 收起」会先把行带回视野再收。

阅读时，边距线里有一截强调墨随阅读位置伸长（文章才有）——就是进度。

## 地址与键盘

- 打开写 `#1.1`（pushState），收起写回所在版块 `#1`；前进后退按地址重排展开状态。
- `#1.13` 这种小节地址：先展开 1.1（跳过显影，直接定格），再滚到小节。互链（「关联篇章」、正文里的站内链接）都换成编号交叉引用：
  `→ 1.2 《字面与光景 · 全样式样张》`，点了就地展开那一条。
- 键盘：Tab 进入任何一条后，↑ ↓ 在命题间移动（含已展开文章的小节），Enter / 空格开合；`j / k` 任何时候可用。
  焦点不在命题上时方向键照常滚动，不劫持阅读。
- 抽查结果（`.probe-keys.cjs`）：↓ 聚焦 1.1 → Enter 展开 → ↓ 进到 1.11 → 开 3.2 自动收 1.1 → 后退回 1.1 → 再后退全收 → 前进再开 → 空格开 1.2，全部符合。

## 色板

- 四个时辰 + 入夜：取 `src/styles/hours.css` 的值（入夜取 `home-storyboard.ts` PALETTE 第 0 档）。
- **底色画在文档上**，不是按滚动插值整页底色：每个版块有自己的底与墨，版块之间一段 34vh 的「潮线」（`linear-gradient(in oklab)`）。
  这样做的原因：如果按滚动位置给整页换底，下一段深色版块的浅色字在屏幕下沿时还压在浅底上，看不见；上一段的深字也会在暗底上消失。
  画在文档上，滚过去时屏幕里自然是一段渐变，字永远在自己的底上——而且无 JS 也成立。
- 固定的东西（页头、导览轨、底部一层环境光）由脚本按所在位置取色：页头取顶部那一行，导览轨与环境光取视口中线；
  在潮线里底色线性插值，墨在中点一次翻面。
- 梦面：`--dw`（注册成数字，1.4s 过渡）0 → 1，全站底色混入 6% 暖沙；强调墨从冷灰墨插到琥珀（浅底用 `#ad7634`，深底 `#e2ae6e`）。
- 深色时辰正文字重 450 → 400（深底上同字重显得更粗）；加粗的底衬改用琥珀 20%。

## 醒 / 梦

- 右上「醒 —— 梦」开关（原站是长按入梦检验，原型用按钮代替）。所有双写的词在 0–520ms 内随机先后换面：失焦 220ms → 换字 → 聚焦。
- `:::wake / :::dream` 块：梦侧出现时 900ms 淡入去糊；块外四个角的发丝对焦框（原站是一对方括号，这里只留四角，免得和边距线打架）。
- `((浮起))` 逐字定格漂浮、振幅乘 `--dw`；`{{流光}}` 只在梦面流过。
- 无 JS、读屏、RM 恒醒面。

## 无脚本 / 减动效

- `<html class="nojs">`，头部一行脚本改成 `js`。无脚本时全部展开（截图 `08-nojs.png`：14044px 全文），导览轨与开关隐藏，「收起」隐藏。
- `prefers-reduced-motion`：所有开合瞬时完成，无显影、无逐块落定、无浮起与流光、无滚动缓动；底色分段照旧（它不是动画）。

## 已知的问题 / 待定

1. **编号超过 9 项**（见上）。随笔一多就要决定：按年分层，还是接受 1.10。
2. **潮线里的固定仪器层**：页头在潮线中段取到的是灰色过渡底，品牌字在那几帧对比偏低（截图 09 顶部）。可以改成页头整体用磨砂玻璃底，或在潮线里取较近一端的颜色。
3. **展开长文时一次性量高**：`.pi` 高度 2600px 的文章在 640ms 里长完，前沿之下的大部分其实是被蒙版遮住的——视觉上没问题，但若内容里有未加载的图片，量到的高度会偏小（`.grown` 换回 auto 后会自己纠正，只是动画末尾会跳一下）。正式版应在图片有固定宽高比时才这样做。
4. **「一瞥」对瞬间的缩略图**在亮色版块里没试过（目前只有暗紫段里有图）。
5. **逐字浮起破坏两端对齐**（与原站同一个已知代价），1.2 样张那段能看到字距被拉开。
6. **关于没有正文**：现在 4 只有一句话和落款，符合「终命题」的设定；如果关于页将来有长文，4 要么变成可展开的（4.1、4.2 …），要么保持一句话、把长文挪出去。
7. **项目正文改用宋体**：原站项目正文是黑体（与随笔拉开体温），放进同一份文本里我统一成宋体、小一号（17px）。要不要保留黑体，待看。
8. 原站的 BGM、长按入梦检验、品牌字标轮转、脑电线等都没有接进来。

## 搬进 Astro 需要什么

- **路由**：主页即这份文本（`/`）；保留 `/articles/<slug>/` 等旧地址做静态重定向到 `/#1.1`（或者保留旧内页作为无 JS/分享落地页，并在页内加 `<link rel=canonical>`）。RSS / sitemap 不变。
- **组件**：`Proposition.astro`（行 + 展开体）、`SectionProp.astro`（整数命题 + 徽标）、`Rail.astro`（替代或并入现有 `Gauge.astro` 导览轨——它已经有节点 / 进度 / 目录，最好把「刻线 + 滑动编号」做成它的一个模式，而不是并存两套）。
- **编号**：构建期生成。`src/markdown/ordinal.mjs` 现在给 h2 注入两位序号，需要改成接收「前缀」（如 `1.1`），输出 `1.11`、`1.211`，并给标题写 `id`。条目编号由集合排序决定——**新增一篇随笔会让旧文章的编号整体后移，旧链接 `#1.1` 会指到别的文章**。这是最大的结构代价：要么倒序编号（最早一篇永远是 1.1，新文章编号递增，但最新的排在最后），要么锚点用 slug（`#co-creation-notes`）而编号只作显示。我倾向后者。
- **内容渲染**：全部正文进一页，首屏 HTML 会随文章数线性增长（现在 29KB）。文章多了以后，展开体应改为构建期分片（每条一个 HTML 片段，展开时 fetch，无 JS 时用 `<noscript>` 或保留内页）。
- **色板**：`hours.css` 的四段可以直接用（这里的变量名一致），`--paper` 与潮线渐变要写进 `global.css`；`reality.ts` 已经逐帧写 `--reality-mix`，原型的 `--dw` 换成 `1 - --reality-mix` 即可，强调墨应改用站内 `--amber` 的插值，而不是这里的 `--acc-w/--acc-d`。
- **字体**：原型的可变字重（450、560、620）在站内不存在——站内只切了 500 / 600 两档静态。要保留连续墨重，需要 `scripts/fonts.mjs` 改切可变字体（体积会大一些）；否则把 hover/展开的墨重变化改成 500 → 600 的离散跳变。
- **验证**：照 AGENTS.md 跑 `npm run build`；截图脚本可沿用 `.shot.cjs` 的场景列表。
