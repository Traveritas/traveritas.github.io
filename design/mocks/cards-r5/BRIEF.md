# cards-r5 · 极简：一个边 + 一层半透明

> 2026-11-02。夜片 / 冰 / 背光 三条被认可，共性是**卡片只靠「一道边 + 一点透光差」存在**。
> 这一批把这条推到极简：只留一个边、一层半透明底，看它能不能自己站住。

## 先看清一件事

站上现在的卡**本来就是**「半透白片 + 1px 边 + 3px 圆角 + 一道标题栏 + 重投影」。所以这一批的真正考题不是「做得更简单」，
而是**同样的公式，凭什么和现在那张不一样**。差别只在三个开关：

| 开关 | 现在 | 这一批要试的 |
| --- | --- | --- |
| 边 | 一圈均匀描边（rgba 黑/白） | 边是**明暗关系的结果**：随光走、有方向、或由填充让出来 |
| 填充 | 不透的白 | 真的**透出背后**：亮度与背后有关，不是常数 |
| 投影 | 很重的一层 | **没有**（或只允许卡外 ≤3px 的接触） |

**判据**：和 `design/_shots-accent/50-list-essay.png`（现在的生产卡）并排看，如果分不出来，这条就算失败。

## 锁定的部分

底图是生产页截的（卡片层已隐去），**不许改、不许盖**：

- `shared/plate-1440.png`（1440×900）
- `shared/plate-390.png`（390×844）

- 不能加遮罩、调色、重画渐变，不能遮住栏头与左下那颗星。
- 位置沿用三栏（随笔 / 瞬间 / 项目），内容用 `shared/fixture.md`。
- 卡片之外只允许极轻的接触影或光。

## 这一批只准有的东西

**卡片 = 一个边 + 一层半透明底 + 文字。** 别的都不许：
- 不许圆角以外的形状、不许切角、不许标题栏、不许小图标、不许胶囊标签。
- 不许投影（那条 3px 接触影是上限）。
- 不许用材质贴图（纸纹、颗粒图、噪点图都不行）。半透明底只能是纯色/渐变。
- 文字直接排在上面。

也就是说：这一批的胜负全在**那道边是怎么立住的**。

---

## 甲 · 亮边 `lit-edge`

**边跟着光走。** 卡片比背景略暗一点点，边是亮的：迎光的一侧（左上）最亮、背光的一侧几乎消失。
不许四边一样亮——那样就是描边。给一个方向的数（比如左上 100%、右下 30%）。

## 乙 · 暗边 `cut-edge`

**卡片比背景亮，边压一条暗线。** 像一张纸的裁口：亮面到暗线到背景，一次干净的下落。
暗线 ≤1px、不要渐变拖尾；卡片内部比边亮，但不要均匀——靠近边的地方略沉一点（2–3 L 以内）。

## 丙 · 无实线 `no-line`

**没有一根实实在在的线。** 边由填充自己的梯度让出来：透明底在 6–10px 内从「几乎无」涨到「有一点」，
外面那圈亮/暗只是这个梯度的边角，不是描边。难度最高，也最容易糊——detail 下必须说得清「边在哪」。

## 交付

### 1. `index.html` —— 四种状态

| 状态 | 触发 | 内容 |
| --- | --- | --- |
| 检索 | 默认 | 1440×900：底图 + 三栏六条 |
| 展开 | `#open` | 同一页切到阅读；背后三栏按你的处理 |
| 细节 | `#detail` | 第一张随笔卡放大到 1.5 倍以上 |
| 窄屏 | 视口 ≤ 720 | 换 `plate-390.png`，一列 |

### 2. `notes.md` —— 五段

1. 这道边是什么（一句）
2. 明度差：卡内 / 边 / 卡外底图，三个数
3. 边的参数：宽度、方向、闭合与否
4. 展开：怎么从卡片来到这里
5. 最容易被否的地方
