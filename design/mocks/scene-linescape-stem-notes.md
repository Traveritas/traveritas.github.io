页面：`/mock/scene-linescape-stem/?v=a&pins=1`（只做了 v=a）。

## 思路

- **圆被举到天上**：圆变小（桌面 0.07W，窄屏 0.15W），圆心沿地平线法向（这个世界的「竖直」，向右偏 14°）抬高 0.42H；茎根是圆心正下方那一点地平线。位置避开左上问句与页头导航。
- **主茎**：9 根线，间距不均、中间粗两侧细；横向带与主线同源的 `waveAt` 极弱波动，越往上越弱；一道很缓的弧（梦面更弯）。根部埋进地平线 8px，由近排的遮挡带与雾吃掉。
- **茎线绕成圆**：在冠下约 1R 处以贝塞尔转弯，切进圆周，再沿圆周向上走一段弧后渐隐；外侧的线切入更高、走得更远。茎心那根只送到圆下沿。意图是「圆是这束线张开后绕成的」。
- **雾层切茎**：沿茎的透明度渐变里有两道凹陷（0.25、≈0.47），像雾横过远处巨物。
- **光**：茎心一道宽而极淡的光沿茎送到圆心，与圆后的 CSS 柔光接上。醒面冷蓝、直；梦面琥珀、更弯更软。
- **远处几株**（`STALKS` / `STALKS_M`）：桌面 5 株、窄屏 2 株，2–3 根线，更矮更淡，顶上微张后散掉。用来把主茎读成「一片巨大植物里最高的一株」，不是孤立器物。
- **倒影错位**：保留。倒影改为「茎 + 冠」一起倒进地形：从茎根沿法向压短的一条窄带 + 下方压扁的环带，整体沿地平线错开；圆呼吸时倒影不动。醒面以线的缺口出现，梦面被照成琥珀。

## 性能（桌面 1440×900，醒面，入场后静置 3 秒，dev 模式）

| 项目 | 结果 |
|---|---|
| 主线程样式重算 / 布局 | 0 / 0 |
| 主线程脚本 | 0.1–0.2ms |
| Worker 每帧（30fps） | 平均 5.9–6.3ms，峰值 9–11ms |
| 每帧点数 | 约 7.2k |

茎带波动、量很小（主茎约 1k 点、远株约 0.5k），逐帧画，没有另做位图缓存——缓存省下的不到 0.5ms，换来的是波动和入场「长出来」都要拆成两层，不值。

## 诚实评价

- **梦面成立，窄屏梦面最好**：暖色的茎把光送进圆里，远处几株若隐若现，读得出「一片会发光的巨大植物」。
- **醒面桌面不成立**：小圆举在一根直茎上，构图本身就是「放大镜 / 棒棒糖」，几轮改茎线都没能摆脱；茎线绕成圆的那段与回声圈叠在一起，看不出来。
- **比 v=a 原版少了东西**：圆不再沉进地形、不被近排遮挡，「在风景里」的感觉弱了；圆也小了，失去了原来那种大尺度。
- 远处几株是加分项，但现在太淡、太短，桌面上像几根划痕。

如果保留这个方向，我会试：圆保持原 v=a 的大小与「下半截沉进地形」，茎从圆后面的更远处升起、穿过圆、一直出画面上沿（看不全）；也就是圆不是茎的冠，而是茎上的一个节。这样不会是棒棒糖，尺度也靠「出画」来给。
