# 变体 J · 星环（Star Rings）· 笔记

## 主张
中心一颗星（1:1 同帧热点），外绕三道发丝环；每环一个缺口，缺口正中一粒小星芒；三环各自转、各挂一根弹簧。
承接 G1 重晕光轮的轻与透，去掉它移动时整组脱离热点的问题；替代 I 露中星（水珠偏暗、偏实物，不切主题）。

## 构成
- 星：沿用 I 的四芒内凹星（竖长横短 10 : 6.5，芒不穿过形心），梦态偏 14° 并浮出 45° 次芒。
- 三环：半径 11 / 17.5 / 24.5px，线宽 1 / 0.9 / 0.8，不透明 0.62 / 0.44 / 0.28（由内向外渐隐）。
- 缺口：48° / 40° / 34°（`stroke-dasharray`，圆头）；小星芒在缺口正中（角 −g/2），尺寸 0.26 / 0.22 / 0.19 × 主星。
- 自转：16s 顺 / 27s 逆 / 41s 顺，起始相位错开（纯 CSS，静息 rAF 0）。
- 颜色：`--ring` = `--fg-soft` → `--amber` 由 `--reality-mix` 连续插值。

## 醒 / 梦（纯 CSS，由 --reality-mix 连续驱动）
- 醒：三道正圆，同心。
- 梦：各环倾角 14° / 22° / 8°、压扁 0.10 / 0.14 / 0.18（初版 0.22 / 0.30 / 0.36，用户嫌扁） 成轨道椭圆，并各自偏开 ≤ 2.6px——永不再同心。
  自转在压扁之内进行，所以缺口与小星芒沿椭圆轨道走。

## 动力学
- 每环一根二维欠阻尼弹簧：ω 26 / 19 / 14（内快外慢），ζ 醒 0.62 / 梦 0.5；离星软上限 4 / 7 / 10px（tanh），硬上限 ×1.6。
  移动时三环依次被甩开，停下后一圈圈归位；星永远在内环里。
- 滚动：三环被页面「带」一下（外环带得多），各自弹回。

## 状态
- 链接：三环依次张开 1.16 / 1.21 / 1.26，星 1.18，环心向链接中心吸附 ≤ 6px。
- 正文 / 输入：三环向星收拢隐去，一道 1 × 22px 插入线浮出、中间留 9.2px 空给星（接替系统 I 形指针；梦态随星偏 14°、转琥珀），星敛到 0.55。
  （初版让内环压成竖线，但压扁的环仍在自转，缺口与小星芒在细条里转出断口和毛刺，已弃。）
- 可拖：三环横宽 1.1 × 0.9，星转 45°。
- 点按：星一缩一回；三环由内向外错开 45ms 依次一缩一回。
- 长按：三环拢向星（外环收得多），星随进度转过半圈；闩锁瞬间星填成 ◆、三环一齐向外化开（环闪），随后从外面重新收回。

## 实测
- `.shot-cursor.cjs cursor-J-star-rings J`：控制台错误 0 · 页面错误 0 · 失败请求 0。
- 静息 5s：`rafLast5s: 0`，`will-change: auto`；逐帧只写 transform / opacity。
- 收敛判据按「环心离目标」而非「离指针」（链接吸附时目标带偏移），I 稿踩过的空转已规避。

## 最不放心的
1. 醒态三道正圆同心，间距又接近等差，静止时仍有一点「靶」的影子；缺口与由内向外渐隐在压它，若仍嫌像，可把间距拉得更不均（如 10 / 16 / 25）。
2. 外环 49px，在密集链接列表上扫过时的存在感。
3. 小星芒只有 3–5px，在亮底上主要是点缀，不承担任何信息。
