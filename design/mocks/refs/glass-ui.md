# 玻璃与层次：半透明面板怎么做得好看

> 2026-11-02 · 服务 `cards-r5` 那道题：固定底图（冷灰 / 薄暮紫 / 深蓝三栏 + 3px 网点）、1.25px 星、衬线标题 + 系统无衬线正文。已经试过「一个边 + 一层半透明底」，结论是「有点意思但差点味道」。
>
> 这份调研不解决「更透」，只解决「像一块材料」。截图均为 1440×900，本机 Chrome 抓取，见 `shots/`；页面会变，数值以截图为准。文中的 L 指 0–255 的亮度（Rec.709 luma），只在同一张截图内比较。

## 结论

1. **味道在边的两条线。** Craft 的胶囊只有 1px 内高光和 6px 软影，没有外描边；Sketch 连高光都不要，靠 39L 的明度跳变。单独一条线是描边，两条线才是厚度。
2. **白 alpha 在三色底上会分裂。** 同一层 `rgba(255,255,255,.3)` 压在冷灰、紫、深蓝上，是三种面板；Dia 的解法是去饱和玻璃——黄底进去，灰面出来。
3. **最便宜的一招是字。** Dia 的 40px 白衬线压在黄上只有 1.5:1，但它是标题，成立；正文守住 7–8:1。大字可以退成一层色，小字不行。

## 深读 5 条

### 1 · Craft — 压在插画上的玻璃胶囊

![Craft 胶囊导航](shots/craft-pill.png)

- **边**：52px 高、26px 圆角。顶缘 1px 高光 `(228,242,249)`，比紧邻填充亮约 22L；底缘 `(244,250,253)` 是整条最亮的一行；左右缘同为 1px 亮线。外侧没有描边，只有下方约 6px 的软影（天空从 `(139,191,217)` 压到 `(126,179,205)`，约 −12L）。
- **面**：白色等效 alpha 从顶部约 0.4 渐到底部约 0.8（按背后天色反推）。透过来的蓝没有被中和，所以整块偏冷。看不到模糊——底本身是平渐变，糊不出信息。
- **字**：导航 14px 系统无衬线，深灰 `(60,67,70)`，对胶囊 8.0:1；字距 0；上下各留约 19px，字只占胶囊高度约 1/4。
- **层次**：浮起，但不压暗背景；厚度全给上下两条 1px 线。它和插画的关系是「放在上面」，不是「嵌进去」。
- **味道在哪**：像一片被背后的光透亮的薄片——底缘比顶缘亮，光是从下面来的；磨砂塑料不会有这个方向。

### 2 · Dia — 黄色场上的灰玻璃窗

![Dia 浏览器窗](shots/dia-window.png)

- **边**：窗口上沿一条 1px 中性灰线 `(160,165,159)`，不是白高光；侧栏与正文之间 1px 亮线 `(237,232,209)`。无外描边，边缘靠「黄 → 灰」的色差立住。
- **面**：背后纯黄 `(255,203,48)`，侧栏出来 `(206,209,199)`：R −49、B +151，黄被洗成暖灰。这不是加白，是把饱和度抽走；正文区 `(249,240,208)` 仍是暖白，同一扇窗里因此有两种「面」。
- **字**：顶部衬线句 40px，纯白压在黄上，对比约 1.5:1——大字成立，小字不行；背后约 360px 的「Dia」只做形；窗内系统无衬线 12–13px，侧栏字对灰面约 7:1。
- **层次**：三层：黄场 → 约 360px 字母 → 窗（浮）。窗沿切过字母，字母被分成「前 / 后」两段；没有用投影，层次是遮挡关系给的。
- **味道在哪**：它没把黄变白，而是把黄变灰——像隔着一层脏玻璃看阳光，不是贴了一张白纸。

### 3 · Death Stranding — 压在场景上的信息层

![Death Stranding 货运面板](shots/ds-cargo.png)

- **边**：列表顶一条 1px 亮线 `(161,211,220)`，只画在标题与内容之间；行与行之间没有线，靠色块。面板无外框、无圆角。
- **面**：面板底 `(12,21,27)`，比周围场景暗约 40–60L；行块是实色蓝 `(18,91,150)`，不透明；无模糊，硬边。
- **字**：标题约 30px 大写、字距约 +0.06em；行 20px；标签 10px 大写 +0.1em；白字对深底 16.9:1，标签约 13:1——它用「足够暗的底」换对比，不靠描边。
- **层次**：嵌在场景里（HUD），不是浮起：无投影、无圆角、无高光。信息层与场景在同一平面，只靠亮度分离。
- **味道在哪**：线只画一条，剩下的交给色块和字距；像在空气里印了一层信息。

### 4 · Linear — 用表面亮度做层级

![Linear 界面](shots/linear-surfaces.png)

- **边**：1px 边框 `(37,39,40)`，比侧栏 `(23,25,26)` 亮约 14L；窗口上沿同一条 `(35,36,37)`。无高光、无外阴影。
- **面**：三层不透明：侧栏 `(23,25,26)` → 主区 `(28,28,29)` → 浮窗 `(27,28,29)`；相邻只差 2–5L。完全不用 blur。
- **字**：13–14px，三级灰：主文约 16:1、次文 `(138,143,152)` 约 5.2:1、标签更低；字距 0，行高约 1.4。
- **层次**：堆叠，不是浮起。层级 = 表面亮度 + 交界处的 1px；侧栏最暗，主区亮 5L，浮窗与主区几乎同亮，靠边框和位置分离。边框只出现在「面与面」之间，不围整窗。
- **味道在哪**：层级是算出来的，不是画出来的——每层只亮一点点，整块像被切削过的深色材料。

### 5 · Sketch — 没有边的窗

![Sketch 窗口](shots/sketch-window.png)

- **边**：没有描边。页面薰衣草 `(218,202,220)` 到窗顶 `(246,246,246)` 只有 1px 过渡，ΔL≈39；左缘同样从 `(238,205,232)` 直接到白。上缘和左缘都没有投影。
- **面**：不透明 `#F6F6F6` 顶栏 + 纯白侧栏；不靠透明。窗外的渐变一直延续到窗边，所以窗像「挖出来」的。
- **字**：衬线标题约 112px，两行，行高约 0.95；正文 17px / 约 1.6 系统无衬线；两者字号差 6.6 倍。
- **层次**：浮起但不用投影，靠明度跳变；窗内再分白侧栏 / 浅灰画布，靠明度差，不加阴影。
- **味道在哪**：它证明「不透明也能浮」——只要边的明度跳变够干净。玻璃不是浮起的必要条件。

## 可借的三招

### 招 1 · 双线边：1px 内高光 + 0.5px 外暗线

单条内高光 = 描边；内高光 + 外暗线 = 厚度。Craft 与 Sketch 是两端——一个靠高光，一个连高光都不要——卡片取中间。

```css
.panel{
  border-radius: 3px;
  box-shadow:
    inset 0 1px 0 rgba(255,255,255,.85),      /* 上缘 1px 高光 */
    inset 0 0 0 .5px rgba(255,255,255,.30),   /* 整圈 .5px 内亮线 */
    0 0 0 .5px rgba(0,0,0,.22),               /* 外沿 .5px 暗线 */
    0 1px 1px rgba(0,0,0,.10);                /* 接触影 */
}
```

数值：高光 alpha `.8–.9`，内亮线 `.25–.35`，外暗线 `.18–.25`。两条线的宽度都 ≤1px；到 2px 就开始像描边。1x 屏上 `.5px` 会取整成 1px，区分靠 alpha，不靠宽度。

要让边随光走，再叠一层方向性亮线（左上 100% → 右下 0）：

```css
.panel::before{
  content:"";
  position:absolute; inset:0;
  border-radius:inherit;
  padding:1px;
  background:linear-gradient(135deg,
    rgba(255,255,255,.55) 0%,
    rgba(255,255,255,.12) 38%,
    rgba(255,255,255,0) 62%);
  -webkit-mask:linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  -webkit-mask-composite:xor;
          mask-composite:exclude;
  pointer-events:none;
}
```

方向性亮线只亮一侧，必须配招 1 的外暗线，否则右下会「没闭合」。

### 招 2 · 去饱和玻璃：只留底图的一点色相

Craft 是加白（.4 → .8），Dia 是抽色（黄 → 灰）。底图是三色横条时，第二种更稳。

```css
.panel{
  background: rgba(238,238,236,.10);
  -webkit-backdrop-filter: blur(8px) saturate(.45) brightness(1.02);
          backdrop-filter: blur(8px) saturate(.45) brightness(1.02);
}
```

- `blur 6–10px`：够把 3px 网点柔化，不够把三栏糊成一片。再大就只是在烧 GPU。
- `saturate .35–.55`：冷灰 / 紫 / 深蓝被拉进同一个灰域，同一张卡在三栏上才像同一张。
- 白色 alpha `≤ .12`：到 .2 就变「白纸」，底图的紫和蓝被盖死。
- 它只统一色相，不统一明度；三栏的明度差还得靠一条 3–5% 的中性渐变或局部压暗补。
- 不要往面板里再加噪点：底图的网点已经是颗粒，两层颗粒会打架；质感靠透明度和色相，不靠 texture。

静态底图的更省事版本（Mica 的思路）：不模糊，只采样一次底图平均色做 tint。

```css
.panel{
  background: color-mix(in oklab, var(--plate-avg) 92%, white);
}
```

没有 `backdrop-filter`，滚动和缩放都不会闪，代价是「背后有什么」只剩一个大意。

### 招 3 · 让字成为一层：大字退色 + 大字穿层

Dia 的 40px 白衬线只有 1.5:1，靠字号成立；正文 12–13px 守住 7:1。同一张卡里，两种字用两套对比度。卡片上不必做到 1.5，2:1 上下就够；再低就看不见了。

```css
.card .title{
  /* 与卡面同色系，退一档；不要纯黑/纯白 */
  color: color-mix(in oklab, #171a21 32%, var(--card-bg, #e9e7ef));
  /* 约 2:1，只在 ≥32px、短句时用 */
}
.card .body{
  color: #1a1c22;   /* 对卡面 ≥8:1 */
}
```

卡面如果跨三栏，标题色要跟着卡面走：写死 `rgba(255,255,255,.62)` 会在深蓝栏上消失。

再放一个 3–4× 的衬线字形在卡后，被卡沿切过——不花一个投影就多一层：

```css
.plate{ position:relative; isolation:isolate; }
.plate .ghost{
  position:absolute; z-index:0;
  left:-40px; bottom:-140px;
  font: 420px/1 var(--serif);
  letter-spacing:-.04em;
  color: rgba(255,255,255,.10);   /* 深底用白；浅底换 rgba(20,22,30,.06) */
  pointer-events:none;
}
.card{ position:relative; z-index:1; }
```

- 字号 3–4× 标题，opacity `.08–.12`；
- 必须被卡沿切到；完整地放在卡外就只是水印；
- 颜色取底图的邻近色，不要纯白。你们那颗 1.25px 的星放大 20 倍放在卡后、只露左下一角，也是同一招。

## 一条别学

**把「玻璃」做成三件套：白 alpha + `blur(20px)` + 一圈均匀白描边。**

这是这类设计最常见的失败，在你们的底上尤其糟：

1. 底图是平渐变 + 网点，`blur(20px)` 没有多少细节可读，只会把网点抹成一块脏色；视觉收益接近 0，GPU 照付。
2. 同一个白 alpha 横跨冷灰 / 紫 / 深蓝三栏，面板在三栏上是三种亮度；文字对比度跟着漂移，浅栏发灰、深栏发黑。
3. 均匀 1px 白描边 + 大投影，让卡片像「贴纸」，不是「材料」。

玻璃的本体是边和明度关系；模糊只负责「让网点消失」这一件事。
