听感与空间美学标杆

  • Apple visionOS UI：玻璃质感极轻触点 + 真实空间早反射，空灵但不抢视线。
  • Monument Valley / Sky 光遇：音高锁死五声音阶与主调，交互即和声的一部分。
  • Zelda BotW / TotK & Gris：水滴、木石、风铃与清澈长尾混响的克制平衡。
  • Sony PS5 系统 UI：近场干脆微触点 + 切页远场环境扩散的层次分层思路。

现成 CC0 素材库 & Web 工具链

  • soundcn (soundcn.xyz)：面向现代 Web UI 的开源精致微交互音效合集（支持一键引入）。
  • Kenney Interface Sounds (CC0)：100+ 极干净的免费 UI 触发/开关底材，适合二次加空间混响。
  • Freesound (CC0 筛选) / Sonniss GDC Free：真实水琴窟、玻璃叩击、风铃与环境脉冲采样宝库。
  • Web Audio 合成 / 轻量 OGG+MP3：本项目已在 sound.ts 预留 fx 通道，单套压缩后仅 ~150KB。
