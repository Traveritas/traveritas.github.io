# 光标（Cursor）· 方向记录与否决项

**本轮简报**（2026-09-24，用户口述）：形状组成**简约、平面**；精美之处由**动画与机制**承担，
不靠材质（渐变、光晕、次表面散射、折光）。

---

## 一、已否决：测量 / 探针类具象隐喻

用户明确表示不喜欢这一类具象的「测量仪器」概念。**勿再提案**。否决范围包括：

- 准星 / 十字准星，以及把 `⌜ ⌟` 微刻角标放大成仪器感的「观测者」叙事；
- 探针、示波器、脑电探针笔尖、显微透镜（loupe）；
- 用「读数 / 测量 / 增益 / 标尺」来解释光标行为的任何说法。

**连带作废**（均为口头提案，未落稿）：以仪器为骨架的「准星游丝」与「示波探针」两条方向。

**不受影响**：把「构块场」母题缩到指针尺度的构造 / 拼装语汇（正交或 14° 短斜线、
按 6px 网格量化吸附、静止时于几种小拓扑间重排）——它不是仪器隐喻，仍在候选之列，
但定位感与点击精度弱于「物」类方案，只宜作为梦态形态。

## 二、需留意的边界

- `src/components/home/RealityGuide.astro` 的 `⌜ ⌟` 角标与 6px 琥珀微核是**既有装饰语言**
  （首次访问的长按引导），不是给光标预备的仪器叙事；光标引用它须停在「同族纹理」这一层，
  不要顺势讲成测量。同理，`src/components/chrome/Eeg.astro` 的波形是背景氛围，
  不宜引出「光标即探针」的联想。
- 材质克制：平面、单色、发丝级线宽；禁止逐帧 blur / box-shadow / filter（同为性能要求，
  参见 `e89186a` 的合成层与硬件变换做法）。
- 双态应由 `--reality-mix` 的**形变**承担（同一个光标两个面），不是两套图形。
