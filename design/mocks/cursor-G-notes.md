# 方案 G · 水汽微晕（Mist Dew / Perception Aura）· 实测笔记

## 主张
晨雾凝露般的低饱和径向微晕 + 1:1 热点微核绝对定锚：游弋时 3.6s 超慢呼吸，行进时流体阻尼拉伸水滴形变，长按向心收拢并在按满瞬间淬炼定格为实心结 ◆。「光标是一滴呼吸的水汽微芒，醒时如银雾清朗，入梦则泛琥珀微温」。

## 醒 / 梦 各自的机制与关键参数
- 元素结构：`.mist-core`（3px 圆润微露热点，1:1 同帧零延迟）+ `.mist-aura`（流体水滴形拉伸容器）+ `.aura-dew`（直径 44px 晨雾微露，节点池固定 6 个）。
- 醒态：阻尼 $\tau = 90\text{ms}$，运动拉伸 clamp $\le 1.25$；冷灰银雾低饱和微晕，正向对齐屏幕轴；清醒沉静，落定即止。
- 梦态：阻尼 $\tau = 120\text{ms}$，带流体悬停感；暖沙琥珀微温，基准整体偏转 $14^\circ$；两态在静止帧差（`?freeze=1`）下角度与色温一眼可辨。
- 静息机制：游弋态由纯 CSS `mistIdleBreath` 驱动 3.6s 超慢周期微呼吸（半径 16px~22px 柔和变化），完全不占用 JS rAF（静息 5s 内严格 0 次）。

## 与其余各案的机制差异
- **vs A 残点 / D 错位双影**：A 为离散粒子拖尾、D 为单纯位移错位；G 拥有连续自洽的流体水汽微晕场，具备呼吸感与水滴表面张力形变。
- **vs B 四点环 / E 菱芯光圈**：B/E 依赖硬质几何折角线条，近距离容易带入准星/取景框联想；G 彻底规避刺眼霓虹与单薄干瘪线条，以半透明树脂晨雾质感提供极其温润的触感。
- **vs C 悬丝**：C 单根发丝在复杂背景下辨识度偏弱；G 在正文时自动横向压缩为 15% 亮度纤细光隙绝不抢字，在链接处通过柔和引力吸附（Magnetic Soft Snap）泛出琥珀暖光温柔衬托目标。

## 实测
- **控制台错误 0 · 页面错误 0 · 失败请求 0**（`.shot-cursor.cjs` 实测）。
- **热点同帧偏差**：`dx: 0 · dy: 0 · dist: 0.00px`（同帧口径，偏差为 0 帧）。
- **静息性能**：移动停止 800ms 内完全收敛；静息 5.2s 增量 `delta: 0 · rafLast5s: 0`；静息 `will-change = auto`。
- **逐帧写入属性**：严格只写 `transform` 与 `opacity`，无每帧颜色/尺寸/样式变更。
- **状态矩阵覆盖（12 项实测）**：
  1. `rest`：3.6s 超慢低频呼吸，微晕半径 16px~22px 柔和变化；
  2. `move`：tau ≈ 100ms 流体阻尼跟随，沿速度方向水滴形拉伸（scaleX $\le$ 1.25）；
  3. `hover-link`：微晕展开至 1.35x 并产生引力吸附（偏移 $\le 8\text{px}$），泛出琥珀温光（图 `05-hover-link.png`）；
  4. `hover-text`：微晕亮度自动淡化至 15%，横向压缩为纤细光隙，退让排版字面（图 `06-hover-text.png`）；
  5. `input`：细致水汽微隙，微核半透不遮挡光标位置；
  6. `drag`：微晕呈现贴附张力态（横向轻微拉宽、张力增强，图 `10-drag.png`）；
  7. `click`：微核瞬间微缩至 0.6x，外晕荡出 2px 扩散微波后收拢（图 `07-click.png`）；
  8. `hold1300 / hold2200`：向心收拢（Inward Implosion），微晕向中心收束至 0.42x，呼吸加速凝聚（图 `08-hold.png`）；
  9. `latch`：按满瞬间爆发极短暂琥珀光华，微核淬炼定格为 45° 实心结 ◆（图 `09-latch.png`）；
  10. `scroll`：微晕略微收拢稳定视觉焦点；
  11. `leave`：随外壳 `fx-cursor-out` 柔和淡出；
  12. 降级：`?cursor=off`、`?reduced=1`、`forced-colors`、触摸事件全线安全回退原生光标（图 `11-off.png`, `12-reduced.png`）。

## 最不放心的
1. 链接悬停引力吸附（Magnetic Soft Snap）在密集多链接快速扫过时需避免生硬拉扯；当前通过限制最大偏移 $\le 8\text{px}$ 与系数 0.22 保持柔和衬托，手感温润自然。
2. 梦态水汽微晕在 paper 浅米色背景下的对比度；已通过多层径向微晕底纹与微核琥珀温光加固层级。
