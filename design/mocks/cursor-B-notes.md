# 方案 B · 四点环比 · 笔记

## 主张
缺口是主角：四段 1px 短弧之间的四个缺口随指针速度开合，缺口图样整体以与速度成正比的角速度进动。醒＝对齐的环（缺口合拢、0°/90°、进动停）；梦＝从未合拢、仍在慢慢转的环（14°、缺口不等宽、进动常在）。

## 醒 / 梦
- **醒**：段角 0/90/180/270°；静息弧长系数 sx=1.000（弧 7.00px，相邻 1px 圆端只余 0.64px 缝 → 读作一整只环）；满速 sx=0.696（弧 4.87px、缺口 3.77px，半径同时 5.5→5.94px）；进动恒 0；静息交 CSS：`.cs-ring` opacity 呼吸 5.6s（墨量），几何不动。
- **梦**：段角 14°+90°·i，逐段再抖 +1.1/−0.9/+0.7/−1.2°；静息 sx=0.82/0.91/0.76/0.87（弧 5.3–6.4px、缺口 2.3–3.4px 不等宽）；满速各自再缩（弧 3.7–4.4px）；进动 ω ∝ 速度、上限 45°/s，静息交 CSS 30s/圈＝12°/s（实测 1.6s 内转角 21.5°→40.9°），并叠 `.cs-arc` 弧长呼吸 7.4s（±6%）。
- 时间常数：速度平滑 τ=55ms；缺口开 τ=60 / 合 τ=175ms；状态过渡 τ=90ms；双态 τ=110ms；dt clamp ≤1/30s；缺口差 <0.06 直接落位（收敛 0.8–1.0s 后 rAF 归零）。

## 与其余三稿的机制差异
- **A 残点**：状态量是**位移**（按行进距离落点、按距离定寿命）；B 是**角度与弧长**，与位移无关——指针停住后梦态仍继续转。
- **C 悬丝**：钟摆动力学（弹簧角、过冲、落回 −4°）；B 无摆、无锚、无单笔画，唯一角度是缺口图样的进动角。
- **D 错位双影**：同一图元的两份副本沿残余位移错开（偏移量即透明度）；B 只有一只环，四段不是可分离副本，梦的「没对齐」＝缺口不等宽 + 整体 14°。

## 实测
- 共享脚本 17 张：`node design/mocks/.shot-cursor.cjs cursor-B-segment-ring B …` → **控制台错误 0 / 页面错误 0 / 失败请求 0**。01/02 两张静止帧追加了 `probe=1`：外壳只在该模式下真的移动鼠标，四重门控才会打开（`ui=0` 仍藏面板），否则无头环境里层根本不显示；其余状态机位已在 `?state=` 上钉住。
- 自建脚本：`%TEMP%/.cursor-B-check.cjs`（写入审计 / 静息 / 12 状态真实交互 / 降级四连 / 像素差）、`%TEMP%/.cursor-B-real.cjs`（1:1 与 6× 放大裁切）；原始数据 `selfcheck.json`、`report.json`、`pinned-table.json`。
- **热点偏差 dx 0 / dy 0 / dist 0.00px**（同帧口径，ageMs 62–75；热点＝本层 0×0 根，恒在指针处）＝ **0 帧**。
- **静息 rAF**：最后移动后 ≈0.8–1.0s 收敛，其后 5s 窗口 **0 次**（面板 rafLast5s=0；rafTotal 44→44 不再增长）。静息 `#cursor-slot` 的 **will-change = auto**；`slotEl=19` 恒定（无池、零每帧分配）。
- **逐帧写入属性**（MutationObserver 审计 1200ms / 73 帧 / 345 次 style 变更）：**只有 transform(329) 与 opacity(13)**；will-change(5 次+3 次清除)、class(1)、animation-delay(1) 均只出现在状态进出那一帧；无 width/height/border-radius/filter/box-shadow/background/color 写入。
- **两态静止帧差异只在环自身**：44×44 取样 inkPx 30、bbox [694,394]–[706,405]；6× 裁切 inkPx 1296、bbox 72×72px（＝12×12 CSS px）。
- **12 项状态矩阵**（真实交互实测，逐项几何见 `pinned-table.json`，图见 `zoom-*.png`／`real-*.png`）：①静息 sx=1、rotate0、rAF0 ②移动 sx 0.77、半径 5.94、梦态另加 42° 进动 ③悬停链接：四段 op 0.005 退场、四角标 op 0.994、盒心外扩 1.42×（臂宽仍 1px）④悬停正文：上下两段 op 0、左右 op 0.382、半径 7.97、弧长 0.62×（字面无线）⑤输入框 ring scale 0.5、op 0.28 ⑥拖拽：角标 op 1、整体 op 0.55 ⑦点按 ring scale 0.818（半径 −1px）→ 1.055 回弹，300ms ⑧长按1300：半径 8.72、线程轴两段 op→0、缺口收拢 ⑨长按2200：同上，且保留梦的不等宽缺口与进动（实测 rotate 16.44°）⑩闩锁：四段 op 0.997/0.983（整环满墨一拍）、半径 5.94、280ms ⑪滚动：缺口一次写入归 1（实测 segSx 全 1）、进动冻结 220ms 后恢复 ⑫离开：root op 0（＋外壳 fx-cursor-out 淡出，实测 slot opacity 0.0097 过渡中）。
- **降级四连**：`?cursor=off` → url 门 0 → fx-cursor-on 0、rafTotal **0**、computedCursor auto；`?reduced=1` → rm 门 0 → 同上 rafTotal 0；`forced-colors: active`（CDP Emulation）→ fc 门 0 → fx-cursor-on 0、rafTotal 0；`pointerType=touch`（CDP 真实触摸）→ fx-cursor-on 摘除、state=off、slot opacity 0、rAF 停；再移动真鼠标 → 恢复。
- **是否像准星**：静息／移动／长按／闩锁**不是**（无穿心线、无形心点，静息读作「○ 上四个极小缺口」）。唯一近亲是 **hover-link 的四角标**（`real-link6x-light-mix1.png`）：环散成四角，四向对称的锁框读感确实存在；压制手段＝环心无任何元素、无任何穿心线、两臂不等长 5 / 3.4、外角 3px 圆（非直角）。**在行内文字链上四角会与字缘相擦**，状态仍可辨（环消失→四角）但不硬朗。

## 最不放心的
1. hover-link 的四角标是本稿离「观测框／准星」最近的一帧；若裁决认为仍太近，换语汇已超出本稿槽位允许的改动范围。
2. 外壳的特效层只有 −4° 抽线（`.fx .thread`）＋一弹，**没有成结 ◆ 与环闪**（`reality.ts` 有，外壳未搬）。故未自造站点特效：长按／闩锁的表达全部限制在环自身（张口 → 整环一拍）。若日后把 ◆ 搬进来，环心需再让出一次。
3. 弧长用 `scale(sx,1)`（绕弧中点）实现：在「逐帧只准动 transform」的前提下无法同时保证严格圆弧与变弧长，缺口最大时弧端半径比中线小 ≈0.5px（弧尖略内收）。
4. 梦·静息**没有**让缺口完全合拢（0.76–0.91）：否则两张 freeze 帧只差一次 14° 旋转、几乎不可辨。这与 brief「静止时缺口合拢成一只完整细环」的字面轻微冲突，是为「两态必须一眼不同」做的取舍。
5. 键盘长按（Shift+Space）外壳从视口中央开始抽线，而我的环停在指针最后位置：张口会被 `reality-holding` 驱动，但位置不跟到中央。
6. 输入框态是「缩到 5.5px＋28% 墨量」，插入符仍在环的覆盖范围内（`live-input-caret.png` 可核），不是完全让开。
7. 「滚动」在静态帧上最弱（截图 13 只体现缺口合拢＋环 1.06）；它的真实读法是动态的（移动中缺口本应张开，滚动即合拢），静态截图承载不了。
8. 未做真实 NVDA/VoiceOver、200% 缩放、真实触摸本混合设备的门槛测试（brief §6 列为发布前内部欠账）；本轮只跑了 headless 下的四重门控与 `pointerType` 模拟。

## 复核（主会话 · 2026-09-24）
- 共用脚本 `.shot-cursor.cjs` 已由主会话修三处：稿名不再重复补 `.html`；**每次拍摄前都合成一次真实鼠标移动（终点固定 760,470）**；`report.json` 改为合并写入。故「01/02 必须追加 `probe=1` 才能开门」**已作废**，01/02 已重拍为无 probe 版本（零错误），四稿光标落在同一位置可横向对读。
- 主会话独立看图复核：`zoom-01-wake-rest.png` / `zoom-02-dream-rest.png` 确认四段短弧的缺口几何干净、无穿插，两态都有可辨差（0°/90° 对齐 vs 14° 偏转 + 暖色）。
- **补一条本稿自评未覆盖的风险**：这个形状的近亲其实不止「准星/观测框」，还有更常见的「**加载指示器**」（四段缺口环＝spinner 的通用语汇）。在站点语境下它靠 14° 偏转与暖色与 spinner 拉开距离，但「一直在慢慢转」的梦态会加强 spinner 联想。若采用，梦态进动建议走**阶跃**而非匀速（与站点「知觉抽帧」同族），把它从「转圈等待」推到「世界在慢慢重排」。
