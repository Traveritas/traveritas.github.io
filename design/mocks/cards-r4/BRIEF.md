# cards-r4 · 再换几个感觉

> 2026-11-02。前一批的两条（冰 / 背光）通过了：方法对，剩下的只是「感觉」够不够多。
> 这一批还是同一套规矩——**底图锁死、只做卡片层、先一句感觉句再用三个参数落下**，换三个新的感觉。

## 已通过的两条（基准，别退回旧路）

- **冰**：边缘一道偏折（跨过边缘的线错开几像素再合拢）、上厚下薄、表面有脊与裂纹；亮面那栏比底图压暗 16 个 L 单位。
- **背光**：卡内 86.4 / 边缘 94 / 卡外 79.5，四面闭合，往里一条 9–15px 的衰减带；零描边、零投影。

这两条证明了一件事：**卡片要靠「材料可感的差」立住，不是靠描边、投影、模糊。** 新的三条也不许用这三样。

## 锁定的部分

底图是生产页截的（卡片层已隐去），**不许改、不许盖**：

- `shared/plate-1440.png`（1440×900）
- `shared/plate-390.png`（390×844）

- 不能加遮罩、调色、重画渐变，不能遮住栏头与左下那颗星。
- 卡片位置沿用三栏（随笔 / 瞬间 / 项目），内容用 `shared/fixture.md`，不许改写。
- 卡片之外只允许极轻的接触影或光。

## 方法：感觉句 → 参数

| 参数 | 要回答什么 |
| --- | --- |
| 明度差 | 卡片比它背后的底图亮多少 / 暗多少（给数值） |
| 边缘 | 硬还是软、多宽、闭不闭合、亮边还是暗边 |
| 质感 | 颗粒、起伏、干湿、冷暖 |

**不要用材质名词当理由。**「因为它是纸所以有毛边」不成立；「要有 12% 不透明度的湿痕和一道 0.5px 的毛边，所以它像被水浸过的纸」成立。

两条硬指标（每一批都查这个）：
- **列表要能扫读**：三栏并排能分出六条、能看出点哪里。
- **不碎**：远看是一个安静的版面。

## 甲 · 夜片 `nightfall`

**感觉句：像从夜里裁下来的一小块。**

- **比底图暗**，暗一档；不靠阴影，靠一道极细的亮缝把它和背景分开。
- 和「背光」正好相反：那条是比背景亮、边缘亮；这条是比背景暗、边缘也亮（缝）。两条并排时能看出差别才算成立。
- 难点：昼面那栏是亮的，暗块放上去会很跳——要么处理得住（让它像"一块夜被贴在这里"），要么在 `notes.md` 里承认它只在夜面成立。

## 乙 · 湿纸 `damp`

**感觉句：像被水浸过又干了的一张纸。**

- 暖、起皱、边缘有湿痕（一圈比纸心深/浅的痕）。
- 光在皱上折：皱是起伏，不是纹理噪点。近看能看出纸被水推过的那些弧度。
- 字压在纸里，像被纸吸住——不是浮在表面。
- 难点：容易变成"手账/旧纸滤镜"。判据是**湿痕和皱是具体的形状**，不是一层 overlay。

## 丙 · 折痕 `crease`

**感觉句：像折过一次的。**

- 有一道**脊**：光沿脊走，脊两侧明暗不同（一侧迎光、一侧背光）。
- 脊的位置定住卡片的"体积"——卡片不是一片平的膜，是被折过的东西。
- 展开时这道折变成中缝：面板从折线两侧摊开，正文沿着脊排。
- 难点：脊容易变成一条装饰线。判据是：**把脊两侧的明暗差单独拿出来看，它仍然有体积。**

## 交付

### 1. `index.html` —— 四种状态

| 状态 | 触发 | 内容 |
| --- | --- | --- |
| 检索 | 默认 | 1440×900：底图 + 三栏六条（随笔 2 / 瞬间 2 / 项目 2） |
| 展开 | `#open` | 同一页切到阅读；背后三栏按你的感觉处理 |
| 细节 | `#detail` | 第一张随笔卡放大到 1.5 倍以上放画面中央，材料要看得清 |
| 窄屏 | 视口 ≤ 720 | 换成 `plate-390.png`，一列 |

### 2. `notes.md` —— 五段，短句

1. 感觉句（一句）
2. 明度差（给数值）
3. 边缘（硬度 / 宽度 / 闭合）
4. 展开：怎么从卡片来到这里
5. 最容易被否的地方

### 3. 截图

```bash
node design/mocks/cards-r4/shot.cjs <你的案子>
```

四张到 `.shots/`：`<案子>-{list,open,detail,mobile}.png`。

**交付前自己至少看两轮**；判断标准是：卡片像不像本来就在这张底图里，以及 detail 下能不能指着说「这就是那个感觉」。
