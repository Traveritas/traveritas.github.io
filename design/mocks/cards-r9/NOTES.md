## 一、换了什么

**分家。** 以前卡面是 canvas 画的一整扇窗（半透明薄片 + 1px 边 + 迎光 + 标题栏下的发丝线），
投影与磨砂由 CSS 的 `box-shadow` / `backdrop-filter` 补。现在 canvas 只画纸上的字（标题栏那一行、标题、简介、标签、配图），
材料搬到 CSS：

| 材料 | 做法 |
| --- | --- |
| 面 | `linear-gradient(180deg, var(--w-face-a), var(--w-face-b))` —— 底图的一次值偏移，上轻下重 |
| 上下两条边 | `box-shadow: inset 0 .6px 0 hi, 0 .6px 0 lo` |
| 收口 | `0 0 0 .5px ring`（极淡的一圈） |
| 悬停 | 四个颜色值各换一组数（180ms 进 / 220ms 出），顶沿左边 62% 亮起一段（`::before`） |
| 焦点 | 四角 11px 的裁切标记（`::after`），不再画浏览器那圈框 |

四个颜色用 `@property` 注册成 `<color>` 才能插值（Chrome / Safari 16.4+ / Firefox 128+）。
三栏数值与 `cards-r8` 的 value 一版完全一致（随笔压暗 `.018 → .092`，瞬间 `.118 → .022`，项目 `.092 → .014`）。

**卡面图改走 `--w-face`。** `wander.js` 里原来写 `el.style.backgroundImage = url(…)`，现在写
`el.style.setProperty('--w-face', url(…))`，`.w-card` 的 `background-image` 是
`var(--w-face, none), linear-gradient(…)`——字在上面，值偏移在下面，一层压一层。这是这次唯一碰到 JS 的地方。

**标签。** 边上从 1px / alpha .32–.34 收到 0.8px / .30（不然一排小签会盖过那两条 .6 的边）。

**阅读窗。** 去了磨砂、投影、1px 描边，换成同一套边（上亮 / 下暗 / 收口）+ 这一栏的纸色；
开的时候纸色在 0.24s 里从 45% 浓到满——不然它会从一张几乎看不见的卡里「硬弹」出一块白板。

## 二、和原型不一样的地方（都是被正式站逼的）

1. **悬停时字距不放开。** 原型悬停三件事：面色、顶沿亮一段、字距放开 0.01em。卡面的字画在 canvas 图里，
   改字距要重画一张（每张卡 2× + 三档降采样），不划算。所以正式站只做前两件：**值 + 边**。
   这一处比原型更静；如果觉得够不着，把 `--w-edge-hi-hov` 从 .7 提到 .85、面跨度再拉 3 L\* 就能「吵」起来（原型 notes 里也是这么说的）。
2. **阅读窗不是那张「几乎看不见的纸」。** 原型的面板是值偏移的强度（白色 .115 → .028），
   但正式站的阅读窗横跨亮暗两半、背后是活的流光——照搬的话，正文是深色的那一半会读到暗处去。
   所以阅读窗保留了原来那层纸色（`--w-glass` / `--w-panel-a`，不透明度从 .93 提到 .986），
   只把「形」换成 value 那套：两条 .6 的边 + 一圈收口，没有磨砂、没有投影。
   **卡的材质与面板的材质因此不是同一个强度**——这只是为了可读，不是结论。
3. **标题栏那行保留了**（空心小圈 + 日期 + 右侧字数 / 状态 / 张数），标签还是小签不是「·」连排，瞬间还是多图。
   按「内容结构不动」做的。标题栏下面那条发丝线去掉了：纸上一共只剩两条边。
4. **远处那几档只有像素块**，没有投影也没有磨砂，现在它们就是几团糊掉的字。漫游里它们露在很细的 `--w-face` 上，
   比原来「一扇扇小玻璃」更像浮着的字。

## 三、没底的地方

1. **悬停偏静**（同 1）。检索里指针压上去能看出来的是顶沿那一段光；漫游里还有整栏的呼吸，所以更不明显。
2. **亮栏的对比**：随笔那半边背景本身就有很亮的流光条，卡面只压到 9%，字压在亮条上时不如原来那层玻璃稳。
   要稳就加面，加了就不像一张几乎看不见的纸——这一处是取舍，没有标准答案。
3. **阅读窗开合的第一帧**：卡是透明的、面板是半透明的，中间靠一个 0.24s 的浓淡过渡。真机上顺不顺还没在 120Hz 屏上验过。
