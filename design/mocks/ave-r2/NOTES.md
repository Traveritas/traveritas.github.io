# Ave 对话框 r2（design/mocks/ave-r2）

> 2026-11-15 ｜ 走 star-set 的服务：`node design/mocks/star-set/serve.cjs` → http://localhost:4680/ave-r2/
> 参数：`?v=1..4&bg=list|explore|dusk|dream&face=0&still`（still = 直接是落定的样子）

前提：作者选了 star-set/dialog.html 的「B 越界」——晶体三轴星在框后、比框大一圈，框内被磨砂糊开、框外清楚。
星的进 / 退场来自 `../star-set/star-set.js`（`spin(slot, { entry })` / `{ exit, done }`）。
r1（ave-r1：纸 / 树脂 / 雾 / 像素）只换材质；这一轮换的是「跟站上哪一块界面同门」。

| 版 | 同门对象 | 要点 |
|---|---|---|
| 1 卡片同门 | 漫游 / 检索的卡片 | 矩形 2px 圆角、发丝边、等宽小字抬头行（○ AVE ··· 时刻 ×） |
| 2 工具栏薄片 | 左下工具栏的薄片、返回键 | 6px 圆角、上亮的边、内侧高光；名牌退成一行衬线小字 + 空心菱 |
| 3 字幕 | （无框） | 每行字底下一条磨砂字幕条，深色名牌；星在字的左后方 |
| 4 斜缝 | 全站 14° 缝线 | 左缘 14° 斜切，斜缝向上下各伸一截发丝；头像也切成平行四边形 |

保住的：头像槽（可关）、名牌 + 空心菱、逐字揭开的线 + 线头、句尾三截碎屑、×。
删掉的：折角轮廓、右侧晶柱与四芒星（星的角色交给越界的三轴星）。
