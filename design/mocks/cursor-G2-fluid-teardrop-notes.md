# 方案 G2-Fluid · 非凸水滴与无缝连续流体力学 · 实测笔记

## 主张
针对 G2 停下瞬间形变跳变（Pop）与悬停压扁反馈，构建“非凸真实水滴 + 笛卡尔连续动力学”流体模型：彻底废除极坐标 $\text{atan2}$ 奇点与硬阈值截断，以笛卡尔拖拽张力向量 $\mathbf{D} = (D_x, D_y)$ 实现全域 $C^1$ 连续阻尼；升级 6 段三阶贝塞尔非凸水滴，高速呈“饱满圆头 + 负曲率收腰 + 拖曳尖锥尾”，静止严格收敛为完美正圆露珠；悬停改为等比例 1.15x 微幅放大，饱满温润。

## 核心数学模型与连续性算法
1. **笛卡尔二阶拖拽张力动力学（无角度奇点，无 Gimbal Lock，彻底消灭 Pop）**：
   - 目标张力向量：$\mathbf{D}^* = -\frac{\mathbf{v}}{\|\mathbf{v}\| + v_0} D_{\max}$，低速严格线性各项同性，高速平滑饱和（醒态 $18\text{px}$，梦态 $22\text{px}$）。
   - 二阶微分系统：$\ddot{\mathbf{D}} + 2\zeta\omega\dot{\mathbf{D}} + \omega^2\mathbf{D} = \omega^2\mathbf{D}^*$（$\omega = 22.0\text{ rad/s}, \zeta = 0.72$），辛欧拉法迭代更新。
   - 速度与张力位移在全操作域 $C^1$ 连续；手停后 $\mathbf{D}^* \to \mathbf{0}$，$\mathbf{D}$ 经一拍极其微小的天然欠阻尼微回弹后平滑收敛至零向量，绝对无突变跳变。
2. **非凸真实水滴几何算法（Non-Convex Realistic Teardrop）**：
   - 拓扑结构：6 段三阶贝塞尔曲线，由尖尾 $P_0$、上收腰 $P_1$、顶弧 $P_2$、圆穹顶 $P_3$、底弧 $P_4$、下收腰 $P_5$ 闭合而成。
   - 非凸收腰（Negative Curvature Waist）：高速拉拽时腰身半宽从 $19.05\text{px}$ 负曲率内收至 $\sim 11\text{px}$，尖尾向后拉长至 $R_0 + 1.45 d$；头部保持流体体积守恒，饱满圆润。
   - 零阶收敛不变性：$d \to 0$ 时，控制点切线解析收敛至 $L_k = \frac{4}{3}(2 - \sqrt{3})R_0$，与半径 $22\text{px}$ 的正六边形圆弧切线严格重合，误差 $< 0.007\text{px}$。
3. **悬停展开修正（Hover Link / Button）**：
   - 坚决杜绝椭圆压扁拉长；目标缩放锁定为等比例微幅放大 $\text{scaleX} = \text{scaleY} = 1.15$（梦态 $1.18$），辅以 $\le 8\text{px}$ 柔和引力吸附（Soft Snap），微透润泽不挡交互。
