PHASE 14 · 背景双态无缝变换 · 第二轮

四稿并置：把「状态差异」从强度换成采样率

上一轮（p13）的三个方向创意成立、落地失败。本轮四稿全部重做，共同的口径是： 真站点复刻 + 候选背景层，而不是独立演示页；每稿自带双态引擎（长按 2200ms 入醒 / 1300ms 回梦）、 三段夜色、真实文案、真实层序，并各自出了截图矩阵与实测数字。本页是四稿的并置裁决页，图均为同机位原图。

裁决先给结论

  1. B 是这一轮最好的单点——醒是线上那条平滑脑电，梦是同一条线被采样并保持成直角阶梯。它在静止截图里一眼可辨，是所有稿子里唯一"同一个东西被两种采样率读出"的直接兑现；而且梦态的路径串比线上现状还短（539 vs 863 字符），等于不加开销。
  2. A 是最好的"背景元素"——你最初要的就是背景。页边标尺版零性能代价、永不进正文列，两态差是同一族线的 0°↔14°。
  3. 建议组合：A（场）+ B（钟）。A 给整页的采样率，B 给时间轴上的采样拍。两者都挂在既有钩子（body[data-reality] / --reality-mix）上，可以分两步上，任何一步单独成立。
  4. C 最安全但最弱：两态差是"有一层柔光带 / 没有"，与你现在已有的 7% 洗染是同一类差异，很可能仍被读成"区别不明显"。
  5. D 最丰富但偏离了你的原话：它的醒态故意保留了整片可见的观测场（醒态亮度达墨色的 9–16%），不再"克制简约"。是否接受，是你的裁决而不是我的。

下列四张卡片的顺序＝我的推荐顺序；每张卡都有诚实的"最不放心的"一段，那些是原作者自己写的，不是我的转述。

00上一轮为什么不成立（本轮共同修正的六条）

  • 做成了功能演示页：控制台、遥测数字（"谐波相千度 94.8%"）、大段方案说明与卖点。判读者看不到"我的站点加上它是什么样"。→ 本轮默认视图干净到可当成品，控制台默认收成角落一枚小开关，截图一律隐藏。
  • 自造内容：假项目名、假文章标题。→ 本轮文案 100% 取自 src/pages/ 与 src/content/（已逐稿 grep 核验）。
  • 背景元素成了主角：过亮光带、巨大方块压字。→ 本轮统一给了红线：背景层最亮处 ≤ 相邻正文墨色亮度差的 35%，四稿各自新增的部分实测最高 32%（C 的 1px 树脂面那一道；A 25.8%、D 23.0%、B 12.3%）。B 稿另有 67–71% 的读数，那是线上本来就有的那条 1.2px 发丝线在浅底上的反差，不是它新增的。
  • 没有真层序：首屏那叠纸是不透明的（.p-base 覆盖 105.4%×104.6% 视口，z −3），p13 让背景铺满首屏，在真站上不成立。→ 本轮四稿都按 墙 −4 / 纸 −3 / 脑电 −2 / 缝线 −1 复刻，并各给一个 layer=through（改挂 −2 穿透首屏）让你裁决首屏要不要有它。
  • 性能红线全踩：移动元素上的 backdrop-filter、全屏 blur(85px)、把脑电扩成三条每帧重绘的曲线。→ 本轮零 backdrop-filter（C 稿做了对照实测证明不需要）、零全屏模糊、零新增常驻 rAF。
  • 只做了夜面一套底色。→ 本轮四稿都有 ?zone=light|deep|paper 三段夜色截图。

05需要你拍板的两件事

  • 要不要让它穿透首屏？A / C / D 三稿都给了 −3（被千层纸完全遮住，首屏保持现状） 与 −2（在纸之上、脑电与缝线之下） 两种挂法——A 叫 layer=below|through、D 叫 layer=under|through。首屏是现在两态差异最强、也是构图最满的地方；我倾向让它被纸遮住，把新层留给"随笔"段以下与内页——那正是目前两态最没差别的地方。（B 稿不在这个问题里：脑电本就挂在 −2，天然穿透首屏。）
  • A 的页边版还是全幅版？页边版零代价、永不进正文列；全幅版更有"被测量过的质地"，代价是 p50 +33%（8× 降速下）。我倾向页边版先上，全幅版留作后手。
  • D 的醒态要不要保持"看得见"？这是四稿里唯一一个醒态有可见内容的。它偏离了你"醒状态比较克制简约"的原话，但换来了醒态自己的秩序感。这一条只有你能定。

07实测口径的一个提醒

四家的「8× CPU 降速帧时间」不能横向比较——每稿复刻的内容量不同，且 headless 在无帧消费方时 rAF 会整段停发（B 稿与 D 稿都如实报告了这一点，D 稿还测出环境自身抖动约 40%）。 有意义的是每稿内部「有层 / 无层」的对照，以及 B 稿那种可复现的页面内计算量（0.30–0.42 vs 0.46–0.61 ms/帧）。 真正上线前应在 npm run preview 的生产构建上、用你 2026-09-22 换面卡顿取证时那套 200% 压力 A/B 方法复测一次。
