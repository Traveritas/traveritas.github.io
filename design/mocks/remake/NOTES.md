# 重做 r1 · 地面与物（2026-11-25）

起点（作者）：整个概念的「地面」= 像素化管线的流光场（像素感）+ 星和水晶干净透明的质感，二者一体。不在这之上再加规则。

## 怎么落的
- **一张画布画全站**（ground.js）：流光场按「格」只算一次，存成低分辨率纹理。
  - 玻璃外：最近邻 + Bayer + 量化 → 像素地面
  - 玻璃里：同一张纹理双线性读 → 平滑、干净（玻璃 = 插值）
  - 晶体：真几何体（三轴星 / 六棱双锥 / 敲过的二十面体 / 立在角上的立方体），里面是放大 + 双线性 + 一点色散的同一片地面，外加薄膜虹彩与一像素棱线
- **页与页不换背景**：主页、名录、阅读是同一片地面上的不同位置。换页时地面平移，格先粗到 3 倍再逐级解析回来，晶体从旧锚点飞到新锚点（晶体追 DOM 里的 `[data-x]`）。
- 主页：一根 14° 的线，三颗晶体挂在上面 = 三处。名录：那颗晶体成为这一处的徽，另两颗缩成旁边的入口。阅读：一整片玻璃，晶体越界压在左上角，点它回名录。
- 醒 = 昼色板 + 平滑时间；梦 = 夜色板 + 12fps 步进（晶体转动也按拍定格）。双面词沿用 [[醒|梦]]。
- 常驻控件只剩两样：左上的位置，左下的工具星。

## 这一版没做 / 故意拿掉的
- Ave（不自动弹；以后可以从工具星里叫出来，或只在首访出现）、声音、检索、标签页、gate、开屏
- 名录里统一字形（NFKC），花体标题只留在项目自己的页里
- 列表里不放标签框

## 改了什么
- **晶体**：去掉按面朝向取色相的薄膜虹彩。现在身子里基本是放大后的地面，面与面靠明暗差（每面接的光不同 + 往里反射上来的一点光），颜色只是一种淡色，色散只在掠射的边上。昼面整体往暗里收，靠暗棱显形。
- **地面元素**（场里按格算，所以也是像素）：断章 · 沿 14° 的风 ／ 闪念 · 偏 14° 落下的细雨 ／ 造物 · 星尘。名录和阅读页上是那一处的；主页上悬停哪扇门，那一处的先漫出来。
- **开屏**：格从 40 倍一拍拍（150ms）收到 1，地面从夜色里亮起来；字、星、位置最后出来。
- **换页**：粗化序列 1→2→4→7→7→5→3→2→1（100ms 一拍），比 r1 明显。
- **同心轨道**：左下的星点开 → 内圈三件（昼夜 / 去处 / Ave），去处、Ave 展开在第二圈；轨道里是一片圆形玻璃（同一张纹理的平滑读法），不再是一块不透明的盘子。文字横排。
- **Ave**：右下，玻璃框 + 像素头像（public/ave/face）+ 逐字出现；框左上一颗越界的三轴星，多轴一条曲线进场、2s 四次缓动、夜里按拍定格。台词直接读 src/data/ave-lines.ts 与各条目的 ave:（有 dream 用 dream）。新访客到主页走 welcome 那一串（第三句时左下的星会亮）；回访说 home-hello；进三处 / 读到某条各说一次（每次来访）。轨道里可以让她安静或再打招呼。声音没接。
- **名字**：AveritA / 的昼梦叙集；三处固定叫 断章 / 闪念 / 造物。昼夜只剩「地面色板」这一层（正文里的 [[昼|夜]] 双面词还跟着它）。
- **名录排法**：断章 = 章节（列外竖线挂编号与日期，大标题）；闪念 = 以图为主的散页，2–3 列按 14° 错开（第 j 列下沉 j × 列宽 × tan14°）；造物 = 陈列小片，同样错开，状态带一枚小菱形。
- 1（名录地面）：名录压到 0.8 的起伏；3（阅读底）：跟昼夜走，夜 = 深玻璃、昼 = 浅玻璃。
