三轴正交的六支（±x ±y ±z），按 yaw / pitch 旋转后做正交投影，得到平面上的一块六边形星。这一页只做一件事：把 toolstar.ts 里每帧手画的那一颗，变成可传参数的原语，再把姿势、尺寸、材质三种判断一次摊开看。

01

旋转一整圈

yaw 0° → 90°，12 步（7.5°/格）。立方对称：90° 与 0° 同形，所以一整圈其实只有 90°。 每格下面写六支的投影半径 —— 数字一样，就是同一颗星。

0° 与 90° 是同一颗

轮廓在呼吸

支长固定，投影半径却在 9.24–16.00 之间摆动：0° 时有三长三短，到 45° 收成六支等长。 观感上不是「转」，是每一次呼吸都把星形压扁、再撑圆。

02

定格

yaw 一格一格往前跳，每一格停住不动。左边是定格，右边是连续 —— 同一速率、同一姿势表，只为把差别摊开。 路径 d 从不被 CSS 补间，靠计时器写属性。
