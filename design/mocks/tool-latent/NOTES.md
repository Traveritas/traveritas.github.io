## 运行


地址参数：

| | |
| --- | --- |
| `?ctx=home｜grid｜read｜gate｜404` | 四种语境（加 `read` 是第五种，见下） |
| `?scene=essay｜moment｜project` | 目录页的三种夜色（浅梦 / 异相 / 深眠） |

## 1 · 那件东西与那个动词

**一件东西**：一张还盖着乳剂的相纸。工具**潜影在画面里**——不占版面、没有边框、没有面板、没有玻璃。
**动词**：显影 / 褪回。

全部实现压在一个式子上：

```css
每一处墨 = color-mix(in srgb, 本色 浓度%, 底色)
```

浓度 0 时它**就是底色本身**，浓度 100 时它是满墨。所以：

- 静置时环是 3.5% 浓度（`--dev-base`），落在那片雾里，看不见；
- 边缘那条痕是 7.5%，**只比周围高一点点，不是一条线**（96px 宽的渐变带 + 上下渐隐的蒙版）；
- 显影中每件东西的浓度由它自己的先后 `--d` 与全局推进 `--spread` 算出；
- 深底上同一个式子自己反过来——底色是深的，墨就是浅的，**不需要为深底另写一套**。

推进分两个数：`--spread` 管浓度，`--open` 管露出的范围（指针那一小片 → 整屏）。
两个都是 `@property` 注册过的数，所以整段动词是 CSS 在插值，JS 只写目标值；`?verb=0.5` 就是把
`--spread` 冻在 0.5 且关掉过渡，拿到的是确定的一帧。

**先后**：每件东西的 `--d = 0.55 × (0.62 × 到落点的距离 + 0.38 × 绕落点的角度)`。
从环心唤出时距离都一样，角度那一项就起作用——显影从上往下顺时针扫过去；
从边缘唤出时距离那一项起作用——从边缘往里漫过来。见 `14-verb-025.png`（只有上半圈显出来）。

## 3 · 三条召唤路径

三条路都写进同一个状态机，唤出的**是同一个面**（`.shot.cjs` 里逐帧比过十二枚字的浓度，三组完全相同）：

1. **常驻边缘露头** — 屏幕右缘有一条 96px 宽、上下渐隐的浓度带（`--devp: 7.5%`），中间偏下有一枚极小的琥珀微光在呼吸（这是唯一的「这里可以」）。
   指针进入右缘 150px 内 → 从落点往里漫开，整圈显影。`10d-edge-hint.png`（只是那条痕）· `10-summon-edge.png`（显影后）。
2. **指针跟随 / 停驻** — 指针在画面任何地方走过，落点周围 250px 那一小片先显影（`10a-pointer-patch.png`）；停住 380ms，那一小片自己长满整圈（`10c-pointer-dwell.png`）。`?dwell=0` 可以只看前半段。
3. **快捷键** — `D` 显影，再按 `D` 褪回。落点在指针处（指针不在环附近时从环心起）。`11-summon-key.png`。

**褪回**：指针挪开热区（环外 170px、右缘 170px、落点 280px 之外）约 120ms 后开始褪，**1.4 秒**褪回灰；
褪的时候蒙版从落点向外收，浓度同时落回底浓度。`13-retract-before.png` → `13-retract-700ms.png` → `13-retract-1700ms.png`。
某一件展开着的时候不自动褪（读的时候不该消失），`Esc` 或点同一枚字收起。

## 5 · 这个方案成不成立，最弱在哪

**我认为成立，但它是最不讨好的一个方案。**

成立的理由：

1. **深底浅底是同一个式子**。简章第 5 节那张表里，浅梦 / 深眠 / 异相 / 晨光四套色的关系，
   在这个方案里不是「四套主题」，而是同一个浓度式子喂不同的本色——`color-mix(本色 浓度%, 底色)`
   在深底上自动变成「灰里浮出浅字」。上一轮那个「一个外观伺候三种底」的死结在这里是自动解开的。
2. **检索不需要另加解释**。匹配的显影、不匹配的退成灰，用的就是环本身的语言，不必再造一套「没找到」的样式。
3. **边界真的只有浓度差**。整个 `latent.css` 里没有一处 `border`、没有一处 `background` 面板、
   没有一处 `backdrop-filter`。这一条是可以逐行核的。
4. **有方向、有先后**。`--d` 让显影从落点漫出去（`14-verb-025.png` 能看出只有上半圈出来了），
   不是整片一起亮——这正是 drift 的 `develop` 草案自己写下的那条风险。

最弱的地方，按严重程度：

1. **可发现性。** 这是四个方案里最差的一个，我给的答案只有一条痕 + 一枚微光。
   站长的机器上「几乎看不见」和「根本看不见」之间只差几个百分点，很可能需要一次真机校准。
   `02-still-grid-essay.png` 与 `10d-edge-hint.png` 是**必须人眼确认**的两帧。
2. **展开之后，工具与正文叠在同一块地方。** 环心那 343×343 就是正文列的中心，
   十二枚字又落在正文列的两侧。我的解法是「显影完成，画面退后」（0.45；某一件展开时 0.3），
   退的也是浓度、不是遮罩。但这是**用一次让步换来的**：`20-core-hour.png`、`20-core-contents.png`
   里正文明明还在那儿，却已经不该被读了。阅读页尤其明显。
3. **浅底上的「蒙了层灰」。** 底浓度 3.5% 已经调到看不出灰了，但深底上同样 3.5% 会显得更脏一点；
   两边的观感不对称，我只保证了「都不显眼」，没做到「都同样干净」。
4. **十二枚字挤在一个环上**，在 1440×900 下 R=300 已经不小；到了 1280×720 一类的小笔电上，
   `Math.max(172, min(min(w,h)*0.34, 300))` 会把它压到 245，字与字之间的弦只有 127px，还算宽裕；
   再小就会开始碰。
5. **`?verb` 冻住的是密度，不是时间线**——`14-verb-05.png` 是「推进到 50% 时的一帧」，
   不是「显影到 0.5 秒时的一帧」，两者不等价（过渡是 `cubic-bezier(0.16,1,0.3,1)`）。截图够用，但别当成时间线读。

## 6 · 发现了但没处理的问题 · 需要人眼确认的地方

**没处理：**

1. **简章表里的 `--faint` 在四种底上都过不了 3:1**（浅底 `#8a94a2` 对 `#c6ced9` 只有 1.94，深底 `#71849c` 对 `#0d1524` 只有 1.82）。
   我没有改这个令牌的值，而是**小字一律改用 `--soft`**，另外新起了一个 `--dim`（正文的第二档，比 `--soft` 深/浅一档，仍过 4.5）。
   `--faint` 现在只用在非文字的装饰上（相纸颗粒）。这四个值要不要回收进 `tokens.css`，请站长定。
2. **`gate` 那一屏的锚色**从简章的 `#a2805c` 改成了 `#7d6146`——前者作小字只有 2.29:1。这是唯一一处我动了简章表里的值。
3. **`面 · 换面` 没有接 `reality.ts`**。原型里它只改 `html[data-face]`，改的是界面文案与正文的两态，不驱动 `--reality-mix` 那一整套插值。
4. **`视图 · VIEW` 是替身**。「漫游 ↔ 检索」在原型里退成「列 / 散」两态，没有 drift/wander 那套空间。
5. **环上六十枚刻度不可点**。原想点环上任意一处跳转，但 `.latent` 是 `pointer-events: none`（否则静置时会吃掉整页的点击），
   把整圈改成可点就等于给全屏加一层透明遮罩。所以跳转做进了「刻」的里面（二十四枚刻度）。**如果站长认为必须点环跳转，这是要重新想的一处。**
6. **梦面的词是我拟的**（寻 / 观 / 境 / 岸 / 存目 / 回响），只守了「不说破」这一条，没有和 `docs/writing.md` 的词表逐字对过。
7. **无脚本兜底**没做（工具层本来就是增强层，简章第 2 节说这轮不要求）；正文与目录的兜底都还在 DOM 里。
8. **手机上是退化的**：环缩到 R=113、只留中文标签，里面那块从环心挪到环下面（`data-mobile=1`），画面退到 0.34。
   不溢出、不压字都核过（`report.json` 的 `layout`），但它已经不是「同一个面」了。
