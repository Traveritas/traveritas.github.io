# 乙 · 咬边 `bite`

> cards-r6。甲的基础全做（值偏移 + 上亮下暗两条 0.6px + 一圈 0.5px 极淡闭合），
> 再加一层：让这两条线沿长度抖 0.2–0.6px，抖完还是同一根 0.6——只是不再像矢量。

## 1. 面怎么做的

一句话：卡片不是一块白膜，是底图在这里整体挪了几个 L 的同一块面——亮栏往下压，
薄暮与深蓝往上提，梯度都是 180deg 的一支，上下再差 3–4 L。
面上没有 `blur()`、没有材质、没有外投影、没有描边；底图的 5px 网点与斜光带原样透过来。

```css
/* 亮栏 */  background-image: linear-gradient(180deg, rgba(23,28,40,.016), rgba(23,28,40,.088));
/* 薄暮 */  background-image: linear-gradient(180deg, rgba(255,255,255,.075), rgba(255,255,255,.020));
/* 深蓝 */  background-image: linear-gradient(180deg, rgba(255,255,255,.10),  rgba(255,255,255,.015));
```

实测（同一 y，卡内 vs 底图）：亮栏 `(179,192,212)` ↔ `(185,198,217)`（压 6–14），
深蓝 `(40,48,57)` ↔ `(20,29,39)`（提 20 → 底部只剩 4）。三栏的数不一样，
因为三栏的底本身不一样：压和提都是相对各自那一块底算的。

## 2. 三栏各给了哪组数

| | Ⅰ 断章 · 亮栏 `#b9c6d9` | Ⅱ 闪念 · 薄暮 `#312731` | Ⅲ 造物 · 深蓝 `#1d2745` |
|---|---|---|---|
| 面 上→下 | 暗膜 .016 → .088 | 白膜 .075 → .020 | 白膜 .100 → .015 |
| 上沿 0.6px | 白 .42 | 白 .34 | 白 .55 |
| 下沿 0.6px | `23,28,40` .26 | `9,6,11` .30 | `6,8,14` .30 |
| 闭合 0.5px | `23,28,40` .14 | 白 .10 | 白 .10 |
| 咬 · 上/下沿 | bf .62 · scale 1.20 · seed 7 | bf .68 · scale 1.32 · seed 11 | bf .55 · scale 1.50 · seed 5 |
| 咬 · 闭合圈 | bf .70 · scale 1.20 · seed 13 | bf .74 · scale 1.24 · seed 19 | bf .60 · scale 1.40 · seed 23 |
| 字 主 / 次 | `#232830` / `#4d5765` | `#e9e2ea` / `#c0b1c4` | `#e3e9f4` / `#adb8ca` |

`numOctaves` 一律 2，seed 固定，**没有任何动画**。位移幅度 = `scale/2`，也就是
0.6 / 0.66 / 0.75px；亮栏最轻（线最实，咬狠了显脏），深蓝最重（线本来就淡，
多咬一点才够「不是画的」）。

## 3. 边：两条线各自的明度与宽度，暗栏怎么反

三条线都做成了能被 `filter` 吃到的实体（`span`），不是 `box-shadow`——shadow 咬不动。

- **上沿** 0.6px，在框内（`border-top`）：受光的那一窄条在纸里。
- **下沿** 0.6px，在框外（`::after`，`top:100%`）：落影落在底图上，不是压在纸上。
- **闭合** 0.5px，整个在框外（`inset:-.5px`）。

次序要命：闭合圈必须画在**上沿之下**。第一版里圈压在上沿上，亮栏那条白线
在像素里根本找不到——那一行是 `(182,189,201)`，该是白的地方一点白都没有。
半像素的圈被吸附到框内那一行，正好盖住 0.6 的白。换了 DOM 顺序之后是 `(196,203,214)`。

暗栏（薄暮 / 深蓝）把两条的明度反号：上沿从暗膜的白 .42 换成白 .34 / .55，
下沿从 `23,28,40` .26 换成近乎黑（`9,6,11` .30 / `6,8,14` .30），闭合圈从暗 .14
换成白 .10。**次序永远不变**：上亮下暗。四边等宽等亮就成了描边，这里始终不是。

咬的实现在 SVG 里，`filter` 区域留 `-8% / 116%`，位移出去的那截不会被裁：

```html
<filter id="bite-a-lit" x="-8%" y="-8%" width="116%" height="116%">
  <feTurbulence type="fractalNoise" baseFrequency="0.62" numOctaves="2" seed="7"/>
  <feDisplacementMap in="SourceGraphic" in2="n" scale="1.2"
                     xChannelSelector="R" yChannelSelector="G"/>
</filter>
```

1× 下量了一下（深蓝那一栏的上沿白线，340 列）：亮度 p10–p90 只差 1.4%，
只有 2 列整段暗下去，线心在 0.16px 内漂。**这在 1× 几乎就是看不见的**——
它真正的效果是线在行与行之间偶尔挪半格、偶尔断一小截，不再是「一条机器画的
等宽亮线」。这不是参数没给够，是 DPR 1 上 0.6px 的线被吸附成一整行、
位移在行内滑动不改覆盖率的结果（想把这一段做实，见第 5 节第 2 条）。
要看它确实在动，去 `#detail`。

## 4. 展开：怎么从卡片来到这里

点任意一张卡 → `#open`：三栏整块退到 0（透明面留着就是一行行鬼影，读不下去），
底图不动；阅读面板从右侧浮起，**同一块材料**——面的公式与深蓝那一栏同宗，
只是它一半压在薄暮、一半压深蓝上，提得略高一点（.115 → .028）才两边都读得清。
边还是三条（0.6 / 0.6 / 0.5），只是边长从 348 变成 760；咬的参数不跟着变，
所以在这张更大的面上，咬口的密度看起来比卡片上稀——这是同一个参数摆在两种尺寸上的
必然结果，不是另调了一套。

文案全部照 `shared/fixture.md`：标题、简介、标签、元信息、正文前四段。

`#detail` 是另一条路：第一张随笔卡凑近看。卡里每一样都乘 3.3（字号、内边距、
0.6 的线、2px 圆角），**噪点的波长也一起乘**：`baseFrequency ÷3.3`（.167 / .182）、
`scale ×3.3`（4.95 / 4.62）。不这么干的话，线放成 2px、毛口还是 0.6px 的尺寸，
看着就成了另一种材料。

## 5. 最容易被否的地方

1. **`#detail` 的框没有乘 3.3。** 348×3.3 = 1148，而亮楔子从右上斜下来
   （`x ≈ 634 − 0.25y`），夜半边最窄处只有 830。硬摆只能切右沿——切完一句简介断在
   屏幕边上，像素是对的、读起来是 bug。所以框收到 820×720：宽按夜半边，**高保留
   1× 的呼吸比**（简介到标签的那段空，比例上要和列表里那张一样）。代价有两个：
   这张卡比列表里的更方；简介的折行位置也换了（688 的栏宽，一行 16 字，
   列表里是 23 字）。如果评审只量框的宽高比或只对折行，这里是第一个会被否的地方。
2. **1× 下几乎看不见咬。** 0.6px 的线在 DPR 1 上被吸附成一整行，位移在行内
   滑动不改覆盖，所以只有偶尔的 1px 台阶和暗段。要它更明显只能把线做厚
   （≥1px）或把 `scale` 推过 2——两条都是 brief 明令不许的。
3. **亮栏那张的「上亮」很弱。** 白 .42 压在已经比底图暗 8% 的面上，只比纸亮
   20 来个数；它读起来更像"纸的顶边"，不像深蓝那栏那样是一条亮线。这是亮的底
   上做受光边的物理限制，不是没做。
4. **`#detail` 的卡左沿正好落在亮楔子的过渡带上**，所以卡面左三分之一偏暖、
   右三分之二偏冷，看起来像一条竖向的光斑。它是底图透过来的，不是渐变画错了；
   但它确实破坏「上淡下浓」的单一方向感。
