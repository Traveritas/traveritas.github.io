# cards-r6 · 同一张底图上的面

> 2026-11-02。前五批都在「边怎么打光」上打转，这一批按调研得到的诊断重做**面**。
> 三条共用一套规则，只是在这套规则上各加一层。

## 诊断（这三条是前提，先读懂再动手）

1. **底图是 5px 一格的世界。** `shared/plate-1440.png` 实测是 288×180 放大 5 倍（99.2% 的 5px 块内同色）。
   现在卡片那条 1px 边比整张图的栅格细五倍——这是「贴上去」的一半原因。
2. **卡片要成为底图的一次「值偏移」，不是一层白膜。** 平涂的半透明底 = 贴纸，没有面。
   偏移方向**随栏反号**：亮栏往下压，暗栏往上提。
3. **边是两条线，不是一圈。** 上沿 0.6px 白、下沿 0.6px 暗、整圈 0.5px 极淡；
   暗栏把明度反过来（上白 55%、下黑 28%）。核心是「上亮下暗」的次序，四边等宽等亮就是描边（现在这张）。
4. **线要有微差。** 矢量线没有颗粒，这是它一眼被认成 UI 的原因。

参考数值（可直接用，也可自己调，但要给数）：
- 亮栏面：`linear-gradient(180deg, rgba(23,28,40,.015), rgba(23,28,40,.085))`
- 暗栏面：`linear-gradient(180deg, rgba(255,255,255,.10), rgba(255,255,255,.015))`
- 边：`inset 0 .6px 0 rgba(255,255,255,.42)`, `0 0 0 .5px rgba(23,28,40,.14)`, `0 .6px 0 rgba(23,28,40,.26)`

参考资料：`design/mocks/refs/glass-ui.md`、`print-edge.md`、`edge-tech.md`，实验台 http://127.0.0.1:4646/edge-lab.html

## 锁死

- 底图不许改、不许盖（`shared/plate-1440.png` / `plate-390.png`），不能遮住栏头与左下那颗星。
- 三栏内容用 `shared/fixture.md`，位置沿用三栏。
- 不许：投影、标题栏、小图标、胶囊标签、材质贴图、`blur()` 堆出来的磨砂。
- 反面教材（调研里被点名的三件套）：**白 alpha + `blur(20px)` + 均匀白描边**。

---

## 甲 · 基准 `value`

把上面的诊断**原样做对**：面是值偏移（亮压暗提），边是上亮下暗的两条 0.6px + 极淡闭合。
不做别的花招。这一条是这一批的标尺——它要证明「光靠值和边就够了」。

## 乙 · 咬边 `bite`

在甲的基础上，给边一点微差：用 `feTurbulence + feDisplacementMap` 让线沿长度抖 0.2–0.6px
（`baseFrequency .5–.8`、`scale 1.2–1.6`、`seed` 固定、不要动画）。
要小心：`scale > 2` 会让圆角出豁口、线断成点。判据是 1× 下**看不出抖动**，只觉得「这条线不是矢量的」。

## 丙 · 网点 `halftone`

在甲的基础上，让卡内的面和底图**同一种网点**：卡内的网点跟着底图的 5px 格走，
密度比卡外密一档或稀一档——卡沿不是画上去的，是网点密度变化的那条线。
这是三条里最激进、也最可能就是「味道」的一条。做法不限（CSS 渐变平铺、SVG pattern、canvas 烘焙都行），
但**必须是 5px 的格**，不能是 1px 噪点（那是另一种颗粒，会和底图打架）。
