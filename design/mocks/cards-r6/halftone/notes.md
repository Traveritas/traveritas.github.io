# 丙 · 网点 `halftone`

## 1. 面：一块 5px 的网版，不是一层膜

底图是 288×180 的方块网点放大 5 倍——格宽 5px，一格一个色。卡里不铺别的东西，
只铺同一套格：一张 **20×20px 的 4×4 Bayer 网版（格 5px、16 档）**，
每格一支墨（亮栏 `#171c28` 压暗，暗栏 `#d8d4e6` / `#cfdcf2` 提亮）。
一条 `linear-gradient` 的 mask 只改**每格墨的浓淡**（亮栏 .28→1、暗栏 1→.30）。
没有另加一层平涂渐变：甲要的「上亮下暗」就是这层 mask，面由格子自己排出来。

所有卡的左上角都落在 5 的倍数上（130/135、620/135、1020/135、620/120…），
背景从卡的左上角起铺，所以卡内的格线和底图的格线是同一张网——
卡的边界就是这张网版被切断的那一条格线，不是画上去的一圈。

一个说清楚的地方：**对的是格，不是图案的相位。** 底图的 5px 抖动是跟着画走的
（实测紫色栏在 (i+j) 奇格上暗 3–4 L\*，但那只是局部，整张图没有一张全局的网版相位），
所以卡里用的是同宽、同档数的另一张有序网版；能对齐的是 5px 的格，不是每一格的明暗。

## 2. 三栏各给的一组数

| 随笔 · 冷灰 | `191,204,217`（L\*81.4） | `#171c28` | .150 | .28 → 1 | 2.1% → 7.5% | −1.4 / −4.7 | 最浓一格 −9.4 |
| 瞬间 · 薄暮紫 | `39,39,49`（L\*16.0） | `#d8d4e6` | .155 | 1 → .30 | 7.8% → 2.3% | +6.2 / +1.9 | 最浓一格 +12.3 |
| 项目 · 深蓝 | `20,29,49`（L\*10.9） | `#cfdcf2` | .160 | 1 → .30 | 8.0% → 2.4% | +7.1 / +2.3 | 最浓一格 +14.3 |

亮栏压暗、暗栏提亮；亮栏上淡下浓，暗栏上浓下淡。
暗栏平均只提 +6～7 L\*（甲给的是 10% 白 ≈ +10）：再往上一档，格里的浅墨就会在夜面上闪成噪点，
所以这一栏宁可面弱一点。平均上墨 = 0.5 × A × mask。

## 3. 边：两条 0.6px + 一条 0.5px

- **亮栏**：上 `inset 0 .6px 0 rgba(255,255,255,.42)`，下 `0 .6px 0 rgba(23,28,40,.26)`，
  闭合 `0 0 0 .5px rgba(23,28,40,.14)`。
- **暗栏**：上 `inset 0 .6px 0 rgba(255,255,255,.55)`，下 `0 .6px 0 rgba(0,0,0,.28)`，
  闭合 `0 0 0 .5px rgba(190,212,255,.13)`。
- 圆角 0：卡沿落在格线上，圆角会把最后一格削掉一个角，所以不要。
- 两条线同宽（0.6px）、不同亮——上亮下暗；四边等亮就退回描边。
- 网版画在两条线**上面**：格里的墨把上沿那条白线按 5px 切成一段一段（顶部 mask 只有 .28，
  所以是 0–4% 的浓淡），这就是「线要有微差」的那点微差，不用另做 turbulence。

## 4. 展开：怎么从卡片来到这里

点任意一张卡 → `#open`。三栏退到 18%（夜面那两栏直接收掉，它们会压在阅读页下面），
阅读页是**同一块网版落到夜的那半边**：墨从「压暗」翻成「提亮」，字也跟着翻成浅色。
不换纸、不换材料——底图那道斜光会从卡里透出来，看得见。

`#detail` 是第一张随笔卡 **3 倍**（260×225 → 780×675），也放在夜面。
格还是 5px：放大的是卡上的东西（字号、内边距都乘 3），格不跟着放大——
版属于底图，不属于字。四边都留在画面里，外面那圈底图的格可以直接对照。

## 5. 最容易被否的地方

- **1× 下的那 20px 周期。** 4×4 Bayer 的周期是 20px，盯着看会露出一点斜向的规律，
  像屏幕不像印张。再放大一档（8×8）会更像纸纹，但「网点」就读不出来了——这是取的那一头。
- **暗栏的面比甲弱。** 平均只提 +6～7 L\*，如果被要求「暗栏也要有清晰的面」，
  往上加就是闪；格内极值已经在 +12～14。
- **detail 把卡放到了夜面。** 列表里是浅底深字，凑近看是夜底浅字。这不是第二张卡，
  是同一块网版换了一边底；但第一眼会被读成「换了张卡」。
- **窄屏的相位。** 390 的底图也是 5px 一格，卡里的格宽一样，但卡高按内容走，
  第二张卡起左上角不在 5 的倍数上，格子和底图差 1–4px（格宽没变，相位漂了）。
  把这几个高度取整就能修掉，现在没修。
- **窄屏的阅读页铺了一块实色。** 底图是一张固定高度的图，长文一滚动就跨过亮暗两半，
  一张网版托不住两种墨——所以 ≤720 的 `#open` / `#detail` 是实色夜面（`#0d1424`），
  网版照旧压在上面。这一处的「值偏移」是断的。
- **「同一种网点」只对到格。** 底图的抖动是随图走的，没有全局相位可对；
  卡里是一张新的有序网版。说是同一张网，成立的是格宽、档数和墨，不是每一格的明暗。
