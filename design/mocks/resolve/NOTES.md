# 解析度 · 原型笔记

把 NEXUS 的「分辨率即醒度」搬进博客：页面上铺一张解析度场，注视的东西完全解析，四周粗一些。
**醒的不清楚是磨砂（连续），梦的不清楚是像素格（离散）**；同一张场、同一套对焦逻辑，只换「不清楚」的种类。
正文永远全分辨率——变粗的只有底色、封面、取景角这些外围的东西。

## 运行

```
node design/mocks/resolve/serve.cjs          # http://127.0.0.1:4410/
node design/mocks/resolve/.shot-resolve.cjs  # 截图 → .shots/（可带名字过滤，如 press）
```

服务以本目录为根，`/fonts/` 借用 `public/fonts`（只读），所以 Noto Serif SC 子集照常生效；子集里没有的字落到 Noto Serif JP / 系统衬线。
直接双击 `index.html` 也能看（只是没有站点字体）。

URL 参数：`mode=a|b`（方案）· `hour=shallow|deep`（时辰）· `state=wake|dream` · `arrive=0`（不做落地）· `rm=1`（按减弱动效跑）· `qd=1`（色阶之间再按格抖动，默认关）。
右下角控制条可以当场切换醒 / 梦、方案 A / B、浅梦 / 深眠，「重新落地」重放落地；切换时整页先粗上去再解析回来。

## 层次

自下而上：底色场画布（z 0）→ 薄片、封面、取景角（z auto，不建层叠上下文）→ 塌缩层画布（z 2）→ 一切文字 `.t`（z 3）→ 控制条。
卡片和行都**不能**有 `transform / opacity / filter / backdrop-filter`，否则会建层叠上下文，里面的字就越不过塌缩层。现站的薄片用了 `backdrop-filter: blur(14px)`，这里换成了纯半透明底（底下的场本来就是糊的）。

## 网格与级别

- 基础格 B = round(2·dpr) 个设备像素（约 2 CSS px，dpr 1.25 时是 3 个设备像素，格子永远是整数设备像素）。
- 8×8 基础格是一块（约 16px），抖动、重画都按块来。
- 级别 L：1 = 2px、2 = 4px、3 = 8px、4 = 16px 的格。都是 2 的幂，对齐在同一张全局网格上，块里装的总是整格。
- 抖动：4×4 Bayer，按块取阈值：`L = floor(连续级别 + bayer(块))`。

## 1 · 对焦（卡片 / 目录行）

- 每个 `.fx`（目录行的 `<a>`、薄片）有 `data-f`：3 静止 → 0 对准，**一级一级跳，不补间**。
- f 同时驱动：
  - 封面级别 `k = ceil(f × 静止级别 / 3)`；
  - 取景角：四角 9px 的发丝角，张开 10 → 6 → 3 → 0px，不透明度 .22 → .45 → .75 → 1，对准时琥珀（`--amber`，醒态冷灰、梦态琥珀）；
  - 标题字距 .08 → .065 → .045 → .03em（只改字距，不糊字、不换色）。
- 时间：进 40 / +100 / +130ms（≈270ms 到位），出 0 / +60 / +65ms（≈125ms 回静）。
- 触发：鼠标悬停、键盘聚焦（Tab 到行或薄片）。触屏没有悬停：读线（视口 45% 高处）附近的那一张算注视。
- 封面是一叠预先算好的层，按 `data-k` 只显示一张：
  - `px1–px4`：2/4/8/16px 的格。先把图按 `<img>` 的同一几何（盒子的 108%）画进半分辨率画布，做求和表（SAT），每格取框内**平均**（不是点采样，所以稳），越粗略降饱和（.96 / .9 / .82 / .74）；
  - `fr1–fr3`：磨砂。建层时用画布 `filter: blur(2.5 / 6 / 12px) saturate()` 一次画好（先垫一张放大的同图，边缘不露底），再压一层时辰的乳白（6% / 13% / 22%）。运行时只切 `visibility`，不跑 CSS filter。
  - `k0`：原图。无 JS 时没有 `data-k`，只有原图。
- 方案 × 两态的静止级别：

| | 封面 | 静止级别 | 底色场 |
|---|---|---|---|
| A 醒 | 磨砂 | 3（12px 模糊） | 磨砂（平滑 + 四周乳白） |
| A 梦 | 像素 | 3（8px 格） | 像素，最粗 16px |
| B 醒 | 像素 | 2（4px 格），对焦两步到位 | 像素，最粗 8px，每 130px 粗一级 |
| B 梦 | 像素 | 3（8px 格） | 像素，最粗 16px，每 95px 粗一级 |

## 2 · 长按

- 页面任意处按住（链接、按钮、控制条除外），或焦点不在链接 / 按钮上时按住空格（落点＝聚焦的卡片中心，否则视口中心）。
- 先静默 170ms（区分点击；期间移动超过 10px 就算取消）。
- 塌缩：半径 R 从 0 涨到「最远角 + 4 级 × 72px」，用时 = clamp(R_end × .55, 760, 1150)ms，`R = R_end · t^1.5`（先慢后快），R 每次按 16px 取整（前沿一块一块地进）。
  每块级别 `L = clamp(floor((R − d)/72 + bayer), 0, 4)`：圈心最粗，前沿那一带是 1–3 级，交界按块抖开。
- 塌缩层取色：格子下面是什么就取什么的平均——封面取 SAT 平均（略降饱和），薄片取「底色场 + 玻璃」，其余取底色场；整体暗一档（浅梦 ×.93、深眠 ×.76），每粗一级再往四角沉色挪半格（看得出一圈圈的级别）。
  跨在封面 / 薄片轮廓上的格按基础格切开、各取各的平均：**物体的边保持笔直，粗的只是它里面**（不切的话缩略图边上会长出参差的台阶，像出错）。
  封面自己已经一样粗或更粗时，塌缩层在那里留空，让封面自己的格子露出来（两套格子不叠着错位）。
- 塌满：停 100ms（一拍）→ 翻面（醒↔梦：文案换面、强调色、封面种类与静止级别、底色场重画）→ 每 50ms 退半级，8 下（400ms）解析回来。翻到梦，外围留在像素上；翻到醒，外围回到磨砂。
- 中途松手：半径按 120 + 420 × (R/R_end) ms 收回去，同一个级别函数，所以也是一级一级解析回来。松了又按，从当前半径接着塌。
- 文字层始终在塌缩层之上，全程全分辨率。
- 只在非空闲时跑 rAF；每帧只重画级别变了的块，一次 `putImageData`。

## 3 · 底色场（替代脑电线）

- 色场是一个平滑函数：时辰底色 → 四角沉下去 → 左上、右下两处光池 → 一道 14° 的淡光带（旧缝线留下的方向）→ 一处带色的池（醒偏雾蓝在左下，梦偏灰粉在右上）。按 4px 一格预先取样，取色只查表。
- **梦（及方案 B）**：每块按到正文列（56rem）的距离取级别——列里是 1（2px，看不出格），出了列每 110px（B 醒 130、B 梦 95）粗一级，上下边缘也粗一点；交界按块抖开。每粗一级色往四角沉色挪一小格（浅梦 13%、深眠 16%），粗格落到色阶上（台阶 = 3 / 2 × (L−1)），所以**看得见的是级别交界那一圈圈抖开的台阶**，而不是噪点。
- **醒（方案 A）**：同一张场，16px 一格取样，平滑放大再 `blur(10px)`，四周按同一个级别函数加一层乳白（最多 55%）。同一份数据，只换重建方式：最近邻 ↔ 平滑。
- 平时静止，只在翻面、长按、切换、窗口改尺寸时重画（视口 1440×900 时整张约 10–25ms）。画布是视口的 1/2 分辨率（dpr 2 时 1/4），最近邻放大。

## 附 · 落地

页面先按 3 级（8px，抖开时一半 4 级）落下，封面算好后每 50ms 退半级，约 300ms 解析到底。减弱动效或 `arrive=0` 时不做。

## 减弱动效

对焦直接跳到终态；长按不画圈，按满 650ms 直接翻面；不做落地；控制条切换直接换。

## 实测（headless Chrome，1440×900）

- 塌缩层整张重画（最坏情况，全部是细格）约 10–15ms；实际按住时只重画变了的块，大多数帧在 17ms 内，3 帧左右 20–28ms。
- 翻面那一刻有一个约 130ms 的长任务：JS 本身（`applyState`）13–27ms，其余是 headless 软件光栅在重绘整页（全屏 `blur(10px)` 的磨砂底、几十张封面层换显隐）。有 GPU 的真浏览器里应该小得多，但没在真机上量过。

## 我拿不准的地方

1. **底色场的存在感**。浅梦上它很淡：只有出了正文列的两侧看得见抖开的级别台阶；深眠上清楚一些。再加强就开始像「纹理」而不是「场」。台阶大小（`step`、`q`）是最该当面调的两个数。
2. **长按圈里的「粗」看不太出来**。底色本来就平滑，16px 的格子和 2px 的格子取到的颜色几乎一样，圈里能读出来的主要是「暗一档」和抖开的边；只有压到封面时才真的看见格子。也许该让圈里的格子带一点色阶抖动（`qd=1` 可以看，但会冒零星亮点）。
3. **磨砂封面在醒态静止时太糊**（12px）：瞬间页的大图几乎认不出内容。可能静止级别该是 2（6px）。
4. **方案 B 的梦和 A 的梦几乎一样**——差别全在醒。若选 B，梦是不是要再粗一级（16px 静止）还没试。
5. **目录行的取景角**框的是整行（含缩略图），对准时像一个选择框；也可以只框缩略图或只框标题。
6. 塌缩层的格子对齐视口网格，封面自己的格子对齐封面左上角，两者不在同一张网格上（已经用「封面自己更粗时留空」绕开最显眼的错位，但不是根治）。NEXUS 是同一张网格，这里因为封面随滚动走，做不到。
7. 长按在链接上不触发（同现站「空白处」语义）；目录行整行是链接，所以在行上按不住。触屏长按会和系统的选字 / 菜单抢，只拦了 `contextmenu` 和 `user-select`，没在真机上试。
8. 「原野」「拱廊」两张的配图是从已有图里裁的局部、字是样稿，只为让像素化有东西可看。

## 搬进 `src/` 需要什么

- 状态来源换成 `reality.ts`：订阅 `onRealityChange` / `xm:reality`，用 `--reality-mix` 的闩锁时刻做翻面；长按手势本身（2200 / 1300ms、成结、细线）是保留现有的还是换成这里的塌缩圈，要先定。两者可以并存：细线管「手势」，塌缩层管「画面」。
- 底色场替换 `Eeg.astro` / `eeg-*`（及 `maskLines`、`fieldVeil`）：做成一个 `ResolutionField.astro` + `scripts/field.ts`，在 BaseLayout 里按 `ambient` 挂；色板直接读 `hours.css` 里每个时辰的变量（`getComputedStyle`），不要在 JS 里再抄一份。
- 封面层：构建期用 astro:assets 直接产出 1/2、1/4、1/8、1/16 的小图（框内平均），像素层不用在浏览器里算；磨砂层同理产出预模糊图。运行时只需要 SAT 给塌缩层取色——也可以退而用 1/8 小图的像素近似。
- 卡片与目录行（`IndexRow.astro`、`pages/moments/index.astro` 的 `.sheet`）要去掉 `backdrop-filter` 与悬停 `transform`，文字元素加一层 `z-index`，否则字越不过塌缩层。现有的悬停叠影（`.ghost`）和这里的对焦会抢同一个悬停，要二选一或合并。
- `prefers-reduced-motion`、无 JS（只剩原图与纯色底）的退路已在原型里走通，搬过去照抄。
- 性能：翻面时把 `renderField` 放到下一帧（塌缩层盖着，看不见），首屏落地等封面层就绪再开始；在真机（尤其手机）上量一次长按的帧时间。
- 文案：控制条只是原型用的，正式站不带。
