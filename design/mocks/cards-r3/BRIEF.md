# cards-r3 · 感觉优先：冰 / 背光

> 2026-11-02。前两批都在给卡片一个「它是什么」的物理解释（雾片 / 斜切 / 开口 / 玻璃 / 图纸 / 印相），
> 方向对不上。这一批换成从**看起来如何**出发：先定感觉，再让它自己长成某个东西——或者谁都不是。

## 锁定的部分

**背景与排版不动。** 这是从生产页截下来的底图，卡片层已经隐去：

- `shared/plate-1440.png`（1440×900）
- `shared/plate-390.png`（390×844）

规则：
1. 底图**不许改、不许盖**：不能加遮罩、不能调色、不能重画渐变，也不能把栏头或工具栏遮住。
2. 卡片之外只允许极轻的接触影或光。你想要「卡片和背景之间有关系」，就在卡片这一层做，不要动底。
3. 卡片位置沿用底图上的三栏（随笔 / 瞬间 / 项目），内容用 `shared/fixture.md`。
4. 底图左下角那颗星是真的，别盖住它，也别另画一颗。

## 方法：感觉句 → 参数

每一案先有一句**感觉句**，然后必须用三个可验收的参数把它落下来：

| 参数 | 要回答什么 |
| --- | --- |
| 明度差 | 卡片比它背后的底图亮多少 / 暗多少（给个大概的数值或清楚的关系） |
| 边缘 | 硬还是软、多宽、闭不闭合、是亮边还是暗边 |
| 质感 | 颗粒、起伏、干湿、冷暖——看得见的那一点「不完美」 |

**不要用材质名词当理由。**「因为它是玻璃所以有高光」这种写法不成立；反过来，「要有 3% 的明度差和一道 1px 的亮边，所以它看起来像薄冰」是成立的。材料可以出现在结果里，不能出现在理由里。

另外两条硬指标（前几批死在这里）：
- **列表要能扫读**：三栏并排时，一眼扫下去能分出六条、能看出点哪里。
- **不碎**：远看是一个安静的版面，不是六个各说各话的东西。

## 甲 · 冰 `ice`

**感觉句：像隔着一层很薄的冰看它。**

- 冷、清楚；边缘略硬，但表面有一点不平整。
- 亮度靠**透光**，不靠白：卡片不该是「白色的一块」，而是「背景被一层东西压过之后的样子」。
- 冰薄到几乎只剩一层膜——太厚就变成磨砂玻璃，太薄就不存在。这个厚度就是这条的赌注。
- 危险：变成「毛玻璃卡片 + 高光」的老套。

## 乙 · 背光 `backlit`

**感觉句：比背景亮一点点，边缘也是亮的。**

- 没有阴影，几乎没有重量，像被背后的光托着。
- 卡片比背景亮一点（多少由你定，但要小），边界由**亮度差**给出；边缘那道亮线是结果，不是描边。
- 字的对比要足够——最容易做坏的是「整个都淡淡的」。
- 危险：亮过头变成发光框；或者淡到读不出层级。

## 交付

### 1. `index.html` —— 四种状态

| 状态 | 触发 | 内容 |
| --- | --- | --- |
| 检索 | 默认 | 1440×900：底图 + 三栏六条卡（随笔 2 / 瞬间 2 / 项目 2） |
| 展开 | `#open` | 同一页切到阅读；背后三栏按你的感觉处理 |
| 细节 | `#detail` | 第一张随笔卡放大到 1.5 倍以上放画面中央，材料要看得清 |
| 窄屏 | 视口 ≤ 720 | 换成 `plate-390.png`，一列 |

- 用 `:target` 或 `location.hash` 切换，不做点击交互。
- 字体：`<link rel="stylesheet" href="/fonts/noto-serif-sc/font.css">` → `font-family: 'Noto Serif SC'`。
- 配图在 `shared/img/`（`moment-1.png` / `moment-2.jpg`）。

### 2. `notes.md` —— 五段，短句

1. 感觉句（一句，就那句）
2. 明度差：卡片比底图亮/暗多少，怎么定的
3. 边缘：硬度、宽度、闭合与否
4. 展开：怎么从卡片来到这里
5. 最容易被否的地方

### 3. 截图

```bash
node design/mocks/cards-r3/shot.cjs <你的案子>
```

四张到 `.shots/`：`<案子>-{list,open,detail,mobile}.png`。

**交付前自己至少看两轮。** 把截图和底图放在一起看：卡片像不像本来就在这张照片里。
