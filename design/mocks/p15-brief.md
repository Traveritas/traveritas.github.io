> 这份简报是四稿共同的口径。你那一稿的**具体设计要点在主会话给你的任务里**，
> 这里只写共同部分：命题、外壳用法、红线、交付物、自验方法。

## 0 · 本轮命题

站点已有两态机制（`morph.ts` 双声轨文字、`brand.ts` Traveritas↔AveritA），
但**空间层几乎没有差别**：只有 7% 的 `--wash` 洗染、极微弱的颗粒变化、
局部文字漂移。用户的原话是「状态之间的区别不是很明显」，要加**背景元素**，
能遵循两态逻辑**无缝**来回变换。醒态要**克制简约**，梦态动态更多，
且更偏品牌字标 `AveritA` 那种**知觉抽帧（量化阶跃）**的风格。

本轮的共同命题（也是与前两轮的分界）：

> **两态差不再靠「有 / 无」，而靠「同一个东西被两种方式读出」。**
> 醒态：秩序在场、绝对静止、可读出几何——**不是隐身**。
> 梦态：同一场被抽帧、被点亮、被量化——**不是换一件新东西**。
> 无缝：长按全程由 `--reality-mix` 连续插值，中途松手能退回。

### 前两轮已经做过什么（务必不要重复，也不要假装没发生）

- **p13（三个方向的第一轮）**：做成了功能演示页（控制台、遥测数字、大段卖点），
  判读者看不到「我的站点加上它是什么样」。整轮否决。
- **p14（真站点复刻版四稿，`design/mocks/p14-index.html` 有完整裁决）**：
  - `p14-b-sampled-eeg.html` 可采样脑电：醒＝线上那条平滑曲线，梦＝同一条被采样并保持成
    直角阶梯。**被评为这一轮最好的单点**，且梦态路径比线上还短。
  - `p14-a-lattice.html` 基线采样栅：同一个刻度场，醒以 0°/36px 读出，梦以 14°/57px 读出。
    最好的「背景元素」，零性能代价。
  - `p14-d-reticle.html` 星野标尺：把版心量线延长成观测场。最丰富，但**醒态故意保留了
    整片可见的观测场（9–16% 亮度），偏离了「醒状态克制简约」**——这一条是上一轮唯一
    悬而未决的裁决点。
  - `p14-c-resin-strata.html` 树脂层理：梦＝版心外露出半透明层理，醒＝整层撤回。
    **最安全但最弱**——两态差是「有一层柔光带 / 没有」，与已有的 7% 洗染同类，
    很可能仍被读成「区别不明显」。这是本轮要避开的失败模式。

**上一轮最重要的一条教训**：醒态**不能隐身**。做成「有 / 无」的两态差，
等于又一个 7% 洗染。醒态必须有**自己的、静止的、可辨识的秩序**——
它克制，但它在场。

## 1 · 外壳用法

```bash
cd "D:/Documents/HTA/My Projects/personal-website"
cp design/mocks/p15-shell.html design/mocks/p15-<你那一稿>.html
```

然后**只改 `p15-shell.html` 里 `P15 BG SLOT` 注释夹住的那一段**：
把 `<div class="p15-slot-empty">…</div>` 换成你的背景层，根节点保持
`<div class="bg" id="p15-bg" data-layer="through">`，样式可以写在夹子里，
也可以放进夹子下方已备好的 `<style>` 中。

外壳里已经就位、**不要动**的：tokens、三段夜色（`?zone=`）、层序、
双态引擎（长按 2200/1300ms、逐帧写 `--reality-mix`、插值 `--amber/--umber/
--ghost-ink/--dream/--wash`）、品牌字标、14° 缝线与琥珀锚点、脑电线、颗粒、
真实文案、右下角调试角标。

**B 稿（谐波残影）额外**可以把夹在 `P15 EEG SLOT` 里的两个函数改掉
（`eegPathD(ph, d)` 返回路径字符串，`d` 是梦度 0..1）；其余三稿不要动脑电。

### 背景层的唯一合法输入是一组 CSS 变量

| 变量 | 含义 |
| --- | --- |
| `--reality-mix` | 1 = 醒 → 0 = 梦，长按期间逐帧连续更新 |
| `--still` | `1 − --reality-mix`，动效倍率（梦 1 → 醒 0） |
| `--amber` `--dream` `--umber` `--ghost-ink` `--wash` | 暖↔冷插值中的强调色 |
| `--bg` `--fg` `--fg-soft` `--line` | 三段夜色 |

**不许 JS 传参、不许自己开 rAF、不许加滚动监听、不许读 DOM 尺寸。**
整层要能在 HTML/CSS 里闭合。

## 2 · 红线

1. **醒态零动画。** 一条 `animation` 都不许在醒态生效（`--still` 为 0 时振幅、
   光量、位移必须归零；靠 `calc(… * var(--still))` 而不是 `display:none`）。
   醒态**看得见**，但绝对静止，能读出几何与秩序。
2. **无缝。** 过渡不是开关：位移幅度 / 光量 / 量化程度都要能随 `--reality-mix`
   连续插值。用 `?mix=0.25|0.5|0.75` 逐帧审视，中途必须是可信的中间态。
3. **不抢字。** 版心（`.container` 42rem）内的背景最亮处 ≤ 相邻正文墨色亮度差的
   **35%**。这一条要自己用像素统计实测，并在 notes 里给出数字。
4. **只用 `transform` / `opacity` / `filter`**，不触发重排重绘。
   会动的元素上**禁用 `backdrop-filter`**（上一轮实测掉 37% 帧）；
   **禁用大面积 `filter: blur()`**（同上，且全屏模糊是上一轮的红线）——
   需要柔光就用 `radial-gradient` 或 `color-mix` 大色差实现。
5. **零新增常驻 rAF、零滚动监听。**
6. **`prefers-reduced-motion`**：恒醒面 + 无动画。（外壳已处理状态机侧，
   你那一层的动效也要跟着停。）
7. **三段底色都要看**：`?zone=light|deep|paper` 下梦态位移与光量都必须可辨，
   醒态都要可读。深色底与纸色底上的观感差别很大，不要只调夜面。
8. **静止帧必须可辨。** 两张 `?freeze=1` 截图（`01` 醒 vs `02` 梦）必须**一眼不同**。
   动效是第二层差异，不能是唯一一层——如果两态差只在「动 / 不动」上成立，
   那它在静止截图里等于没有，也就仍然是「区别不明显」。
   所以梦态除了动，还要有**静态属性**的变化：构图/位置整体偏移一到两档、
   线宽或边界的处理改变、重叠区的规则改变、暖色出现——任选其一并说清楚。
9. **只动 `design/mocks/`**，不碰 `src/`，不提交 git。

## 4 · 自验

```bash
node design/mocks/.shot-p15.cjs p15-<letter>-<name> <letter>
#  → design/mocks/.shots-p15-<letter>/ 11 张固定机位
# 脚本自带临时静态服务器（随机端口），不需要另外起 .serve-*.cjs
```
矩阵全部带 `?freeze=1&ui=0`：CSS 动画停在 0% 帧、脑电固定相位，
所以两态对照是**确定帧**，可以逐像素比。

**你必须自己看图**（Read 图片），不是只看脚本没报错。至少确认：
① 醒态在 01/04 两张里确实「看得见但静止」，不是隐身；
② 02/05 的梦态与醒态在缩略图上**一眼可辨**；
③ 03（`?mix=0.5`）是可信的中间态，不是两种图案的叠加；
④ 09 的 3× 裁片里细节确实存在（1px 线不是糊的）；
⑤ 版心内的正文没有被背景层压到读不清。

另外自己跑一次交互确认：用 puppeteer 调 `window.__p15.hold()` / `release()`，
或按住 `?ui=1` 角标左边空白处拖 slider，确认长按 1300ms 到梦、2200ms 到醒、
中途松手会退回——**这一条是「无缝」的验收**，静态图证不了它。
