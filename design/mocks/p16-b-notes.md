# p16-b 边边相重合 ↔ 接缝错开 · Edge-Coincident Tiling → Opened Seams

## 主张
两态差不在图样，而在**同一片构造体的内部排布规则**：醒＝块内正方形边边相重合（零重叠、共边落在同一条格线、轮廓是阶梯直角的整流形）；梦＝同一批正方形各自沿「它脱离的那条共享边」的法向滑开、错开搭接，交叠处露出一枚 1px 琥珀窗。大块在两态都成立，变的是它怎么被拼起来。

## 醒（tiled）
- 24 个构造体＝从 2×2 / 2×3 / 3×3 矩形里挖角得到的**阶梯整流形**（4–7 块正方形，同一模块 m＝57–145px；只挖角与边、保持连通，3×3 的中心保留＝回形）。整片**零重叠**、每块与其邻居共享 **100% 边长**（判据 ≥60%）。
- 共享边＝两枚 1px 边框**相邻**落在同一条格线上。3× 剖面实测：外轮廓 3 设备像素（1 CSS px）、共边 6 设备像素（2 CSS px），**峰值亮度与单线相同（3.0–3.35%）**⇒ 重缝重的是宽度、不是深度（见「最不放心的」1）。
- 醒态动画只有平移：三档 14° 同向**往返**（0→+A→0），A＝240/300/360px、周期 100/84/68s、峰速≈8.4/12.5/18.5px/s；幅度乘 σ(--tl-k)，梦态严格为 0。`.tl-drift` 提层（will-change:transform）。

## 梦（loose）
- 每块沿它挑中的那条共边的法向滑开 0.30–0.52 边长（68% 真「脱离」＝离开那条边，32% 朝那条边滑出窗），再带 ±0.12 边长的切向错开（否则只是百叶窗式的张开）。渲染位置＝ loose + (tiled−loose)×σ，σ＝smoothstep（两端导数为 0、f(0.5)=0.5）⇒ 按下逐帧裂开、松手逐帧合上、中途停在「半合缝」。
- 交叠沿用 D 稿规则（解析求交 → 1px 琥珀窗），但**整档合成一个 opacity 组**（逐帧只改 3 个元素，不是逐窗写）；叠深 ≤3（3px 采样，生成期与落位期双重淘汰）。
- 另有：整场沿 14° 登记 10px×still（静止帧上的第一层错开）；三档 steps(1,end) 原地阶跃（0–3 整数像素、净位移 0、7 步＋3s 呼吸、幅度×still）。

## 与 D 稿的差别（继承了哪些 / 解决了哪条不放心的）
- **继承**：固定种子 LCG、程序化生成一次后零运行时成本、smoothstep σ 归零、解析求交→1px 琥珀窗、同一点最多叠 3 块、三档视差＋梦态整数像素阶跃、梦态整场登记偏移。
- **解决 D 稿第 1 条不放心（归位 2329px）**：放弃「内容复制两份＋整周期位移」，改成**净位移为 0 的往返**——归位 ≤ 一个振幅（最坏 360px，实测远档 232→224→208→156→104→46→11→0，方向与「合缝」同向），首尾同帧仍然严格成立且不需要内容副本（节点 472→217）。
- **未继承**：卫星小方块（独立单块没有共边邻居，会破坏断言②）、醒态的角部搭接（本稿醒态零重叠）；分布也不再用 u 方向周期约束，改在屏幕坐标里做（断言①要求跨构造体也零重叠，屏幕坐标下才好核）。
- 用户说 D 稿「不太像我理解的样子」＝要的是「边边相重合」这个**可断言的几何**：本稿把它写成生成期断言①②并逐项实测（DOM 独立重算一致）。

## 实测
- **版心内背景最亮处 / 相邻墨色亮度差**（同机位 freeze 逐像素 on/off；分母同时给标题墨与正文墨 --fg-soft）：deep 醒 4.9%/8.1%、梦 12.0%/20.1%；light 醒 14.2%/16.3%、梦 24.0%/**27.6%**；paper 醒 14.8%/15.6%、梦 25.6%/27.1%。最坏 **27.6%**（light 梦，对正文墨），红线 35%。首屏 deep 醒 9.6%/梦 23.9%；移动端 醒 8.2%/梦 20.8%。
- **生成期断言**：醒 ① 零重叠 **0 对**（130 块全对枚举，最差面积交 0px²）；② 共边 **min 100% / avg 100%**，<60% 的块 **0**。梦 ① 叠深 **max 3**（3px 采样、含跨构造体）；② 构造体错开后的整体尺寸 **175–358px**（要求 160–420）。最小交叠窗边 12px；DOM 独立重算与自报逐项一致；醒态 computed transform ≡ (tiled−loose)、落点**全整数像素（0 例外）**⇒ 1px 线不糊。
- **醒态 animation 清单**：`#p15-bg` 内 6 条＝tl-drift×3（生效）＋tl-step×3（醒面矩阵恒等，各路幅度全含 var(--still)）；全页 7 条（外壳 1 条＝缝线锚点呼吸）。**新增 rAF 0、滚动/尺寸监听 0、resize 重算 0**（2.5s 内 rAF 187 vs 外壳 188，监听 9 vs 9，全在外壳状态机里）。
- **生成**：**217 个节点**（24 构造体＋130 正方形＋51 窗＋12 容器），耗时 **22.5–24.9ms**（构造体尝试 196 次、一次通过 137；落位重试 113 次、落位失败 0）；t=0 视口内可见 ≈10–14 个构造体。
- **8× CPU 降速「有层 / 无层」帧时间**（页内 rAF 4s，每档两趟）：醒 **有层 241/242 帧、p50/p95/max 全 17ms ＝ 无层**（未提层时同一对照是 220/239 帧、p95 33ms）；梦 有层 216–238 帧、p95 33ms（≈1/4 拍掉一帧，来自三档 steps 跳变的重新栅格化）↔ 无层 240–242 帧全 17ms。提层代价另测：mix=0.5/0.25/0 下 will-change 有/无**逐像素完全相同**（0/604 800，最大通道差 0）。
- **无缝**：钉住 animation-delay 的 t=0 vs t=T **0/1 296 000 差异、最大通道差 0**；t=T−50ms 差 0.9%（通道差 2）；t=T/2 差 30.4%（位移最大）。`?mix=0.5` 静止帧是可信的「半合缝」，不是两种图案叠加。
- **长按**（每次新开一页）：1320ms 到梦 / 2242ms 到醒（墙钟计时）。一对共享过边板片的接缝宽度逐帧：醒→梦 0→2.3→15.3→68.3→79px（σ 1→0.97→0.81→0.14→0）；梦→醒 79→75.4→61.5→39.4→4.4→0；600ms 松手 34.2→15.1→0 退回醒面。证据图 `.shots-p16-b-extra/hold-{A-350ms,A-900ms,B-1100ms,C-600ms}.png`。

## 最不放心的
1. **共享边是「两条 1px 相邻」（2px 带），不是「两条 1px 重叠成一条变深的线」**：border-box 下两枚 1px 要落在同一像素就必须互相重叠 ≥1px，而「醒态零重叠」是硬约束——我选了零重叠，于是「变深」变成「变宽」（峰值与单线相同）。若裁决要字面的重合变深，唯一出路是把格距改成 m−1（相邻两块各重叠 1px），代价是断言①作废。
2. **醒态峰速只有 8.4–18.5px/s**（D 稿 22–36），且每半个周期有一次降速转向。这是「归位 ≤ 一个振幅」这条取舍的另一面：要更快的流动就得把长按归位距离推回 500px 以上。
3. **断言里「整体尺寸」的定义是我定的**（max(bbox.w, bbox.h)）；若裁决按对角线算，最大 ≈505px，会超出 420 的框。
4. 构造体内正方形等大（块与块之间 m 差 2.5×），比 D 稿「大块＋卫星小方块」少一层尺度对照——换来的是「每块至少一个共边邻居」能在全场成立。
5. 生成耗时 22.5–24.9ms（D 稿 5.6–7.4ms）：零重叠 / 叠深 / 跨构造体三重检查在生成期的代价，一次性；共用脚本 09 号裁片仍是文档坐标（落在正文段），共享边与 1px 线的逐点证据我另出了视口相对的 `.shots-p16-b-extra/{zoom3x,cluster3x}-{wake,dream}.png`。
