# 星 · 竖排 / 同心轨道（工具栏原型）

> 2026-10-18。换面仍是长按；左下角一颗三轴正交六芒星只是开关，点开是工具栏。
> 同一颗星、同样六类工具，A / B 两种展开方式并排比较。不沿用之前 `tool-*` 四个方案的形态，只借了它们的字体服务与 `layout-plane/data.js` 的真实内容。

## 运行

```bash
node design/mocks/tool-star/serve.cjs     # http://localhost:4645/tool-star/
node design/mocks/tool-star/.shot.cjs     # 截图 → .shots/（ONLY=a-go,b-set 只拍一部分）
```

右上角切换 A / B、目录页 / 阅读页。地址参数：`?v=A|B` `?ctx=index|read` `?open=1` `?tool=go|find|page|set` `?face=dream`。
键盘：`/` 直接打开寻找 · `Esc` 先收详情、再收工具栏。

## 六类

| 类 | 点击后 | A 竖排 | B 同心轨道 |
| --- | --- | --- | --- |
| 去处 | 详情 | 薄片：页面名列表 + GitHub / RSS | 外圈放射排开，可循环转动 |
| 寻找 | 详情 | 薄片：输入框 + 标签 + 年月 | 输入框是轨道上方的一条平直薄片；标签一圈（循环）、年月一圈 |
| 本页 | 详情（只在阅读页） | 薄片：目录 + 字号 / 行距 | 平直薄片，贴在轨道上方的屏幕一侧（长标题不上弧） |
| 面 | 直接切换 | 从图标位置扩圈换面（原型里是简化的圆形揭开，不是像素塌缩） | 同左 |
| 声 | 直接切换 | 三根微弦，静音平卧 | 同左 |
| 设置 | 详情 | 薄片：动效 / 光标 / 记住面 / 夜色 + 时刻滑轨 | 设置项放射排一圈（点击轮换取值）；夜色是更外圈一段 23:07→06:31 的弧形滑轨，带整点刻度 |

## 星

±x ±y ±z 六支，正等轴视角下投影成六芒星；前面的支更实。醒面静止；梦面按「动效」设置缓慢自转（完整 / 轻 / 静止）。
开合时转 90°（立方对称，转完和原来同形），工具从它这里出来。

## 轨道的规则

- θ 从星正右 0° 到星正上 90°，列表从上往下顺时针读；每一圈的可见弧按半径算（越近星，能看见的弧越宽）。
- 可循环的圈：项少时按需复制，周期总是大于可见弧，所以转出去的从另一头回来。
- 滚轮 / 拖动转圈，松手吸附到最近一格。
- 轨道下有一层以星为圆心的底色，半径跟最外一圈走，免得字压在正文上。
- 圆弧说不好的东西（输入框、长目录）不上弧，退回平直薄片。
