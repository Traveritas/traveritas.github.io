# 方案 H · 百合罗塞特（Lily Rosette / Organic Petals）· 实测笔记

## 主张
以 3 片非对称开角与轻柔弧度的半透明磨砂几何花瓣，环抱 1 枚 1:1 热点微核。摒弃机械刺缀与十字准星，汲取百合花型之空灵抽象：动如水中游弋，静如压花凝睇；长按导引全屏引线，按满瞬间扎合锁死，熔铸为全站实心琥珀结 ◆。

## 醒 / 梦 各自的机制与关键参数
- 元素：`.lr-core`（2px 热点微核，1:1 同帧绝对定锚）+ `.lr-rosette`（3 片半透明磨砂花瓣 `p1/p2/p3`，节点数 14）。
- 醒：基准角 $0^\circ$，阻尼 $\tau = 75\text{ms}$（坚挺笃定，0 过冲）；冷灰细线与微透磨砂（`var(--fg)` 10% 充填 / 48% 发丝描边）。
- 梦：基准角 $+14^\circ$（对齐全站缝线倾角），阻尼 $\tau = 110\text{ms}$（柔性微欠阻尼，浮动游弋）；暖沙琥珀半透明磨砂（`var(--amber)` 18% 充填 / 65% 描边）；静息时由纯 CSS `lrFloat1~3` 驱动非机械异步微呼吸（消费 `--still`，静止 0 rAF）。

## 与其余方案的机制差异
- **vs A 残点**：A 是离散粒子拖尾，手停即散；H 是具备完整生命周期的**有机罗塞特形态**，动静皆有体量与呼吸。
- **vs B 四点环**：B 仍带有圆弧环与雷达读数联想；H 采用 3 片非对称花瓣，彻底打破机械放射对称，气质纯净空灵。
- **vs C 悬丝**：C 单根 9px 斜毛体量过薄且缺乏向心定锚；H 拥有绝对同帧的微核与花冠纵深，兼具极高精度与辨识度。
- **vs D 错位双影**：D 仅有方点错位；H 在链接悬停时**绽放（Bloom）**为三向柔角取景框架，微核化为花蕊光斑托起目标。
- **vs E 菱芯光圈**：E 偏硬朗正交折角；H 将几何折角柔化为具有机弧度的半透明花瓣，长按时花瓣顺导轨贴合，闩锁时合拢熔铸。

## 实测与自检数据（.shot-cursor.cjs 10 机位实测）
- **控制台错误 0 · 页面错误 0 · 失败请求 0**（全机位 100% 通过）。
- **热点同帧偏差**：`dx: 0 · dy: 0 · dist: 0.00px`（全状态采样龄 660~681ms，1:1 绝对定锚，**0 帧延迟**）。
- **静息性能**：停止移动后 0.3s 完全收敛，`rafLast5s = 0`，静止 `will-change = auto`（运动期提合成层）。
- **逐帧写入属性**：严格只写 `transform`（translate3d / rotate / scale）与 `opacity`，**零**颜色/尺寸/filter/shadow 逐帧写入。
- **状态矩阵全覆盖**：
  1. `rest`：3 瓣呈非对称自然开合（$0^\circ, 118^\circ, -124^\circ$），微核悬浮中央；
  2. `move`：随速度展开迎风微摆（$\pm 5^\circ$），柔性滞后（$\tau \approx 90\text{ms}$，滞后 $\le 2.4\text{px}$）；
  3. `hover-link`：三瓣优雅绽放（半径 $8.5\text{px}$）形成三向柔角取景框，微核膨胀为花蕊光斑（$1.75\times$）；
  4. `hover-text / input`：三瓣向中轴迅速闭合折叠，融合成纤细羽管垂直标尺（宽 $\approx 1.2\text{px}$），微核淡化至 $0.22$，完全不抢字面；
  5. `click`：$40\text{ms}$ 内向心合拢骤缩至 $1.4\text{px}$，随后微弹复原，清脆笃定；
  6. `hold1300 / hold2200`：三瓣对齐 $-4^\circ$ 站点引线轴，上下一对转化为平行的引线导轨，前端引领引线抽出；
  7. `latch`：按满瞬时（$35\text{ms}$）三瓣向中心超速扎紧锁死，紧裹微核熔铸为全站实心琥珀结 ◆；
  8. `drag`：三瓣呈弧度收拢的前倾握持姿态；
  9. `leave`：随 `fx-cursor-out` 平滑淡出；
  10. 降级：`?cursor=off`、`?reduced=1`、`forced-colors`、触摸事件全线安全回退系统原生光标。
