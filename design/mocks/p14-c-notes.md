# p14-c 树脂层（Resin Strata）· 自验收笔记

**一句话主张**：梦态是沉在画面深处、只在页边露出的半透明树脂层理——大面积色差 + 一道 1px 树脂面 + 极缓慢的整像素顿挫位移；醒态整层撤回，只留下那道 1px 面。

**醒态 / 梦态各是什么**
- 梦（`data-reality="dream"`，默认）：版心之外有两三条 14° 层理（`--bg` 派生的冷暖各偏一档，振幅约 `--bg` 的 3–5%），一条 1px 「树脂面」（墨色 26%）与它的琥珀微光段（约画面 0.01%）。层体在 12s / 19s 里以 `steps(1,end)` 走 ≤8px 的整像素位移——量化的时间，不是漂浮。
- 醒（长按空白 2200ms 闩锁 / 无 JS / RM / `?face=wake`）：层体 opacity→0，**只剩那道 1px 面**。实测醒态与「整层关掉」的逐像素差：剔面后最大 ΔL=0.0070（墨色的 0.8%）、全幅平均 **0.0000**——是「有/无」，不是「多/少」。

**「不用 backdrop-filter 也能读成磨砂」——成立。**
磨砂的读法来自四件事，全都不需要采样背景：① `color-mix(--bg …)` 的大面积极低饱和色差；② 层理软边（羽化 ~8px）给出「面」的轮廓；③ 1px 亮边＋一小段琥珀微光给出高光；④ 全站 `feTurbulence` 颗粒（5–8.5%）给细颗粒。反证：`?bf=1` 把 `backdrop-filter` 加在同一块会动的层理上，8× 降速下 5 秒内帧数 369→231（-37%）、p50 由 17ms 变 33ms。

**实测三条**（1440×900，`?zone=deep`，层=`through`，全部定格后取像素）
1. 层最亮处 vs 相邻墨色：1px 树脂面 ΔL=0.2812（墨色亮度 0.8786 的 **32.0%**）；层理最亮处 ΔL=0.0602（**6.9%**）；版心内（272–1168）最大 ΔL=0.0277（**3.2%**，落在版心右缘）、平均 0.0024（**0.27%**）。
2. 文字与板子的最近距离：1px 面的可见段自 x=1202 起（遮罩 83.5% 起渐显），版心右缘 x=1168；最近一处文字是随笔段轴线右端的 `23:19 → 01:11`，距面 **45px**（证据 `15-nearest-2x`，2× 裁切）。做法＝板子避开版心（有边界的那一档全部关在版心之外），落到文字背后的只剩无边界的大面积色差（≤3.2%、无轮廓），因此不可能干扰阅读。
3. 8× CPU 降速、页内 rAF 驱动滚动整 5 秒的帧间隔（定稿轮，见 `.shots-p14-c/REPORT.txt`，各两趟）：**A 无层** 368 / 376 帧，p95 17 / 17ms，max 117 / 50ms；**B 有层·层理** 369 / 361 帧，p95 17 / 17ms，max 50 / 117ms（与 A 逐项持平）；**C 有层·撕边片（带 drop-shadow）** 343 帧，p95 33ms，max 50ms；**D 有层·层理＋backdrop-filter 对照** 231 帧，p50 33ms，p95 50ms，max 50ms。注：前几轮 B 出现过 337–383 帧、p95 17–33ms 的抖动（±10% 帧数，属噪声），D 的四轮始终稳定地差一档（帧数 -35%~-45%、p50 翻倍）。

**形状的推荐：B「层理」**（`?shape=stratum`，默认）。理由是矩形圆角会立刻读成 UI 卡片，而层理没有闭合轮廓、只有一道 1px 面，**读成材质而不是组件**；撕边片（`?shape=sheet`，`10-shape-A`）承接首屏纸语言、轮廓更明确、同机位更「看得见」，但它仍是一块有边界的「物」，且需要 `drop-shadow`（实测无代价，但多一层滤镜）。两者同机位对照见 `10-shape-A` / `11-shape-B`。

**已知不足**
- 梦态的层被刻意压到「刚好可辨」：25% 缩放对照（`17-quarter-dream` / `18-quarter-wake`）看得出右侧变朦胧，但不算抢眼；再往上是「特效」，往下是「没做」，我选了偏安静的一侧，请以这两张裁量。
- ≤1280px：层理去掉遮罩收成全幅极淡色差，并**去掉那道 1px 面**——窄屏上任何横贯视口的线都会经过文字行；故窄屏醒态残留的是「极淡色差」而非边界（`07-mobile390-dream`）。
- 醒面的强调色是**离散**切换（真站点由 reality.ts 逐帧插值），这是为守住「除 `--reality-mix` 外不逐帧写 root 变量」而做的取舍。
- 脑电只画一帧（RM 语义）：真站点是 30fps rAF，本轮禁新增常驻 rAF；首屏也省掉了千层纸的指针视差（同上）。
- 控制台面板（默认收起、截图 `?hud=0` 时 `display:none`）用了 `backdrop-filter: blur(2px)`，这是全稿唯一的 backdrop-filter，且它是静止小面；若要保留，建议改成不透明底色。
- 未在真实 GPU/60Hz 设备上复核，p95 数字来自 headless（`--disable-gpu`）＋8× 降速。

**相对 p13 的针对性修正**
1. 默认视图干净：控制台收成右下角一枚 22px 开关，截图一律 `?hud=0`；无遥测、无方案说明文案。
2. 文案全部取自 `src/pages/index.astro` 与 `src/content/**`（含 `:::wake/:::dream` 真实两态块），不自造。
3. 禁止圆角面板压字：层没有「几何体」，有边界的部分（层理/撕边/1px 面）全部只出现在版心之外。
4. 默认零 `backdrop-filter`；它只作 `?bf=1` 对照变体存在，并已量出代价。
5. 层序对齐真站点并让层**看得见**：墙 -4 / 纸 -3 / 层 -2（与脑电同层、DOM 在前故在其下）/ 缝线 -1 / 正文 ≥0。`?layer=behind` 挂在 -4，首屏逐像素与「无层」**完全相同（ΔL=0.0000）**——p13 就栽在这里，本稿把它做成可对照的证据（`13-hero-behind` vs `09-baseline-off`）。
6. 三段夜色都实现（`?zone=light|deep|paper`，含各自 `--line`；token 写在 `html` 上，与 night.ts 写 root 一致），截图矩阵覆盖。

**第一轮自验收看到的问题与改法**
- 派生色在 `:root` 上用 `var(--bg)` 解析，而 `--bg` 当时写在 `body` 上 → 层拿的是光面色值，梦面炸成一堆亮条。改：token 挂 `html[data-zone]`（同 night.ts），派生色随之换段。
- 层理自带的 `feTurbulence` 层在深色底上平均抬高约 13% 亮度——材料成了「灰板」。改：删掉层内噪点，颗粒交给全站 `.grain`（首屏那几张纸也是这么做的）。
- 遮罩挂在会动元素的**祖先**上 → 每帧重新遮罩整棵子树（p95 100ms vs 基线 50ms）。改：遮罩下沉到层理自身，并把层理盒收到右侧 34%（可见处只有这一条），p95 回到 17ms。
- 1px 面与 14° 缝线在版边只差 39px，读成「同一条线画了两遍」。改：层理整体上移 140px，两线相隔 ~100px。
- 截图脚本吃了 `scroll-behavior:smooth`，抓拍停在滚动途中；分段轴线的 1s 入场过渡又污染像素探针。改：一律 `behavior:'instant'`，`freeze()` 同时钉住轴线。
