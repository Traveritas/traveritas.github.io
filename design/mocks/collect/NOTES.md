## 运行

```bash
node design/mocks/collect/server.cjs     # http://localhost:4650/collect/?view=explore
node design/mocks/collect/.shot.cjs      # 截图 → .shots/（ONLY=tiers,dark,approach,take,panel,mobile）
```

地址参数：`?hold=N` 停一下的稀有度门槛 · `?luck=N` 每次判定的机会放大 N 倍（`0` 不掷）· `?dev=1` 调试条（召来某一件、清空存档、看判定次数）· `?ink=scene|white|tier` 外壳线色 · 其余同 wander（`?scene=moment` 深色的夜）。

## 文件

| | |
| --- | --- |
| `items.js` | 物件清单：`id / name / odds / text{wake,dream} / art`，加一件就是加一项；`extra`（voice / oc / more / fx）是以后的扩展位 |
| `ornament.js` | 外壳：按稀有度生成几层放射细线，`draw` 按「完整度」画到一部分 |
| `collect.js` | 判定、出现（同一套景深 / LOD）、拾起、口袋与清单、导出导入、调试条 |

## 判定

- 镜头每往前越过一层（0.5），远处生成新的一层窗，同一刻掷一次。从最稀有的往下逐件掷 `1/odds`，中了第一件就停。
- 只算**往前推到过的最远处**（每个场景各记一个），来回推拉不会重复掷。过渡进行中不掷。
- 一次滚轮约推 0.19，大约滚三下掷一次。现在最常见的一件是 1/5，加上其余几件，每层约三分之一的机会出现东西。

## 出现与拾起

- 物件和外壳的每一层都是和窗一样的 DOM 元素，`z-index` 按深度给，所以窗可以从两层外壳之间穿过去。离焦平面越远越像素化。
- 外壳每层在不同深度上（见下面「前后关系」），鼠标移动、镜头平移时层与层之间会错开。
- 只有在焦平面附近（|ln δ| < 0.16，触屏放宽到 0.24）点它才算收下，这时光标是手形。离得远时点它，镜头会把它推到焦平面。错过了就没了。
- 停一下：稀有度达到门槛（默认 1/1000 起，`?hold=N` 改，`0` 都不停；以后放进设置）的东西，镜头要越过它的焦平面时会被按住 1.8 秒，之后照常滑动。
- 收下之后外壳从外往里合拢，物件飞进左下角的口袋，原地留一行字（名字、几率、醒态那句），过几秒散掉。

## 外壳：稀有度藏在花纹里

| 档 | 几率 | 规整纹阶数 | 层数 | 生长纹 | 转速 |
| --- | --- | --- | --- | --- | --- |
| 0 | 1/2 – 1/9 | 6 | 2 | — | 快 |
| 1 | 1/10 – 1/99 | 8 | 3 | — | |
| 2 | 1/100 – 1/999 | 12 | 3 | 6 支，只分一次叉，几乎对称 | |
| 3 | 1/1,000 – 1/99,999 | 16 | 3 | 6 支，分两次叉 | |
| 4 | 1/100,000 – | 24 | 3 | 8 支，分两次叉，有偏差 | 周围退进底色 |
| 5 | 1/100,000,000 – | 17 | 3 | 7 支，分三次叉，偏差最大 | 几乎不转；周围退进底色 |

- 常见档是规整的几何（花瓣、圆、波、星），只画到一部分。
- 第 2 档起，最里一层换成生长纹：从一道细环上长出几支枝，分叉，末端卷起或结一粒芽。形状每支共用，偏差每支各不相同。靠近焦平面时从种子一点点长出来，过了焦平面不再缩回。
- 线有粗细：主干、侧枝、细枝、芽依次变细。

## 另外几种外壳（`?shell=`，2026-10-26）

`shells.js`，和 `ornament.js` 同一个接口，不给 `?shell` 时仍是放射细线。截图 `ONLY=shells SHELLS=contour,text node .shot.cjs` → `.shots/sh-*`，总对照 `.shots/_shells.png`。

| `?shell=` | 是什么 | 稀有度藏在哪 |
| --- | --- | --- |
| `contour` | 等高线（第二版）：地形靠走势出形——一座峰沿一个方向拉长、一侧陡一侧缓；线连成整条再平滑。**每一道线各自一层，深度按高度给**（高的朝镜头凸），起伏幅度按档位 0.05 → 0.2。计曲线（从上往下每第 3 道）上沿线写字，字在哪儿线就让开 | 道数、起伏；第 2 档起有山脊，第 3 档起有副峰，第 4 档多一道支脊，最稀有一档是火山口（口沿一圈最高，坑底的线退到物件后面）。字：醒态一句 → 加梦态 → 第 3 档起最里一道写「只有它有的」那句（暂时是名字与几率） |
| `text` | 字环：物件自己的醒 / 梦两句绕成圈，相邻圈反向转 | 圈数、字号越来越小；第 3 档起有细衬线；第 4 档起最里一圈卷成螺旋；最外一圈用 `extra.more`（没有就先放名字与几率，等宽字） |
| `moire` | 摩尔纹：几片细线栅（平行 / 同心 / 放射）叠在不同深度 | 栅的种类和片数；层与层的视差和慢转让干涉纹一直在流 |
| `agate` | 玛瑙带：低饱和的不规则同心色带，颜色取物件图的平均色 | 带的道数、粗细不均；从外往里长；第 3 档起中间是晶洞（一圈尖朝里的晶齿） |
| `glass` | 玻片：斜插的载玻片，每条边按朝向接光 | 片数；第 2 档起有圆盖片、第 3 档起有缺口片、第 4 档起有蚀刻字的片（名字与几率；最稀有一档刻梦态那句），最稀有一档多一片计数格 |
| `window` | 一扇窗：物件住在网站同款的小窗里，窗头是名字与几率 | 套的层数、转开的角度；最稀有一档外面两层只剩影子 |

- 填色类（玛瑙、玻片、窗）的所有层都在物件后面（dz ≥ 0.006），线类的最里一层仍贴着物件、略靠前。
- 收拢、像素化、停一下、周围退进底色都照旧。

## 前后关系

- 层按半径分圈，圈与圈之间留缝，互不重叠。
- 从里到外一层比一层远（单调变化，不再前后交替）。越往后越淡、线越细；清楚的那一档里，后面的层再加一点模糊。
- 树脂片（每层底下垫一片很淡的半透明填色）默认关掉，`?sheet=1` 打开对照。
- 定下来用平放。`?tilt=1` 是另一种做法，留作对照：整朵外壳像一只浅碗，朝镜头仰起约 35°，跟着指针转一点，外圈沿法线往下沉。前后关系最明显，但更像一个"物体"，没那么像光。
- 线色（`scene`）：深色的夜里用这一夜的反光色提亮，浅色的夜（随笔）里用边色。
