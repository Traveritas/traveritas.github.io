# 方案 S2 · 菱形微晶星芒核（Diamond Rhombus Spark Core）· 实测笔记

## 主张
基于变体 G2 表面张力凝露水晕基底，将中心热点重构为“微型各向异性菱芒微晶核（Anisotropic Diamond Spark）”。以 2.4px × 3.4px 双棱面冷白微晶与穿透长短轴的微弱折射羽芒，凝结晨露中央析出的极星微闪；游弋交替差频微烁，悬停微绽琥珀温意，遇字化为发丝导轨，按满熔铸实心琥珀结 ◆。「露纳星芒，晶润共生；动如碎光，定显凝结之形」。

## 醒 / 梦 各自的机制与关键参数
- 元素结构：`.spark-core`（1:1 同帧绝对热点）+ `.spark-kernel`（棱面菱核，左切面冷白高光/右切面折射微阴影）+ `.spark-rays`（各向异性针芒：长轴 1px × 13px / 短轴 7px × 1px）+ `.spark-amber-glint`（琥珀反射）+ `.spark-knot`（固化实心结 ◆）+ `.dew-aura`（水晕基底）。
- 醒态：质朴清晰的冷白微晶星芒，正向对齐屏幕轴；阻尼 $\tau = 82\text{ms}$，游弋差频微烁（3.4s / 4.9s 纯 CSS 互质循环）。
- 梦态：温润透亮的暖沙琥珀星露，整体顺时针偏转 $14^\circ$（严格对齐全站缝线倾角）；阻尼 $\tau = 105\text{ms}$，常驻微温琥珀反射。
- 静息机制：游弋态由纯 CSS 驱动星芒交替微烁与水露呼吸，JS rAF 落定即停（静息 5s 内严格 0 次），`will-change` 归 `auto`。

## 核心重构与微交互生命周期
- **游弋（Idle）**：晶核与羽芒由 3.4s 与 4.9s 互质周期交替差频微烁（Twinkling Sparkle），极度宁静且无机械循环感。
- **悬停链接（Hover Link）**：羽芒向外微绽（Bloom 1.75x），微核投射出微温琥珀反射，水滴铺展为透亮水膜。
- **悬停文字（Hover Text）**：横轴羽芒闭合收束，纵轴与晶核收敛为 1px 发丝中轴导轨（透明度 20%~25%），字面 100% 畅通。
- **点击（Click）**：晶核微震（高频阻尼脉冲微颤），四向折射羽芒瞬态收紧（0.42x）后弹回，水面荡出微波。
- **长按（Hold）与固化（Latch）**：长按时菱芒旋转 45° 顺应全屏抽线，羽芒向核收束；按满瞬间晶核超速固化，熔铸为全站实心琥珀结 ◆。

## 实测
- **控制台错误 0 · 页面错误 0 · 失败请求 0**（`.shot-cursor.cjs` 实测验证）。
- **热点同帧偏差**：`dx: 0 · dy: 0 · dist: 0.00px`（同帧口径，0 延迟 0 偏差，旋转对称性保持中心严格定锚）。
- **静息性能**：停止后 59 帧平滑收敛；静息 5s 增量 `rafLast5s: 0`；静息 `will-change = auto`；固定 15 节点池，逐帧只写 `transform` 与 `opacity`。
- **状态矩阵覆盖（12 项实测）**：
  1. `rest`：交替差频微烁（晶核 3.4s / 羽芒 4.9s），静息 0 rAF；
  2. `move`：tau ≈ 82ms 跟随，水滴拖尾，星芒保持高精晶体几何；
  3. `hover-link`：羽芒微绽 1.75x，投射琥珀反射，水滴铺展透亮水膜（图 `05-hover-link.png`）；
  4. `hover-text`：横芒闭合，晶核收束为 1px 细发丝导轨，透明度 $\le 25\%$（图 `06-hover-text.png`）；
  5. `input`：纤细发丝微隙，不遮挡输入光标；
  6. `drag`：贴附张力拉宽（图 `10-drag.png`）；
  7. `click`：晶核微震，羽芒收紧 0.42x，荡出 3.2px 表面波（图 `07-click.png`）；
  8. `hold1300 / hold2200`：菱芒旋转 45°，羽芒收紧向心凝聚（图 `08-hold.png`）；
  9. `latch`：按满瞬间晶核超速固化，熔铸为 45° 实心琥珀结 ◆（图 `09-latch.png`）；
  10. `scroll`：星芒稳定视觉焦点；
  11. `leave`：随外壳 `fx-cursor-out` 柔和淡出；
  12. 降级：`?cursor=off`、`?reduced=1`、`forced-colors`、触摸安全降级原生光标（图 `11-off.png`, `12-reduced.png`）。

## 最不放心的
1. 微晶星芒在密集小字上的视觉干扰；已实测验证通过横芒闭合与晶核收缩（scaleX: 0.38，opacity: 0.25），字面畅通无阻。
2. 45° 旋转与全站缝线倾角在换面时的过渡平滑度；已通过最短圆弧插值与 Latch 瞬间超速固化实现无缝熔铸。
