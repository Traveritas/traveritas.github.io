# 变体 I · 露中星（Dew Star）· 笔记

## 主张
星是露的芯：星 1:1 同帧在指针上，露由二维弹簧牵着、软上限 9px，**星永远在露里**——露被星拖着走，而不是跟在后面。

## 针对前几稿的修正
- **G2 凝露**：移动时整滴露落后 ~40px、与微核脱离，读成两个东西 → 本稿露心离星软上限 9px（tanh），弹簧状态硬上限 14px（去掉外向径向速度，快甩后不长时间回摆）。
- **G2-fluid**：尖尾像彗星 / 卡通，停下时环鼓胀 → 本稿只用椭圆，形变由落后量本身给出（沿落后方向拉长、垂直方向 1/√ 体积守恒），停下的回摆就是弹簧自身的一拍欠阻尼，不另加动画。
- **S1 / S2 星核**：星只有 3–5px，糊成「+」，近似准星 → 本稿星高约 12px，四芒内凹、竖长横短（10 : 6.5），芒不穿过形心；实心剪影，不是线。
- **光源不跟着转**：形变矩阵写成对称矩阵 R(θ)·diag(along, perp)·R(−θ)，只拉伸不旋转，所以左上那片柔光在任何方向的拖动下都留在原处（光源不跟着转）。单个 `matrix()` 写入，没有 rotate 的角度跳变。

## 质感（第二轮，2026-09-27）
- 用户反馈：高光与边缘偏动画风，要雾蒙蒙的。→ 去掉发丝弯液面、左上高光粒、右下焦散弧；露改为中心薄雾 → 外缘浓雾 → 羽化入背景（38px），外加一圈极淡水汽晕（48px），左上只留一整片柔光；点按涟漪改为一圈化开的雾带。
- 坑：`radial-gradient(circle, …)` 默认 farthest-corner，渐变超出圆、被 border-radius 裁成硬边；全部改为 `circle closest-side`。

## 醒 / 梦（由 --reality-mix 纯 CSS 连续驱动，长按全程顺滑）
- 醒：正圆雾露 38px + 正立单星，前景色；弹簧 ω 21 / ζ 0.62。
- 梦：露偏 14° 成微椭（1.07 × 0.94）+ 琥珀雾；星偏 14°，浮出 45° 半尺寸次芒；弹簧 ω 17 / ζ 0.5（更软、多回摆一拍）。

## 状态
- 静息：露 5.2s 微呼吸（0.955），星 4.6s 一明一暗；纯 CSS，rAF 0。
- 链接：露等比 1.3、星 1.18，露向链接中心吸附 ≤ 6px。
- 正文 / 输入：露收成竖直水线（0.09 × 0.76），星缩 0.55——给出插入位置，不压字。
- 可拖：露横宽 1.16 × 0.9，星转 45°。
- 点按：星一缩一回（360ms 衰减余弦），露一颤，从露沿荡开一圈。
- 长按：露向星收拢到 0.54，星随进度转过半圈；闩锁瞬间星的四条内凹边「填满」成 ◆（交叉淡入），外荡一圈大涟漪，720ms 后回到星。
- 滚动：露被压扁一下（300ms）。离开窗口：随外壳淡出。

## 实测
- `.shot-cursor.cjs cursor-I-dew-star I`：控制台错误 0 · 页面错误 0 · 失败请求 0。
- 静息 5s：`rafLast5s: 0`，`will-change: auto`。
- 逐帧只写 transform / opacity；DOM 17 个元素（含 SVG path），无逐帧分配、无逐帧布局读取（链接中心只在 pointerover 时读一次）。
- 修正：外壳不派发 `xm:reality`（G2 依赖它，闩锁其实从未触发）；本稿改为监听 `data-reality` 变化。

## 最不放心的
1. 链接态露放大后压在链接字上，梦态琥珀底略显奶，长链接上可再降 d-amber 填充。
2. 正文态的水线很淡，主要靠小星定位；若觉得插入位置不够清楚，可把水线不透明度再提。
3. 雾化后露在亮底上偏淡，移动时的拉伸不如硬边版醒目。
