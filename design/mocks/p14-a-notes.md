# p14-a 基线采样栅 · 自验收笔记

## 一句话主张
把双态的开关从「强度」换成「采样率」：同一个刻度场，醒态以 0°、36px 读出（精确、静止、几乎不可见），
梦态以 14°、57px 读出（倾斜、失配、每 240ms 逐格点亮、整场整数像素下潜）——换的不是图案，是读它的采样头。

## 醒态是什么
版心外缘一条 1px 竖轨，加自轨向页外伸出的 1px 刻度；横平、绝对静止、自成 36px 一条的节奏（不假装对齐正文行）。
夜面下最亮处只占相邻正文墨色亮度差的 3.3%，且全程落在正文列之外——看上去像纸张本身的对齐痕。

## 梦态是什么
同一族线整体歪到 14°（与缝线同角，七级跳变 0°→2°→…→14°，与 brand.ts 的七步轮转同拍），间距失配到 57px。
每 240ms 有一格亮起、向下走一格（七格一循环，因周期恰为七格，回环无缝），整场以 1px 台阶缓慢下潜 7px。
## 三条实测
1. **首屏可见性**：`layer=below` 时本层被千层纸的不透明底纸（`.p-base` 105.4%×104.6% 视口，z-3）完全遮住；
   01/02 首屏截图与关掉本层逐像素一致。只有 `layer=through`（改挂 -2）才在首屏出现（10/12 两张）。
2. **背景层最亮处占相邻正文墨色亮度差**（PNG 像素解码，同机位 on/off 冻结动画逐像素对比）：
   夜面页边 梦 16.9% / 醒 3.3%；夜面全幅 9.0%；光面 25.8% / 18.8%；纸面 24.8% / 17.4%；首屏穿透 7.8%。
   最高 25.8%，红线 35%。全幅变体从正文行下穿过，最坏情况正文对比度仍有夜 5.9:1、光 8.7:1、纸 5.1:1，均 ≥4.5:1。
3. **8× CPU 降速滚动 5 秒**（1440×900，5 次轮转取样取中位，帧间隔 ms）：
   无本层 p50 50.0 / p95 83.3 / 最长 116.7 ｜ 页边标尺 p50 50.0 / p95 66.7 / 最长 83.4（1.00× / 0.80×）
   ｜ 全幅铺满 p50 66.7 / p95 100.0 / 最长 150.1（1.33× / 1.20×）。页边版与无层基线同档。

## 新增层的 JS 依赖：零
整层在 HTML/CSS 里闭合，脚本没有一行是为它写的；钩子只有真站点本就存在的 `body[data-reality]`／`--reality-mix`／`--still`，
页面脚本干的仍是真站点原有的那几件事（双态引擎、纸叠视差、脑电、缝线锚点、品牌轮转、三段夜色换面）。无 JS 时本层按醒面渲染。

## 已知不足
- **全幅变体有真实代价**（p50 +33%）。它要铺满旋转后的视口，必然是一块 1.3M px 渐变面加一层 mask；
  8× 降速把这一步放大（headless 走 `--disable-gpu` 软件合成，大层代价比 GPU 合成重）。页边版几乎免费。
- 梦态的「逐格点亮」单帧看不出来：静止截图只能给出「倾斜 + 间距失配 + 亮格位置」三样证据，动感需实跑。
- 光面的红线余量只剩 9 个百分点（25.8% vs 35%），日后若要再提亮一档必须重测；量化依赖 CSS `round()`（Chrome 125+），
  老引擎退回平滑插值（写法里留了回退声明），仍是同一族线，只是倾斜不再是七级跳变。

## 相对 p13 的针对性修正
- 默认视图干净：控制台默认只是右下角一枚 20×20 开关，截图一律 `?chrome=0` 全隐；无遥测数字、无方案说明。
- 文案一字未造：首屏千层纸、随笔梯、项目台账（含八阶成形与 `✓ 公开仓库`／`○ 暂无公开`）、关于三锚、
  真实文章正文，全部取自 `src/pages/index.astro` 与 `src/content/`。
- 层序照真站点：墙 -4 / 底纸·醒纸·梦叶 -3 / **本层 -3 或 -2** / 脑电 -2 / 缝线 -1 / 正文 ≥0。
  本层 DOM 排在 `.page` 与脑电之前，故 -2 时脑电与缝线仍压在其上；fixed 且挂在 `.page` 之外。
- 无 backdrop-filter、无 blur、无常驻 rAF；`--reality-mix`/`--still` 只驱动 opacity 与 transform，
  颜色与渐变一律由量化后的 `--lat-k` 派生（一次保持里只变 7 次，不逐帧重栅格化）。
- 三段夜色齐备，墨色一律 `color-mix(--fg N%)` 与墨同源，无写死颜色；任何模式下列的几何体都不落在文字行上
  （页边版根本不进正文列，全幅版以最暗的一档从行下穿过）。验收对称：11 张矩阵截图 + 6 张补充机位 + 4 张 on/off 留档。
- 参数：`?zone=light|deep|paper`（三段夜色）｜`?lat=edge|full`（页边标尺／全幅铺满）｜`?layer=below|through`（-3 纸下／-2 穿透）
  ｜`?bg=off`（对照基线）｜`?face=dream|wake`｜`?reduced=1`｜`?chrome=0`（藏控制台）｜`?freeze=1`（冻结动画，仅实测用）。

## 第一轮自验收看到什么、怎么改的
- 第一轮夜面刻度亮得刺眼、两条竖轨像仪表框 → 夜面墨浓 22%/30% 砍到 8%/11%，全幅变体再乘 0.58，
  刻度长度 24px→17px；梦/醒的亮度差因此拉开到 16.9% vs 3.3%。
- 轨位原本按 `.container-wide`（56rem）定位，落进了项目段更宽的 `.still-col`（68rem）里，刻度横穿台账正文；
  改按全站最宽一栏（34rem）定位，刻度只向页外伸出。
- 第一版全幅变体把整个旋转盒（1665×1260）连 mask 一起栅格化，8× 降速下 p50 涨到 1.5×；
  改为把倾角写进渐变角（`repeating-linear-gradient(var(--lat-turn))`），恒为视口大小、无旋转层，回到 1.33×。
- 实测脚本本身也修了两处：`scroll-behavior:smooth` 让截图抓在半途；探针区误压缝线与脑电（rAF 唯一动源），
  现已改为 instant 滚动、探针避开 y≥500 的缝线带、并在 `?freeze=1` 下只画一帧脑电。

## 如果只能留一个视觉元素
留**页边标尺的轨 + 刻度**（`lat=edge`）。它是本稿唯一同时满足「零性能代价、永不进正文列、两态差异可读」的那一件：
醒态几乎不可见，梦态同一族线歪成 14° 并与缝线同角——零新增 JS，也不需要读者学习任何新符号。
