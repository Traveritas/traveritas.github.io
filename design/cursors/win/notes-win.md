# Windows 光标主题 · 纸刃与尾环

2026-10-31 · 落点 Windows 10 / 11 桌面光标主题；不是站点 CSS。

## 1 · 怎么走到这一版

- **星在环心（B）**：同心、对称，读起来像罗盘；热点在环心，点击位置说不清。
- **星在环外（W1）**：星先走、环拖后；点击点在外缘的星尖，(9,2)，偏得厉害。
- **星指环心（N6）**：星尖落在环心，热点 (16,16)；靠一颗 2.2px 菱形标出来。**失败**：环把落点围住了，菱形又太小，第一眼找不到点在哪。
- **纸刃 + 尾环（T3，当前）**：默认箭头必须有尖；星环缩到箭尾，只做记号。热点回到箭尖 (5,4)。

## 2 · T3 的构成

- **箭头**：纸刃，尖 (5,4)，左缘一折，墨线收边；热点就是左上尖端。
- **尾环**：r 5.2，圆心 (20,22.5)，缺口 100° 朝向箭尾；箭尾从缺口穿进去。
- **环里的星**：4.25px，长锋朝箭头；纸面 + 墨边，和箭头同一族。
- **热点**：32px (5,4)，48px (8,6)，64px (10,8)。环不参与点击。

## 4 · 验证

- Windows `LoadCursorFromFile` 通过（T3 已验）。
- .cur 头：3 档，热点 (5,4) / (8,6) / (10,8)，32 位 DIB。
- 手动试：控制面板 → 鼠标 → 指针 → 浏览 → `star-ring.cur` → 应用。只改 Arrow，随时换回。

## 5 · 17 个角色

默认箭头用 T3；星环整颗留给不需要「尖」的角色。

| Windows 角色 | 形状 | 热点 | 动 |
| --- | --- | --- | --- |
| Arrow / 正常选择 | 纸刃 + 尾环（T3） | 箭尖 | 静 |
| Help / 帮助选择 | T3，尾环缺口里一个小问号 | 箭尖 | 静 |
| AppStarting / 后台运行 | T3，尾环慢转 | 箭尖 | .ani |
| Wait / 忙 | 星在环心，环转（旧 B） | 环心 | .ani |
| Crosshair / 精确选择 | 对称四芒星，短芒；不画长十字 | 星心 | 静 |
| IBeam / 文本选择 | 竖线 1.2px，中缝一颗小星 | 线心 | 静 |
| NWPen / 手写 | 笔尖形，纸面 + 墨边 | 笔尖 | 静 |
| No / 不可用 | 缺口环 + 14° 斜线，星收小 | 环心 | 静 |
| SizeNS / 垂直调整 | 双头竖箭 | 中心 | 静 |
| SizeWE / 水平调整 | 双头横箭 | 中心 | 静 |
| SizeNWSE / 对角线 1 | 双头斜箭 | 中心 | 静 |
| SizeNESW / 对角线 2 | 双头斜箭（另一向） | 中心 | 静 |
| SizeAll / 移动 | 四向，星在中心 | 中心 | 静 |
| UpArrow / 候选选择 | 箭头朝上的纸刃 | 尖端 | 静 |
| Hand / 链接选择 | 纸手，腕上一道 14° 折 | 食指 | 静 |
| Pin / 位置选择 | 纸 pin，星在尖端 | 尖端 | 静 |
| Person / 人员选择 | 纸人，胸前一颗星 | 头心 | 静 |

四支 Resize 共用一支双头箭，旋转 0 / 90 / 45 / 135。
