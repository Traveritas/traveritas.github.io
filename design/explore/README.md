## 规则要点

- 单文件静态稿，可用 CDN，浏览器直接打开；不接真实数据、不做路由。
- 克制的是概念（一个核心想法做深做透），充分的是执行（版式、层级、动效、响应式全部到位）。
- 覆盖真实入口：项目 / 随笔 / 关于 / 标签，导航链接对得上，文案可自拟。
