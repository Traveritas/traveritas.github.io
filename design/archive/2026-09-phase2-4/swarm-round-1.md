# landingpage_swarm · 并行会话方向登记

> 用法：每个并行探索会话把自己最终打算创作的方向在此**简单描述**后开工；
> 开工前先读已有条目，**与已有条目或 design/mocks 里已有方向重合的，换方向再登记**。

## 会话登记

### 2026-09-19 · 会话 A：悬浪（suspended wave）—— 状态：已产出，待用户验收

- **一句话**：主体不是几何巨构，而是一道**悬停在半空、永远不会落下的巨浪**——「正在发生的事」被暂停，而非「被摆放的物」。
- **与已有方向的差异**（核对过 p2/p3 全部稿件）：已有主体全是几何直线体（环 J / 门 K / 塔 L / 碑 M / 柱列 / 断梁）或平面场（水面 / 花田 / 台地 / 山脊）。悬浪是第一个**有机曲面巨构**；水首次从「平面」变成「立体的悬停体」。
- **为何契合醒梦**：审美简报说世界「可能马上消失」——悬浪是这句话的形状：下一秒就要落下，却永远停在落下之前。母题「在场而非摆放」的直接兑现：浪不是一件物，是一件被暂停的事。
- **局部规则（一条）**：浪悬停不落——浪脚水面平静如镜，无飞沫无涟漪；水下的浪影更大、自体发暖光（梦里的浪更盛，规则继承自 J 的水下补齐）。
- **材质**：磨砂半透明受光壳（roughness 0.9 + 高密度噪点贴图 + emissive 暖芯微透）——审美简报推荐组合「磨砂玻璃 + 半透明树脂」首次做主体级。
- **继承的已验证资产**：J✦ 底盘（连续晕染水面着色器 / 四时色板循环 / uDream / 滚动镜头 / 字平面遮挡穿插 / 尺度锚点小碑 / 性能纪律）。
- **产出**：`design/mocks/p4-suspended-wave.html`（活体 Three.js 稿，已加入 p3-index.html 索引「并行探索」区块）。
- **验证记录**（浏览器截图六轮迭代）：整帧 / 主峰放大 / 滚动深处（换季联动）/ 移动端 390px 均核过像素。中途修掉三个关键 bug：①背坡 z 方向反了（浪朝镜头倾泻成幕布）②浪檐背面受光成粉红条带 ③水下浪影浮在水上。最终成立：峰谷分明的浪群剪影、峰处前卷檐口下勾、竖排字「它是人在即将醒来时」下半泡进浪壳被稀释、远景横排被浪峰咬住、水下暖浪影清晰、磨砂颗粒可辨。
- **遗留可调项**：移动端 brand 与导航间距（p3 底盘既有行为）；浪头卷曲幅度是「抽象↔拟真」的保守取值，可再放大或收回；浪芯暖光强度克制（可加强）。
- **给其他会话的提示**：本方向占用了「有机曲面悬停体 × 水面」的组合；请避开「浪/波浪/悬浮曲面」近邻方向（如悬停的山、倒扣的浪），以免与 P4 正面重合。

### 2026-09-19 · 会话 B：群浪（murmuration）—— 状态：已产出，judge 四帧通过，待用户验收

- **一句话**：世界上没有任何被摆放的物体——唯一的"建筑"是**数千只活体个体组成的群**（椋鸟群舞式），它们定期试图聚成环、聚成宣言的字，又在成形瞬间散开；醒时字能成形，入梦字散作群。
- **与已有方向及会话 A/C 的差异**（核对过 p2/p3 全部稿件 + 本登记簿）：已有主体全是"物"（几何巨构 / 有机悬浪 / 缺席的洞）或平面场，动效全是环境（换季 / 涟漪 / 雨 / 雾）。群浪是第一个**以群体生命本身为主体**的方向：去巨构化，无水面、无建筑，只有天色、地平线与群。与 V1 游光的区别：游光是 70 道水下光痕特效层（正弦巡游、不聚形、不成字），群是主角且有集体行为（聚形 → 呼吸 → 溃散的状态机）。与 D/M 字系统的区别：碑是刻死的字，群是"活字"——聚与散之间。与 C 天缺的区别：B 的粒子聚形（向心、成字、可重复），C 的剥落单体只做一次单向旅程（离心、消散）。
- **为何契合醒梦**：「世界可能马上消失」的字面化——字刚刚聚成可读的那一瞬就开始散；记忆试图聚形而失败。母题「在场而非被摆放」的极致：群不是被摆放的，它永远正在发生。
- **局部规则（一条）**：醒（页顶）群能聚成可读的环与字；越往深处滚（入梦），群越不听话——聚形越来越散、越来越短，天色由暮入夜，最后只剩满天星屑与几乎不可读的宣言。
- **穿插/遮挡**：反用 p3 的"字被碑遮"——宣言大字留在 DOM（清晰、受光），群点 canvas 叠在其上飞过时**活物短暂遮住字**。
- **产出**：`design/mocks/p4-murmuration.html`（活体 Three.js 稿；3200 点 CPU 多子步积分 + 离屏 canvas 字形像素采样 + 单 draw call Points；状态机 drift→gather→hold→burst；滚动=入梦：hold 缩短、字形散乱、天色暮→夜、DOM 翻浅色、余烬点发亮）。
- **验证记录**（judge 视觉评审四帧 + 截图多轮迭代）：盘旋 / 聚环 / 聚字「不是梦」/ 入梦夜景四帧全 pass；评语「环带毛边与缓旋、点字将散未散兑现了活物写成的母题」「夜色明确成立、余烬清晰醒目、由暮入夜叙事完整」。中途修掉的关键问题：①聚字不可读（三因：字形采样点数须与个体数同量级——步长 5px≈3400 点 vs N=3200；hold 弹簧稳态误差 ~0.3 世界单位会糊掉 0.15 宽的笔画，改位置强收敛 e=0.16/帧；切向绕行字形状减弱至 0.28）②`.scroll-length` 90vh 不可滚（独立发现并修复，220vh；与会话 C 的提醒相互印证）③IAB 截图环境 rAF 节流 + 程序化 scrollTo 不派发事件——mock 内置 `?auto`（setInterval 驱动）与每帧兜底 readScroll。
- **测试入口**：`?auto`（应对无头/节流环境）、`&fast`（压缩状态机周期）、`&shape=t1|t2|t3|ring`（锁定聚形）。
- **遗留可调项**：夜帧金色余烬（seed>0.93，占 7%）数量处于概念上缘，勿再加密；drift 盘旋的丝缕感还可再强化（当前偏均匀云）；聚形序列目前 5 段固定循环，可改为随滚动位置偏好某形状。
- **给其他会话的提示**：本方向占用了「活体群体 × 聚形成字 × 天空暮夜」的组合；请避开「鸟群/鱼群/虫群/粒子成字」近邻方向。滚动 bug 修复已在 p4-murmuration.html 内（220vh），与 C 的 260vh 同源同理。

### 2026-09-19 · 会话 C：天缺（the absence）—— 状态：已产出，待用户验收

- **一句话**：主体是一个**巨大的「没有」**——天上裂开一处不规则的巨型空洞，露出洞后更暖更亮的「别处」；世界从自己的边缘持续剥落（纸屑、线缕、云絮）缓慢飘向缺口，穿过即溶解。**缺从不扩大，也从不愈合。**
- **与已有方向及会话 A/B 的差异**（核对过 p2/p3 全部稿件 + 本登记簿）：已有主体全部是「物」（几何巨构 / 有机悬浪 / 生命群）。天缺是第一个**以「缺席」为主体**的方向——纪念的是「不在」，审美简报母题候选「巨型空洞」首次启用。与 B 群浪的区别：B 的粒子聚形（向心、成字），C 的剥落单体只做一次单向旅程（离心、消散、不成形、不聚集）；宣言字永不消散（字幡完好地立在场上，任剥落物从幡前穿过）。与 J 巨环同为竖向巨形但构成相反：环有实体、洞没有；环站在水上、缺开在天上（本项目第一个天空主体构图，地面只是纸原）。
- **为何契合醒梦**：「世界可能马上消失」的字面化——世界确实正在消失，只是永远消失不完。洞内不是黑暗深渊，是暖白的别处之光：醒侧是磨砂的天光，入梦全场转冷灰时，**洞里的暖是冷世界里唯一透过来的暖**（继承 Jc 冷晨的规则）。
- **局部规则（一条）**：一切剥落物只向缺口去，穿过即溶；缺口呼吸（边缘缓慢起伏）但半径不变。
- **穿插/遮挡**：剥落纸屑群横穿场上两幅竖排字幡（活物短暂遮字，继承 H/I 验证过的字平面穿插）；洞的暖光在地上投出一片「晒斑」；近景大纸屑从镜头前漂过。
- **产出**：`design/mocks/p4-absence.html`（活体 Three.js 稿；连续域扭曲纸原着色器 + 洞缘 fbm 溶解 + 剥落物 InstancedMesh CPU 积分）。
- **验证记录**（浏览器截图六轮迭代）：桌面 1600×900 醒/梦两态、洞缘放大像素核对、移动端 390×844 均核过。洞缘三轮才成立：halo 过大曾把 tear 平面显形成"矩形卡片"，内圈径向渐变曾让它读作"太阳"——最终配方 = 收紧 alpha 过渡 + 洞内近缘一圈琥珀"切口唇边" + 低频角向 fbm 撕口轮廓 + 每粒随机歼灭半径的"溶解壳"（纸屑在洞口散成一层渐消的壳）。纸屑曾一度过量成"纸片暴风"，回调后以纸色为主、约两成墨色点缀。竖屏镜头向洞偏转修掉主体出画。侧注「缺从不扩大　也从不愈合」。
- **给其他会话的提醒（底盘 bug）**：P3 底盘 `.scroll-length{height:90vh}` 低于视口高度，**整页根本不可滚**（uDream/滚动镜头从未被触发的假验证风险）；J✦ 落地 index.astro 前务必修（p4 已改 260vh）。另：给「可能马上消失」类方向提示，请避开「天空破洞/剥落/消散」近邻方向。
